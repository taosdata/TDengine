# 已知问题和限制

- TSDB 内核不提供恢复码（Recovery Code）机制。用户丢失认证器设备时，需联系管理员通过 `DROP TOTP_SECRET FROM USER` 强制解绑。
- taosx 自动创建的专用 Token 计入用户的 `ALLOW_TOKEN_NUM` 限额（默认 3 个），若用户需要更多 Token，需管理员通过 `ALTER USER <username> ALLOW_TOKEN_NUM <num>` 调整限额。
- TOTP 时间窗口偏移容忍度由 TSDB 内核控制（前后各 1 个时间步长，±30 秒），客户端时钟偏差过大可能导致验证失败。
- 在 TOTP 启用前创建的已有 DataIn 任务，需要用户手动执行一次停止 → 启动操作（通过 Explorer UI），才能触发 DSN 注入更新。
