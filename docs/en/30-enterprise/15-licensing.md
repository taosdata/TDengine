## Introduction

TDengine Enterprise license is managed by enabling activeCode for TDengine cluster of the hosts in the cluster.


## activeCode and Licensed Items

- An activeCode contains the values of one or more licensed items. The licensed items include expiration time, number of data collection points, storage size, number of databases, number of users, number of dnodes, number of CPU cores, etc.
- The license is applied per cluster. If there are multiple valid activeCode, then for each licensed item the maximum value among multiple activeCodes is the effective one.


## Generate activeCode

- activeCode is generated by TDengine support team, based on machine code or cluster ID.授
- Acquire machine code: run `taosd -k` on the target host, machine code must be generated for each host in the cluster.

```shell
$ taosd -k
machine code: KGQ8Y+haR3iz4lHnX9gHngYl
```

- Acquire cluster ID: run `show cluster\G`, all the hosts in a cluster share same cluster ID.

```shell
taos> show cluster\G;
*************************** 1.row ***************************
         id: 3743835620574542136
       name: 324cbefb-e667-462f-9ebd-d9b0fc753bb3
     uptime: 0
create_time: 2023-08-31 10:37:36.767
    version: trial

Query OK, 1 row(s) in set (0.001976s)
```

## Enable activeCode

1. activeCode can be enabled by `taos.cfg` configuration file or SQL command, and can be shown by `show dnodes` SQL command.
2. SQL command precedes configuration file. If both ways are used, the activeCode in `taos.cfg` is ignored.S
3. The way of using SQL command is recommended. 
4. The activeCode enabled by SQL command is stored in the cluster. 
5. Since 3.1.0.0, activeCode enabled in `taos.cfg` can be shown by `show dndoes` command too.


### Configuration File

In `taos.cfg` file, add one line starting with `activeCode`, followed by a space and then the code. Then, the activeCode can be enabled by rebooting the mnode leader or waiting for 5 minutes.

```shell
activeCode z9sdqG8w67fqBXlHnxWAQezQc/mabvN9N2maa6ksK6JJWl7OxrPZ2ElaXs7Gs9nYSVpezsaz2di72ZL6EAo0mcYiPlK2dDdmAt3P46xKs4Q=
```
### SQL

You can also use `alter dnode` to enable an activeCode. 

In following example, enable activeCode for a specific dndoe.下

```shell
taos> alter dnode 1 'activeCode' 'tP+2soIXpPwxqdKIK2Vz80laXs7Gs9nYN2maa6ksK6JJWl7OxrPZ2ElaXs7Gs9nYSVpezsaz2djdUysgjtzivcYiPlK2dDdmABPzBHc7VCc=';
Query OK, 0 row(s) affected (0.003637s) 
```

Enable same activeCode for all dnodes in the cluster.

```shell
taos> alter all dnodes 'activeCode' 'Wn8j+6KVVRnGIj5StnQ3Zs2XgtVr+h+Vue1VyrZhTL/HeS3wtya3rcYiPlK2dDdmYddxLWSWeUDGIj5StnQ3ZsYiPlK2dDdmrRsroQil5AE=';
```

### Drop activeCode

Both ways work.

```shell
taos> alter dnode 5 'activeCode' '';
taos> alter dnode 5 'activeCode';
taos> alter all dnodes 'activeCode' '';
taos> alter all dnodes 'activeCode';
```
