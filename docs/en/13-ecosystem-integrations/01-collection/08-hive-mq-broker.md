[HiveMQ](https://www.hivemq.com/) is an MQTT broker with free personal and enterprise editions. It is designed for enterprise and machine-to-machine communication and provides scalability, manageability, security features, and an open-source extension SDK. You can use the HiveMQ extension for TDengine to persist MQTT data to TDengine. For configuration and usage instructions, see the [HiveMQ extension for TDengine README](https://github.com/huskar-t/hivemq-tdengine-extension/blob/b62a26ecc164a310104df57691691b237e091c89/README.md).
