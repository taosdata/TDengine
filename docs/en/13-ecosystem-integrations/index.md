This chapter explains how to integrate TDengine with common third-party tools: data collection and message queues, visualization, BI / analytics, database management tools, and IoT platforms. In most cases, you only need to complete connection or plugin configuration to read, write, or visualize data in TDengine.

For zero-code ingestion from industrial protocols, message queues, or relational databases, or to publish subscription data to MQTT, Kafka, and other downstream systems, see [Data Ingest and Delivery](../08-data-ingest-and-delivery/index.md). For programming interfaces and connector APIs, see the [Developer's Guide](../10-developer-guide/index.md). For component operations (such as taosAdapter), see [Product Components](../12-operations-and-tooling/03-components/index.md).

This chapter includes:

- [Data Collection](./01-collection/index.md): Prometheus, Telegraf, collectd, StatsD, Icinga2, Kafka, Flink, EMQX / HiveMQ, and more.
- [Visualization](./02-visual/index.md): Grafana, Perspective, and more.
- [Analytics](./03-bi/index.md): Power BI, Tableau, Superset, Spark, Pandas, and more.
- [Database Management](./04-tool/index.md): DBeaver, qStudio, JetBrains, and more.
- [IoT Platforms](./05-iot/index.md): Node-RED, Ignition, and more.
