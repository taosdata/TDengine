Release date: **2026-03-02**

| Release type | Recommended for |
| --- | --- |
| Maintenance release | Users of stream processing, virtual tables, privileges, XNode, or taosdump backup of virtual tables |

## 1. Highlights

- A subscription through taosAdapter supports token login.
- taosdump can export and import virtual tables.
- A super-table template name and a child-table name support expressions.
- The maximum of `supportVnodes` is changed from 4096 to 1024.
- Names of encryption functions become keywords, so they are no longer written as ordinary content.
- fast-xml-parser [CVE-2026-25896](https://nvd.nist.gov/vuln/detail/CVE-2026-25896) (`GHSA-m7jm-9gc2-mpf2`) is fixed.

## 2. Features

- A taosAdapter subscription supports `TOKEN`.
- taosdump can export and import virtual tables.
- A super-table template name and a child-table name can be computed from an expression.

## 3. Enhancements

- When a large number of child tables already have subscriptions, frequent tag changes have less effect on writes.
- A virtual-table query that includes `tbname` is faster.
- The default number of log files kept by taosX, taosExplorer, taosKeeper, and taosAdapter is 3.
- The error from `CREATE XNODE TASK` is clearer.
- taosExplorer has a set of usability adjustments.

## 4. Fixes

### 4.1 Severe issues

- Querying a view without privilege crashed the process. Affected versions: `v3.4.0.0` through `v3.4.0.2`.
- Reading a table whose composite primary key contained `VARCHAR` crashed stream processing while taking the timestamp. Affected versions: `v3.3.7.0` through `v3.4.0.2`.
- Querying `DECIMAL` with stmt crashed the process. Affected versions: all versions.
- `xnoded` judged the time zone incorrectly and exited. Affected versions: `v3.4.0.0` through `v3.4.0.2`.
- `TIMETRUNCATE` occasionally returned no result. Affected versions: all versions.
- A sliding stream trigger judged the scan range incorrectly when `SLIDING` was smaller than `INTERVAL`. Affected versions: `v3.3.7.0` through `v3.4.0.2`.
- While trigger requests were pending, `MAX_DELAY` reset the wait, so calculation was not triggered for a long time. Affected versions: `v3.3.7.0` through `v3.4.0.2`.
- Merging out-of-order rows of a trigger table that has a primary key produced the wrong result. Affected versions: `v3.3.7.0` through `v3.4.0.2`.
- A stream subquery reported a missing timestamp primary key when the first column of a `JOIN` was a placeholder such as `_twstart`. Affected versions: `v3.4.0.0` through `v3.4.0.2`.
- A stream subquery that contained `INTERVAL` set the result timestamp column incorrectly. Affected versions: `v3.3.7.0` through `v3.4.0.2`.
- Memory kept growing when a disabled user created a new connection. Affected versions: `v3.4.0.0` through `v3.4.0.2`.

### 4.2 Privileges

- `GRANT ALL`, `START` / `STOP STREAM`, and `ALTER VIEW` did not take effect after they were granted.
- A user who already had `DROP STREAM` still could not drop a stream.
- An auditor could not view the full user information.
- After an ordinary user created an ordinary table, the user could not write to it without an explicit grant.
- Dropping a role with `IF EXISTS` reported an error. The error for insufficient privilege was unclear.
- Creating an audit database returned no result when no encryption key was set.

### 4.3 Other issues

- On macOS, `taos_query` on a native connection kept increasing port usage.
- An STMT auto-create request was not released, so memory leaked.
- Creating an XNode reported an unexpected error. An XNode task stayed in created. Creating a data source that uses an Agent failed. The task Parser length is extended to 48 KB. A wrong length calculation made task creation report that the data was too short.
- taosExplorer: a subscription connectivity check returned nothing; switching a shared topic reported a syntax error; creating a backup plan reported an error; SQL was not escaped correctly while editing a task; a batch API reported an error; the list was empty after a DataIn task was created; the grid area now adapts.
- MySQL did not support `TINYINT(1)` / `BOOLEAN`. Viewing the OPC PLC point list reported an error.
- taosX accepts the `information_schema` result changes on `v3.4`.

## 5. Security

### 5.1 Vulnerability fixes

See the [security advisories](https://docs.taosdata.com/security-guide/security-advisories/).

- fast-xml-parser is upgraded. The entity-name regular expression no longer bypasses encoding checks. [CVE-2026-25896](https://nvd.nist.gov/vuln/detail/CVE-2026-25896), advisory `GHSA-m7jm-9gc2-mpf2`.

### 5.2 Hardening

After encryption function names become keywords, a write no longer stores those names as ordinary content.

## 6. Upgrade notes

### 6.1 Upgrade path

Direct upgrade, rolling upgrade, downgrade, and the minimum client version are not stated separately on this page.

### 6.2 Behavior changes

- taosX, taosExplorer, taosKeeper, and taosAdapter keep 3 log files by default. Older logs are deleted.
- The maximum of `supportVnodes` changes from 4096 to 1024.
- The new keywords are in section 6.4. Those names can no longer be written into data without backticks.

### 6.3 Configuration changes

| Parameter | Purpose |
| --- | --- |
| supportVnodes | Upper limit of vnodes on one node. The maximum changes from 4096 to 1024. |

### 6.4 Keyword changes

When one of these words is used as a database, table, super table, child table, column, or tag name, quote it with backticks regardless of case.

`AES_DECRYPT`, `AES_ENCRYPT`, `FROM_BASE64`, `MD5`, `SHA`, `SHA1`, `SHA2`, `SM4_DECRYPT`, `SM4_ENCRYPT`, `TO_BASE64`.

### 6.5 System table changes

None.

### 6.6 Dependency changes

| Component | Dependency | v3.4.0.2 | v3.4.0.9 |
| --- | --- | --- | --- |
| taosKeeper | golang.org/x/crypto | 0.36.0 | 0.45.0 |
| taosKeeper | golang.org/x/net | 0.38.0 | 0.47.0 |

### 6.7 Before you upgrade

An upgrade from `v3.3.6` cannot keep the old stream processing. See [Compatibility Notes](../../07-stream-processing/02-instructions.md#compatibility-notes).

A cluster that already runs the new stream processing on `v3.4.0.0` or later does not repeat those steps when it rolls to this release.
