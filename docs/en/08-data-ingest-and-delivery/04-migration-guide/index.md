This chapter describes a general approach to migrating existing time-series data and applications to TDengine, including assessment, data-model design, historical backfill, incremental-data protection, validation, and application cutover.

Migration guides describe end-to-end workflows. For connector configuration, protocol syntax, and component parameters, see the relevant reference documentation.
