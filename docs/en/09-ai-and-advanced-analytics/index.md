TDengine provides time-series forecasting, anomaly detection, missing-value imputation, and correlation analysis through the external analytics agent TDgpt, using SQL. It can also connect to external AI applications in read-only mode through MCP.

This chapter includes three parts:

- [TDgpt](./01-tdgpt/index.md): Installation, Anode management, data preprocessing, model evaluation, and algorithm extensions.
- [Advanced Analytics](./02-advanced-analytics/index.md): `FORECAST`, anomaly windows, missing-value imputation, and time-series correlation analysis.
- [TSDB MCP](./03-mcp-tdengine-tsdb.md): Configuration and read-only tools for the TDengine MCP Server.
