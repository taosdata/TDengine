> The advanced analytics features described in this section require TDgpt. Deploy TDgpt and register the service with TDengine first. For instructions, see [Installation](../01-tdgpt/02-tutorial.md).

This section describes TDengine advanced analytics for time-series data, including forecasting, anomaly detection, missing-value imputation, and correlation analysis. For built-in functions such as `CORR`, see [Built-In Functions](../../05-tdengine-sql/04-data-query/03-function.md). To inspect Anode status, use [SHOW ANODES](../../05-tdengine-sql/09-system-info/03-show.md#show-anodes).
