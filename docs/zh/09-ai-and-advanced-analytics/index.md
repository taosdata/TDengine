TDengine 通过外置分析智能体 TDgpt，以 SQL 方式提供时序预测、异常检测、缺失补值与相关分析等能力；并可通过 MCP 以只读方式对接外部 AI 应用。

本章包含三部分：

- [TDgpt](./01-tdgpt/index.md)：安装部署、Anode 管理、数据预处理、模型评估与算法扩展。
- [高级分析](./02-advanced-analytics/index.md)：`FORECAST`、异常窗口、缺失补值与时间序列相关分析。
- [TSDB MCP](./03-mcp-tdengine-tsdb.md)：TDengine MCP Server 的配置与只读工具说明。
