TDengine TSDB 的 2026 年路线图如下。

## 产品能力

### 2026 Q1

1. 存储：批量标签修改、动态调整数据缓存的 LRU
2. 查询：子查询、外部窗口、ANY/SOME/ALL/EXISTS 运算符、窗口及插值增强、`EXPLAIN` 和 `SHOW QUERIES` 优化
3. 虚拟表：虚拟超级表查询性能优化、订阅虚拟表的元数据变更、虚拟表和源表的引用校验
4. 流式计算：按自然周/月/季/年触发、事件触发条件优化、分组计算性能优化、虚拟超级表触发支持子表增删改
5. taosX：适配 TSDB 权限管理，Windows 适配，扩展 Transform 解析功能，导出导入顺序一致性优化，力控实时库，KingHistorian 数据源优化，MQTT 支持多个 Broker 等
6. 安全：强制访问控制、三员权限、防 SQL 注入 / 拒绝服务 / 溢出攻击；root 默认密码强制修改、审计信息不经过 taosKeeper、敏感数据删除后强制覆盖；权限控制完善；存储加密与加密集群升级；TOTP / TOKEN 认证及通知；taosExplorer / 连接器 / taosX 安全加固与漏洞修复，禁止篡改配置文件

### 2026 Q2

1. 查询：自然周/月/季/年，时区改造，状态窗口多状态列；窗口函数和 `OVER` 子句，支持 `COUNT(DISTINCT)`，函数分类整理，时间线退化处理
2. 虚拟表：引用其他虚拟表的列、引用标签列；虚拟表继承；虚拟超级表列名修改
3. 流式计算：叶子节点层级汇总，多级子事件
4. 联邦查询：支持 MySQL、PostgreSQL、InfluxDB
5. 集群：元数据变更支持事务，数据快速恢复，CPU 亲和性绑定
6. 连接器：借助 taosAdapter 的高可用，STMT2、BLOB、Decimal、传输压缩、压测工具等多语言全面支持
7. 工具：taosExplorer 多项配置优化，taosdump 升级改造
8. 安全：强制访问控制、三员权限；全链路认证、传输安全与高可用及安全部署指南；JWT token secret 动态管理；发布版本 SBOM，CI 内存安全预检测

### 2026 Q3

1. 查询：支持标量相关子查询和 Hash Join，优化复杂查询性能；新增 20 多个查询函数，优化窗口函数性能
2. 虚拟表：虚拟普通表支持定义标签列、虚拟子表支持自定义列，支持引用不同精度库
3. 流式计算：优化历史计算、多测点、多分组、重算、虚拟表触发等场景性能，并提升可维护性
4. 联邦查询：查询下推和流式计算优化，动态加载第三方库，插件化打包
5. 数据订阅：支持连续查询以便订阅虚拟表的时序数据
6. 集群：集群全量与增量备份，扩大元数据事务的支持范围，降低集群运维操作对写入的影响
7. taosX：高可用、可观测性、稳定性优化提升

### 2026 Q4

1. 存储：TEXT 数据类型、不定长字符串数据类型、库名修改、列名修改
2. 查询：查询并行化、增加可观测指标；支持 MySQL 运算符及函数、UDF 函数框架重构
3. 连接器：生态集成扩展，Python、Rust、C#、ODBC 连接器优化
4. taosX：逻辑备份和恢复性能优化，类型支持补全
5. 资源管控：taosX、引擎的内存管控
6. 最佳实践：全链路压缩、全链路负载均衡
