本页介绍如何通过 TDengine Cloud 快速体验 TDengine TSDB。使用云服务时，你无须在本地安装和运维服务，即可创建实例、访问示例数据，并体验查询、数据订阅和流式计算等能力。

TDengine Cloud 是全托管的时序大数据云服务平台，继承了 TDengine Enterprise 的核心能力，并提供资源弹性伸缩、高可用、容器化部署和按需付费等云服务能力。它还提供多角色用户管理、数据共享、私有链接、备份与恢复等企业级服务，适合快速验证 TDengine 的功能和性能。

对于中小型企业，TDengine Cloud 可以降低部署和运维成本；对于大型企业，它也可以作为概念验证和测试平台，帮助缩短项目上线周期。项目成熟后，你还可以根据需求选择私有化部署。

## 新用户注册

按照以下步骤注册 TDengine Cloud 账号：

1. 打开浏览器，访问 [TDengine Cloud](https://cloud.taosdata.com)，在右侧“注册”区域填写姓名和企业邮箱地址，然后点击“获取验证码”按钮。

2. 检查企业邮箱，找到主题为“你的 TDengine Cloud 注册账户验证码”的邮件。复制邮件中的 6 位验证码，并粘贴到注册页面的“验证码”输入框中。然后点击“注册 TDengine Cloud”按钮，进入客户信息补全页面。

3. 在客户信息补全页面的“手机号”输入框中填写有效手机号码，并点击“验证”按钮完成验证。验证通过后，设置符合要求的密码，然后点击“继续”按钮，进入“创建实例”部分。

## 创建实例

按照以下步骤创建 TDengine 实例：

1. 选择公共数据库。TDengine Cloud 提供可供公共访问的智能电表等数据库。通过浏览和查询这些数据库，你可以立即体验 TDengine 的功能和性能。你可以在此步骤启动数据库访问，也可以后续再启动；如果不需要，可以直接点击“下一步”按钮跳过。

2. 创建组织。输入一个有意义的名称，用于代表你的公司或组织，便于管理云上资源。

3. 创建实例。填写实例区域、名称、高可用选项和计费方案等必填信息。确认无误后，点击“创建”按钮。大约等待 1 分钟，新的 TDengine 实例便会创建完成。随后，你可以在控制台中对该实例进行各种操作，如查询数据、创建订阅、创建流等。

TDengine Cloud 提供多种计费方案，包括入门版、基础版、标准版、专业版和旗舰版，以满足不同客户的需求。如果现有计费方案无法满足你的特定需求，可以联系 TDengine Cloud 客户支持团队定制计费方案。注册后，你将获得一定免费额度，用于体验服务。
