- 已安装客户端驱动（使用原生连接必须安装，使用 REST 连接无需安装）

:::info

由于 TDengine 的客户端驱动使用 C 语言编写，使用原生连接时需要加载本机已安装的客户端驱动共享库，通常包含在 TDengine 安装包中。Linux 服务端安装包附带客户端，也可参考 [用安装包快速体验](../../../04-quick-start/01-download-and-install/02-package.md)。在 Windows 环境开发时需要安装对应的 [Windows 客户端](https://www.taosdata.com/cn/all-downloads/#TDengine-Windows-Client)。

- `libtaos.so`：在 Linux 系统中成功安装后，会自动拷贝至 `/usr/lib/libtaos.so`，该目录包含在自动扫描路径上，无需单独指定。
- `taos.dll`：在 Windows 系统中安装完客户端后，会自动拷贝到系统默认搜索路径 `C:/Windows/System32` 下，同样无需单独指定。
- `libtaos.dylib`：在 macOS 系统中成功安装后，会自动拷贝至 `/usr/local/lib/libtaos.dylib`，该目录包含在自动扫描路径上，无需单独指定。

:::
