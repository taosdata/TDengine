发布时间：**2026-07-02**

## 特性

  1. C# 连接器支持 Adapter 高可用。
  2. JDBC 支持 Adapter 高可用。
  3. Rust 连接器支持 Adapter 高可用。
  4. TSDB CLI 交互模式下新增支持通过 subscribe 命令订阅 Topic 数据。
  5. TSDB 支持通过 License Server 进行授权管理。
  6. 状态窗口的表达式新增支持常量、标签列和逻辑运算符。

## 优化

  1. C WebSocket 连接器支持 decimal 数据类型。
  2. ODBC WS 连接器新增支持传输压缩。
  3. Python UDF 依赖的 taospyudf 库改为随安装包统一发布，不再需要手动执行 pip3 install taospyudf 和 ldconfig。
  4. Windows 平台新增共享存储功能。
  5. Windows 平台新增对 UDF 功能的支持。
  6. Windows 平台新建数据库时，WAL_LEVEL 默认值设为 2，表示强制刷新。
  7. base64 函数新增支持非字符串类型参数。
  8. taos-explorer 连通性检查的错误提示信息。
  9. taosX 新增配置项 backup.auto_create_dir，支持自动创建备份目录。
 10. taosX-agent OPC UA 数据接入新增存储转发功能。
 11. vnode 处于 learner 角色时，不再参与选主流程。
 12. 提升 ASOF Join 的查询性能。
 13. 提升流计算查询语句中 JOIN 查询的执行效率。
 14. 支持列查询结果脱敏展示。
 15. 支持动态修改参数 tmqMaxTopicNum 和 mqRebalanceInterval。
 16. 支持在微秒 (us) 精度数据库中使用 stmt2 查询。
 17. 支持通过 show create stream 命令查看流计算的创建语句。
 18. 改进 taos-explorer 登录失败后的错误提示信息。
 19. 新增 kill compact compact_id force 命令，支持强制删除正在运行的数据重整任务。
 20. 新增配置参数 WALDeleteOnCorruption（默认开启），WAL 文件损坏时自动修复并移除损坏文件。
 21. 流计算事件窗口的子事件通知中，新增父事件 ID 字段。
 22. 调整 taosX 接入 OPC UA 批次整体失败时的重试与超级表创建策略，避免数据丢失。

## 修复

  1. 3.3 版本升级至 3.4 版本时，ROOT 用户无权限创建新用户的问题。
  2. 3.3 版本升级至 3.4 版本时，多副本 mnode 场景下部分权限设置失效的问题。
  3. C WebSocket 连接器无模式写入时微秒精度转换错误的问题。
  4. K8s 部署时无法获取正常容器资源信息的问题。
  5. LoF 支持多列数据异常检测。
  6. STMT 高效写入模式下删除表并重建同名表后数据写入错误的问题。
  7. STMT2 使用 concat 函数时导致程序崩溃的问题。
  8. Windows 平台下 Native 库设置时区 TZ 格式错误的问题。
  9. Windows 平台下 WebSocket 接口设置 timezone 失效的问题。
 10. Windows 平台下 taosdlog 日志记录顺序错误的问题。
 11. taos-explorer 创建数据接入任务时保存失败的问题。
 12. taos-explorer 的 datain 任务中修改任务名称不生效的问题。
 13. taosExplorer DataIn 任务同步进度显示异常的问题。
 14. taosX 任务 Kafka 规则中过滤条件显示异常的问题。
 15. taosX 使用 UDT 和超级表模板时出现数据采集故障的问题。
 16. taosX 同步 InfluxDB 数据时，measurement 数量过大导致的 OOM 问题。
 17. taosX 接入 MQTT 数据时过滤条件不生效的问题。
 18. taosX 接入 PI 数据源时连接报错的问题。
 19. taosX 消费 Kafka 数据时，完善 Kafka 集群异常后的重试机制。
 20. taosX 的 MQTT 任务配置 UDT 解析与过滤条件后，任务创建失败的问题。
 21. taosX 的 PI Connector 在 PI Vision 使用 CDR 时实时刷新失败的问题。
 22. taosX 的 PI Connector 接入数据时无法修改超级表名和列名的问题。
 23. 从 v3.3.8.x 版本升级到 3.4.1.9 版本时流状态的兼容性问题。
 24. 修复流计算中使用 UDF 时，函数编号超出范围导致的进程崩溃问题。
 25. 创建超级表的标签顺序与自动建表的标签顺序不一致时，订阅结果错误的问题。
 26. 副本数为 2 时执行 balance vgroup 报错的问题。
 27. 多客户端并发无模式写入时，触发修改同一个超级表报错的问题。
 28. 存在大量超级表时，执行 show stables 命令出现卡死 / 挂起的问题。
 29. 执行 balance leader 操作处理反引号（飘号）标识符出错的问题。
 30. 查询线程内存分配失败时因提前释放指针导致的崩溃问题，并修复错误路径下的资源泄漏。
 31. 流计算中子查询表达式计算时使用值缓存导致查询结果错误的问题。
 32. 流计算使用 %% trows 写入 varchar 类型数据时发生崩溃的问题。
 33. 英文环境下 Explorer 查询结果导出 CSV 时中文内容乱码的问题。
 34. 虚拟表查询包含 STATE_WINDOW 但未使用实际聚合函数时，报 Invalid Parameter 错误的问题。
 35. 频繁修改用户权限且同时执行 show users 等操作时引发程序崩溃的问题。
