发布时间：**2026-08-17**

## 特性

  1. taosExplorer 流计算页面支持对流任务进行启动、停止与重算操作，无需手写 SQL。
  2. 官网问答 MCP 工具优化与 ask-teddy 问答技能。
  3. 流计算支持外部源联邦查询（含 InfluxDB），完善触发模式、stream options 与 SHOW 可观测字段。
  4. 流计算新增可观测性指标，通过 information_schema 系统表展示实时延迟、吞吐、历史填充与重算进度等监控信息。

## 优化

  1. Explorer 支持通过 allowedOrigins 配置跨域 HTTP/WebSocket，使 IDMP 等跨源场景下数据写入 WebSocket 可用。
  2. Python WebSocket 连接器新增 user_app 参数以标识应用程序名称。
  3. WebSocket STMT2 在 close 时释放关联查询结果集，与 native STMT2 行为对齐。
  4. taosX Kafka 数据接入增加 zstd 压缩消息解析支持。
  5. taosdump 备份/恢复时自动写入 backup.log / restore.log，记录版本、参数与完整 SQL 等信息。
  6. taosdump 支持通过 -M/--content 选择 basic/ext-meta/all 备份恢复内容，默认仅处理基础数据并分阶段恢复扩展元数据，避免跨库虚拟表依赖导致恢复失败。
  7. taosgen 支持普通测量列使用 TIMESTAMP 类型，并支持时间字符串到时间戳的转换。
  8. 完善 taosExplorer 数据订阅示例代码页步骤条的滚动跟随与步骤定位。
  9. 完善 taosX 增量备份/恢复，支持借助 schema snapshot 从任意备份点恢复，并新增虚拟表与流计算任务的 schema 恢复。
 10. 提升 XNODE TASK parser / JOB config 容量上限（分别至 960 KiB / 1 MiB），支持 taosX 创建 400+ 字段等大配置数据导入任务。
 11. 提升 taosX Kafka Connector 的数据消费能力与吞吐量。
 12. 提升大时间范围内 last() 查询性能，通过内部非空预过滤跳过全 NULL 数据块。
 13. 新增配置参数 numOfStreamRunnerDeploys、numOfStreamRunnerReplicas，用于调节流计算 Runner 部署数与副本数。
 14. 流计算外层派生表过滤场景可继续使用 external window，降低 INTERVAL 窗口资源占用。

## 修复

  1. 3.4.1.0–3.4.2.3 在 root 运维时 taosd -k 生成机器码与低版本不一致的问题。
  2. 3.4.2 引入 RPC CRC 后部分查询性能下降的问题；x86 客户端启用硬件 CRC，并新增 rpcCrcEnable 配置项。
  3. Explorer OPC CSV 上传因 /upload 响应格式变更解析失败，导致配置文件路径为空并校验报错的问题。
  4. Explorer PI/OPC 配置页拼写错误及标签样式问题，避免 path filter 等配置显示异常。
  5. Explorer 创建备份任务时因界面超时可被重复点击导致重复创建任务的问题。
  6. Explorer 慢 SQL 页面分页异常导致内存飙升、切换页大小后无数据以及查询失败后按钮永久禁用的问题。
  7. Explorer 授权页错误展示 IDMP 相关授权项及状态的问题。
  8. Explorer 数据接入任务活动明细不显示失败原因及错误/警告信息的问题，并补全部分数据加工错误的活动记录。
  9. INTERVAL 查询因逻辑 Scan 克隆遗漏时区日界字段导致报 Executor internal error 的问题。
 10. InfluxDB 1.x 高基数同步可能漏读数据导致与源端不一致的问题，并完善相关导入配置与可靠性校验。
 11. InfluxDB 同步任务在仅选择少量 measurement 时仍全量加载 bucket 元数据、导致接入耗时过长的问题。
 12. OPC 采集任务在连接断开且存在异常节点时可能 panic 退出、导致任务无法正常启动的问题。
 13. PI Connector 因列名超长导致任务反复重启与数据丢失。
 14. Python 原生连接器异步查询因未保留回调导致进程崩溃的问题。
 15. SHOW SUBSCRIPTIONS 在 vnode 恢复场景下因结果块容量估算不足导致进程崩溃的问题。
 16. STMT2 interlace 场景下关闭时因 tableCols 重复释放导致 core 的问题。
 17. STMT2 多表交替绑定及 taosdump 恢复时大小表交替导致提交失败、小表数据丢失的问题。
 18. STMT2 查询绑定后未保留会话时区等上下文，导致 to_char 等时间函数返回时区错误的问题。
 19. STMT2/WebSocket 自动建表写入时，bind 后、exec 前删除子表会报 Table does not exist，且无法按已绑定 tag 自动重建并完成写入的问题。
 20. TIMETRUNCATE 固定时区偏移解析不完善，以及 scalar/join 路径 POSIX 符号语义不一致的问题。
 21. TIMETRUNCATE 在 join / subquery 等 scalar 路径下，隐式会话时区与显式固定偏移（如 +0800）对 1d/1w 截断结果不一致的问题。
 22. TMQ 同步流计算自动创建的普通表时，taosAdapter 因元数据解析错误而崩溃的问题。
 23. VGroup 在尚未收到有效心跳上报时被误判为 offline 的问题。
 24. Windows All-in-One 安装后 taoskeeper 无法正常启动的问题。
 25. Windows 上 TIMETRUNCATE 等函数因 ISO/POSIX 时区偏移符号不一致导致时区转换错误的问题。
 26. Windows 下 taos 客户端在关闭连接时因 libuv 竞态概率性卡住的问题。
 27. Windows 版 taosdump 因 Snappy 编译启用 BMI2 等指令，在旧 CPU 上启动即崩溃；并修正崩溃 dump 文件名误用 taosd 前缀的问题。
 28. imputation 补值结果写入起始位置未重置，导致补值结果不正确的问题。
 29. last/last_row 在重叠 INTERVAL+SLIDING 窗口下直查与子查询结果不一致，以及多周滑动窗口相位不稳定的问题。
 30. mnode 多副本从 3.3 升级到 3.4.2.0–3.4.2.4 时角色升级未执行，导致系统默认角色与用户权限丢失的问题。
 31. snapshot 限速到达上限后速度降为 0、实际传输速度低于设定值的问题。
 32. stable 经历 DROP TAG 后再 ADD TAG 时，对已有子表执行 SHOW CREATE TABLE 报 Unexpected generic error 的问题。
 33. stmt2 自动建表写入时重复解析 tag 导致性能远低于提前建表的问题。
 34. taosBenchmark 并行混合查询（mixed_query）未按 SQL 的 result 配置写出查询结果文件的问题。
 35. taosExplorer S3 备份任务因取消 S3 dumper 时误取消整任务而失败的问题。
 36. taosX taos-to-taos 同步无法正确迁移虚拟子表的问题。
 37. taosX 任务级备份异地恢复时未识别 `-1` 子目录导致命令成功但数据未恢复的问题。
 38. taosX 创建 TMQ 备份任务首次提交因校验阶段创建 Topic 形成循环等待而超时的问题。
 39. taosX 同步在目标端不可用（如 taosd 宕机）时将可恢复错误误判为致命错误，导致进程退出且目标恢复后无法继续同步的问题。
 40. taosX 周期备份因周期参数未生效而无法按计划停止、备份持续增长的问题。
 41. taosX 备份到阿里云对象存储因 Path-style 访问失败的问题，新增 S3 URI style（path/virtualhost）配置。
 42. taosX 备份无法正确处理含特殊字符表名的问题。
 43. taosX 指定表备份前全量检查耗时过长，且遇错即停止导致无法继续备份其他表的问题。
 44. taosX 经 TMQ WebSocket 持续拉取大量数据时，因心跳未及时刷新 taosAdapter 读超时，约每 2 分钟断连导致数据传输异常的问题。
 45. taosX 默认监听在部分平台仅接受 IPv6，导致使用 127.0.0.1 创建的 xnode 显示 offline 的问题。
 46. taosdump 备份过程中服务不可用时误判为取数完成，导致备份数据缺失的问题，并完善短暂不可用时的重试。
 47. taosdump 按时间范围备份时，主键时间列非 ts 命名报 Invalid column name 的问题。
 48. taosdump 断点续传（-C）更换备份格式（-F）时未校验一致性，导致目录内混入不同格式文件、恢复失败的问题。
 49. to_timestamp 解析日期时受线程遗留 errno 影响，导致合法日期随机报 format mismatch 的问题。
 50. 仅通知且无计算内容的流配置 MAX_DELAY 时，WAL 无数据响应触发空指针导致 core 的问题。
 51. 创建 XNODE CSV 数据写入任务时默认字段引用符导致提交失败的问题。
 52. 删除 xnode 后备份/ETL 任务仍可能被分配到已删除 xnode 并执行失败的问题。
 53. 单节点首次部署中途异常中断后，默认元数据（如 root/cluster/mnode）未完整创建导致连接报 Invalid user 的问题；启动时自动补建缺失对象。
 54. 同一 SQL 中多个 MAVG、STATECOUNT、STATEDURATION 与 ts 或普通列共存时报错的问题。
 55. 启用 SQL 标签缓存时，已缓存子表被删除后 Kafka 同步任务因表不存在而停止的问题。
 56. 客户端连接关闭过程中收到服务端响应时触发 abort 的问题。
 57. 将不适合走 tag index 场景下的 IDX ERROR 误报日志降为 debug，避免干扰排查。
 58. 开启共享存储（ssEnabled）但未配置默认访问串（ssAccessString）时，执行 DROP DATABASE 导致 taosd 崩溃的问题。
 59. 普通用户 CREATE DATABASE 后客户端未立即刷新权限缓存，紧接着自动建表写入时报 Permission denied 的问题。
 60. 流计算 FILL_HISTORY 在 PARTITION BY 场景下，部分子表在历史起点后无数据时触发 Internal error，导致历史结果无法生成的问题。
 61. 流计算 WebSocket 通知帧超过 1 MiB 导致远端接收失败的问题。
 62. 流计算 nodelay_create_subtable 在尚无真实窗口时的建表请求不再以占位窗口进入执行器，避免虚拟表扫描报 Invalid parameters 导致输出子表无结果。
 63. 流计算处理自动建表数据时因无效时间戳导致计算范围过大、CPU 占用过高的问题。
 64. 流计算外部窗口复用结果块时未按批次扩容，可能导致越界写并引发 taosd 崩溃的问题。
 65. 流计算扫描 WAL metadata 时二次填值越界导致节点 core 掉线的问题。
 66. 状态心跳处理未释放 SStatusReq 嵌套数组导致的内存泄漏问题。
 67. 虚拟子表 SELECT TAGS 按源表数据行错误展开结果，以及 EXPLAIN SELECT TAGS 因空扫描列链表解引用导致进程崩溃的问题。
 68. 虚拟表在 ALTER TAG 后因按位置误匹配 tagRef，导致 SELECT TAGS 查询报 Planner slot key not found 的问题。
 69. 除 INTERVAL 外其他窗口暂不支持聚合 DISTINCT，解析阶段直接报错。
