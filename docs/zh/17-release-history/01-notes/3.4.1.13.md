发布时间：**2026-07-02**

| 版本类型 | 推荐升级对象 |
| --- | --- |
| 维护版本 | 从 `v3.3` 升级到 `v3.4`、使用流计算、STMT 或 taosX 接入 PI、MQTT、InfluxDB 的用户 |

## 1. 版本亮点

- 状态窗口表达式支持常量、标签列和逻辑运算符。
- 支持通过 License Server 授权。
- taos shell 交互模式可以用 `SUBSCRIBE` 订阅 topic。
- JDBC、Rust、C# 连接器支持 taosAdapter 高可用。
- Windows 支持 UDF 和共享存储。新建库的 `WAL_LEVEL` 默认为 2。
- WAL 损坏时默认自动修复并去掉损坏文件。

## 2. 新特性

- 状态窗口的表达式支持常量、标签列和逻辑运算符。
- 支持通过 License Server 管理授权。
- taos shell 交互模式新增 `SUBSCRIBE`，用于订阅 topic。
- JDBC、Rust、C# 连接器支持 taosAdapter 高可用。
- 可以用 `SHOW CREATE STREAM` 查看流的创建语句。
- 列查询结果可以脱敏展示。
- `BASE64` 函数支持非字符串参数。
- ODBC WebSocket 连接器支持传输压缩。C WebSocket 连接器支持 `DECIMAL`。
- taosX-Agent 的 OPC UA 接入支持存储转发。
- 新增 `KILL COMPACT compact_id FORCE`，可以强制结束正在运行的数据重整。

## 3. 优化

- Windows 支持 UDF 和共享存储。Windows 上新建数据库的 `WAL_LEVEL` 默认为 2，即每次写入强制刷盘。
- `tmqMaxTopicNum` 和 `mqRebalanceInterval` 可以动态修改，社区版也可以修改。
- 微秒精度库可以使用 `STMT2` 查询。
- 新增 `walDeleteOnCorruption`，默认开启。WAL 文件损坏时自动修复并移除损坏文件。
- 流计算事件窗口的子事件通知增加父事件 ID。
- 流计算中的 `JOIN` 和 `ASOF JOIN` 更快。
- Learner 角色的 vnode 不再参与选主。
- taosX 新增 `backup.auto_create_dir`，可以自动创建备份目录。OPC UA 整批失败时的重试和超级表创建策略调整，避免丢数。
- taosExplorer 的连通性检查和登录失败提示更明确。
- Python UDF 依赖的 taospyudf 随安装包发布，不必再手工执行 `pip3 install taospyudf` 和 `ldconfig`。

## 4. 问题修复

### 4.1 严重问题

- 从 `v3.3` 升级到 `v3.4.0.0` 至 `v3.4.1.6` 时，多副本 mnode 上部分权限失效，root 不能创建新用户。升级到本版本后请核对用户和权限。
- 从 `v3.3.8` 升级到 `v3.4.1.9` 时，流状态不兼容。
- 频繁修改用户权限并同时执行 `SHOW USERS` 时进程崩溃。影响版本：`v3.4.0.0` 至 `v3.4.1.6`。
- 查询线程分配内存失败时提前释放指针，导致崩溃。影响版本：所有版本。
- STMT 使用 `CONCAT` 时崩溃。影响版本：所有版本。
- STMT 高效写入中删除表并重建同名表后，数据写错。影响版本：所有版本。已经写入的数据需要核对。
- 流计算子查询表达式使用值缓存，结果错误。影响版本：`v3.3.7.0` 至 `v3.4.1.6`。
- 流计算使用 `%%trows` 写入 `VARCHAR` 时崩溃。使用 UDF 时函数编号超出范围导致崩溃。影响版本：`v3.3.7.0` 至 `v3.4.1.6`。
- 创建超级表的标签顺序和自动建表的标签顺序不一致时，订阅结果错误。影响版本：所有版本。
- taosX 同步 InfluxDB 时 measurement 过多导致内存耗尽。影响版本：所有版本。
- taosX 接入 MQTT 时过滤条件不生效。影响版本：所有版本。已经接入的数据需要按过滤条件核对。
- 超级表很多时，`SHOW STABLES` 卡住。影响版本：所有版本。

### 4.2 查询、写入与升级

- 多客户端并发无模式写入并同时修改同一超级表时报错。
- 虚拟表查询包含 `STATE_WINDOW` 但没有实际聚合函数时，报 Invalid parameter。
- `BALANCE LEADER` 处理反引号标识符出错。副本数为 2 时 `BALANCE VGROUP` 报错。
- Kubernetes 部署时不能拿到正常的容器资源信息。
- Windows 上 WebSocket 设置时区无效，原生库的 `TZ` 格式错误，taosd 日志顺序错误。
- C WebSocket 无模式写入时，微秒精度转换错误。

### 4.3 taosX 与 taosExplorer

- taosX：Kafka 规则里的过滤条件显示异常；Kafka 集群异常后的重试更完整；UDT 和超级表模板一起使用时采集失败；MQTT 同时配置 UDT 解析和过滤条件时任务创建失败；PI Connector 不能修改超级表名和列名；PI Vision 使用 CDR 时不能实时刷新；接入 PI 时连接报错；与 taosX 的网络短暂中断后 PI Connector 不能自动恢复。
- taosExplorer：DataIn 同步进度显示异常；英文环境导出 CSV 时中文乱码；修改 DataIn 任务名不生效；创建数据接入任务保存失败。

## 6. 升级须知

### 6.1 升级路径

直接升级、滚动升级、降级和客户端配套版本未在本页另写。

### 6.2 行为变更

- Windows 上新建数据库的 `WAL_LEVEL` 默认为 2。已有库不变。
- `walDeleteOnCorruption` 默认开启。WAL 损坏时会自动修复并移除损坏文件。
- `tmqMaxTopicNum` 和 `mqRebalanceInterval` 可以动态修改，社区版也可以修改。
- Python UDF 不再要求单独安装 taospyudf。
- 从 `v3.3` 升级到本版本之前的 `v3.4` 时，多副本 mnode 上的权限和 root 建用户可能失效。本版本予以修复，升级后仍需核对。

### 6.3 配置参数变更

| 参数 | 作用 |
| --- | --- |
| walDeleteOnCorruption | WAL 文件损坏时是否自动修复并移除损坏文件。默认开启。 |
| tmqMaxTopicNum | 订阅 topic 数量上限。可以动态修改。 |
| mqRebalanceInterval | 订阅再均衡间隔。可以动态修改。 |
| backup.auto_create_dir | taosX 备份时是否自动创建目录。 |

### 6.4 关键字变更

无。

### 6.5 系统表变更

无新增系统表。流计算子事件通知增加父事件 ID 字段。

本版本没有移除系统表。

### 6.6 依赖库变更

依赖库版本没有变化。

### 6.7 升级前操作

从 `v3.3.6` 升级到本版本时，旧流计算不能直接沿用。步骤见 [流计算兼容性说明](../../07-stream-processing/02-instructions.md#兼容性说明)。

已经在 `v3.4.0.0` 及之后按新流计算运行的集群，滚动到本版本时不必重复。
