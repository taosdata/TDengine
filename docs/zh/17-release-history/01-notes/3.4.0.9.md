发布时间：**2026-03-02**

| 版本类型 | 推荐升级对象 |
| --- | --- |
| 维护版本 | 使用流计算、虚拟表、权限、XNode 或 taosdump 备份虚拟表的用户 |

## 1. 版本亮点

- taosAdapter 的订阅支持令牌登录。
- taosdump 可以导出和导入虚拟表。
- 超级表模板名和子表名支持表达式。
- `supportVnodes` 的最大值从 4096 调整为 1024。
- 加密相关函数名改为关键字，避免被当成普通内容写入。
- 修复 fast-xml-parser 的 [CVE-2026-25896](https://nvd.nist.gov/vuln/detail/CVE-2026-25896)（`GHSA-m7jm-9gc2-mpf2`）。

## 2. 新特性

- taosAdapter 订阅支持 `TOKEN`。
- taosdump 支持导出和导入虚拟表。
- 超级表模板名和子表名可以用表达式计算。

## 3. 优化

- 海量子表已有订阅时，频繁修改子表标签对写入的影响降低。
- 虚拟表查询包含 `tbname` 时更快。
- taosX、taosExplorer、taosKeeper、taosAdapter 默认保留的日志个数改为 3。
- `CREATE XNODE TASK` 的报错信息更明确。
- taosExplorer 界面做了一批易用性调整。

## 4. 问题修复

### 4.1 严重问题

- 查询没有权限的视图时进程崩溃。影响版本：`v3.4.0.0` 至 `v3.4.0.2`。
- 流计算读取含 `VARCHAR` 复合主键的表时，取时间戳导致崩溃。影响版本：`v3.3.7.0` 至 `v3.4.0.2`。
- 使用 stmt 查询 `DECIMAL` 时崩溃。影响版本：所有版本。
- `xnoded` 时区判断错误，进程退出。影响版本：`v3.4.0.0` 至 `v3.4.0.2`。
- `TIMETRUNCATE` 偶发不返回结果。影响版本：所有版本。
- 流计算滑动触发时，`SLIDING` 小于 `INTERVAL` 会判错扫描区间。影响版本：`v3.3.7.0` 至 `v3.4.0.2`。
- 流计算触发阶段积压请求时，`MAX_DELAY` 会重置等待时间，计算长时间不触发。影响版本：`v3.3.7.0` 至 `v3.4.0.2`。
- 流计算处理带主键触发表的乱序数据时，合并结果错误。影响版本：`v3.3.7.0` 至 `v3.4.0.2`。
- 流计算子查询里 `JOIN` 的第一列是 `_twstart` 等占位符时，误报没有时间戳主键。影响版本：`v3.4.0.0` 至 `v3.4.0.2`。
- 流计算子查询含 `INTERVAL` 时，结果时间戳列设置错误。影响版本：`v3.3.7.0` 至 `v3.4.0.2`。
- 被禁用的用户创建新连接时，内存持续增长。影响版本：`v3.4.0.0` 至 `v3.4.0.2`。

### 4.2 权限

- `GRANT ALL`、`START` / `STOP STREAM`、`ALTER VIEW` 授权后不生效。
- 已有 `DROP STREAM` 权限仍不能删除流。
- 审计员不能查看用户完整信息。
- 普通用户创建普通表后，如果没有显式授权，不能写入。
- 使用 `IF EXISTS` 删除角色时报错。权限不足时的报错不明确。
- 未设置加密密钥时，创建审计数据库没有返回结果。

### 4.3 其他

- macOS 上原生连接的 `taos_query` 使端口占用持续增加。
- STMT 自动建表请求没有释放，造成内存泄漏。
- 创建 XNode 时报意外错误。XNode 任务停留在 created。使用 Agent 的数据源创建失败。任务 Parser 长度扩展到 48 KB。长度计算错误导致创建任务报数据长度不足。
- taosExplorer：订阅连通性检查没有返回；切换共享主题报语法错误；创建备份计划报错；修改任务时 SQL 没有正确转义；批量接口报错；DataIn 任务创建成功后列表为空；网格区域自适应。
- MySQL 不支持 `TINYINT(1)` / `BOOLEAN`。OPC PLC 查看点位列表报错。
- taosX 兼容 `v3.4` 上 `information_schema` 查询结果的变化。

## 5. 安全

### 5.1 漏洞修复

详情见 [安全公告](https://docs.taosdata.com/security-guide/security-advisories/)。

- 升级 fast-xml-parser，修复实体名正则导致的编码绕过。[CVE-2026-25896](https://nvd.nist.gov/vuln/detail/CVE-2026-25896)，漏洞 ID `GHSA-m7jm-9gc2-mpf2`。

### 5.2 安全加固

加密函数名改为关键字后，写入时不会再把这些名字当成普通内容入库。

## 6. 升级须知

### 6.1 升级路径

直接升级、滚动升级、降级和客户端配套版本未在本页另写。

### 6.2 行为变更

- taosX、taosExplorer、taosKeeper、taosAdapter 默认保留的日志个数改为 3。更早的日志会被删掉。
- `supportVnodes` 的最大值从 4096 改为 1024。
- 新增关键字见第 6.4 节。这些名字不再能不加反引号写入数据。

### 6.3 配置参数变更

| 参数 | 作用 |
| --- | --- |
| supportVnodes | 单节点 vnode 数量上限。最大值由 4096 调整为 1024。 |

### 6.4 关键字变更

下列词用作库名、表名、超级表名、子表名、列名或标签名时，不论大小写都要用反引号。

`AES_DECRYPT`、`AES_ENCRYPT`、`FROM_BASE64`、`MD5`、`SHA`、`SHA1`、`SHA2`、`SM4_DECRYPT`、`SM4_ENCRYPT`、`TO_BASE64`。

### 6.5 系统表变更

无。

### 6.6 依赖库变更

| 组件 | 依赖库 | v3.4.0.2 | v3.4.0.9 |
| --- | --- | --- | --- |
| taosKeeper | golang.org/x/crypto | 0.36.0 | 0.45.0 |
| taosKeeper | golang.org/x/net | 0.38.0 | 0.47.0 |

### 6.7 升级前操作

从 `v3.3.6` 升级到本版本时，旧流计算不能直接沿用。步骤见 [流计算兼容性说明](../../07-stream-processing/02-instructions.md#兼容性说明)。已经在 `v3.4.0.0` 及之后按新流计算运行的集群，滚动到本版本时不必重复。

从 `v3.4` 以前的版本升级到本版本时，taosX 不会自动迁移已有任务。此前任务存在 SQLite 中，`v3.4` 起存在 mnode 中。升级前在 taosExplorer 中导出任务；升级后导入，再启动需要运行的任务。没有在升级前导出时，升级后的 taosExplorer 中看不到这些任务。步骤见 [从 v3.4 以前的版本升级到 v3.4.x 时迁移任务](../../12-operations-and-tooling/03-components/06-taosx.md#从-v34-以前的版本升级到-v34x-时迁移任务)。已经在 `v3.4.0.0` 及之后运行、任务已在 mnode 中的集群，滚动到本版本时不必重复上述步骤。
