## 1. 版本亮点

- **联邦查询**：可通过虚拟表查询外部数据源，流计算任务也可以执行联邦查询。支持 MySQL、PostgreSQL 和 InfluxDB v3，默认关闭。
- **查询增强**：新增窗口函数与 `OVER` 子句、聚合函数 `DISTINCT`、按自然时间单位对齐的窗口、多列状态窗口，以及 `TEXT` / `FILE` 内联数据源。
- **时区**：新增连接级时区，支持 IANA 时区与夏令时。
- **虚拟表**：虚拟超级表支持继承；虚拟子表的普通列和标签列支持跨表引用。
- **流计算**：新增 `ROLLUP BY`，按标签层级汇总；事件窗口 `true_for` 可分别设置开始和结束条件。
- **连接与安全**：C、Go、Python、Node.js WebSocket 连接器支持 taosAdapter 高可用。修复多个可导致 taosd 崩溃的内存安全问题。

## 2. 新特性

### 2.1 联邦查询与虚拟表

- 支持基于虚拟表的联邦查询。外部数据源为 MySQL、PostgreSQL 和 InfluxDB v3，使用前需同时打开客户端和服务端的 `federatedQueryEnable`（默认关闭）。详见 [联邦查询](../../05-tdengine-sql/04-data-query/06-federated-query.md)。
- 流计算任务支持联邦查询。
- 虚拟超级表可以继承其他虚拟超级表。详见 [虚拟超级表继承](../../05-tdengine-sql/02-ddl/04-virtualtable.md#虚拟超级表继承)。
- 虚拟子表的普通列可以引用其他虚拟子表。
- 虚拟子表的标签列可以引用物理子表和其他虚拟子表。

### 2.2 SQL 与查询

- 支持窗口函数和 `OVER` 子句。详见 [窗口函数](../../05-tdengine-sql/04-data-query/07-window-function.md)。
- 聚合函数支持 `DISTINCT`，例如 `COUNT(DISTINCT col)`。
- 新增 `TEXT` 和 `FILE` 内联数据源，可在 `FROM` 中直接使用行值或 CSV 文件，无需建表，可参与 `SELECT`、`JOIN`、`UNION` 和 `INSERT INTO SELECT`。详见 [TEXT 内联数据源](../../05-tdengine-sql/04-data-query/01-query.md#text-内联数据源)和 [FILE CSV 文件数据源](../../05-tdengine-sql/04-data-query/01-query.md#file-csv-文件数据源)。
- 新增按自然时间单位划分的窗口，窗口对齐本地日历边界（自然日、周、月、季、年）。时间单位新增季度 `q`。详见 [INTERVAL 查询](../../05-tdengine-sql/10-time/01-timezone.md#interval-查询)。
- 新增连接级时区，支持 IANA 时区名称和夏令时。详见 [时区与自然时间单位](../../05-tdengine-sql/10-time/01-timezone.md)。
- 状态窗口支持多个状态列。详见 [状态窗口](../../05-tdengine-sql/04-data-query/04-distinguished.md#状态窗口)。
- 外部窗口支持 `FILL`。详见 [外部窗口](../../05-tdengine-sql/04-data-query/04-distinguished.md#外部窗口)。
- 窗口查询中可以使用原始列、标签列、标量函数和不定行函数。
- 窗口查询中可以使用 `CSUM`、`DIFF`、`DERIVATIVE`、`MAVG`、`STATECOUNT`、`STATEDURATION`、`LAG`、`LEAD`、`FILL_FORWARD`，并可与 `INTERVAL` + `FILL`（`NULL` / `NONE` / `VALUE` / `NULL_F` / `VALUE_F`）一起使用。
- 新增 `REGEXP_EXTRACT`。详见 [REGEXP_EXTRACT](../../05-tdengine-sql/04-data-query/03-function.md#regexp_extract)。
- 新增 `SLEEP`，用于在测试中模拟超时。
- `GREATEST` / `LEAST` 可通过 `ignoreNullInGreatest` 选择是否跳过 NULL。默认不跳过。
- `DIFF`、`CSUM`、`MAVG`、`STATECOUNT`、`LAG`、`LEAD`、`FILL_FORWARD`、`UNIQUE` 可以在没有时间列的场景下执行。

### 2.3 流计算

- 流计算触发新增 `ROLLUP BY tag_name`，按标签层级汇总。详见 [触发分组](../../07-stream-processing/01-syntax.md#触发分组)。
- 事件窗口的 `true_for` 可以分别设置开始条件和结束条件。
- `SHOW STREAMS` 可以指定数据库，并用 `LIKE` 匹配流名称。

### 2.4 元数据与集群运维

- 超级表、子表、虚拟表的元数据更新支持事务。
- 支持 CPU 亲和性绑定，默认关闭。详见 [CPU 亲和性](../../12-operations-and-tooling/03-components/01-taosd.md#cpu-亲和性)。
- 支持在运行时临时关闭指定 vnode。
- `taosd -r` 新增 `--vnode`，可指定要修复的 vnode。
- 数据修复工具新增拷贝修复模式。
- 新增 `snapshotRateLimit`，限制每个 dnode 发送快照的带宽，默认 `0`，表示不限速。
- 新增 `retryOnOverloadBaseInterval`、`retryOnOverloadTimeout`，控制服务端过载时的客户端重试。默认分别为 `1000` 毫秒和 `60000` 毫秒。

### 2.5 连接器

- C、Go、Python、Node.js WebSocket 连接器支持 taosAdapter 高可用。对应客户端参数为 `adapterHa`，默认 `false`。详见 [adapterHa](../../12-operations-and-tooling/03-components/02-taosc.md#adapterha)。

### 2.6 taosX

- 支持把数据导出为 Parquet 文件。
- DataOut 支持把数据导出到 Kafka。
- OPC UA 数据源支持采集告警与事件（Alarm & Events）。
- 支持备份和恢复指定的数据表。

### 2.7 平台支持

- Windows 支持 MQTT 订阅。
- Windows 支持 UDF。

### 2.8 工具

- taosdump 可以导出流计算的创建语句。

## 3. 优化

### 3.1 查询

- 提升 `INTERP` 插值查询性能。
- 提升子查询按主键列排序时的执行效率。
- 子查询扫描时，取子查询与外层查询时间范围的交集，减少扫描量。
- 子查询、`UNION ALL` 和多层嵌套查询会自动选用结果集中的 `TIMESTAMP` 列作为时间线列。
- 优化联邦查询的元数据拉取和解析。

### 3.2 流计算

- `COUNT_WINDOW(N, 1)` 支持历史数据重算。
- 流计算支持虚拟表跨表引用和标签引用。
- 优化虚拟超级表聚合查询的执行。
- 分组数量在 50 万到 100 万时，流计算启动更快。

### 3.3 存储与集群

- 多副本快照改为按需传输文件，加快恢复。
- 修改 `serverPort` 后，数据订阅使用的内部端口自动更新。
- 改进没有 snode 时创建 TSMA 失败的错误提示。
- 调整 Windows 平台的 RPC 传输选项以提高性能。

### 3.4 工具

- taosdump 提升备份速度、恢复速度和备份文件压缩比。旧备份文件可用新版恢复。
- 改进 taosdump `-p` 输入密码出错时的提示。
- taosExplorer 改进批量上传 CSV 并导入数据库的处理。
- taosExplorer 改进数据库对象的树形展示。

### 3.5 taosX

- 接入 pspace 时，可按 `/` 拆分点位长名称生成子标签，同时保留原始长名称标签，并提供 `name` 变量。
- 提高高基数场景下同步 InfluxDB 数据的速度。

## 4. 问题修复

### 4.1 严重问题

下列问题会导致服务不可用或数据错误。

- 扫描 `information_schema.ins_tags` 并解析虚拟表标签引用时，taosd 死锁。影响版本：`v3.4.2.0`、`v3.4.2.1`。
- `INTERVAL AUTO` 的起始时间为 `INT_MAX` 时，查询进入无限循环。影响版本：`v3.3.5.0` 至 `v3.4.1.17`。该语法自 `v3.3.5.0` 引入，`v3.4.1.18` 与 `v3.4.2.0` 起已修复。
- 流计算初始化表列表失败时，taosd 崩溃。影响版本：`v3.3.7.0` 至 `v3.4.1.17`。
- 对单行数据做压缩或解压时，进程崩溃。影响版本：`v3.4.1.16` 及更早版本。
- STMT 异步写入报错后再次绑定执行，进程崩溃。影响版本：`v3.3.3.0` 至 `v3.4.1.16`。`v3.3.6.53` 及之后的 `v3.3.6` 补丁已修复。
- Windows 上多个并发查询使用临时文件时文件名冲突，导致读到错误数据并崩溃。影响版本：`v3.4.1.17` 及更早版本。
- taosX 定时增量备份偶发数据缺失。影响版本：所有版本。`v3.3.6.52` 及之后的 `v3.3.6` 补丁、`v3.4.1.15` 及之后的 `v3.4.1` 补丁、`v3.4.2.0` 起已修复。
- taosX 消费 Kafka 做历史补录时，早于 keep1 窗口的数据被丢弃。影响版本：所有版本。`v3.3.6.54` 及之后的 `v3.3.6` 补丁、`v3.4.1.19` 及之后的 `v3.4.1` 补丁、`v3.4.2.1` 起已修复。
- taosX 处理线程退出后资源未释放，最终 XNode 不可用。影响版本：`v3.4.0.0` 起至本版本修复前。
- 三副本 mnode 之间用户令牌同步不及时，新建的 XNode 鉴权失败并一直离线。影响版本：`v3.3.6.49` 及该系列后续版本，全部 `v3.4.0`，`v3.4.1.0` 至 `v3.4.1.18`，以及 `v3.4.2.0`、`v3.4.2.1`。`v3.3.7` 没有用户令牌。
- 动态打开 IP 白名单后，dnode 自身 FQDN 不在名单中，集群节点无法登录。影响版本：`v3.1.1.46` 至 `v3.4.1.14`。`v3.3.6.52` 及之后的 `v3.3.6` 补丁已修复。

### 4.2 查询

- 修复底层超级表结构变更后，虚拟表报列顺序不匹配的问题。
- 修复打开 BI 模式后，虚拟超级表执行 `LAST()`、`FIRST()`、`LAST_ROW(*)` 不返回 `tbname` 列的问题。
- 修复 `LEFT ASOF JOIN` 与 `DIFF` 一起查询、中间结果超过 65535 行时执行失败的问题。
- 修复在 `JOIN` 中使用 `TIMETRUNCATE` 时，左右表时区换算不一致、结果错误的问题。
- 修复查询 `information_schema.ins_tables` 时，`COUNT` 与 `PARTITION BY` 或 `GROUP BY` 一起使用后分组键（如 `stable_name`）为空的问题。

### 4.3 流计算

- 修复未使用 `INTO` 时，事件通知发送失败的问题。
- 修复一次触发生成多个窗口时，标量子查询配合窗口伪列没有输出的问题。
- 修复通知过滤条件 `WHERE` 的判定错误、推送结果不符合预期的问题。
- 修复配置 `fill_history` 阈值后，向空表写入阈值之前的数据却触发历史回填的问题。

### 4.4 写入与连接器

- 修复 STMT 参数绑定执行带 `INTERVAL` 的 `SELECT` 时阻塞的问题。
- 修复无模式（Schemaless）写入报 `Invalid schema version` 的问题。
- 修复 ODBC 写入失败时不返回错误信息的问题。
- 修复通过 TMQ 或 raw block 写入非法 NCHAR 时未校验，随后按列过滤普通表失败的问题。

### 4.5 数据订阅

- 修复修改子表标签或删除子表后，订阅过滤结果不正确的问题。已删除子表在 WAL 中的历史写入可以正常解析。

### 4.6 taosX

- 修复双活任务遇到空连接时异常终止的问题。
- 修复向 S3 备份或从 S3 恢复失败的问题。
- 修复失败的备份任务无法删除的问题。
- 修复备份任务配置成功后，在 taosExplorer 中不显示的问题。
- 修复数据迁移时，源库与目标库标签顺序不一致导致写入错误的问题。
- 修复 Kafka 数据源配置多条转换规则时，部分序号错误导致字段为空的问题。
- 修复 PI Connector 的 Dataset Filter 配置异常的问题。
- 修复 PI Connector 按元素过滤点位时，下载的 CSV 结果错误的问题。
- 修复 PI Connector 把 Int16 当成 Int32 处理的问题。

### 4.7 taosExplorer

- 修复无法展示普通表的问题。
- 修复用户授权仍使用旧版权限语法、执行授权语句报错的问题。
- 修复表格页面滚动条无法拖动的问题。

## 5. 安全

### 5.1 漏洞修复

详情见 [安全公告](https://docs.taosdata.com/security-guide/security-advisories/)。

- [GHSA-vxcq-cqrc-f8j3](https://github.com/taosdata/TDengine/security/advisories/GHSA-vxcq-cqrc-f8j3)：SQL 解析过程中存在 double-free，可导致 taosd 崩溃。影响版本：`v3.2.3.8` 至 `v3.4.1.14`。
- [GHSA-v8cj-fw82-9jjf](https://docs.taosdata.com/security-guide/security-advisories/#ghsa-v8cj-fw82-9jjf-td-sec-2026-018)：子查询处理过程中存在 use-after-free 或 double-free，可导致 taosd 崩溃。影响版本：`v3.4.1.0` 至 `v3.4.1.14`。
- [GHSA-f8pf-77fh-53wv](https://docs.taosdata.com/security-guide/security-advisories/#ghsa-f8pf-77fh-53wv-td-sec-2026-019)：投影计算过程中存在 double-free，可导致 taosd 崩溃。影响版本：`v3.0.0.0` 至 `v3.4.1.14`。
- [CVE-2025-58050](https://nvd.nist.gov/vuln/detail/CVE-2025-58050)：依赖库 PCRE2 存在安全漏洞，已升级到 10.47。影响版本：`v3.4.1.17` 及更早版本。这些版本捆绑的 PCRE2 为 10.45 或更低。
- 自动建表时权限控制失效，用户可能在没有权限的情况下创建子表。影响版本：`v3.4.1.14` 及更早版本。`v3.3.6.52` 及之后的 `v3.3.6` 补丁已修复。
- 恶意构造的 RPC 消息可导致拒绝服务，已加强消息长度校验。影响版本：`v3.4.1.14` 及更早版本。
- 密钥更新只在 mnode leader 上生效，其他节点仍使用旧密钥。影响版本：`v3.4.1.16` 及更早版本。

### 5.2 安全加固

- RPC 通信新增身份认证，避免通信内容明文传输。
- 修改密码后，断开使用旧密码建立的连接。
- 查询落地的临时文件改为加密存储。
- 加强 UDF 文件路径校验。
- 加强字符串结束符校验。

## 6. 升级须知

### 6.1 升级路径

- 支持直接升级的源版本：`v3.3.7` 及后续版本
- 是否支持滚动升级：支持，范围为 `v3.4.2.0` 至 `v3.4.2.2`
- 是否支持降级或回滚：支持，范围为 `v3.4.2.0` 至 `v3.4.2.2`
- 客户端与连接器的最低配套版本：`v3.4.2.0`

### 6.2 行为变更

- RPC 通信新增身份认证，避免通信内容明文传输。更早版本的客户端和服务端无法通信。
- 修改密码后，使用旧密码建立的连接会被断开，后续请求返回认证失败。使用连接池的应用需要在修改密码后更新配置，并重建连接池。
- 普通用户写入不存在的表，且没有通配权限时，错误信息由 `Permission denied or the target object does not exist` 改为 `Table does not exist`。按错误信息或错误码分支的应用需要调整。
- 新增连接级时区，生效顺序为 SQL 参数、连接、全局配置。未做连接级设置时，服务端计算仍回退到服务端全局时区。本版本起，普通列读取使用连接时区。
- 查询落地的临时文件改为加密存储。对存在大量结果的查询性能有轻微影响。
- macOS 上执行 `USE` 的输出改为 `Database changed.`，与 Linux 一致。解析 `taos` shell 输出的脚本需要按新输出修改。
- `ignoreNullInGreatest` 控制 `GREATEST` / `LEAST` 是否跳过 NULL。默认值为 `0`，任一参数为 NULL 则返回 NULL，不改变已有查询结果。设为 `1` 才跳过 NULL。

### 6.3 配置参数变更

#### 6.3.1 License 授权

| 参数 | 作用 |
| --- | --- |
| `clsEnabled` | 是否启用集群授权服务。默认 `0`，关闭 |
| `clsUrl` | 授权服务地址。默认空字符串 |
| `clsLicenseId` | License ID。默认空字符串 |
| `clsQuotaSlotId` | 配额 Slot ID。默认空字符串 |
| `clsRefreshInterval` | 授权刷新间隔。默认 `3600` 秒 |

#### 6.3.2 CPU 亲和性

| 参数 | 作用 |
| --- | --- |
| `enableCpuAffinity` | 总开关。默认 `0`。`0`：关闭；`1`：按管理、读取、写入绑定 CPU |
| `managementCpuCores` | 管理线程占用的 CPU 核数。默认 `1` |
| `readCpuCores` | 读取线程占用的 CPU 核数。默认按剩余核数的一半计算 |
| `otherCpuCores` | 写入线程占用的 CPU 核数。默认按剩余核数的另一半计算 |

#### 6.3.3 联邦查询

| 参数 | 作用 |
| --- | --- |
| `federatedQueryEnable` | 是否启用联邦查询。默认 `false` |
| `federatedQueryConnectTimeoutMs` | 建立外部数据源连接的超时（毫秒）。默认 `5000` |
| `federatedQueryQueryTimeoutMs` | 执行外部查询的超时（毫秒）。默认 `1000000000`，等于最大值时不限时 |
| `federatedQueryMaxPoolSizePerSource` | 单个数据源的最大连接池。默认 `64` |
| `federatedQueryIdleConnTtlSec` | 空闲连接存活时间（秒）。默认 `600` |
| `federatedQueryProbeTimeoutMs` | 探活超时（毫秒）。默认 `5000`。当前暂未实现 |

#### 6.3.4 认证与安全

| 参数 | 作用 |
| --- | --- |
| `authMech` | 客户端认证方式，取值为 `auto`、`scram` 或 `legacy`。默认 `legacy` |
| `forceScram` | 强制使用 SCRAM，禁用 legacy 回退。默认关闭 |

#### 6.3.5 过载重试

| 参数 | 作用 |
| --- | --- |
| `retryOnOverloadBaseInterval` | 服务端过载时，客户端重试的初始间隔（毫秒），之后按指数退避。默认 `1000` |
| `retryOnOverloadTimeout` | 服务端过载时，客户端重试的最长总时长（毫秒）。默认 `60000` |

#### 6.3.6 同步

| 参数 | 作用 |
| --- | --- |
| `snapshotRateLimit` | 每个 dnode 发送快照的带宽上限（MB/s）。默认 `0`，表示不限速 |

### 6.7 升级前操作

`v3.3.6.0` 之后流计算已重新设计。从 `v3.3.6` 及更早版本升级到本版本之前，必须先清掉旧的流计算对象，再在新版本上重建。未做这些操作时，taosd 会启动失败。

升级前按下面的顺序操作：

1. 删除全部流计算任务。`DROP STREAM` 只删除任务，不删除已经写出的结果数据。可先用 `SHOW STREAMS` 列出任务。
2. 删除全部 TSMA：`DROP TSMA [db_name.]tsma_name`。TSMA 的结果超级表会随 TSMA 一起删除。
3. 删除全部 snode：`DROP SNODE ON DNODE dnode_id`。删除时 snode 及其副本必须在线，否则删除失败。
4. 删除 snode 相关目录：
   - `dataDir` 下的 snode 目录，默认 `/var/lib/taos/snode`
   - `checkpointBackupDir` 指定的目录，默认 `/var/lib/taos/backup/checkpoint/`
5. 删除全部流计算结果表（可选）。

升级完成并部署新的 snode 之后，再按新版本语法重建流计算。
