发布时间：**2026-08-30**

## 特性

  1. taosExplorer 支持在流计算页面查看流任务运行状况（延迟、输入/输出速率、历史进度、失败原因）及重算记录。
  2. TDinsightV3 新增流计算观测面板，并预置流失败与重算失败告警规则，可通过通知策略转发至钉钉等渠道（需 TDengine 3.4.2.7+）。
  3. 流计算触发支持嵌套窗口，可在 WINDOW 中组合多层窗口并通过外层上下文变量驱动内层计算。
  4. 支持 DROP VTABLE 批量删除多张虚拟普通表/虚拟子表（含跨库）。
  5. 支持通过一条 CREATE VTABLE 语句批量创建多个虚拟子表。
  6. 虚拟普通表与普通表支持 owned 标签列，可通过 CREATE/ALTER 定义与维护，并支持 SHOW CREATE、SHOW TAGS、ins_tags。

## 优化

  1. taosX TMQ 同步任务在 consumer 重建时对 subscribe 增加有限重试，降低源端短时重启导致整任务失败的概率。
  2. taosX 提升 CSV 导入在数十万文件目录下的可配置性与吞吐，避免解析/建任务超时及导入速度随文件数急剧下降。
  3. taosX-Agent 可靠写入 ACK 引入协议与 UUID v7 身份基础（本阶段保持旧写入路径，不改变 Kafka offset 行为）。
  4. 增强流计算手动重算可靠性，失败不再拖垮整条流，未完成请求可持久化恢复，并通过系统表暴露错误信息。
  5. 流计算任务首次因错误停止时向 taosKeeper 上报失败指标，便于告警与运维观测。
  6. 数据订阅 TMQ 在 timer 心跳超过两个周期未上报时，由 poll 线程补充发送心跳，降低消费者误判离线的概率。
  7. 改进查询 PARTITION BY 分组缓存与 spill 策略，降低高基数小分组场景下因内存页不足导致的频繁磁盘读写。
  8. ALTER DATABASE 支持动态修改 MAXROWS，配合 COMPACT FORCE 可使已有 fileset 按新块大小生效。
  9. 支持 0 级多挂载点场景下 WAL 新建段在多个挂载点间轮询分配，消除 WAL 单盘 IO 瓶颈。
 10. 新增 FLUSH MNODE 与 taosd -fMnode，并增强 sdb JSON 导出/导入，支持故障场景下离线修改全局参数等元数据。

## 修复

  1. taosExplorer 编辑普通表时未正确加载字段列表，导致编辑页面不显示字段的问题。
  2. taosExplorer 普通表详情弹框将复合主键字段误显示为标签，并错误展示超级表与标签区域的问题。
  3. taosExplorer 数据写入任务预览映射中，子表名模板列经 cast 为空时未保留前后缀导致显示错误的问题。
  4. taosExplorer 按指定备份点恢复时因缺少任务名或 DSN 参数未正确编码导致恢复失败的问题。
  5. taosExplorer 跨域策略过严，导致 IDMP 等不同源访问时 HTTP CORS 预检失败与 WebSocket 握手被拒的问题。
  6. taosX MySQL 数据源任务停止后再启动无法按断点续传、从配置起始时间重新同步的问题。
  7. taosX OPC UA「选择数据点位」模式下，点位 id 含 :: 或 , 时被错误截断，导致部分点位无法采集的问题。
  8. taosX 从 MySQL 实时同步时 delay 同时回拨窗口起点，导致查询窗口重叠、数据重复写入的问题。
  9. taosX 接入 MySQL 时示例查询和历史同步不再发出超过查询间隔的大窗口 SQL，避免超时导致无法同步。
 10. taosX 备份任务在完成判定时因查询非属主 vgroup 位点而永久悬挂的问题。
 11. taosX 强化 Kafka 消费与下游写入链路的超时/IPC 可靠性，并补充连接池与连接器观测指标，便于定位消费中断类故障。
 12. taosdump 仅恢复 ext-meta 时未先创建全部数据库再执行流/Topic DDL，导致跨库依赖恢复随机失败的问题。
 13. Rust WebSocket 连接器关闭连接时未清理 channel 中待处理请求，导致资源未释放的问题。
 14. XNode 任务解析含转义字符时按反转义前长度落库，尾部 NUL 在升级后导致 JSON 解析失败、任务无法加载的问题。
 15. XNode 任务创建者用户被删除后，root 或具备相应权限的用户无法删除/更新该任务并报用户不存在的问题。
 16. STMT2/WebSocket 查询使用 tbname = ? / tbname IN (?) 时从表名占位符取错值，导致路由到错误 vgroup、查询结果为空的问题。
 17. STMT2 写入时删除并以同名重建超级表后仍使用旧 suid 缓存，导致 Table does not exist 的问题。
 18. STMT2 参数绑定写入 DECIMAL 时，在只绑定部分列或列 ID 不连续场景下误用其他列精度导致 Decimal value overflow 的问题。
 19. 流计算启用 `nodelay_create_subtable` 创建分组结果子表时，子表在 `information_schema` / `SHOW TABLES` 可见但 `SELECT` 报表不存在的问题。
 20. 流计算外部窗口复用结果块时未按批次扩容，可能导致越界写并引发 taosd 崩溃的问题。
 21. 流计算手动重算（RECALCULATE STREAM）时用户指定的 FROM/TO 范围被运行时边界裁剪，导致部分数据未参与重算的问题。
 22. 流计算在集群 balance 等场景下 reader 任务短暂不存在时触发任务失败、导致流计算异常的问题。
 23. 数据订阅 WebSocket TMQ 客户端收到错误应答时反序列化失败导致请求挂起或报错的问题。
 24. 虚拟超级表查询在引用关系变化后偶发返回 Invalid parameters（0x118）的问题。
 25. 虚拟超级表查询在源表 VGroup 路由过期时重试未刷新源库元数据，偶发报 No valid epSet 的问题。
 26. 查询 regexp_in_set 使用 NCHAR 列作为分隔符或传入空 NCHAR 时结果不正确的问题。
 27. 查询 INTERP 等语句通过视图或预处理语句时误报函数冲突错误（0x80002680）的问题。
 28. 查询 RESTful 接口 TO_CHAR 等时区敏感函数时，将 +0800 等 ISO8601 偏移错误按 POSIX 解析，导致时区结果偏差的问题。
 29. 查询跨多个 VGROUP 的 LEASTSQUARES 时因数据消费顺序不确定导致斜率、截距结果不稳定的问题。
 30. 时区相关错误返回未格式化的 Invalid timezone: '%s'，以及文件描述符耗尽等系统错误被误报为非法时区的问题。
 31. 时区设置不再拒绝 UTC0、UTC8 等省略正号的 POSIX 偏移写法。
 32. 离线副本通过 snapshot 恢复后未正确应用 leader 的数据库 KEEP 配置，导致保留策略不一致、过期数据无法按新策略清理的问题。
 33. 存在未完成事务时执行 SHOW TRANSACTIONS 可能因 oper 列缓冲区溢出导致 taosd 崩溃的问题。
 34. 数据库 minRows 与 maxRows 相等时执行 SHOW DISK_INFO 或 SHOW TABLE DISTRIBUTED 可能导致 taosd 崩溃的问题。
