发布时间：**2026-04-01**

| 版本类型 | 推荐升级对象 |
| --- | --- |
| 功能版本 | 使用子查询、流计算、虚拟表、数据订阅或从 `v3.3` 升级权限的用户 |

## 1. 版本亮点

- 支持外部窗口，时间范围由子查询指定。支持标量子查询，以及 `ANY`、`SOME`、`ALL`、`EXISTS`、`NOT EXISTS`。
- 新增 `LAG`、`LEAD`、`FILL_FORWARD`。`INTERVAL` 和 `INTERP` 的 `FILL` 可以指定插值时间范围。
- 流计算支持按自然周、月、季、年定时计算，并可以在源表没有新数据时发超时通知。
- 可以批量修改子表标签。虚拟表增加引用校验。
- 数据订阅支持令牌登录，并感知虚拟表元数据变更。
- Windows 上可以使用 taosX、TDgpt 和流计算。

## 2. 新特性

### 2.1 查询

- 支持[外部窗口](../../05-tdengine-sql/04-data-query/04-distinguished.md#外部窗口)。时间范围由子查询显式指定。
- 支持非相关标量子查询，以及不带 `FROM` 的标量子查询。`IN` 可以使用非相关子查询。
- 支持 `ANY`、`SOME`、`ALL`、`EXISTS`、`NOT EXISTS`。
- 支持 `LAG`、`LEAD`、`FILL_FORWARD`。
- `INTERVAL`、`INTERP` 的 `FILL` 支持插值时间范围。`FILL(PREV/NEXT/NEAR/LINEAR)` 可以填充前后的非 NULL 值。
- `BLOB` 支持 `CAST` 和 `SUBSTR`。
- 可以批量修改子表标签值。
- taosd 增加数据修复模式。`RESTORE DNODE` 可以指定 `VGROUP ID`。
- TDgpt 支持多变量异常检测。

### 2.2 流计算与订阅

- 流计算可以按自然周、月、季、年定时计算。
- 源子表或虚拟子表长时间没有新数据时，可以发送超时通知。
- 流计算支持 `NODELAY_CREATE_SUBTABLE`，没有数据写入时也可以先建结果表。
- 流计算支持多分组批量计算和批量删除。虚拟超级表触发可以感知子表增删、标签修改和列映射变化。
- 流计算子查询支持 `IN`、`ANY`、`SOME`、`ALL`、`EXISTS`、`NOT EXISTS`。
- 数据订阅感知虚拟表元数据变更，并支持令牌登录。
- Go、Rust、C WebSocket 订阅支持令牌。Go REST 连接器支持 `TOKEN`。taos shell 可以用令牌登录。

### 2.3 平台、权限与工具

- Windows 支持 taosX、TDgpt 和流计算。
- taosX 增加可见性权限，以及系统和对象权限。新增力控 pSpace 数据源。OPC-UA 连通性检测支持故障转移。Kafka 采集可以按过滤条件写入多个超级表。
- KingHistorian 同步中点位可以自动更新。结束时间为空时可以持续迁移。
- MQTT 可以配置多个 Broker。
- taosdump 支持 `DECIMAL` 和 `BLOB` 的导入导出，并可以用 `STMT2` 写入。
- taosgen 支持 Windows，并可在配置文件里设置日志目录。
- taosKeeper 可以导出当前全部指标。
- taosExplorer 支持密码登录获取令牌、TOTP 和 Bearer Token。会话可以自动续期。登录可以启用验证码。

## 3. 优化

- 虚拟超级表的聚合、`GROUP BY`、时间窗口、事件窗口、会话窗口和状态窗口查询更快。引用列很多时的查询更快。创建失败时会指出哪一列类型不匹配。
- 虚拟表增加与源表的引用校验，包括引用关系保存、源表变更检查、引用关系查询和可用性验证。可引用的原始表数量上限改为不限制，并移除 `WIN_OPTIMIZE_BATCH`、`WIN_OPTIMIZE_SINGLE`。
- `LAST_ROW` 查询更快。可以动态调整 LRU 分片数量，以加快 `LAST`。
- 交错写入时订阅更快。
- 子查询作为主键过滤条件时更快。
- `JOIN` 和窗口连接可以基于选择函数的结果再运算。
- `SHOW QUERIES` 显示执行进度。`EXPLAIN ANALYZE` 修正算子耗时，并增加算子指标。慢日志上报更及时。
- SQL 报错更明确。
- 可以修改 root 的 `PASSWORD_LIFE_TIME`、`PASSWORD_REUSE_TIME`、`PASSWORD_REUSE_MAX`、`ALLOW_TOKEN_NUM`。密码最小有效期默认为 1 天。
- 订阅密码错误时，返回与连接失败一致的 Authentication failure。
- taosX 备份在获取 Offset 失败时仍能生成备份点。OPC 自定义标签属性支持字符替换。
- Explorer 的数据源和 Transform 界面、授权页、JSON 规则输入框和激活码显示框做了易用性调整。
- TDgpt 服务端改用 Gunicorn。JDBC taos-ws 文档中的示例设置 `varcharAsString=true`。

## 4. 问题修复

### 4.1 严重问题

- 虚拟表做聚合且带 `PARTITION BY` 标签时崩溃。虚拟表参数绑定查询崩溃。查询虚拟超级表偶发崩溃。影响版本：`v3.3.6.0` 至 `v3.4.0.9`。
- 虚拟子表列类型与映射源表不一致（通常是增删同名列）时查询异常。影响版本：`v3.3.6.0` 至 `v3.4.0.9`。
- 查询虚拟子表的时间戳列和数据列时，数据列没有引用源表会报 Planner slot key not found。影响版本：`v3.3.6.0` 至 `v3.4.0.9`。
- 查询虚拟超级表报 Invalid value in client。影响版本：`v3.3.6.0` 至 `v3.4.0.9`。
- 虚拟超级表会话窗口的结果不正确。影响版本：`v3.3.6.0` 至 `v3.4.0.9`。
- `LAST` 读取 `BLOB` 时崩溃。影响版本：所有版本。
- 表达式或函数里调用 `TRIM` 时崩溃。影响版本：所有版本。
- `SAMPLE` 的数据量超出 32 位整数范围时可能崩溃。影响版本：所有版本。
- 两个聚合查询用 `UNION ALL` 合并时可能崩溃。影响版本：所有版本。
- 比较两个标签列并使用索引时 taosd 崩溃。影响版本：所有版本。
- 订阅与流计算同时高并发时，极低概率崩溃。影响版本：`v3.3.7.0` 至 `v3.4.0.9`。
- 流计算 `FILL_HISTORY` 失败。结果表已存在时 schema 和 tag 同步失败。影响版本：`v3.3.7.0` 至 `v3.4.0.9`。
- 流计算聚合结果上的过滤条件不生效。常量作为起始时间过滤时结果错误。含 `JOIN` 的结果集为空时仍输出数据。影响版本：`v3.3.7.0` 至 `v3.4.0.9`。
- 流计算临时文件没有释放，磁盘占用持续增大。影响版本：`v3.3.7.0` 至 `v3.4.0.9`。升级后新的运行不再继续堆积；已经占满的磁盘空间需要自行清理临时文件。
- 流计算 `SLIDING(0s)` 被错误地创建成功。影响版本：`v3.3.7.0` 至 `v3.4.0.9`。
- 订阅长期没有数据时，部分 vnode 停止消费。订阅 rawdata 失败。影响版本：所有版本。
- 从 `v3.3.8` 升级到 `v3.4.0.0` 或 `v3.4.0.1`，再升级到 `v3.4.0.2` 及之后，root 执行部分操作报权限不足。影响版本：`v3.4.0.0` 至 `v3.4.0.9`。升级到本版本后请核对 root 权限。

### 4.2 查询、存储与权限

- `ins_streams` 里看到的 SQL 不完整。
- `EXPLAIN` 解析子查询时没有结果。`DROP TSMA IF EXISTS` 不生效。
- 有删表权限时，`DROP TABLE IF EXISTS db.not_exist_table` 仍报权限不足。
- 拥有 `sysinfo` 只读权限的用户查看无权字段时，语句报错，不再返回 NULL。与 `v3.3.8` 一致。
- `ssEnabled` 的动态修改范围配置错误。`SS_CHUNKPAGES` 的默认值没有生效。共享存储上传期间执行 `COMPACT` 报 Operation not supported。
- 打开全部调试日志时，日志量过大使 taosd 的 CPU 持续偏高。
- taos shell 中子查询带 `LIMIT` 时，只显示前 100 行的限制失效。
- Windows 上 dmp 文件生成异常。
- TDgpt 的 Docker 镜像缺少 gcc 相关组件，PyTorch 推理无法运行。

### 4.3 taosX、taosdump 与 taosExplorer

- taosdump 恢复数据库时没有包含 VGroups 信息。
- taosX：大量 CSV 同时处理时断点锁竞争；同步 `VARBINARY` / `BLOB` 报错；taosd 不正常时迁移任务状态不符合预期；停止 taosX 后任务没有迁移；XNode 数据复制任务不能进入运行状态。
- Kafka 数组写入格式统一为 JSON。OPC-DA 偶发采集中断，或无法枚举点位。
- TDinsight 的 taosX 面板任务信息显示错误。导入任务时不能选择数据库。Parser 参数超长时错误信息不明确。`SHOW XNODE TASKS` 按 ID 排序。
- taosExplorer：写入配置错误时预览不符合预期；删除拆分规则后报错；订阅权限留空时报错；任务过滤导致字段值丢失；密码含特殊字符时部分请求失败；`xor_allowed_duration_secs` 修改无效；支持相对路径反向代理；数据复制任务报 Bad Request。

## 5. 安全

### 5.1 漏洞修复

- taosExplorer 修复一处 SQL 注入。任务上没有漏洞 ID 或 CVE 编号。
- 详情见 [安全公告](https://docs.taosdata.com/security-guide/security-advisories/)。

### 5.2 安全加固

- 增加 SQL 注入、拒绝服务和溢出防护。敏感数据删除后强制覆盖。
- taosAdapter 和 taosKeeper 增加 `readHeaderTimeout`，默认 10 秒，用于降低慢速请求占用连接的风险。
- C 和 Rust WebSocket 连接器做了安全加固。
- 新增 `enableAdvancedSecurity`。未打开高级安全编译选项时默认 `0`，关闭密码过期、强密码和密码轮换，允许使用默认密码，默认行为与 `v3.3` 一致。打开高级安全编译选项时默认 `1`。
- 新增 `enableGrantLegacySyntax`。为 `1` 时，`v3.4` 的授权语法兼容 `v3.3`。
- 移除 `forceReadConfig`。

## 6. 升级须知

### 6.1 升级路径

直接升级、滚动升级、降级和客户端配套版本未在本页另写。

### 6.2 行为变更

- 未授权时，不再因为机器码变化反复检查。授权状态保持 ungranted。
- 计算授权测点时，排除 log 库和审计库里已知系统超级表的子表。另保留 1000 个测点余量，只在判断是否超出授权时使用。`SHOW GRANTS` 仍显示实际测点数。虚拟表不计入测点。log 库或审计库已经存在时，升级不会自动重算测点。需要修正时，把对应 vnode 的 `vnode.json` 里 `vndStats.timeseries` 置为 0 后重启。不要改 `vndStats.ntimeseries`。
- `NULL` 参与比较的结果为 NULL。`IN` / `NOT IN` 里的 NULL 比较规则有变化，已有语句的结果可能不同。
- 社区版与企业版不能互连。
- 拥有 `sysinfo` 只读权限的用户查看无权字段时，语句报错，不再返回 NULL。
- taosdump 恢复数据库时会带上 VGroups 信息，恢复出的库的 VGroups 可能与旧备份不同。
- root 可以修改密码有效期、重用次数和允许的令牌数。密码最小有效期为 1 天。
- `v3.3.7.0` 至 `v3.4.0.9` 之间，不要用 `ALTER DNODES` 修改 `ssEnabled`。
- `v3.3.8.20` 至 `v3.3.8.22`，以及 `v3.4.0.10` 至 `v3.4.0.14`，新建库的 `SS_CHUNKPAGES` 默认不是 512 MB 对应的切分。若之后可能使用 S3，建库时显式指定，例如 `CREATE DATABASE d1 SS_CHUNKPAGES 131072`。已有库不受影响。

### 6.3 配置参数变更

| 参数 | 作用 |
| --- | --- |
| enableAdvancedSecurity | 是否启用密码过期、强密码和密码轮换。未打开高级安全编译选项时默认 `0`。 |
| enableGrantLegacySyntax | 为 `1` 时，授权语法兼容 `v3.3`。 |
| auditSaveInSelf | 开启后审计信息不再经过 taosKeeper，创建审计库时同时创建 operations 超级表。打开高级安全编译选项时默认开启。 |
| tmqWriteRefDB | 订阅是否写入引用库相关数据。 |
| tmqWriteCheckRef | 订阅写入时是否检查引用。 |
| readHeaderTimeout | taosAdapter 和 taosKeeper 读取请求头的超时。默认 10 秒。 |

移除 `forceReadConfig`。移除 Hint `WIN_OPTIMIZE_BATCH`、`WIN_OPTIMIZE_SINGLE`。

### 6.4 关键字变更

下列词用作库名、表名、超级表名、子表名、列名或标签名时，不论大小写都要用反引号。

`ANY`、`SOME`、`EXTERNAL_WINDOW`、`CACHESHARDBITS`。

### 6.5 系统表变更

`SHOW QUERIES` 增加查询进度。

本版本没有移除系统表。

### 6.6 升级前操作

从 `v3.3.6` 升级到本版本时，旧流计算不能直接沿用。步骤见 [流计算兼容性说明](../../07-stream-processing/02-instructions.md#兼容性说明)。

已经在 `v3.4.0.0` 及之后按新流计算运行的集群，滚动到本版本时不必重复。
