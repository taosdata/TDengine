## 特性

1. 6660036900 特性：支持基于虚拟表实现联邦查询
2. 6492554061 特性：支持虚拟超级表继承其他虚拟超级表

5. 6934772510 特性：外部窗口支持 FILL 子句
6. 6944899507 特性：新增 TEXT 和 FILE 内联数据源，支持在 SQL FROM 子句中直接使用行值数据（TEXT (col_list) VALUES ...）或 CSV 文件（FILE (path, col_list [, options])）作为查询表源，可参与 SELECT、JOIN、UNION 及 INSERT INTO SELECT，无需创建持久化表

8. 6927171373 特性：状态窗口支持通过多个状态列划分窗口
9. 6659773700 特性：允许原始列、标签列、标量函数、不定行函数在窗口查询中使用
10. 6659794715 特性：支持 CPU 亲和性绑定
11. 6968250338 特性：支持 REGEXP_EXTRACT 函数
12. 6507136288 特性：支持 SLEEP 函数，用于模拟超时场景
13. 6549502576 特性：支持窗口函数与 OVER 子句
14. 6511919698 特性：支持在聚合函数中使用 DISTINCT 关键字
15. 6592836563 特性：流计算事件窗口的 true_for 语句支持独立设置开始与结束条件的判断规则
16. 6996636537 特性：流计算任务支持执行联邦查询
17. 6979200215 特性：流计算触发新增 ROLLUP BY tag_name 子句，支持按标签层级逐层汇总计算结果
18. 6659965197 特性：超级表、子表、虚拟表的元数据更新支持事务
19. 6955602052 特性：数据修复工具新增拷贝修复模式
20. 6665209146 特性：C Websocket 连接器支持 Adapter 高可用
21. 6662936374 特性：Go Websocket 连接器支持 Adapter 高可用
22. 6665270968 特性：NodeJs Websocket 连接器支持 Adapter 高可用
23. 6665221613 特性：Python Websocket 连接器支持 Adapter 高可用
24. 6755452428 特性：taosX 支持数据导出为 Parquet 文件
25. 6755550481 特性：taosX DataOut 支持将数据导出到 Kafka
26. 6956269849 特性：taosX OPC UA 数据源新增告警与事件（Alarm & Events）采集能力
