## 转义字符表

| **字符序列** | **代表的字符** |
| ---- | --- |
| `\'` | 单引号 `'` |
| `\"` | 双引号 `"` |
| `\n` | 换行符 |
| `\r` | 回车符 |
| `\t` | 制表符（tab） |
| `\\` | 反斜杠 `\` |
| `\%` | `%`（规则见下） |
| `\_` | `_`（规则见下） |

## 转义字符使用规则

1. 标识符中的转义字符（数据库名、表名、列名、别名）
   1. 普通标识符：若包含转义字符则报错。普通标识符只能由数字、字母和下划线组成，且不能以数字开头。
   2. 反引号标识符（`` ` ``）：内容保持原样，不进行转义。
2. 数据中的转义字符
   1. 遇到上表定义的转义序列时会进行转义（`%` 与 `_` 见下条）。若 `\` 后不是合法转义序列，则忽略该 `\`（例如 `\x` 保持为 `\x`）。
   2. 对于 `%` 和 `_`：二者在 `LIKE` 模式匹配中为通配符，因此在 `LIKE` 中分别用 `\%` 和 `\_` 表示字面量 `%` 和 `_`。若在 `LIKE` 上下文之外使用 `\%` 或 `\_`，结果仍为字符串 `\%` 和 `\_`，而不会变成 `%` 和 `_`。
