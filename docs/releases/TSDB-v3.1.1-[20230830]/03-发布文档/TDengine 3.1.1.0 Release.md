# TDengine 3.1.1.0 Release

## 1. Release Date:  August/31

### 1.1 User Manuals: [3.1.1.0 Release User Manuals](https://taosdata.feishu.cn/wiki/VxKLw2MuoibuvvkrAsLcLC6bneh) 

### 1.2 Highlights

1. S3 can be used as level 3 storage
2. Query performance improvement
3. Stream processing can be used in DB of 3 replications

## 2. New Features/Improvements

1. Audit log
2. S3 storage
3. Comment for stable columns (Canceled)
4. Query
   - Performance improvement for Join
   - Performance improvement for interval + limit
5. Stream Processing and TMQ
   - Stream processing for DB of 3 replications
6. Cluster
   - RAFT membership change optimization to make replica change more reliable
7. New Data Type: medium blob (<=64KB)
8. Linux/ARM64
