# TD-25464：feat/TD-22970 分支性能对比测试

## 1. 测试结论：

对比了 3.0 分支 和 feat/TD-22970 分支的写入和查询性能，总体上写入性能基本相当；
查询性能也总体上差不多，但是有部分查询 feat/TD-22970 分支比 3.0 分支慢了非常多，比如在 10000000表，每个子表 10 条记录的场景下
select last_row(*) from meters group by tbname slimit 10000， select last_row(*) from meters partition by tbname slimit 10000 等查询慢比 3.0 分支慢了20多倍

## 2. 测试环境：

- 硬件环境：
  - CPU: 16C Intel(R) Core(TM) i7-10700 CPU @ 2.90GHz
  - MEM: 64 GB
  - DISK: 1TB Samsung SSD
- 软件环境：
  - TDengine  feat/TD-22970 分支 (70a598f072)，main 分支 (1d649bccb6)
  - Taos-tools: main 分支
