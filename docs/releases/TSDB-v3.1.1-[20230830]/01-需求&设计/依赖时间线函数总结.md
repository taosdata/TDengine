# 依赖时间线函数总结

以下为对于依赖时间线输入顺序的总结(3.1.1.0之后)，除了给出对每个函数的计算逻辑/物理意义给出依赖的必要性之外，还有一个很重要的原因是，所有的时间函数对于超级表直接查询会做时间戳重复判断，需要隐式使用时间列主键参与运算。判重的逻辑对于顺序输入很容易，而对于乱序数据处理起来会很复杂。
