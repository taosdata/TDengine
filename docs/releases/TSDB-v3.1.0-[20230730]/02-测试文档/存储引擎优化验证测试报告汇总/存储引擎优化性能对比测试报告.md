### 3.4 测试结论

1、三条查询语句select * from meters order by ts desc limit 1000;select * from meters order by current desc limit 1000;和select count(*) from meters;
     vgroup少的情况下耗时都明显偏长、
      随着vgroup的增加，耗时一直在减少，但后面到 vgroup=20时提升基本不明显了。
2、stt_trigger=2｜8 ｜16时，查询耗时没有明显变化，这个和@贾靖斌 测试结果也一致。
