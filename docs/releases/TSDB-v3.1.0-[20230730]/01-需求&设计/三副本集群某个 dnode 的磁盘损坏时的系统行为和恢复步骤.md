# 三副本集群某个 dnode 的磁盘损坏时的系统行为和恢复步骤

@Benguang
1. 当出现某个 dnode 的磁盘损坏时的系统。
当数据写入过程中，如果发生数据磁盘损坏，当前dnode将会报错，并退出进程。三副本集群，将会触发重新选主，当有两个副本正常时，可在10s以内产生新的leader，继续提供集群读写服务。
由于集群uptime定时器，通过事务周期性更新集群运行时间状态，mnode节点所在数据盘发生损坏时，mnode所在dnode将会报错，并且退出进程。如果mnode为三副本，且有两个副本正常时，将会重新选主，成功后继续提供服务。
磁盘故障检查，为磁盘写入失败触发。包含两个方面：
- WAL写入失败触发。容忍磁盘满。对mnode和vnode有效。
- vnode落盘失败触发。不容忍磁盘满。仅对vnode有效。
1. 更换磁盘后如何恢复
更换磁盘后，故障节点可通过restore dnode命令进行恢复。
