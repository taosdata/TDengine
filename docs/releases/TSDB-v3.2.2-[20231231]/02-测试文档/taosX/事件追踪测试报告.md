# 事件追踪测试报告

## 1. Jira

TD-26000

## 2. Concept

- TID: Trace ID
- DTID: Data Trace ID, DTID = Stream ID + Batch Number
- QID: Query ID (taos/taosd)

## 3. Scope

除连接器日志以外的其它日志，包括：
- agent.log
- taosx.log
- taoslog*
- taosdlog*
