## 1. 整数类型扩展支持

- 如下整数类型，支持传入浮点数和可解析为浮点数的字符串
  - TINYINT
  - TINYINT UNSIGNED
  - SMALLINT
  - SMALLINT UNSIGNED
  - INT
  - INT UNSIGNED
  - BIGINT
  - BIGINT UNSIGNED
- 支持对数据列、tag列传入浮点数

### 1.1 传入浮点型

- 支持传入浮点型数据，将其四舍五入后取整
- 转换后超出对应字段的表示范围，写入失败并报错

### 1.2 传入字符串

- 只接受首字符作为符号位，+为正数，-为负数，首位是数字或小数点的按正数处理，其余字符则报错
- 接下来连续2字符可解读为十六进制数、二进制数的，转换为整数
  - 十六进制数值表达式以0x 开头，后续只包含0-9、a-f字符，表达式中出现的字母大小写均可，0x后出现规定外的字符则报错
  - 二进制数值表达式以0b开头，b大小写均可，后续只包含0、1两种字符，0b后出现0/1外的字符则报错
- 其它含有小数点等非0-9数字的，一律按浮点数解析
- 浮点数解析成功，四舍五入后取整；反之写入失败并报错
  - 可解读为科学计数法数值的，转为浮点数，四舍五入后取整
    - 中间的e大小写均可，例如1e3、2.33E15
    - 表达式中只能出现一次字符e, 一次小数点
    - 出现多于1个非数字字符则报错
- 其他字符串均不支持
  - 不支持特殊值字符串
    - Nan：表示值不是数字，比如除0会得到`NaN`
    - -Inf：负无穷大,`-Infinity`
    - Inf：正无穷大,`Infinity`
  - 不支持运算表达式，例如 1+2
- 转换为整数后，超出对应字段的表示范围，写入失败并报错

## 2. 字符串处理规则和之前差异点

1. 支持十六进制数、二进制数，支持带+、- 号（mysql\pg 同支持）
   - 修订前整型字段不支持传入十六进制数、二进制数，新版支持
   - 支持带符号 -0x40、+0x40 、+0b100、-0b100
   - 支持'' 字符串中的十六进制，二进制数 ，如' -0x40 '，'+0b10'
      - Mysql 不支持'' 中的十六进制、二进制数
      - pg支持'' 中的 十六进制数，不支持''中的二进制数
   - 目标类型是浮点型时，不支持字符串''中的二进制数
2. 浮点数支持小数点后无数字、小数点前无数字（mysql\pg 同支持）
   - 新版支持: 2. , 2.e10,  ' 2.' , '2.e10', '.2' , '.2e2'

## 4. 参考

### 4.1 Mysql

- 兼容模式，非默认（SET sql_mode = ''）
  -  支持浮点型输入，四舍五入转为整型
  - 支持二进制、十六进制
    - 0x40, 0b10 识别为 64 和2
    - 支持带符号，-0x40 和 +0b10 识别为 -64 和 2
    - ''内 不支持二进制、十六进制，'0x40', '0b10' 报错
  - 支持运算表达式
    - 支持 +,-,*,/,%,(), &,  |, <<, >>
    - 支持 ^ 按位运算处理，4^2 = 6
    - 支持 布尔运算：！，<, >, <=, >=， 值转为0或1
    - 不支持~
  - 未标识为字符串的，例如25u而不是'25u', 不能转为数值报错
  - ''内的字符串，截取字符串头部的数值，四舍五入为整型存储
    - '2.5a1' 存为3，'12xxx' 存为12
    - 不识别字符串内的二进制、十六进制字符串, '0x40', '0b10'报错
    - 转换失败的字符串, 例如 '' , 'abc' , '0000x1f'按0值处理
  - 截断为整数后，超上限数值保存为上限值，超下限数值保存为下限值
- 严格模式，未配置情况下默认此模式（SET sql_mode = 'TRADITIONAL'）
  - 支持纯整数或浮点数输入，例如'9'， '2.03'
  - 字符串不能整体转换为数值的，报错
    - '12abc' 会报错，兼容模式下存为12
    - '12u', '2.02f' 会报错，兼容模式下存为12 和 2
  - 截断为整数后，超限则报错
- https://dev.mysql.com/doc/refman/8.0/en/out-of-range-and-overflow.html

### 4.2 PostgresSQL

- 接受运算表达式，结果错误或超限的，写入失败并报错
  - 支持 +,-,*,/,%,(), &,  |, <<, >>
  - 支持^，按指数幂处理，4^2 = 16
  - 不支持 ！，&&， ||， ~，<, >
- 接受无''标识的非十进制数值表达式, 转为整数
  - 接受浮点数，小数部分四舍五入，4.1 存为4， 5.5 存为6
  - 接受科学表达式、十六进制、二进制
  - 不接受数值后跟类型标识，传入 11u 会报错
  - 不接受特殊值：Nan，Inf、-Inf
- 带有'' 标记是否字符串，尝试按数值表达式解析，但比较受限
  - '40' 能识别为整数
    - 数字后跟类型标记报错，例如'10u'报错
  - 能识别十六进制、二进制表达式
    - '-0x40' 存为-64, '-0b1010' 存为-10
  - ''内的浮点数报错，例如'4.0'， '-2.' 报错
  - ''内的科学表达式会解析失败，1e3 能识别，'1e3'  报错
  - ''内的运算表达式报错，2+3能识别，'2+3'则报错
- 数值转换为整数后超限的，写入失败并报错
- http://www.postgres.cn/docs/14/datatype-numeric.html#DATATYPE-INT
- https://www.postgresql.org/docs/current/datatype-numeric.html#DATATYPE-INT
