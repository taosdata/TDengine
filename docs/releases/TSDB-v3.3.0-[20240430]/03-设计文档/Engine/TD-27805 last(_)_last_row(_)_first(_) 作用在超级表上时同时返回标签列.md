# TD-27805 last(*)/last_row(*)/first(*) 作用在超级表上时同时返回标签列

## 1. 背景

select * 查询超级表返回所有普通列+标签列的值，但是last_row(*)、first(*) 和last(*)只返回普通列，两者行为需要保持一致。对于子表和普通表，select *、last_row(*)、first(*) 和last(*), 只需要返回普通列。

## 4. 行为说明

4.1 增加配置选项 multiResultFunctionStarReturnTags
该配置选项默认是关闭的，last_row(*)、first(*) 和last(*)还是保持之前的行为，即不返回tag列。开启该配置，last_row(*)、first(*) 和last(*)的行为变更见4.2

4.2 函数行为变更
- 对于超级表，last_row(*)、first(*) 和last(*)返回超级表的全部普通列和标签列
- 对于子表、普通表，行为不变。last_row(*)、first(*) 和last(*)返回普通列。
- 对于子查询，行为不变。last_row(*)、first(*) 和last(*)返回用户子查询指定的列。

## 5. 性能

- last(*)，因为last(tag)没有缓存，所以会降低查询性能；tag特别多的时候，也会影响性能。
- last_row(tag)因为每条计算结果只获取一张表的tag信息，性能影响小；在tag特别多的时候，会影响性能。
- first(*) 因为column和tag都没有缓存，在tag特别多的时候，会影响性能。
