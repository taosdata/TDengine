# 需求说明：区分企业和社区版日志

## 1. 引言

### 1.1 优先级要求

在 2024 年 4 月底的版本支持

### 1.2 版本要求

企业版、社区版

## 2. 需求目标

部分客户购买一套企业版，但经常要求为其部署的社区版提供技术支持，他们提供的主要材料是日志截图。交付部门尤其是客户支持职能，希望能从日志截图上区分企业版和社区版。

## 3. 功能需求

这是一段典型的 taosd 日志
```shell {wrap}
03/05 14:55:36.243758 00143388 MND mq re-balance start
03/05 14:55:36.243768 00143388 MND mq re-balance completed successfully
03/05 14:55:36.243773 00143388 MND rebalance cnt sub, value:0
03/05 14:55:40.548136 00143394 DND ERROR failed to send status req since Operation timeout, epSet:{192.168.0.44:6030}, inUse:0
```

在时间戳或线程 ID 后增加一个字符，标识不同版本的日志。企业版用 E，社区版用 C，如有其他版本还可继续扩充。
```shell {wrap}

## 4. 企业版日志
```
