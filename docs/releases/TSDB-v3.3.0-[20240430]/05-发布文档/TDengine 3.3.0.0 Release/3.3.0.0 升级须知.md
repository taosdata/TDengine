# 3.3.0.0 升级须知

1. 升级后不可回退：从低版本升级到 3.3.0.0 后，因为元数据存储变化，无法回退到旧版本 3.2.3.x 或更低版本
2. 双副本：承载了一个或多个双副本 database 的 dnode 掉线，系统阻塞时间与该 dnode 上涉及双副本的 vnode 数量成正比，约 0.5*n (秒），n 为 vnode 数量，此阻塞时间正在优化中，会在后面的小版本中发布
3. taosExplorer 的 “系统管理-数据同步” 功能，不能向低版本的 DB 同步数据，在提交任务时会进行版本检查；类似地，在低版本上创建“数据写入 - TDengine 3.x ”类型的任务，从高版本同步数据时，会直接报错。
4. taosExplorer 的 “数据写入” 功能，对于 TDengine 3.x 类型的任务，metrics 中的以下指标由于对性能有影响，暂时移除：
   - 本次运行指标：
      - written_rows
      - written_points
      - points_per_second
      - rows_per_second
      - success_blocks
   - 累计运行指标：
      - total_written_rows
      - total_written_points
      - total_points_per_second
      - total_rows_per_second
      - total_success_blocks
5. 以上变更，还会对 TDinsight for taosX 上 TDengine 3 类型的面板产生影响：
   - Task Info 面板的 written_rows, total_written_rows
   - Inserted_rows Rate 面板
   - Inserted_points Rate 面板
6. TDinsight for taosX 上，对新增的以下两个数据源的监控尚未提供：
   - MySQL
   - PostgreSQL
