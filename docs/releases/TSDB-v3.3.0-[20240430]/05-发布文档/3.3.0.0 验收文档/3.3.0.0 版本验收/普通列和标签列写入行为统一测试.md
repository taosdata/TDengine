# 普通列和标签列写入行为统一测试

## 1. 测试内容一：标签过滤查询故障

操作：
create stable s (ts timestamp,a int)tags(c binary(10)); //创建超级表
create table subtable1 using s tags(002); //创建子表，注意，此处故意少了单引号，系统不报错
insert into subtable1 values(now,1); //插入子表
 
select * from s where c='002';
select * from s where c like '002';

采用自动建表的方式，可以用c='002'查询
insert into subtable2 using s tags(002) values(now,1) ;
select * from s where c='002' ;

## 5. 测试内容三：tag 为 int 类型时，无法使用 float 类型的数据建表

create table stb1(ts timestamp, c1 int) tags(t1 int);
create table tb1 using stb1 tags(1.1); 
create table stb2 (ts timestamp, c1 int) tags(t1 float); 
create table tb2 using stb1 tags(1);

## 9. 测试内容五：geometry类型的标签列写入数据后，提示"Unknown WKB type 767" 错误

创建数据库，超级表，子表，其中子表标签包含geometry，
create database db;
use db;
create stable st1 (ts timestamp, c1 int) tags(t1 int, t2 geometry(512)); 
create table ct1 using st1 tags(1, "LINESTRING (1.000000 1.000000, 2.000000 2.000000, 5.000000 5.000000)");
向子表写入部分数据
insert into ct1 values(now,100);
查询子表，select * from st1;
