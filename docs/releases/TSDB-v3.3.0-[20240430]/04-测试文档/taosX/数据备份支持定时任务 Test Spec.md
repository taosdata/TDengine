### 9.1 功能

在提测时，开发应保证 basic 类型的用例全部通过。
|  | Description | Expected Results | result for developer | Result | Jira | Automated | Memo |
| --- | --- | --- | --- | --- | --- | --- | --- |
| basic | 1.启动方式选择“立即启动”
2.其余均为默认配置（重复间隔为不重复） | 下发的备份任务策略为立即启动，重复周期不重复，任务列表显示的下次执行时间为空 |  |  |  |  |  |
|  | 1.启动方式选择“立即启动”
2.重复间隔配置为“每天重复” | 下发的备份任务策略为立即启动，重复周期为每天重复，任务列表显示的下次执行时间为次日00:00:00 |  |  |  |  |  |
|  | 1.启动方式选择“立即启动”
2.重复间隔配置为“自定义重复”，配置重复间隔 | 下发的备份任务策略为立即启动，重复周期为自定义重复，任务列表显示的下次执行时间为配置的任务启动时间+重复时间间隔 |  |  |  |  |  |
|  | 1.启动方式选择“自定义时间启动”，配置有效的时间
2.其余均为默认配置 | 下发的备份任务的下次执行时间为配置的自定义时间，重复周期不重复 |  |  |  |  |  |
|  | 1.启动方式选择“自定义时间启动”，配置有效的时间
2.重复间隔配置为“自定义重复”，配置重复间隔 | 下发的备份任务的下次执行时间为配置的自定义时间，在下次备份完成后，下次执行时间会变为当时时间+重复间隔 |  |  |  |  |  |
