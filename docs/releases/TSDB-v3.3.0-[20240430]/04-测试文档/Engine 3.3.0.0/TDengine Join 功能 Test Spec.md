# TDengine Join 功能 Test Spec

## 1. 测试目标

测试需求文档：[Join 功能](https://taosdata.feishu.cn/wiki/NZIJwC2Iyi6o1DkdCNtcdsVanRb)
本次TDengine Join功能的增强，从Join类型的支持上增加了很多，从之前的只支持Inner join，增强到支持除Cross Join等时序数据库中基本没有需求场景的 Join 类型外的所有 Join 类型，包括传统库中的 Left Join、Right Join、Full Join、Semi Join、Anti-Semi Join 以及时序库中特色的 ASOF Join、Window Join。测试目标主要是保证各种Join查询在超级表、子表、普通表及子查询数据集上的功能、准确性，语法/参数错误提示正常；inner join较之前的查询性能不下降。

## 3. 测试结论

 本次测试主要对已有的inner join，以及新增的full join、 left/right outer join、left/right semi join、left/right anti join、left/right asof join、left/right window join的功能、小数据量正确性及性能进行测试，测试结论如下：
1. 各种join的连接条件、过滤、包含子查询、排序、空表或空值连接、超级表、子表、普通表连接、嵌套查询、复合主键等场景进行测试，功能符合预期
2. 各种join中定义的约束或限制条件的异常场景，均有相应错误信息提示，与需求文档一致
3. 对小数据量数据集通过计算及对比的方式进行正确性验证，部分测试（inner join、outer join、full join）与PG结果进行对比；部分测试（semi join、anti join、部分left asof join）与Clickhouse结果进行对比，结果一致
4. 通过博创联动数据集进行性能验证（与Panwei确定：性能优化会在后续版本逐步完成）
  - inner、outer中对join结果集按主键时间排序 + limit查询和嵌套查询join结果集 + limit两种场景查询时间略高于PG查询时间，其他查询时间均低于PG
  - full join中嵌套聚合查询join结果集的时间高于PG，其他结果均低于PG
  - semi、anti join、left asof join查询时间经过优化后有大幅提高，但大部分查询时间均高于Clickhouse
  - right asof、window join查询时间经过优化后有大幅提高，由于Clickhouse不支持，暂未与其他产品对比

## 5. 已知问题和限制

- 输入时间线限制 - 目前所有 Join 都要求输入数据含有效的主键时间线，所有表查询都可以满足，子查询需要注意输出数据是否含有效的主键时间线。
- 连接条件限制
  - 除 ASOF 和 Window Join 之外，其他 Join 的连接条件中必须含主键列的主连接条件； 
  - 且主连接条件与其他连接条件间只支持 AND 运算；
  - 作为主连接条件的主键列只支持 timetruncate 函数运算（不支持其他函数和标量运算），作为其他连接条件时无限制；
- 分组条件限制
  - 只支持除主键列外的 TAG、普通列的等值条件；
  - 不支持标量运算；
  - 支持多个分组条件，条件间只支持 AND 运算；
- 查询结果顺序限制
  - 普通表、子表、子查询且无分组条件无排序的场景下，查询结果会按照驱动表的主键列顺序输出；
  - 超级表查询、Full Join或有分组条件无排序的场景下，查询结果没有固定的输出顺序；
因此，在有排序需求且输出无固定顺序的场景下，需要进行排序操作。部分依赖时间线的函数可能会因为没有有效的时间线输出而无法执行。
- 嵌套 Join 与多表 Join 限制
  - 目前除 Inner Join 支持嵌套与多表 Join 外，其他类型的 JoiN 暂不支持嵌套与多表 Join。

测试重点包括：
功能：
针对每一种join查询中涉及到的测试点，写出覆盖测试点的sql查询集合进行查询；sql查询语句满足语法正确及参数正确；对查询中语法和参数中的约束和限制，查询给出清晰合理的错误提示信息
准确性：
对Inner Join、Outer Join、Full Join使用PG进行结果一致性校验
对Semi Join、Anti-Semi Join、ASOF Join使用clickhouse进行结果一致性校验
对Window Join使用kdb进行结果一致性校验
性能：
对Inner Join、Outer Join、Full Join，使用相同的数据集、查询语句完成查询，记录查询时间并进行对比。
对其他类型的查询，仅记录查询时间，暂不与其他产品进行对比。
性能测试会根据硬件配置及数据集大小测一组数据作为参考，非本次测试重点。
