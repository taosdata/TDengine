# 订阅功能测试用例

### 1. 订阅功能测试用例

测试大纲：订阅测试主要涉及的改动是tmq_get_json_meta（获取meta信息的 json 描述），只涉及taosx 部分改动，所以用例集中在订阅类型、订阅来源、消费进度的组合来测试，对于数据内容，涉及顺序数据，乱序数据，删除数据，更新数据的不同组合，这里batch 写入时，注意有 interlace 和非interlace 两种模式。对于 topic，尽量涉及 基本列查询，tbname 过滤，tag 过滤，标量函数计算，常量等。
着重点：
1. 对于 snapshot 为 false 的默认场景，基本没有影响，验证pk 下的基本组合即可。
2. 对于 snapshot 为 true 的默认场景，不开放给用户，只给 taosx 使用，则只测试 taosx 的迁移场景 @霍琳贺 ，我可以协助测试，确定 taosx 使用的消费者配置，针对顺序乱序删除和更新数据验证。
