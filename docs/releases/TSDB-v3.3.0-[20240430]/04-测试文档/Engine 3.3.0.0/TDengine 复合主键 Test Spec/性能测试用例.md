##### 6.2 测试结论

1. 无乱序场景下，有 PK 和无 PK 列的写入性能及流计算性能相当；
2. 无乱序场景下，有 PK 列时内存消耗较多；
3. 乱序 50% 场景下，写入 QPS 下降了 33 %，因乱序带来大量重算，流的 latency 升高了 143%，CPU 资源占用有小幅上涨；
