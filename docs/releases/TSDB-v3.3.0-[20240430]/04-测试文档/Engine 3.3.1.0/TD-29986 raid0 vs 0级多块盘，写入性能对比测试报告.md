# TD-29986 raid0 vs 0级多块盘，写入性能对比测试报告

## 1. 测试目标

本次测试的目标是验证TDengine配置多个挂载点与raid0场景下，多种数据写入的性能、资源占用对比，找出多挂载点模式与raid0对比的性能差距瓶颈。

## 3. 测试结论

经测试，单节点软raid 0 与多挂载点写入速度在相同硬件配置，相同vgroup、schema、interlace值，raid 0在大多数情况下写入速度高于多挂载点20%左右，数据参考如下：


|  | Raid 0 | 多挂载点 |
| --- | --- | --- |
| VGgroup：16 Column：4 Interlace：1 | 16.16 MB/s | 12.27 MB/s |
| VGgroup：16 Column：4 Interlace：1000 | 29.49 MB/s | 27.26 MB/s |
| VGgroup：16 Column：100 Interlace：1 | 43.43 MB/s | 49.21 MB/s |
| VGgroup：16 Column：100 Interlace：1000 | 100.04 MB/s | 91.85 MB/s |
| VGgroup：32 Column：4 Interlace：1 | 19.63 MB/s | 11.92 MB/s |
| VGgroup：32 Column：4 Interlace：1000 | 23.68 MB/s | 16.62 MB/s |
| VGgroup：32 Column：100 Interlace：1 | 36.73 MB/s | 34.21 MB/s |
| VGgroup：32 Column：100 Interlace：1000 | 65.59 MB/s | 84.03 MB/s |

## 7. 测试范围及重点

本次测试的重点如下： {folded="true"}
1. 挂载点与RAID0配置磁盘分别为：1、2、4
2. 在不同磁盘数量配置下：宽表写入（100列）、窄表写入（4列）
3. 指定vgroups数量为16、32
按照以上测试点组合，即是本次测试范围
