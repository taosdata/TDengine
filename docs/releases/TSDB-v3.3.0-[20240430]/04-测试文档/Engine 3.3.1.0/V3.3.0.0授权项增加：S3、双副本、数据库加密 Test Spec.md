# V3.3.0.0授权项增加：S3、双副本、数据库加密 Test Spec

## 1. 测试目标

V3.3.0.0增加了新功能项，企业版授权相应增加了对新功能项（S3、双副本、数据库加密）的授权支持。
1. 保证taosd对新增功能项的授权完成
2. 在功能项授权过期时，保证taosd的功能项不受影响
3. 在基础授权过期时，taosd行为与授权失效保持一致

## 3. 测试结论

1. 新增功能S3存储、双副本、数据库加密已支持授权
2. S3存储默认授权时间为系统创建时间+10天，双副本和数据库加密在release模式下，默认授权关闭，只有授权后可正常使用
3. 基础功能未过期，S3存储授权过期后，S3对象上传会在taosd日志打印警告信息，客户端无授权过期提醒；双副本和数据库加密会在创建数据库时提示授权过期错误提示
4. 基础功能过期，S3存储、双副本、数据库加密功能授权过期，均提示授权过期错误
