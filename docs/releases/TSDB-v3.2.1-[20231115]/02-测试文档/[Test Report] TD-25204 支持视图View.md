# [Test Report] TD-25204 支持视图View

### 1. 概述：

视图设计文档：[支持视图](https://taosdata.feishu.cn/wiki/BqJGwWxUMiwXhpkHag2czjSwn2K) 
此次对视图功能的支持范围，参考如下：

| 类型 | 功能项 | 是否支持 | 备注 |
| --- | --- | --- | --- |
| 创建视图 | 是 |  |
| 更新视图 | 否 |  |
| 修改视图 | 否 |  |
| 查看视图 | 是 |  |
| 权限控制 | 是 | 由于视图写入功能暂不支持，写权限只能通过系统表判断 |
| 删除视图 | 是 |  |
| 创建视图 | 否 |  |
| 更新视图 | 否 |  |
| 修改视图 | 否 |  |
| 查看视图 | 否 |  |
| 刷新视图 | 否 |  |
| 权限控制 | 否 |  |
| 删除视图 | 否 |  |

此次视图使用场景范围，参考如下：

| 场景 | 是否支持 | 备注 |
| --- | --- | --- |
| SQL查询 | 是 |  |
| SQL写入 | 否 |  |
| STMT查询 | 否 |  |
| STMT写入 | 否 |  |
| 订阅 | 是 |  |
| 流计算 | 否 |  |

综上，此次视图测试范围包括非物化视图的创建、查看、删除及权限控制；使用场景包括SQL查询和数据订阅。
其中，权限控制部分的视图写权限只在物化视图中应用，暂不在此次测试范围。

Mem: DDR4 16GB* 16
