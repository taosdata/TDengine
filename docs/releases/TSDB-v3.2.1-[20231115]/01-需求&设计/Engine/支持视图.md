# 支持视图

## 1. 概念

从 TDengine 3.2.1.0 开始，TDengine **企业版**提供视图功能，便于用户简化操作，提升用户间的分享能力。

视图（View）本质上是一个存储在数据库中的查询语句。视图（非物化视图）本身不包含数据，只有在从视图读取数据时才动态执行视图所指定的查询语句。我们在创建视图时指定一个名称，然后可以像使用普通表一样对其进行查询等操作。视图的使用需遵循以下规则：
- 视图可以嵌套定义和使用，视图与创建时指定的或当前数据库绑定使用。
- 在同一个数据库内，视图名称不允许重名，视图名跟表名也推荐不重名（不强制）。当出现视图与表名重名时，写入、查询、授权、回收权限等操作优先使用同名表。
在视图满足一定的条件下，可以对视图进行 INSERT、UPDATE、DELETE 操作，这种视图称之为可更新视图。
用户也可以选择将视图进行物化，即将视图数据写入视图对应的存储表中，这种可以被物化的视图称之为物化视图。

## 2. 语法

### 2.1 创建（更新）视图

```plaintext
CREATE [ OR REPLACE ] VIEW [db_name.]view_name AS query
```

说明：
- 创建视图时可以指定视图绑定的数据库名（*db_name*），未明确指定时默认为当前连接绑定的数据库；
- 查询语句（*query*）中推荐指定数据库名，支持跨库视图，未指定时默认为与视图绑定的数据库(有可能非当前连接指定的数据库)；

### 2.2 查看视图

1. 查看某个数据库下的所有视图
```sql
SHOW [db_name.]VIEWS;
```

1. 查看视图的创建语句
```sql
SHOW CREATE VIEW [db_name.]view_name;
```

1. 查看视图列信息
```sql
DESCRIBE [db_name.]view_name;
```

1. 查看所有视图信息
```sql
SELECT ... FROM information_schema.ins_views;
```

### 2.3 修改视图

```plaintext
ALTER VIEW [ IF EXISTS ] view_name ALTER [ COLUMN ] column_name SET DEFAULT expression
ALTER VIEW [ IF EXISTS ] view_name ALTER [ COLUMN ] column_name DROP DEFAULT
```

### 2.4 删除视图

```c
DROP VIEW [IF EXISTS] [db_name.]view_name;
```

### 2.5 创建物化视图

```plaintext
CREATE MATERIALIZED VIEW [ IF NOT EXISTS ] view_name
    [ WITH ( create_table_parameter [= value] [, ... ] ) ]
    AS query
```

### 2.6 刷新物化视图

```plaintext
REFRESH MATERIALIZED VIEW view_name
```

### 2.7 修改物化视图

```plaintext
ALTER MATERIALIZED VIEW [ IF EXISTS ] view_name ALTER [ COLUMN ] column_name SET DEFAULT expression
ALTER MATERIALIZED VIEW [ IF EXISTS ] view_name ALTER [ COLUMN ] column_name DROP DEFAULT
```

### 2.8 删除物化视图

```c
DROP MATERIALIZED VIEW [IF EXISTS] view_name [, ...] [ CASCADE | RESTRICT ];
```

## 3. 系统表

增加 ins_views 系统表，非 sysinfo 表。

| 列名 | 数据类型 | 说明 |
| --- | --- | --- |
| view_name | BINARY(192) | 视图名称 |
| db_name | BINARY(64) | 视图所属数据库名 |
| effective_user | BINARY(24) | 视图有效用户名 |
| create_time | TIMESTAMP | 创建时间 |
| type | BINARY(128) | 视图类型（可更新、物化等） |
| query_sql | BINARY(2048) | 视图关联的SQL语句 |
| parameters | BIANRY(2048) | 建表参数 |
| default_values | BIANRY(2048) | 列默认值 |
| target_table | BINARY(192) | 可更新视图对应的输出表 |

## 4. 权限

### 4.1 说明

视图的权限分为 READ、WRITE、ALTER 三种，查询操作需要具备 READ 权限，写入操作需要具备 WRITE 权限，对视图本身的删改操作需要具备 ALTER 权限。

### 4.2 规则

- 视图的创建者和 root 用户默认具备所有权限。
- 对其他用户进行授权与回收权限可以通过 GRANT 和 REVOKE 语句进行，该操作只能由 root 用户进行。
- 视图权限需单独授权与回收，通过db.*进行的授权与回收不含视图权限。
- 视图可以嵌套定义与使用，同理对视图权限的校验也是递归进行的。
- 为了方便视图的分享与使用，引入视图有效用户（即视图的创建用户）的概念，被授权用户可以使用视图有效用户的库、表及嵌套视图的读写权限。注：视图被 REPLACE 后有效用户也会被更新。

具体相关权限控制细则总结如下：

| 序号 | 操作 | 权限要求 |
| --- | --- | --- |
| 1 | CREATE OR REPLACE VIEW （创建新视图） | 用户对视图所属数据库有 WRITE 权限 **且** 用户对视图的目标库、表、视图有查询权限，若查询中的对象是视图需满足当前表中第8条规则 |
| 2 | CREATE OR REPLACE VIEW （覆盖旧视图） | 用户对视图所属数据库有 WRITE 权限 且 对旧有视图有 ALTER 权限 **且** 用户对视图的目标库、表、视图有查询权限，若查询中的对象是视图需满足当前表中第8条规则 |
| 3 | DROP VIEW | 用户对视图有 ALTER 权限 |
| 4 | SHOW VIEWS | 无 |
| 5 | SHOW CREATE VIEW | 无 |
| 6 | DESCRIBE VIEW | 无 |
| 7 | 系统表查询 | 无 |
| 8 | SELECT FROM VIEW | 操作用户对视图有 READ 权限 **且** 操作用户或视图有效用户对视图的目标库、表、视图有 READ 权限 |
| 9 | INSERT INTO VIEW | 操作用户对视图有 WRITE 权限 **且** 操作用户或视图有效用户对视图的目标库、表、视图有 WRITE 权限 |
| 10 | GRANT/REVOKE | 只有 root 用户有权限 |

### 4.3 语法

#### 4.3.1 授权

```sql
GRANT privileges ON [db_name.]view_name TO user_name
privileges: {
    ALL,
  | priv_type [, priv_type] ...
}
priv_type: {
    READ
  | WRITE
  | ALTER
}
```


#### 4.3.2 回收权限

```sql
REVOKE privileges ON [db_name.]view_name FROM user_name
privileges: {
    ALL,
  | priv_type [, priv_type] ...
}
priv_type: {
    READ
  | WRITE
  | ALTER
}
```

提示：
- 按照规则说明，通过dbname.*进行授权与回收权限时，数据库下的视图**不会**被授权与回收权限；

## 6. 举例

- 创建视图
```c
CREATE VIEW view1 AS SELECT _wstart, count(*) FROM table1 INTERVAL(1d);
CREATE VIEW view2 AS SELECT ts, col2 FROM table1;
CREATE VIEW view3 AS SELECT * from view1;
```

- 查看视图
```c
SHOW VIEWS；
```

- 查询数据
```c
SELECT * from view1;
```

- 写入（更新）数据
```c
INSERT INTO view2 values (now, 1);
```

- 删除数据
```c
DELTE FROM view2 WHERE ts > 0;
```
