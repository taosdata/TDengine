## 2. 背景

在 TDengine 集群的多副本架构中，当 leader 向 follower 发送快照数据时，若多个 vgroup 同时进行快照复制，磁盘写入量叠加会在 follower 节点产生严重的 IO 瓶颈，影响正常业务的读写性能。

本特性引入 dnode 级别的快照发送限速机制，通过全局带宽控制，避免快照复制过程对系统正常 IO 造成过大冲击。

## 3. 定义

| 术语 | 定义 |
|------|------|
| Snapshot（快照） | 当 follower 的 WAL 落后过多时，leader 将完整数据以快照形式发送给 follower 进行数据追赶 |
| Token Bucket（令牌桶） | 一种经典的限速算法，通过令牌的产生和消耗来控制流量速率 |
| dnode | TDengine 集群中的物理节点进程 |
| vgroup | 虚拟数据分片组，包含 leader 和 follower 副本 |

## 4. 行为说明

### 4.1 新增配置参数

引入服务端配置参数 `snapshotRateLimit`：

| 属性 | 值 |
|------|-----|
| 参数名 | `snapshotRateLimit` |
| 类型 | int32_t |
| 单位 | MB/s |
| 默认值 | 0（不限速） |
| 有效范围 | 0 ~ 10240 |
| 作用域 | 服务端 |
| 动态修改 | 支持，立即生效 |

### 4.2 SQL 示例

```sql
-- 设置单个 dnode 快照限速为 50 MB/s
ALTER DNODE 1 'snapshotRateLimit' '50';

-- 设置所有 dnode 快照限速为 50 MB/s
ALTER ALL DNODES 'snapshotRateLimit' '50';

-- 取消限速（恢复不限速）
ALTER ALL DNODES 'snapshotRateLimit' '0';
```

### 4.3 行为规则

- 当 `snapshotRateLimit = 0` 时，不进行任何限速，行为与功能引入前完全一致
- 限速作用于 **发送端（leader）**，每个 dnode 独立控制自身的快照发送总带宽
- 当令牌耗尽时，发送端不阻塞，而是退出本轮发送循环，等待 follower 的 ack 触发下一轮发送
- 快照重传（resend）不受限速影响，以确保丢包恢复不被限流
- 限速精度为 block 粒度，实际吞吐量与配置值的偏差在 ±1 个 block 以内

### 4.4 出错处理

- 参数值超出范围（<0 或 >1024）：`ALTER DNODE` 返回参数错误
- 参数类型错误：`ALTER DNODE` 返回参数错误
- 限速不影响快照复制的正确性，仅影响速度

## 5. 性能

- 当 `snapshotRateLimit = 0`（默认）时，不引入任何额外开销，`TryConsume` 直接返回 true，`Deduct` 为空操作
- 当限速启用时，快照发送速度被控制在指定带宽内，降低了对业务 IO 的干扰
- 对正常的 Raft 协议消息处理无影响（非阻塞设计）

## 6. 安全

无特殊安全考量。`ALTER DNODE` 需要管理员权限（root/管理员账号），符合现有权限模型。

## 7. 兼容性

- 完全向后兼容。默认值 `0` 表示不限速，与未引入此功能前的行为一致
- 不涉及通信协议变更
- 不涉及数据格式变更

## 8. 运维

- 运维人员可在快照复制导致 IO 压力过大时，动态设置限速值缓解压力
- 建议在大规模扩容（添加新 dnode 触发大量快照）前预设合理的限速值
- 恢复正常后可随时设置为 0 取消限速

## 9. 使用场景

### 场景 1：集群扩容

新增 dnode 加入集群后，多个 vgroup 的 leader 同时向新节点发送快照。此时设置 `snapshotRateLimit` 可避免新节点磁盘 IO 被打满。

### 场景 2：节点故障恢复

某节点宕机恢复后，多个 vgroup 需要通过快照追赶数据。限速可保护该节点的 IO 不被集中的快照写入耗尽。

### 场景 3：混合部署环境

当 TDengine 与其他服务共享磁盘 IO 时，通过限速避免快照复制影响其他服务的性能。

## 10. 约束和限制

**约束**：
- 限速仅作用于快照发送，不影响正常数据写入和查询的 IO

**限制**：
- 限速精度为 block 粒度，无法精确到字节级
- 限速为单 dnode 粒度，无法实现集群级别的全局统一限速调度

## 11. 常见错误和排查

| 现象 | 可能原因 | 排查方法 |
|------|---------|---------|
| 设置限速后快照复制明显变慢 | 正常行为 | 确认限速值是否设置过低 |
| 设置限速后仍有 IO 瓶颈 | 限速值设置过高，或 IO 压力来源非快照 | 通过 IO 监控确认压力来源 |
| ALTER DNODE 报错 | 参数值超范围或类型错误 | 检查参数值是否在 0~10240 范围内 |

## 12. 可观测性

- 首次触发限速时输出日志：`snapshot rate limited, current rate: %d MB/s`
- 不逐 block 记录日志，避免日志洪泛
- 对 taos shell、taos Explorer、TDinsight 无影响

## 13. 安装和卸载

无特殊要求。参数随 TDengine 服务端升级自动可用，无需额外安装步骤。
