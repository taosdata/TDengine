### 3. 分析报告

本特性将 MCP 传输层从仅支持 Streamable HTTP 扩展为同时支持 SSE（Server-Sent Events）。SSE 是单向服务端推送协议，安全风险主要集中在连接资源管理和事件流内容保护。

核心发现：共识别出 `4` 个潜在威胁，其中 `中危` `2` 个，`低危` `2` 个。

### 4. 威胁识别与分析（STRIDE）

#### 4.1 威胁评估

| 威胁ID | 威胁描述/攻击场景 | STRIDE | 风险等级 |
| --- | --- | --- | --- |
| T-MCPSSE-01 | 攻击者大量并发建立 SSE 连接但不消费事件，导致服务端连接池耗尽 | D（拒绝服务） | 中 |
| T-MCPSSE-02 | SSE 事件流中包含敏感数据（如查询结果），未授权客户端通过窃听获取 | I（信息泄露） | 中 |
| T-MCPSSE-03 | SSE 连接超时设置不当，长期空闲连接占用服务端资源 | D（拒绝服务） | 低 |
| T-MCPSSE-04 | SSE 事件流中的事件 ID 或 data 字段被恶意注入，可能导致客户端解析异常 | T（篡改） | 低 |
