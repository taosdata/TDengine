> 本内容为 TDengine 安全功能演示，适合于安可/等保认证的演示操作。

## 前置条件

> 演示开始前由 **root** 执行以下命令，统一创建共用资源。各演示项目直接引用，不再重复创建。

1. **确认服务状态**

```Bash
systemctl status taosd taoskeeper taosadapter   # 三项服务均应为 active
taos -u root -ptaosdata                          # 确认默认密码可登录
```

2. **创建业务演示库及样本数据**

> 供访问控制（T025/T026）、数据安全（T036）、备份恢复（T037/T038）、漏洞扫描（T031）共用。

```SQL
create database power keep 3650d;
create stable power.meters (ts timestamp, voltage int, current float) tags (location nchar(64));

insert into power.d_bj using power.meters tags ('beijing')
  values ('2025-01-10 10:00:00', 220, 1.5)
         ('2025-01-10 10:01:00', 221, 1.6)
         ('2025-01-20 08:00:00', 219, 1.4);

insert into power.d_sh using power.meters tags ('shanghai')
  values ('2025-01-10 10:00:00', 218, 1.3)
         ('2025-01-10 10:01:00', 217, 1.2);
```

3. **创建演示用户**

> 以下用户供多个演示项目共用，统一提前创建。

```SQL
create user demo_user pass 'abcd@1234';
create user analyst1  pass 'abcd@1234';
create user old_user  pass 'abcd@1234';
create user biz_user  pass 'abcd@1234';
```
