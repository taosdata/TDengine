# 数据迁移支持矩阵

数据迁移目标端： TDengine 3.0.4.0 或以上

| 数据源 | 版本 | taosExplorer taosX （针对企业版用户） | 云服务 （针对云服务用户） |
| --- | --- | --- | --- |
| TDengine 3.x | 3.0.4.0 及以上 | 1.1.0 或以上 | 用户可以自助进行，3.0.6已经测试可以，但是迁移时间过长（7亿行，需要15天以上） |
| TDengine 2.x | 2.4.0.10 以上，2.6（测试中） | 1.1.0 或以上 | 用户可以自助进行 |
| InfluxDB | 1.7，1.8，2.0-2.7，InfluxDB Cloud（测试中） | 1.1.0 或以上 | 用户可以自助进行 |
| OPC UA | OPC-UA Schema v1.05.02-2022-11-01 Supported Platform（OPC-UA servers）：https://github.com/gopcua/opcua#tested-platforms | 1.1.0 或以上 | 用户可以自助进行 |
| OPC DA | OPC DA Automation Wrapper 2.02 | 1.1.0 或以上 | 用户可以自助进行 |
| Pi | Requires AF SDK 2.10 | 1.1.0 或以上 | 用户可以自助进行 |
| MQTT | 3.1 / 3.1.1 / 5.0 | 1.1.0 或以上 | 用户可以自助进行 |
| Kafka | 0.8.2 及以上，0.9.0 及以上 | 1.1.0 或以上 | 暂不支持自助 |
| CSV | 无版本 | 1.1.0 或以上 | 不支持 |
| OpenTSDB | 待定，开发进行中 | 1.2.0 或以上 | 不支持 |
| ClickHouse | 待定，开发进行中 | 1.2.0 或以上 | 不支持 |
| AVEVA Historian | 2020 RS SP1 | 1.3.0 或以上 | 暂不支持自助 |

注： taosX/taos-Explorer 已发布最新版本为 1.1.0
