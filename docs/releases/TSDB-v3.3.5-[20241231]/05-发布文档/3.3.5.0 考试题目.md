# 3.3.5.0 考试题目

#### 1. 第一部分，笔试题目，所有人回答

1. 说明 TDgpt 的技术特点
2. 举例说明 TDengine 和那些国产化操作系统做过适配
3. 什么是流计算的 Force Window Close 模式，常用于什么场景
4. 简要描述 Last 数据缓存的技术特点
5. 为什么需要 compact
6. Flink 连接器支持那些功能？
7. taosX 跨网闸数据同步使用什么方案实现？
8. CSV 文件目录监听适用于什么场景？

#### 2. 第二部分，笔试题目，售前交付回答

1. 以智能电表数据模型为例，编写 SQL 语句，使用 arima 算法进行预测，每 10 个采样点是一个周期，返回置信区间是 95% 的上下边界
2. 以智能电表数据模型为例，编写 SQL 语句，使用 iqr 算法进行异常检测，寻找电流值的异常窗口
3. 以智能电表数据模型为例，编写 SQL 语句，创建一个 **Force Window Close 的流计算，计算 5 分钟的断面电压**
4. 说明如下四个参数的含义：queryUseMemoryPool、minReservedMemorySize、singleQueryMaxMemorySize、queryNoFetchTimeoutSec
5. 说明 Interval 语句中，auto 关键字的含义
6. 说明 Interp 函数中，有几种填充模式，解释其含义
7. 客户端连接支持哪几种选项
8. 编写 SQL 语句，获取某 DB 的时序数据占用空间、WAL 占用空间、压缩比
9. taosX MQTT 解析支持那些压缩算法 
10. JDBC 连接器参数绑定在哪种场景下的性能得到了提升
11. 新增了哪个 BI 工具的支持

#### 3. 第三部分，实操题目，售前交付回答

1. 使用 taosBenchmark 默认数据模型（智能电表）写入 1 万张子表，每表 1 万条数据，采样频率 1Hz 。
2. 部署 SuperSet（使用 WebSocket 连接）并展示如下数据：
   - 使用 Line Chart 展示 `d1` 子表的每分钟平均电压（`voltage`）。
   - 使用 Table 展示前 1000 条时序电流（current）电压(voltage) 值。
3. 安装 TDgpt，使用 arima 算法预测 `d1` 子表的未来 100 秒的电压
4. 通过 SQL 统计磁盘空间和压缩比
5. 执行 compact，观察 compact 的执行进度
6. 通过 SQL 统计 compact 之后的磁盘空间和压缩比
