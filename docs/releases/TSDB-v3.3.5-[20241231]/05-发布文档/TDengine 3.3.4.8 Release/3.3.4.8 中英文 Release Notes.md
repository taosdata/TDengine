# 3.3.4.8 中英文 Release Notes

### 1. 中文

```markdown

### 2. 新特性

### 3. 优化

1. TD-30934 优化：提升 TSBS 测试的查询性能
2. TS-5450 优化：支持同时修改单个子表的多个标签值
3. TD-32913 优化：taosBenchmark WebSocket 版本支持写入线程绑定VGROUP 写入功能
4. TD-32998 优化：优化状态窗口的错误码
5. TS-5677 优化：取消窗口查询必须使用聚合函数的限制

### 4. 修复

1. TS-5656 修复：Explorer Node.js 示例代码修复
2. TD-32863 修复：WAL 未分布到多个 0 级挂载点的问题
3. TS-5645 修复：流计算异常退出可能导致死锁
4. TD-32735 fix(taosX): OPC CSV 点位配置 enabled=0 时需要转义的table drop 失败
5. TD-32824 修复：修改 WAL_level 时 WAL 文件读取失败的问题
6. TD-32831 修复：创建流计算节点时的死锁问题
7. TD-32838 修复：副本快照同步时的 race condition.
8. TD-32855 修复：升级到 3.3.4.3 后 Percentile 函数性能下降的问题
9. TD-32860 修复：系统表 ins_dnode_variables 中的 dataDir 信息不完整问题
10. TD-32861 修复：WHERE 条件在 INTERP 函数中不生效的问题
11. TD-32942 修复：流计算 force window close 模式下重启失败的问题
12. TD-32943 修复：包含 ”GROUP BY“ 常量的 SQL 语句会报语法解析错误
13. TD-32967 修复： OPC-DA 连接检查报 NOCONFIG 错误
14. TD-32999 修复：流计算在 force_window_close 模式下未按指定规则生成子表名
15. TD-33048 修复：在特定场景下，schemaless 写入模式中出现的“schema is old”问题
16. TS-5628 修复：在弱网下可能出现订阅数据部分缺失
17. TS-5580 修复：通过标签过滤子表时数目不正确的问题（可能导致 taosdump crash）
18. TS-5669 修复：打开 RPC 压缩时单个 dnode 重启可能导致集群状态异常
19. TS-5683 修复：Grafana 使用 CASE WHEN 配置告警结果不符合预期
20. TS-5630 修复：频繁执行 union 查询时可能出现的 crash
21. TS-5679 修复：订阅参数 enable.auto.commit=false 不生效


```

### 5. English

```markdown

### 6. New Features

### 7. Optimizations

1. TD-30934 enh: improve the query performance of TSBS.
2. TS-5450 enh: support alter multiple tag values of a single child table at the same time.
3. TD-32913 enh: taosBenchmark WebSocket version supports writing thread binding VGROUP writing
4. TD-32998 enh: optimize the error code of the status window.
5. TS-5677 enh: remove the restriction that window query must include aggregate functions.

### 8. Fixed issues

1. TS-5656 fix: use websocket in node.js example of explorer
2. TD-32863 fix: the problem that WAL is not distributed to multiple level-0 mount points.
3. TS-5645 fix: abnormal exit of stream computing may lead to a deadlock.
4. TD-32735 fix(taosX): fix drop table unexpected error when point set enable=0 in opc csv
5. TD-32824 fix: failed to read WAL file when alter WAL_level from 0 to 2.
6. TD-32831 fix: deadlock when create snode.
7. TD-32838 fix: The race condition during replica snapshot synchronization.
8. TD-32855 fix: the performance degradation of the percentile function after upgrading to 3.3.4.3.
9. TD-32860 fix: the info of dataDir in ins_dnode_variables is incomplete.
10. TD-32861 fix: WHERE condition not work in statements with INTERP function
11. TD-32942 fix: taosd restart failed while use force window close mode in stream computing.
12. TD-32943 Fix: SQL statements containing “GROUP BY constants” will report “Executor internal error”.
13. TD-32967 fix: fix OPC-DA connection incorrect NOCONFIG error
14. TD-32999 fix: in force_window_close mode, the stream computing fails to generate the sub-table names according to the specified rules.
15. TD-33048 fix: 'schema is old' occurring in schemaless write mode under specific scenarios.
16. TS-5628 fix: taosX sync with subscription may lost messages in websocket
17. TS-5580 fix: incorrect sub-table count when filtering by tags (which may cause taosdump crash).
18. TS-5669 fix: restart a single dnode when RPC compression is enabled may lead to an abnormal cluster state.
19. TS-5683 fix: unexpected Grafana alerting with CASE WHEN
20. TS-5630 fix: taosd may crash when performing UNION queries frequently.
21. TS-5679 fix: subscribe with enable.auto.commit=false not work as expected


```
