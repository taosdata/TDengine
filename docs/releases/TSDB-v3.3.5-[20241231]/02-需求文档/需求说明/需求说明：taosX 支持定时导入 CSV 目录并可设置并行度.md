# 需求说明：taosX 支持定时导入 CSV 目录并可设置并行度

TS-5088

## 一、需求背景

taos-explorer 已经支持 CSV 导入功能，现状
1. taos-explorer 界面上，点击“上传”按钮上传一个 CSV 文件，创建数据写入任务导入该文件的数据
2. 通过其他方式（例如命令行），将多个文件上传到 taosX server 所在服务器，将目录在 taos-explorer 界面中登记，随后 taosX 服务遍历目录下的所有 CSV 文件，批量同步数据
对于第二点，有如下缺失
1. 当目录下的文件不断变化时，不能将 taosX 配置成永不停止任务
2. 无法配置 taosX 并发度，意味着 taosX 只有一个线程（或进程）

##  二、需求目标

1. 提供 watchType 选项，taosX 定期（每 interval 毫秒）监控目录中的新数据文件，或者处理一次当前路径中的数据文件然后退出
2. 支持 taosX 的并发度配置，存在两种并发类型
   - 并发类型一：单线程依次读取所有 CSV 文件，读取后的数据分发到多个写线程，适用于设备数据混在一个文件的场景
   - 并发类型二：多线程并发读取多个 CSV 文件，读取和写入在同一线程，适用于不同设备数据分布在不同文件的场景
在底层，taosX 将文件读取过程拆分为两个子任务，即目录监控和数据处理。目录监控由单个非并行（并行度 = 1）任务实现，而数据处理由多个并行运行的任务执行。
1. 目录监控任务的作用是扫描目录
   - 支持通配符或者类似方式，过滤文件名并找到要处理的文件，分配到不同的数据处理任务中
   - 对于分配给同一个数据处理任务中的多个文件，支持文件排序规则，配置文件处理的先后顺序
   - 分配数据文件时，底层要检测文件是否正在被打开，避免处理不完整的文件
2. 数据处理任务包括读取和写入两个子任务，读取和写入各自配置并行度，文件处理结束后，有几种方式
   - 移动处理过的文件到另外一个目录中
   - 删除处理过的文件
   - 重命名处理过的文件
需要支持可观测项，查看历史处理过的文件、起始时间、记录数目、导入速度等。
