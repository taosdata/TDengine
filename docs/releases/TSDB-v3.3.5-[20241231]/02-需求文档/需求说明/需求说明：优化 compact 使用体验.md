# 需求说明：优化 compact 使用体验

## 一、需求背景

在 [TDengine 可运维观测需求](https://taosdata.feishu.cn/wiki/OrX7woLVbiGy0ekld25c141VnPf) 中的第 8、9、10、11 项中，李珲对数据整理功能提出了改进要求，且得到了 Jeff、Wade、洪泽等参会人员的认可。本文对现有数据整理功能进行体验的基础上，提出改进需求。

## 二、需求概述

数据整理功能，将存储的数据文件进行整理，删除文件空洞和无效数据，提高数据的组织度，从而提高存储和查询的效率，语法如下
```sql
COMPACT DATABASE db_name [start with 'XXXX'] [end with 'YYYY']； 

SHOW COMPACTS [compact_id]；

KILL COMPACT compact_id；
```

用 taosBenchmark 创建 db 并写入一些数据，对其执行数据整理操作
```sql
taos> compact database db;
              result              |     id      |             reason             |
==================================================================================
 accepted                         |  2096110110 | success                        |
Query OK, 1 row(s) in set (0.008201s)

taos> show compacts;
 compact_id  |            db_name             |       start_time        |
=========================================================================
  2096110110 | db                             | 2024-06-06 18:57:20.410 |
Query OK, 1 row(s) in set (0.003425s)
```

从以上输出可以看到，数据整理存在如下用户体验问题，需进行优化改进
1. 数据整理前，无法获取是否需要重整的基础信息
2. 数据整理过程中，无法观测已经执行的时长、已经完成百分比、预估执行结束的时间
3. 数据整理过程中，以 dnode 的最大能力进行，没有流量控制
4. 数据整理只能细化到时间段，不能细化到特定 VGroup
5. 不能指定任务启动时间
6. 不能定期执行任务

## 三、需求描述

#### 1. 调整重整语法

建议语法
```sql
compact database db 
    start with '2020-01-01 00:00:00.000' end with '2020-01-20 00:00:00.000' 
    exec at '2024-06-11 00:00:00.000'
    speed 10

compact vgroups [3, 4] 
    exec at '08:00' after 3d 
    speed 10
    
```

语法说明
1. database：指定数据库名称
2. start with：开始时间
3. end with： 结束时间
4. **新增 vgroups：指定虚拟节点组列表**
5. **新增 exec at：任务定期执行时间，未设定此值时，任务立刻执行**
6. **新增 after：文件组结束的几天后定期执行**
   - **设定了 after 时，exec at 后为一天内的某个时刻**
   - **未设定 after 时，exec at 后为绝对时间点**
7. **新增 speed：最大磁盘读取速度，单位为 MB**
主要逻辑
1. 参数 database 和 vgroups 二选一
2. 通过限制每个 dnode 的最大磁盘读取速度，达到限速的目的
3. 基于开始、结束的时间，寻找所有的数据文件组
4. 通过 exec at 和 after 的设定，决定任务在固定时间执行，或者在每个文件组结束后的特定时间点执行

#### 2. 查看重整任务

语法不变，调整输出信息
```sql
taos> show compacts; 

 compact_id  | vgroups | database | exec at | after | status     | speed | created_time            | 
=====================================================================================================
  2096110110 | 2,3     | d1       | 8:00    | 3d     | scheduling | 10MB  | 2020-01-01 00:00:00.000 |

Query OK, 1 row(s) in set (0.003425s)
```

#### 3. 删除重整任务

语法不变
1. 如果任务正在执行，停止任务
2. 如果任务未到定期执行时间，删除任务

#### 4. 预览数据分布

建议语法
```sql
preview compact vgroups [2, 3] start with 'x' end with 'x'
preview compact database d1 start with 'x' end with 'x'
```

语法说明
1. preview：表示这是一个预览命令，可用其他关键字代替
输出结果
1. VGroup 编号、数据库名称
2. 文件编号、文件大小、文件起始时间
3. 碎片化程度：低、中、高、完美
4. 文件中的所有记录条数、被删除的记录条数、被更新的记录条数
5. 文件中 block 数量、每个 block 记录条数的平均值、每个 block 记录条数的中位数
6. 文件中的数据乱序情况（例如存在时间交织的 block 比例）

#### 5. 查看重整进度

建议语法，输出如下信息
1. VGroup 编号、数据库名称
2. 文件编号、文件起始时间
3. 当前执行状态：正在运行、已经结束、尚未开始
4. 当前进度：百分比（按照已处理的 block 数目估算）
5. 任务开始时间、预期结束时间、已经执行的时长
6. 重整前 Block 总数、已经被重整的 Block 数目
7. 重整前文件大小、已经被重整的 Block 占用的磁盘大小
```sql
show compacts 2096110110 progress;
```
