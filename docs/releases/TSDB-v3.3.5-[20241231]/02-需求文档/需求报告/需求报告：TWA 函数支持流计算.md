# 需求报告：TWA 函数支持流计算

## 1. 需求描述

目前电力行业 SCADA 场景中，需要经常计算发电量、耗电量，一般都是基于瞬时功率对时间求积分。
河北电力调度中心期望在其新一代调度云中，在 SCADA 场景利用 TDengine 中的 twa 时间加权函数实现该功能。
因 twa 函数目前尚不支持流计算，需要研发进行开发。

### 1.1 需求说明与示例

#### 1.1.1 业务场景描述

一区 EMS/SCADA 中，每隔 10 秒的固定间隔，对超级表符合条件的子表，利用 twa 函数瞬时功率分组计算发电量，然后将计算后的结果累计至日、月、年的结果子表中存储

#### 1.1.2 需求说明

1. 支持标签列筛选符合条件的子表
2. 支持新建子表动态加入流计算，一旦子表符合筛选条件，立即加入运行中的流计算
3. 固定时间间隔进行积分计算(河北电力的时间跨度为 10 秒)，结果更新到流计算结果表中（日、月、年累计表）
4. 支持 FILL HISTORY 选项

#### 1.1.3 补充行为说明

1. 流计算开启后，从 T 时刻开始，每间隔固定时间（10 秒）都应更新结果表
   - FILL HISTORY 开启时，T 为表中第一条记录写入时间
   - FILL HISTORY 关闭时，T 为表中第一条记录写入时间和流计算创建时间的最晚值
2. 即便没有写入事件，须按时触发计算，与 2.x 的连续计算 interval/sliding 行为一样

#### 1.1.4 示例

```sql {wrap}
create stream s2 into stable_2 as
select _wstart,twa(power) from source where tag1 in('y1','a2') partition by tbname interval(10s)
```
