## 3. 测试范围

V1 仅包含以下内容：
1. 检查主键时间戳溢出：溢出时可选择归档、丢弃、报错
2. 检查主键时间戳空：空时可选择归档、丢弃、报错、使用当前时间
3. 检查子表表名长度溢出：溢出时可选择归档、丢弃、报错、截断、截断且归档
4. 检查子表表名包含非法字符：包含非法字符时可选择：归档、丢弃、报错、非法字符替换为指定字符串
5. 检查子表表名模板变量空值：变量空值时可选择丢弃、留空、变量替换为指定字符串 
6. 检查列名长度溢出：溢出时可选择归档、丢弃、报错
