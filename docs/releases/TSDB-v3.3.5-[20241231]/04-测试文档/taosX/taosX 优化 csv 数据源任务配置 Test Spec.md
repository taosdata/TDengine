# taosX 优化 csv 数据源任务配置 Test Spec

## 1. 测试目标

验证 CSV 数据源任务的功能项满足 FS 优化的设计。

## 3. 测试范围

- 创建任务时的参数变化
  - CSV 文件上传：上传多个文件、选择是否保留已处理完成的文件
  - CSV 目录配置：支持匹配模式、监听目录、监听间隔、文件排序
- 查看任务详情页面的变化
- 查看运行指标
  - 累计指标：增加 total_csv_files、total_csv_files_completed、total_csv_files_completed_rows 三个指标
  - 本次运行：增加 csv_files、csv_files_completed、csv_files_completed_rows 三个指标
- 新增断点文件
- 编辑任务与复制任务的相应修改
