## 4. 行为说明

### 4.1 新增记录内容

Audit 记录如下操作：
delete from stable where
delete from table where
实际所记录的是删除数据的 SQL ，不会记录所涉及的数据。

在现有的 audit 库中 operations 表（该表schema保持不变）里，会记录 delete 操作的如下信息：
- timestamp
- Username
- clientIP
- clusterId
- operation（在本场景中只有一个取值“delete”）
- Dbname
- TableName
- sql

### 4.2 配置

- dnode：增加开关 enableAuditDelete，在删除数据的频次太高导致性能问题时，可以临时关闭，默认值是 true。
- taosc：从服务端获取配置 enableAuditDelete，如果为 true 则向 mnode 发送 DELETE 操作的相关信息，如果 false 则不发送

### 4.3 发送方式

taosd 采用异步批量发送，发送频率与 create table 和 drop table 这2个已存在的audit操作相同。

## 15. 附录

### 15.1 实现方式

客户端将删除数据的sql，传给mnode，mnode将客户端消息，转换成json消息，转发给taoskeeper。

json消息格式与之前的消息格式保持不变，故taoskeeper,taosExplorer等下游组件无需改动。

### 15.2 消息定义

新增客户端到mnode的消息
- 消息名称：
TD_DEF_MSG_TYPE(TDMT_MND_AUDIT, "audit", NULL, NULL)
- 消息体：
typedef struct {
  char    db[TSDB_DB_FNAME_LEN];
  char    table[TSDB_TABLE_NAME_LEN];
  char    operation[AUDIT_OPERATION_LEN];
  int32_t sqlLen;
  char*   pSql;
} SAuditReq;
int32_t tSerializeSAuditReq(void* buf, int32_t bufLen, SAuditReq* pReq);
int32_t tDeserializeSAuditReq(void* buf, int32_t bufLen, SAuditReq* pReq);
void    tFreeSAuditReq(SAuditReq* pReq);

- 消息体注释：
operation：delete，目前为该固定值，为以后扩展预留
db：database name
table：超级表名或者子表名
pSql:删除数据的原始sql语句，最大长度65472
sqlLen：sql语句的长度
