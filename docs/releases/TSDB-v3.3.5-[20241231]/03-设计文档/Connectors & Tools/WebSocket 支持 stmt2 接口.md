## 3. 定义

stmt2 API: 预处理语句版本 2 API。

## 4. 行为说明

JSON 总请求格式

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| action | string | 请求动作 |
| args | []byte | 具体请求内容 |

以下各章节的 JSON 请求内容均为 args 内容

### 4.1 创建 stmt 实例

对应 taos_stmt2_init, JSON 格式

#### 4.1.1 请求

Action：stmt2_init

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| req_id | uint64 | 请求 ID |
| single_stb_insert | bool | 单个 stmt 实例只有单个超级表写入 |
| single_table_bind_once | bool | 单个子表在单次执行中只有一次数据绑定； |

#### 4.1.2 返回

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 错误码 |
| message | string | 错误信息 |
| action | string | stmt2_init |
| req_id | uint64 | 请求ID |
| timing | int64 | 执行时间 |
| stmt_id | uint64 | stmt实例ID |

#### 4.1.3 样例

请求
```go
{
        "action": "stmt2_init",
        "args": {
                "req_id": 291,
                "single_stb_insert": false,
                "single_table_bind_once": false
        }
}
```

返回
```go
{
        "code": 0,
        "message": "",
        "action": "stmt2_init",
        "req_id": 291,
        "timing": 984460,
        "stmt_id": 1
}
```

### 4.2 绑定 sql

对应 taos_stmt2_prepare，JSON 格式

#### 4.2.1 请求

Action：stmt2_prepare

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| req_id | uint64 | 请求 ID |
| stmt_id | uint64 | stmt 实例 id |
| sql | string | 绑定语句 |
| get_fields | bool | 是否返回绑定信息 |

#### 4.2.2 返回

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 错误码 |
| message | string | 错误信息 |
| action | string | stmt2_prepare |
| req_id | uint64 | 请求ID |
| timing | int64 | 执行时间 |
| stmt_id | uint64 | stmt实例ID |
| is_insert | bool | 是否为插入语句 |
| fields | jsonarray | 属性（可能为 null，get_fiedls 为 false 此字段为 null） |
| fields_count | int | 数量（查询使用,get_fiedls 为 false 此字段无效） |

字段属性

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 名称 |
| field_type | int8 | 类型 |
| precision | uint8 | 精度 |
| scale | uint8 | 有效位数(未使用) |
| bytes | int32 | 大小 |
| bind_type | int8 | 绑定类型 列* *= 1, 标签 = 2, 表名 = 4 |

#### 4.2.3 样例

请求
```json
{
        "action": "stmt2_prepare",
        "args": {
                "req_id": 3,
                "stmt_id": 1,
                "sql": "insert into ct1 using test_ws_stmt2_ws.stb tags (?) values (?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)".
                "get_fields": false
        }
}
```

返回
```json
{
        "code": 0,
        "message": "",
        "action": "stmt2_prepare",
        "req_id": 3,
        "timing": 487147,
        "stmt_id": 1,
        "is_insert": true,
        "fields": null,
        "fields_count": 0
}
```

### 4.6 绑定数据

对应 taos_stmt2_bind_param，**此接口使用二进制格式请求，返回 JSON 格式**

#### 4.6.1 请求

Action：**9**
固定 header

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| req_id | uint64 | 请求 id |
| stmt_id | uint64 | stmt实例id |
| action | uint64 | 操作id |
| version | uint16 | 协议版本 1 |
| col_idx | int32 | 列号，全绑定传 -1 |

数据内容

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| TotalLength | uint32 | 数据内容的全部长度,包括 TotalLength 字段长度 |
| TableCount | int32 | 多少个数据（对应 TAOS_STMT2_BINDV 中 count） |
| TagCount | int32 | 需要绑定多少个标签（sql 中 tag 有多少个问号） |
| ColCount | int32 | 需要绑定多少个列（sql 中列有多少个问号） |
| TableNamesOffset | uint32 | 表名的偏移量（基于数据内容开始）,如果没有则为 0 |
| TagsOffset | uint32 | tag 的偏移量，如果没有 tag 则为 0 |
| ColsOffset | uint32 | 列的偏移量，如果没有列则为 0 |
| TableNameLength | [tableCount]uint16 | 每个表名的长度包含'\0' 长度，最大长度 db+tbname+\0 = 64 + 192 + 1 = 257，如果 TableNamesOffset 为 0 则没有此项 |
| TableNameBuffer | []byte | 表名的二进制数据包含'\0'，如果 TableNamesOffset 为 0 则没有此项 |
| TagsDataLength | [tableCount]uint32 | 标签数据的长度, Count 个元素, 每个元素为一张表 tag 数据的长度，如果某个表不绑定 tag 则对应的 length 为 0 ，如果 TagsOffset 为 0 则没有此项 |
| TagsBuffer | []byte | 标签数据，格式见下表，如果 TagsOffset 为 0 则没有此项 |
| ColDataLength | [tableCount]uint32 | 列数据的长度, Count 个元素, 每个元素为一张表列数据的长度，如果某个表不绑定列则对应的 length 为 0 ，如果 ColsOffset 为 0 则没有此项 |
| ColBuffer | []byte | 列数据，格式见下表，如果 ColsOffset 为 0 则没有此项 |

列和标签数据格式

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| TotalLength | uint32 | 当前 数据的全部长度,包括 TotalLength 字段长度 |
| Type | int32 | 数据类型（对应TAOS_STMT2_BIND 中 buffer_type） |
| Num | int32 | 多少行数据（对应TAOS_STMT2_BIND 中 num） |
| IsNull | [Num]byte | 每个 tag 是否为 null, Num 个元素（对应TAOS_STMT2_BIND 中 is_null） |
| haveLength | byte | 是否有长度，0 为没有，1 为有，当数据类型为变长时必须有长度（binary, nchar, json, varbinary, varchar） |
| Length | [Num]int32 | 每个数据长度, Num 个元素，当 hasLength 为 0 时，无该字段（对应TAOS_STMT2_BIND 中 length） |
| BufferLength | uint32 | Buffer 的长度，如果数据全为 null 则 bufferLength可以为 0 并且 Buffer 是空的 |
| Buffer | [BufferLength]byte | 绑定数据（对应TAOS_STMT2_BIND 中 buffer）如果数据不是变长类型则需要留出空数据的位置（与 Native 规则一致） |

#### 4.6.2 返回

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 错误码 |
| message | string | 错误信息 |
| action | string | stmt2_bind |
| req_id | uint64 | 请求ID |
| timing | int64 | 执行时间 |
| stmt_id | uint64 | stmt实例ID |
