# 20241231 引擎部版本规划（1030 讨论稿）

## 1. Highlights

1. JDBC Websocket 多表低频的写入性能提升 1-2 倍
2. 替代海迅数据库（在地调业务上，用户不需要修改应用程序代码，甚至可能不需重新编译）
3. TSBS 提升逐行写入性能提升
4. 数据同步支持隔离网闸
5. Flink Connector 发布
6. 天脉系统适配
7. 支持微软对象存储
8. 降低流计算的资源消耗，包括 CPU 和 IO 操作
9. CSV 导入功能支持监听文件目录
10. 数据分析功能
