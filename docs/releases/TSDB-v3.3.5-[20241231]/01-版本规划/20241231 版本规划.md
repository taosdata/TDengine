# 20241231 版本规划

表格中若未特别标注完成时间，默认将在 1231 版本发布时完成。

## 1. Highlights

1. TDgpt 第一版发布
2. 天脉系统适配
3. 支持微软对象存储（直连 Azure Blob）
4. 流计算支持 Force_window_close 模式
5. 提升开启 Last 缓存的数据写入性能 
6. 增加查询的消耗内存控制
7. JDBC Websocket 多表低频的写入性能提升 1-2 倍
8. 数据同步支持隔离网闸
9. Flink Connector 发布
10. taosX 支持持续导入新 CSV 文件
11. 替代海迅数据库（在地调业务上，用户不需要修改应用程序代码，甚至可能不需重新编译）
