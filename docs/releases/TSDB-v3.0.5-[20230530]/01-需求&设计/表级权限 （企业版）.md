# 表级权限 （企业版）

### 1. 背景

TDengine 已经支持数据库级别的权限，可以对用户授予或回收其在指定数据库或全部数据库上的读写权限。但是在一些业务场景下，数据库粒度的权限控制还不能满足用户的需求，用户需要更细粒度的权限控制，例如超级表级别、子表级别等。
超级表级别我们可以参照目前数据库级别来实现，让用户指定超级表来设置权限。而子表级别需要额外的考量，TDengine 可以支撑亿级别的子表数量，让用户按子表名来逐个配置权限是不现实的，且我们内部也不好实现（子表列表过大）。所以针对子表级别的权限控制，我们需要提供一种通过标签条件指定子表的方式。

### 2. 语法 

```sql
GRANT privileges ON priv_level [WITH tag_condition] TO user_name
 
privileges : {
    ALL
  | SUBSCRIBE
  | priv_type [, priv_type] ...
}
 
priv_type : {
    READ
  | WRITE
}
 
priv_level : {
    dbname.tbname
  | dbname.*
  | *.*
  | topic_name
}

REVOKE privileges ON priv_level [WITH tag_condition] FROM user_name

privileges : {
    ALL
  | priv_type [, priv_type] ...
}
 
priv_type : {
    READ
  | WRITE
}
 
priv_level : {
    dbname.tbname
  | dbname.*
  | *.*
}
```

在现有语法基础上扩展 priv_level 支持表级权限，并增加 WITH 子句用于限定一类子表, WITH 子句后面可以是针对任意标签和 tbname 的标量过滤条件。

### 3. 限制

- 支持超级表和普通表设置，子表需通过超级表+tag条件来设置
- 每个表只支持一次授权，如果改动需先REVOKE再GRANT实现
- 只支持通过SQL语句方式进行的鉴权（STMT/SCHEMALESS暂不支持）
- 只支持SELECT、INSERT语句

### 4. 语义

用户可以通过 dbname.tbname 来为指定的表（包括超级表和普通表）授予或回收其读写权限，不支持直接对子表授予或回收权限。
用户可以通过 dbname.tbname 和 WITH 子句来为符合条件的所有子表授予或回收其读写权限。使用 WITH 子句时，权限级别必须为超级表。
表级权限和数据库级权限的关系：

|  | 表无授权 | 表读授权 | 表读授权有标签条件 | 表写授权 | 表写授权有标签条件 |
| --- | --- | --- | --- | --- | --- |
| 数据库无授权 | 无权限 | 对此表有读权限，对数据库下的其他表无权限 | 对此表符合标签权限的子表有读权限，对数据库下的其他表无权限 | 对此表有写权限，对数据库下的其他表无权限 | 对此表符合标签权限的子表有写权限，对数据库下的其他表无权限 |
| 数据库读授权 | 对所有表有读权限 | 对所有表有读权限 | 对此表符合标签权限的子表有读权限，对数据库下的其他表有读权限 | 对此表有写权限，对所有表有读权限 | 对此表符合标签权限的子表有写权限，所有表有读权限 |
| 数据库写授权 | 对所有表有写权限 | 对此表有读权限，对所有表有写权限 | 对此表符合标签权限的子表有读权限，对所有表有写权限 | 对所有表有写权限 | 对此表符合标签权限的子表有写权限，数据库下的其他表有写权限 |


各种子句的执行权限与授权的关系：

|  | 数据库读授权 | 数据库写授权 | 超级表读授权 | 超级表写授权 | 超级表读授权有标签条件 | 超级表写授权有标签条件 |
| --- | --- | --- | --- | --- | --- | --- |
| INSERT | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 有权限* |
| SELECT FROM 子表 | 有权限 | 无权限 | 有权限 | 无权限 | 有权限* | 无权限 |
| SELECT FROM 超级表 | 有权限 | 无权限 | 有权限 | 无权限 | 有权限* | 无权限 |
| ALTER TABLE 子表 | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 有权限* |
| ALTER STABLE | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 无权限？ |
| CREATE TABLE 子表 | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 无权限？ |
| CREATE STABLE | 无权限 | 有权限 | 无权限 | 无权限 | 无权限 | 无权限 |
| DELETE FROM 子表 | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 有权限* |
| DELETE FROM 超级表 | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 有权限* |
| DROP TABLE 子表 | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 有权限* |
| DROP STABLE | 无权限 | 有权限 | 无权限 | 有权限 | 无权限 | 无权限 |
| INSERT 子表 SELECT |
| SHOW CREATE TABLE 子表 | 有权限 | 无权限？ | 有权限 | 无权限？ | 有权限* | 无权限？ |
| SHOW CREATE STABLE | 有权限 | 无权限？ | 有权限 | 无权限？ | 有权限 | 无权限？ |
| SHOW TABLES | 有权限 | 有权限 | 有权限 | 有权限 | 有权限* | 有权限* |
| DESCRIBE 子表 | 有权限 | 无权限？ | 有权限 | 无权限？ | 有权限* | 无权限？ |
| DESCRIBE 超级表 | 有权限 | 无权限？ | 有权限 | 无权限？ | 有权限 | 无权限？ |

说明：
带有“*”表示仅标签匹配的子表有权限，不匹配的子表无权限；
带有“?”表示行为存疑；

### 5. 相关语句调整

#### 5.1 information_schema.ins_user_privileges系统表

增加 tag_condition 列，用来显示用户指定的标签过滤条件。对不涉及的权限条目，此列显示 null。

#### 5.2 show user privileges语句

增加 tag_condition 列，用来显示用户指定的标签过滤条件。对不涉及的权限条目，此列显示 null。
