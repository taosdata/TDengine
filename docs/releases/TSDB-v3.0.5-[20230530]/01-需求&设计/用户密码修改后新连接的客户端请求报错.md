# 用户密码修改后新连接的客户端请求报错

TD-23421

## 背景

- 参照  [TS-3035](https://jira.taosdata.com:18080/browse/TS-3035)，用户修改密码后，通过 taosadpater 使用老密码发起的新的连接请求未报错，仍然能正常返回。只有使用新密码访问过一次，使用老密码发起的请求才会报错。
```cpp
原因如下：
1）taosadapter 内部通过连接池管理与 taosd 的 RPC 链接。
2) taosadapter 是通过感知新发起的连接中，用户密码是否发生变化，来决定更新还是复用连接池中的 RPC 链接。
```

- Refer:  [TS-3035 修改密码后，通过新连接发起的请求需要报错](https://taosdata.feishu.cn/wiki/wikcn1aT6qEaJnZ7TBCdqMOUL80) 

## 期望

### 2.1 用户修改密码后

- 使用老密码通过 taosadapter 发起的新的请求，需要报错。
- 使用老密码访问的正在执行的 taosdapter 请求，可以正常响应。
- 使用老密码在已经登录的 taos  shell 客户端，可以正常发起请求及响应。
- 使用新密码发起的 taosadapter/taos shell 请求，可以正常返回(当前行为)。

## 接口变更

### 3.1 taos/taosadapter 接口

- taos.h 新增一个 API taos_set_notify_cb 供应用方设置回调函数。
```cpp
typedef enum {
  TAOS_NOTIFY_PASSVER = 0,
} TAOS_NOTIFY_TYPE;

/**
 * param   param specified by taos_set_notify_cb
 * ext    for extend
 * type   TAOS_NOTIFY_TYPE
*/
typedef void (*__taos_notify_fn_t)(void *param, void *ext, int type);

/**
 * param  the lifecycle of param is managed by app
*/ 
DLL_EXPORT int taos_set_notify_cb(TAOS *taos, __taos_notify_fn_t fp, void *param, int type);
```

- 目前， 只支持用户密码变化后对应用设置的函数进行回调。取值为：

| **__taos_notify_fn_t** | **param** | **ext** | **type** |
| --- | --- | --- | --- |
|  | userName | int32_t* passVer | TAOS_NOTIFY_PASSVER |


| **taos_set_notify_cb** | **taos** | **fp** | **param** | **type** |
| --- | --- | --- | --- | --- |
|  | TAOS * | fp by app | userName | TAOS_NOTIFY_PASSVER |
