#  row的长度到 64k 

## 1. 需求来源

[Increase the maximum row length to 64K](https://taosdata.feishu.cn/wiki/wikcnxFabKRYMviPcWyq2NAMdKe) 

## 2. 测试说明

1、明确边界值

| version | row max len | column max len | tag row max len | tag column |
| --- | --- | --- | --- | --- |
| 3.0.5.0 | 65531 | 65517 | 16384 | 16382 |

2、各数据类似占用的长度
[TIMESTAMP ：8]、  [BOOL ：1]、
 [ INT ：4]、 [BIGINT ：8] 、[FLOAT： 4] 、[SMALLINT ：2]、
 [DOUBLE ：8]、[TINYINT ：1]、
 [BINARY：1]、 [VARCHAR：1]、 [NCHAR：4]
