# TD-22308 增加有流场景下的异常测试

## 一、测试概述

背景参考[云服务平台生产系统恢复](https://jira.taosdata.com:18090/pages/viewpage.action?pageId=224628630)，流计算的全量测试用例中已经覆盖了有流场景的删库/删表/删流等异常操作，但数据规模比较小；本次测试需要在一定的数据规模下进行测试，流语句覆盖尽可能多的功能，同时限制服务器资源，人为制造 CPU、内存等资源过载的情况，并覆盖删流/删表/kill taosd/重启/关机断电等异常，确保系统不 crash 或者 taosd 重启后可以正常恢复。

### 3.3 测试场景

| **场景** | **预期结果** |
| --- | --- |
| 一定数据规模下建流，然后持续写入，写入一段时间后进行删记录/删表/删流等操作 | taosd不会crash |
| 一定数据规模下建流，然后持续写入，写入一段时间后kill 并重启 taosd | taosd可以恢复工作 |
| 一定数据规模下建流，然后持续写入，写入一段时间后进行服务器断电操作，然后再将服务器重启 | taosd可以恢复工作 |
| 控制cpu资源，建流并持续写入，在cpu资源耗尽情况下kill 并重启 taosd | taosd可以恢复工作 |
| 控制内存资源，建流并持续写入，使OOM，然后重启 taosd | taosd可以恢复工作 |
| 控制磁盘资源，建流并持续写入，disk空间不足，然后 kill taosd，空出一部分空间后重启 taosd | taosd可以恢复工作 |
