# 集群负载再平衡 （企业版功能）

## 1. 背景

在滚动升级的过程结束后，vnode的leader都会集中在一个dnode节点。这样会造成写入和查询的负载都集中在一台服务器上，而另外两台服务器（假定三节点集群）近乎于空闲。
为了解决上述问题，希望能够提供一种简便易用的手段能够使集群的负载再次实现（大体）均衡。

## 2. 语法

```bash
balance vgroup leader;
```


## 3. 功能和影响

让所有的vgroup的leader在各自的replica节点上均匀分布。这个命令会让vgroup强制重新选举，通过重新选举，在选举的过程中，变换vgroup的leader，通过这个方式，最终让leader均匀分布。
Raft选举本身带有随机性，所以通过选举的重新分布产生的均匀分布也是带有一定的概率，不会完全的均匀。
命令的副作用是影响查询和写入，在vgroup重新选举时，从开始选举到leader选举出来这段时间，这个vgroup无法写入和查询。选举过程一般在秒级完成。所有的vgroup会依次逐个重新选举。
