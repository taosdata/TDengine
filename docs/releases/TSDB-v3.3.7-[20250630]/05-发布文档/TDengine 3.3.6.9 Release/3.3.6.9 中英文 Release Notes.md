# 3.3.6.9 中英文 Release Notes

### 1. 行为变更

```markdown

### 2. 行为变更

   - TS-6396 : Explorer Transform 支持了带换行符的 JSON Payload 解析
   - TS-6511 : 导入且未运行任务时，可修改 Kafka group 和 client ID
```

### 3. 中文

```markdown

### 4. 特性

   - TS-5723  特性：OPCDA Agent 支持断线缓存
   - TD-34446 特性：支持 Spark 获取 TDengine 数据
   - TD-34807 特性：添加生态支持 SSRS（SQL Server Reporting Services）

### 5. 优化

   - TS-6479  优化：优化数据订阅 offset 更新逻辑
   - TD-34392 优化：更新驱动程序的版本号的生成方式
   - TS-6396  优化：Explorer 解析 Payload 支持 JSON 包含换行符
   - TS-6475  优化：Kafka/MQTT 解析 JSON 允许保留原始字段
   - TS-6511  优化：导入任务后 kafka group 和 client ID 可以被修改
   - TS-6518  优化：配置参数持久化的产品行为
   - TS-6405  优化：Explorer 页面展示普通表和虚拟表
   - TS-6558  优化：支持取消正在执行的 compact 任务
   - TS-6532  优化：数据库表名中关于特殊字符 ` 的处理

### 6. 修复

   - TD-34846 修复：Rust WebSocket 连接器修复订阅偶发丢数据问题
   - TD-32192 修复：Explorer 企业版文档链接跳转到标签页
   - TD-34038 修复：客户端在查询心跳消息异常时发生内存泄漏
   - TD-34833 修复：stmt2 高效写入在自动建表时内存泄漏
   - TD-34925 修复：使用 taosd -C 命令时，部分配置参数未显示
   - TD-34931 修复：停止 taosX 任务后不重置指标以修复停止后指标为 0 的错误
   - TD-35027 修复：消费组名称包含冒号时，订阅失败
   - TS-6526  修复：文件数量多时 taosX 恢复任务造成 OOM
   - TS-6557  修复：stmt2 报错信息与错误码不一致的问题
   - TS-6570  修复：Explorer 查询语句默认LIMIT 不生效
   - TS-6571  修复：在非 insert 和 select 语句中使用 stmt2 会导致 crash
   - TS-6572  修复：大量重复数据的写入可能导致 taosd 重启
   - TS-6583  修复：taosX Windows 上断线续传只读不写
   - TS-6491  修复：aarch64 taos Shell 无法输入中文
   - TS-6542  修复: Compact 命令的时间范围解析错误导致对应的数据文件组未能重整。
   - TS-6524  修复：开启白名单时，删除 dnode 操作可能失败

```

### 7. English

```markdown

### 8. Features

   - TS-5723  feat: support persisent cache in agent of opc
   - TD-34446 feat: support Spark retrieving data from TDengine
   - TD-34807 feat: add support for SSRS (SQL Server Reporting Services)

### 9. Enhancements

   - TS-6479  enh: optimize the update logic for data subscription offsets.
   - TD-34392 enh: update the method for generating driver version numbers
   - TS-6396  enh: Explorer support \n in JSON payload
   - TS-6475  enh: Kafka/MQTT support keep original payload/value
   - TS-6511  enh: kafka group and client_id should be editable after imported
   - TS-6518  enh: optimize the config parameter's persistence behavior
   - TS-6405  enh: Explorer support normal table and virutal tables
   - TS-6558  enh: support for cancelling compact tasks in progress.
   - TS-6532  enh: optimize the processing of backtick (`) character in database table names

### 10. Fixes

   - TD-34846 fix: fix tmq data loss via rust websocket connector
   - TD-32192 fix: fix doc link target 
   - TD-34038 fix: memory leak in taos client when querying heartbeats fails.
   - TD-34833 fix: memory leak during stmt2's high-efficiency writing while auto-creating tables.
   - TD-34925 fix: some config are not displayed when using the taosd -C command
   - TD-34931 fix: do not reset metrics after task stopped to view in explorer
   - TD-35027 fix: subscription fails when the consumer group name contains colon
   - TS-6526  fix: fix oom when restore with many files
   - TS-6557  fix: the error message and error code for stmt2 are inconsistent.
   - TS-6570  fix: fix explorer sql limit detection in backend
   - TS-6571  fix: using stmt2 in non-insert and non-select statements causes crash
   - TS-6572  fix: massive writes of duplicate data may cause taosd to restart.
   - TS-6583  fix: taosX persist queue not work for read in windows
   - TS-6491  fix: aarch64 taos shell input chinese chars error
   - TS-6542  fix: time range parsing error in the compact command caused the corresponding data file groups to fail to reorganize.
   - TS-6524  fix: when enabling the whitelist, drop dnode operations may fail.

```
