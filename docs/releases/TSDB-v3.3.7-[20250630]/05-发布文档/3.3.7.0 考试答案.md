# 3.3.7.0 考试答案

#### 1. 第一部分，笔试题目，所有人回答

1. 3.3.7.0 版本的主要功能有那些？
   - 流计算全新发布
   - MQTT 数据订阅
   - 多级存储支持共享存储
   - TDgpt 支持协变量预测
   - 支持 BLOB 数据类型
2. 那些场景有可能用到流计算？
   - 数据分级存储与智能降采样
   - 预计算加速实时决策
   - 异常检测和低延迟告警
3. 新版本流计算解决了那些问题？
   - 资源消耗严重
   - 高可用实现复杂
   - 计算资源无法隔离
   - 查询扩展能力受限
4. 新版本流计算的主要特点有那些？
   - 触发计算解耦：触发层与计算层分离，触发表（事件源）≠ 计算表（数据源）
   - 多种驱动机制：批流一体，事件时间驱动和定时计算，支持数据预过滤
   - 全局计算自由：计算资源池化，任意 SQL 查询，支持回写与通知
5. 新版本流计算支持那些触发方式？
   - 定时触发：系统时间驱动
   - 滑动触发：事件时间驱动
   - 窗口触发：时间、会话、事件、状态、计数
6. 数据订阅支持 MQTT 协议后，能解决什么问题？
   - 零代码集成：显著降低系统集成复杂度，实现基础设施无缝融合
   - 数据持久化与高可用：通过共享订阅、消费组、多副本功能的结合，共同保证整个数据链条的高可用
7. 多级存储配合共享存储，能给用户带来那些价值？
   - 降低存储成本：数据可以存储在更便宜的介质，迁移前进行数据整理，能够大幅度降低存储成本
   - 降低节点数目：多个存储设备挂载在同一台物理机上，可以降低物理节点数目
   - 提高写入吞吐：同时写入多块磁盘，CPU 不是瓶颈的情况下，可显著提高写入吞吐
8. 为什么要开发 BLOB 数据类型？
   - 全量原始报文存查：车联网 CAN 总线报文超出 Binary 类型 64KB 上限，被迫采用分片存储+拼接方案
   - 存储性能优化：​​二进制数据在进入数据文件前只能缓存在磁盘中，反复合并造成写入性能下降明显
9. 解释一下什么叫协变量预测，未来协变量预测又有什么不同？
   - 除目标变量历史值外，引入外部变量（协变量）作为输入，显式注入外部信息，共同预测目标变量。例如可引入节假日标签和天气数据预测发电量
   - 相比于历史协变量预测，未来协变量预测可引入天气预报、生产计划等未来数据，显著提高预测的准确度。
10. tsgen 是什么工具，一期支持哪些功能？
   - tsgen 定位是时序数据生成和压测工具
   - 一期支持了任务依赖，实时生成数据写入 TDengine，通过读取 csv 文件中 tag 来创建子表等功能。
11. 二季度我们生态对接方面，有哪些进展？
   - 支持了开源大数据处理引擎 Spark
   - 支持了开源可视化编程工具 Node-RED 
   - 支持了开源虚拟知识图谱系统 Ontop
   - 支持了 SQL Server Reporting Services
12. 哪些连接器支持了 IPv6？
   - 所有连接器：C,JDBC, Go, Rust, C#, Python and Nodejs.
13. 什么是 SparkplugB ？
   - [Sparkplug](https://www.eclipse.org/tahu/spec/sparkplug_spec.pdf) 是由 [Eclipse Foundation 的 TAHU 项目](https://www.eclipse.org/tahu/) 开发的开源规范，旨在为 MQTT 提供一套明确定义的 payload 和状态管理体系。其主要目标是在工业物联网领域实现互操作性和一致性。
14. Explorer 企业版是否可跳过注册？
  可以：
   - 企业版正式版无需注册；
   - 3.3.7.1 之后试用版可通过配置环境变量 EXPLORER_SKIP_REGISTER=true 跳过注册

#### 2. 第二部分，笔试题目，售前交付回答

1. 流计算中有哪几种触发方式，分别说明语法关键字？
   - **定时触发：Period**
   - **滑动触发：**Sliding
   - **窗口触发：**
      - **滑动窗口触发**：**Interval + Sliding**
      - **会话窗口触发**：Session
      - **状态窗口触发**：State_Window
      - **事件窗口触发**：Event_Window
      - **计数窗口触发**：Count_Window
2. 流计算的触发分组支持哪几种？
   - 不分组
   - 按标签分组
   - 按普通子表、虚拟子表分组
3. 流计算中有哪几种占位符？
   - 定时触发：_tprev_localtime、_tnext_localtime  
   - 滑动触发：_tprev_ts、_tcurrent_ts、_tnext_ts  
   - 窗口触发：_twstart、_twend、_twduration、_twrownum
   - 通用占位符：
      - _tgrpid
      - _tlocaltime
      - %%n
      - %%tbname
      - %% trows
4. 流计算中对非典型数据写入场景的控制选项有那些，分别什么含义？
   - WATERMARK：指定数据乱序的容忍时长，超过该时长的数据会被当做乱序数据
   - EXPIRED_TIME：指定过期数据间隔并忽略过期数据，未指定时无过期数据
   - IGNORE_DISORDER：指定忽略触发表的乱序数据，未指定时不忽略乱序数据
5. 编写建流语句：超级表 stb1 的每个子表在每 5 分钟的时间窗口结束后，计算这 5 分钟的 col1 的平均值（如果没有数据则忽略），每个子表的计算结果分别写入超级表 stb2 的不同子表中
  ```sql {wrap}
  CREATE stream sm1 INTERVAL(5m) SLIDING(5m) FROM stb1 PARTITION BY tbname 
    STREAM_OPTIONS(IGNORE_NODATA_TRIGGER) 
    INTO stb2 AS 
      SELECT _twstart, avg(col1) FROM %%tbname 
      WHERE _c0 >= _twstart AND _c0 <= _twend;
  ```

1. MQTT 数据订阅如何实现高可用
   - 通过共享订阅、消费组，实现 Subscriber、Broker 层面的高可用
   - 通过多副本，实现 Database 层面的高可用
2. 介绍共享存储中各类型数据文件的分布
   - head、sma、tomb、stt 文件与本地文件一一对应
   - data 文件拆分为多个数据块，以对象方式保存在共享存储中
3. 为什么 BLOB 数据类型的写入速度更快
  采用了单独的存储引擎，不需要反复的数据合并
1. 编写历史协变量预测和未来协变量预测的 SQL 示例
   - 历史协变量预测
  ```bash {wrap}
  ---- 第一列（val）为主变量，之后的列（past_co）为历史协变量，调用 moirai 基础时序模型
  select _frowts, forecast(val, past_co, 'algo=moirai') from foo;
  ```

   - 未来协变量预测
  ```sql {wrap}
  ---- 未来协变量的输入需要在 SQL 语句中补充。示例中，未来协变量列 future_co_val 的值通过 dynamic_val 设置
  select _frowts, forecast(val, past_co, future_co, "algo=moirai,rows=4, dynamic_val =[1 1 1 1], dynamic_val_col = future_co") from foo;
  ```

1. C Native 和 WebSocket 连接器接口一样吗？使用上如何区分？
   - C Native 和 WebSocket  接口是完全一样的，在使用 WebSocket 时需要先调用  taos_options(TSDB_OPTION_DRIVER, "websocket") 来初始化驱动。
2. C WebSocket 接口如何使用多个 taosadapter 进行负载均衡？
   - 在 taos.cfg 配置 `adapterList ip:port,ip2:port2`
