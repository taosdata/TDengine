#### 3. 第三部分，实操题目，售前交付回答

1. 使用 taosBenchmark（或者其他自己写的数据生成程序）写入官网智能电表的示例数据，100 个电表，先生成历史数据，然后实时数据每秒钟一条
2. 思考六个流计算场景，分别使用定时触发、时间窗口触发、计数窗口触发、事件窗口触发、状态窗口触发、会话窗口触发，将结果写到另外的数据库中（可以是同一集群）
3. 利用“TDengine 的 MQTT 数据订阅功能”，自己寻找一个 MQTT 可视化工具，展示如上流计算结果的数据订阅过程
4. 启动 taosX 服务，订阅如上的实时数据，写入到另外的数据库中（可以是同一集群）
5. 配置 taosd、taosadapter、taoskeeper 、taosx、taosExplorer 支持通过 IPv6 访问
