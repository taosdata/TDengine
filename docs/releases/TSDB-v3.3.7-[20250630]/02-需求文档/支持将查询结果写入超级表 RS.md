## 3. 需求目标

支持通过一条 SQL 语句将查询结果写入指定的超级表中，并在对应的子表不存在时自动创建子表。

## 4. 功能需求

### 4.1 **语法定义**

```sql
   INSERT INTO stb_name [(field1_name, ...)] subquery
```

### 4.2 **使用说明**

1. 执行写入语句时，insert into 支持超级表
2. SQL 语句中仅能包含一个超级表，不支持向多个超级表写入
3. 在 field_name 列表中必须指定 tbname 列，否则报错
   - tbname 对应的子表不存在时，自动创建子表
   - tbname 对应的子表存在时，不创建子表，同时子表的标签值也不会发生更新
   - tbname 列在查询结果中必须为字符串, 其中字符不支持转义, 当存在不能作为表名的特殊字符时，可以报错或者更改为字符`-`（在写 FS 时决定）
4. 在 field_name 列表中可不指定标签列
   - 当不包含标签列，或者标签列不是对应超级表的全集时，如果需要创建子表，标签值将被设置为 NULL
5. 在 field_name 列表中必须指定数据列
   - 数据列必须包含超级表中的主键时间戳列，如果涉及复合主键，还必须包含复合主键列
   - 当数据列不是对应超级表的全集时，未指定的数据列设置为 NULL

## 5. 性能需求

在未实现本功能时，如果需要将查询结果写入到超级表，分两个步骤
1. 将数据写入到临时的 CSV 文件中
2. 通过 insert 语句将 CSV 文件导入数据表中
本功能实现后，所需写入时间必然要低于以上时间。测试时，需要考虑 100 万子表的场景。
本期不考虑内部多线程处理，但可考虑通过 STMT 等方式加速。如确有性能要求，可考虑将查询语句分成多个，在 taos shell （app）侧并行处理。
