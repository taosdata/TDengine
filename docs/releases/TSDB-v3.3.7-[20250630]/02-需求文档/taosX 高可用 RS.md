# taosX 高可用 RS

## 1. 引言

taosX 是 TDengine 企业版的一个核心组件，为用户提供另代码数据接入的能力。目前 taosX 以单节点方式运行，存在单点故障风险。随着 taosX 功能和使用场景的不断扩展，单节点服务方式无法满足更高性能和通量的数据接入需求，高可用支持将作为高优先级需求支持。

### 1.1 术语与缩写名词

- **高可用性**（High Availability, HA）：确保系统或服务在规定的时间内可用的能力。
- **故障转移**（Failover）：在主系统不可用时，自动切换到备用系统的过程。
- **负载均衡**（Load Balancing）：将请求分配到不同的服务器以优化资源使用和响应时间。

## 3. 需求目标

1. 在任何单点故障发生时，保证业务连续性。
2. 提供水平扩展能力，在当前吞吐量无法满足时，通过工作节点的水平扩展实现能力提升。
3. 提供故障监控与及时报警功能，便于运维团队快速响应。
