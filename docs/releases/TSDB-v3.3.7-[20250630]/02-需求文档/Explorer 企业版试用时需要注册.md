# Explorer 企业版试用时需要注册

## 1. 引言

### 1.1 术语与缩写名词

1. 企业版：Enterprise 版本。
2. 试用版：企业版提供 15 天试用时长，此时称为试用版（`trial`），使用激活码激活后为正式版（`official`）。

### 1.2 相关文档资料

JIRA ：https://jira.taosdata.com:18080/browse/TS-6918

### 1.3 优先级要求

低

### 1.4 版本要求

企业版

## 3. 需求目标

根据[TDengine 品牌、产品命名说明](https://taosdata.feishu.cn/wiki/JzjOw6YKbiDGpskD2O0cMO4EnNh) 的调整，以及 TDengine 企业版开放下载试用的策略调整，Jeff 提出在新的企业版试用时 Explorer 需要注册，按此实现。

## 4. 功能需求

1. 用户使用用户名和密码验证通过后，如果是企业版或社区版，需要进行注册；
2. 一个实例仅需注册一次，下次登录时不需要重新注册；
