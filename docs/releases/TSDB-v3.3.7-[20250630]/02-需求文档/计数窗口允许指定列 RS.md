# 计数窗口允许指定列 RS

## 1. 引言

### 1.1 术语与缩写名词

`count_window`：指定窗口类型为计数窗口，按固定的数据行数来划分窗口
1. `count_val`：常量，正整数，必须大于等于 2
2. `sliding_val`：常量，窗口滑动的数量，必须大于等于1，小于等于 `count_val`
```sql
window_clause: {
  count_window (count_val[, sliding_val])
}
```

## 3. 需求目标

增强 `count_window` 语法，允许为计数窗口指定时序数据列

## 4. 功能需求

在 `count_window` 语法中，增加 `col` 字段，指定用来计数的数据列（不能是标签列）。对于被指定的数据列，如果该列中有空值（NULL、NONE），则不计数。建议语法如下
```sql
window_clause: {
  count_window ([col, ]count_val[, sliding_val])
}
```

1. 支持在批查询中使用
2. 支持在流计算中使用
3. 支持在虚拟表中使用
划分后的窗口，真正的数据条数（`count(*)`)可能大于 `count_val`，以如下数据集为例
