# 连接器与 TDengine 版本兼容性 FS

## 1. 背景

一直以来，除 Rust 连接器兼容所有 TDengine 版本外，其他连接器是会引入 break change，此时在官网列出与 TDengine 版本匹配关系。随着企业版用户越来越多，很多用户升级连接器或者升级 TDengine，导致版本不兼容问题，因此最好有一种技术手段能告诉用户版本不匹配，最低要求什么 TDengine 版本。

## 4. 行为说明

1. 应用调用连接器接口建立连接时，若版本不匹配，会收到报错异常或错误码，错误信息为： 
```shell
Version mismatch. The minimum required TDengine version is x.x.x.x.
```


1. **所有连接器从现在开始，要求必须兼容 TDengine 3.3.6.0 及以上版本。也就是说从现在开始，不能引入 break change。**
**     为保证这一点，所有连接器 CI 里需要增加 TDengine 3.3.6.0 的 build.yml**

1. 对于 Native 和 REST 连接，原则上不引入新功能，只做 bug fix。若必须调用新接口，则先判断版本是否支持。
2. 对于 taosAdapter 提供的新接口，连接器内部判断版本支持才调用。
3. WebSocket  方式获取服务端版本方式：
  创建连接之后立马发送请求 `{"action":"version"}`
  响应样例 `{"code":0,"message":"","action":"version","version":"3.3.6.3.alpha"}`

## 5. 性能

因为缓存服务端版本，对性能影响不大。

## 6. 兼容性

没有新增接口，不破坏兼容性。

## 7. 运维

本 FS 约束了连接器和 TDengine 版本对应关系，在版本不匹配时报错，方便交付运维。
