我们现在是md5算法做的密码策略，用户做等保三级的人说：md5现在已经可以破解了，不安全了，要再加额外的验证

## 4. 行为说明

### 4.1 增加sm4加密

在现有的md5的基础上再增加sm4，也即密码先用md5算hash，然后将hash用sm4加密。

### 4.2 加密配置

增加配置项encryptPassAlgorithm，取值范围 ‘sm4'，默认值为空。
- 当设置为空是，行为与现有行为不变。
- 当设置为'sm4'时，会将密码在md5的基础上，使用sm4加密后存储到mnode中。用户登录时，也会将密码在md5的基础上加密，再与mnode中的存储值进行比较。

### 4.3 密钥配置

加密需要用key，需要提前设置，与加密数据库是设置的key相同。具体设置过程可以参看加密数据流程中的密钥配置。
