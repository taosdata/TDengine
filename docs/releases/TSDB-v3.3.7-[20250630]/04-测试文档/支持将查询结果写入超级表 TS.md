### 7.4 性能

新功能，没有历史情况进行对比，本地简单测试了一下
10000张子表，每个子表2行数据，采用自动建表，写入耗时：
```plaintext
Query OK, 20000 row(s) affected (0.793265s)
```

提前建好表，写入耗时
```plaintext
Query OK, 20000 row(s) affected (0.493661s)
```

按照100w子表，每个子表100行，写入subquery会报错，磁盘空间不够了（建议使用控制写入条数不要过多，同时按照tbname进行排序）：
```plaintext
DB error: No enough disk space [0x8000012E] (3101.734351s)
```

但是cpu和内存占用没有释放，正在查原因
