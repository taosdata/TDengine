# 3.4.0.0 考试答案

#### 1. 第一部分，笔试题目，所有人回答

1. v3.4.0 安全功能在哪几个维度有提升？
   - 身份鉴别：强口令、多因素认证、登录控制
   - 访问控制：RBAC 权限模型、细粒度权限管控
   - 传输安全：TLS+SASL 分层加密
   - 存储安全：全量透明存储加密
   - 安全审计：五级粒度审计、审计日志安全存储
2. v3.4.0 虚拟表查询性能优化主要体现在哪些查询场景？
   - 虚拟表投影查询
   - 虚拟表聚合函数和选择函数查询
   - 虚拟表状态窗口查询
3. v3.4.0 流计算在性能方面有那些提升？
   - CPU 占用降低 30% 以上
   - 内存占用降低 25% 以上
   - 计算延迟降低 10倍 以上
4. v3.4.0 数据订阅有那些提升？
   - 在数据订阅时通过 enable.wal.marker 选项**延长 WAL 的保留时间**
   - 支持通过执行 RELOAD TOPIC 命令，使数据订阅无需重建即生效
5. 哪些场景有可能用到事件窗口支持子事件窗口的流计算功能？
   
   适用于需要精细化监控复杂事件的场景，例如：
   1. 工业设备故障分级监控（设备振动值≥60开启预警子窗口，≥90开启告警子窗口，振动值＜70关闭窗口）
   2. 电力负荷波动监控（负荷≥80%开启常规波动子窗口，≥95%开启过载子窗口，负荷＜60%关闭窗口）
   3. 环境监测多阈值预警（PM2.5≥75开启轻度污染子窗口，≥150开启重度污染子窗口，PM2.5＜50关闭窗口）

6. 独立授权服务适用于什么部署场景？
   
   企业内部存在多套集群，且需统一管理所有集群的用量

#### 2. 第二部分，笔试题目，售前交付回答

1. 解释一下非相关标量子查询？
   - 子查询不依赖父查询的任何字段，可独立执行
   - 执行结果为单个值（标量），用于父查询的条件判断或字段赋值

2. 流计算中事件窗口触发支持子事件窗口的语法格式？
   
   ```sql
   EVENT_WINDOW(START WITH (start_cond_1, start_cond_2 [,...]) [END WITH end_cond])
   ```

3. 虚拟表性能优化中，针对状态窗口查询新增了哪两种优化策略？
   
   先从窗口定义时给的数据列中提取窗口边界，当窗口触发后，再激活后续数据对齐与计算逻辑
   - WIN_OPTIMIZE_BATCH，以批处理方式一次处理多个窗口
   - WIN_OPTIMIZE_SINGLE，一次仅处理单个窗口

4. 状态窗口零状态功能中，zeroth_state 过滤与 where 条件过滤的核心区别是什么？
   - zeroth_state 是先计算完整状态窗口，再过滤零状态窗口
   - where 条件是先过滤数据，再基于剩余数据计算状态窗口

5. 解释一下 TLS 和 SASL 的作用？
   - TLS：通用的加密传输机制，保证数据在网络传输过程中的安全性与完整性
   - SASL：通过挑战-响应机制，对于密码、密钥等关键信息，进行额外的加密传输

6. 身份鉴别有那些行为？
   - 强密码限制
   - 资源限制
   - 密码过期和用户锁定
   - 允许和禁止 Host / 时间
   - 多因素认证（TOTP）
   - TOKEN 认证

7. 存储安全有那些特点？
   - 配置文件加密存储
   - 权限和密码相关的数据文件加密存储
   - 时序数据相关的数据文件加密存储
   - 支持国密算法和秘钥生命周期管理

8. 权限控制有那些特点？
   - 基于角色的访问控制
   - 表、列级权限
   - 读写权限细化
   - 权限定期审查
   - 允许删除默认系统管理员 root
