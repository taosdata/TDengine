# 独立授权服务 - 用户手册

## 1. 背景

FS：[独立授权服务 - FS](https://taosdata.feishu.cn/wiki/Jw8IwVcVgiTilakmgcJcSHORn7e)
RS：[独立授权服务 RS](https://taosdata.feishu.cn/wiki/PGn6wzFwNiZbg3kVMmscaGCDn9d)

## 2. 授权服务器（GrantServer）

### 2.1 部署 

在授权服务器上部署企业版的特殊版本（需通过`-DAUTH_SERVER=1`编译），记录其 FQDN（全限定域名），然后启动服务（支持单节点或多节点配置）。

### 2.2 授权

授权方式：使用 [授权工具](https://taosdata.feishu.cn/wiki/OydKwSf1jidC04ki9V2c65NvnKe#DCAjdtZUQoCs5cxGSZuchxfUntg) taosGrant，需添加特殊选项。其中，`--auth-server`的默认值为 0，若需显式指定授权服务器则设为 1。
```sql
./taosGrant --auth-server [0|1] (默认值 1，其余参数与普通授权一致）
```

### 2.3 创建授权库和超级表

执行以下 SQL 创建超级表，各字段含义参考 “[数据表字段](https://taosdata.feishu.cn/wiki/Jw8IwVcVgiTilakmgcJcSHORn7e#share-PstZdUChwosVjFxmaJicIGDRnXe)” 。
```sql
CREATE Database auth;
CREATE STABLE auth.grantserver (
    ts TIMESTAMP,
    auth_time VARCHAR(24),
    auth_status VARCHAR(12),
    auth_code INT,
    auth_usage VARCHAR(4096),
    auth_updated BOOL,
    machine_code VARCHAR(7552),
    fqdn VARCHAR(19200),
    first_ep VARCHAR(256),
    create_time TIMESTAMP,
    boot_time DOUBLE) 
TAGS (cluster_id VARCHAR(64),
    enables BOOL,
    auth_quota VARCHAR(4096));
```

### 2.4 创建授权管理员用户

创建用户`authroot`并授予权限。
```sql
CREATE USER authroot PASS 'auth125!' SYSINFO 1 CREATEDB 1;
GRANT ALL ON auth.* TO authroot;
```

### 2.5 启动 taosadapter

在授权服务器上部署并启动`taosadapter`，修改其配置文件：
- `taosConfigDir`：设置为 GrantServer 的`cfg`目录；
- `port`：固定为 6041（不可修改）。
授权过程会调用`taosadapter`的 REST API，需确保其正常运行。

## 3. 被授权集群

### 3.1 配置

启动前需在`taos.cfg`中添加以下配置项：
```typescript
authReq          1
authReqUrl       127.0.0.1:6030
authReqInterval  60
```

配置项含义：
1. `authReq`：是否向 `GrantServer`发送授权请求，0 表示不发送（默认），1 表示发送；
2. `authReqInterval`：授权请求间隔（单位：秒），默认 259200（3 天），最大值 2592000（30 天）；
3. `authReqUrl`：授权请求目标地址，格式为`ip:port`（即`GrantServer`的 FQDN +  taosAdapter Port）。

### 3.2 获取 clusterID

启动集群后，执行以下命令查询目标集群的`clusterID`：
```sql {wrap}
show cluster\G;
```

返回结果中，`id`字段的值即为`clusterID`（示例如下）：
```sql

*************************** 1.row ***************************
         id: 2073807968208859198
       name: 4de444bb-993d-4bf0-91dd-fd4dc210c0b41b5
     uptime: 95700
create_time: 2025-10-14 19:35:24.656
    version: official
expire_time: 2026-01-01 08:00:00.000
Query OK, 1 row(s) in set (0.009722s)
```

### 3.3 添加授权子表

基于上一步获取的`clusterID`，在 `GrantServer` 中创建授权子表，`tag`参数说明：
- `cluster_id`：需填写被授权集群的`clusterID`；
- `enables`：设为`true`时允许授权，`false`时禁止；
- `auth_quota`：授权配额，格式为键值对字符串（多键之间用分号`;`分隔，部分键的多值用逗号`,`分隔）。
**示例**：

## 5. 授权信息

配置完毕之后，大约1分钟左右可以通过查询表查到授权是否成功的信息，如果超过2分钟还是没有信息，则可能出错，具体出错信息需要查询auth_server和auth_client的日志

### 5.1 查询授权信息

每次心跳会向子表写入一条数据，可通过以下 SQL 查询
```sql

## 6. 查询所有的集群最新心跳纪录

select last_row(*) from auth.grantserver; 

## 7. 查询某个cluster的全部心跳记录

select * from auth.{childTableName};
select * from auth.grantserver where cluster_id={clusterId};

## 8. 查询授权信息

select tags enables,auth_quota from auth.{childTableName};
select tags enables,auth_quota from auth.grantserver where cluster_id={clusterId};

## 9. 查看授权状态是成功还是失败（是否为0）

select last_row(auth_code) from auth.{childTableName};
```

### 9.1 修改授权信息

仅支持修改`enable`（授权开关）和`auth_quota`（授权配额），其他信息禁止修改。修改后需延迟 最大60 秒生效。
```sql

## 10. 禁用某个集群的授权

alter table auth.{childTableName} set tag enables=0;

## 11. 修改某个集群授权参数

alter table auth.{childTableName} set tag auth_quota='...';
```

  ```c {wrap}
  limitAuthClients --可以授权的集群数量（新增）
  basic
      expire             --过期时间
      limitTimeSeries    --测点数
      limitCpuCores      --cpu核心数
      limitDnodes        --dnode数量
      limitVnodes        --vnode数量
      limitStorageSize   --存储大小
  ```
