## 4. 行为说明

### 4.1 按指定间隔循环回收内存

添加配置参数 memory_reclaim_interval 指定时间间隔，单位：秒，默认值： 300 即 5 分钟，最小值：10 。

### 4.2 发送 SIGHUP 信号强制回收内存

仅 UNIX 环境下可用：
```bash {wrap}
kill -1 `pidof taosx`
```
