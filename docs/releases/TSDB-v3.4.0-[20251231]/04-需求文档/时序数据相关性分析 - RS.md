## 2. 引言

### 2.1 术语与缩写名词

**时间序列相关性分析：**检测两个或多个序列之间的统计关联，包括同步性、滞后性及因果性。相关性分析多用于以下的领域：
- 描述序列间的相似模式（如季节性的同步）
- 监控异常关联变化（如传感器数据突变）
- 描述一个时间序列对另一个时间序列的影响

**自相关‌（ACF）**：检测同一序列不同时间点数据的相关性，用于识别时间序列的周期性。
**皮尔逊相关系数（Pearson correlation coefficient）**：用于衡量两个时间序列之间线性相关程度的指标，其值介于 [-1, 1] 之间。
**时间滞后互相关（TLCC）**：评估两个时间序列之间的动态性关系，例如引导-追随关系。TLCC 通过逐步移动一个时间序列向量并反复计算两个信号间的相关性来测量。
**动态时间规整（DTW）**：计算两个时间序列间相关路径最短的方法，能够处理不同长度（采样间隔）的信号。可用于描述形状相似性（波动趋势）。

## 4. 功能需求

### 4.1 相关性分析函数

Corr 函数计算皮尔逊相关系数，返回值为 `double`， 返回结果在区间 [-1, 1] 内。只能对数值型列进行处理。
```sql
---  计算两列数据 col_1  和 col_2 的皮尔逊相关系数。
select corr(col_1, col_2) from foo 

---- 返回结果
0.431
```


dtw 函数计算两个输入列的动态时间规整结果值，返回值为 `double`。只能针对数值型列进行处理。
```sql
--- 前两个参数是两个输入列 
--- 第三个参数是计算序列点之间距离的度量方法。可选：1) 欧式距离 euclidean 和 2) 曼哈顿距离 manhattan
select dtw(col_1, col_2, 'euclidean') from foo

--- 返回结果
0.33
```


dtw_path 函数计算两个输入时间序列的动态时间规整配对结果（非规整结果值）, 以 varchar 形式返回（col_1， col_2 ）
```sql
--- 前两个参数是两个输入列 
--- 第三个参数是计算序列点之间距离的度量方法。可选：1) 欧式距离 euclidean 和 2) 曼哈顿距离 manhattan
--- 第四个参数指示返回结果是对应配对的 行号 (index) 或者 真实数值（value)
select dtw_path(col_1, col_2, 'euclidean', 'index') from foo

--- 返回结果
dtw_path
--------------
(0,0)
(0,1)
(1,2)
(2,3)
(3,4)
(4,5)
```


Tlcc 函数，计算不同时间滞后（时移）下的相关系数，量化一个序列相对于另一个序列的领先或滞后效应。返回值为 `double`， 只能针对数值型列进行处理。
```sql
---- 前两个参数是用于计算相关性的两列输入数据
---- 第三个参数是 col_2 相对于 col_1 的滞后点位数（阶数）, 可以为负值。
---- 第四个参数是 col_2 相对于 col_1 滞后点位数最大值（阶数上限）
---- 如果 lag_start == lag_end == 0，此时计算结果等于 corr(col_1, col_2)
select tlcc(col_1, col_2, lag_start, lag_end) from foo

---  返回结果
lag | corr
---------- 
0   | 0.1
1   |0.3
2   |0.6
3   |0.75
4   |0.8
5   |0.75
6   |0.6
7   |0.3
8   |0.1
```
