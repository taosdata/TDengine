### 3. 分析报告

本报告针对 TDengine JDBC 连接器（原生连接 & WebSocket 连接）进行威胁建模，覆盖连接建立、认证、传输、参数绑定、自动重连/负载均衡/Failover、高效写入等能力。
- 核心发现：识别出 `7` 个潜在威胁，其中 `高危` `3` 个，`中危` `3` 个，`低危` `1` 个。
- 主要风险场景：
   - 数据在传输与重连场景中的窃听/篡改（缺省未强制 TLS，存在跳过证书验证选项）。
   - 凭据暴露与弱口令使用（示例与默认值使用 `root/taosdata`，凭据放在 URL/配置文件）。
   - 负载均衡/Failover/自动重连缺乏一致的身份校验与端点信任约束，可能被劫持或错误复用凭据。
- 结论：功能价值明确，但需以“强制安全默认值（TLS、凭据管理）、禁用危险绕过项、对重连与多端点加强身份/完整性验证”为前置条件。

### 4. 威胁识别与分析（STRIDE）

功能描述：JDBC 驱动提供原生（JNI）与 WebSocket 两类连接，支持多端点负载均衡、自动重连、参数绑定、高效写入、数据订阅等。

#### 4.1 关键实体与数据

| 实体/数据 | 描述 | 敏感性 |
| --- | --- | --- |
| JDBC URL/Properties | 包含 user/password、useSSL 等连接信息 | 高（含凭据） |
| taos.cfg 等客户端配置 | 可能含 firstEp/secondEp、凭据或端点信息 | 高 |
| 传输数据流 | SQL、查询/写入数据、订阅数据 | 高 |
| 端点列表 | 多个 WebSocket/原生节点地址 | 中 |
| 自动重连/探活状态 | 用于重连和重平衡的状态信息 | 中 |
| 日志/错误输出 | 可能包含 URL、参数或内部路径 | 中 |

#### 4.2 威胁评估

| 威胁 ID | 威胁描述 / 攻击场景 | STRIDE | 相关组件 / 数据流 | 风险等级 |
| --- | --- | --- | --- | --- |
| T-JDBC-01 | 传输未强制 TLS：示例默认 `TAOS-WS://`、`useSSL` 可关闭，可能明文传输或被中间人篡改。 | I/T | WebSocket/原生传输 | 高 |
| T-JDBC-02 | 跳过证书验证：`disableSSLCertValidation` 可被开启，易遭中间人攻击。 | S/I/T | WebSocket TLS 建连 | 高 |
| T-JDBC-03 | 凭据暴露与弱口令：默认 `root/taosdata`，示例将密码放在 URL/日志/配置文件中。 | I | URL、Properties、配置文件、日志 | 高 |
| T-JDBC-04 | 多端点负载均衡/Failover 未做端点信任校验（无 pinning/一致 TLS 策略），可能接入恶意端点。 | S/T | 多端点连接、重连 | 中 |
| T-JDBC-05 | 日志/错误信息泄露：URL/参数在错误或诊断日志中输出，泄露凭据或内部路径。 | I | 日志、错误输出 | 中 |
| T-JDBC-06 | SQL 注入风险：若应用使用字符串拼接而非参数绑定；文档未强调绑定的安全性。 | T/S | SQL 执行层 | 低 |

### 5. 安全需求与设计约束

| 威胁 ID | 转化后的安全需求 / 设计约束 | 类型 | 优先级 |
| --- | --- | --- | --- |
| T-JDBC-01 | SEC-JDBC-001：WebSocket 默认必须使用 TLS（`wss`），原生连接需启用加密通道并记录最低 TLS 版本与推荐 cipher；默认拒绝明文。 | 安全设计约束 | 高 |
| T-JDBC-02 | SEC-JDBC-002：`disableSSLCertValidation` 仅限测试环境，生产默认禁用且需显式开关与高亮警告；开启时记录安全告警。 | 安全设计约束 | 高 |
| T-JDBC-03 | SEC-JDBC-003：禁止在文档示例中使用弱口令/内嵌密码；推荐通过安全配置（env/secret manager）注入；配置文件需权限最小化（600/640）。 | 安全功能需求 | 高 |
| T-JDBC-04 | SEC-JDBC-004：多端点需同一 TLS 策略与证书验证/可选 pinning；仅允许受信端点列表，拒绝未验证主机名/IP。 | 安全设计约束 | 中 |
| T-JDBC-05 | SEC-JDBC-005：日志/错误输出需脱敏（隐藏密码、token、路径）；默认不打印 URL 全量查询串。 | 非功能安全需求 | 中 |
| T-JDBC-06 | SEC-JDBC-006：文档与示例必须优先使用 `PreparedStatement` 参数绑定，明确其为防 SQL 注入的要求。 | 安全功能需求 | 低 |
