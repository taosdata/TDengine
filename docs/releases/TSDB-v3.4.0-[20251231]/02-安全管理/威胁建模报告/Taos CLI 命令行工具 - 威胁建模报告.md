### 3. **分析报告**

本报告针对 TDengine TSDB CLI 工具的连接、执行 SQL、导入导出、TAB 补全、网络检测功能进行威胁建模。该工具作为客户端入口，可直连内核或云服务，暴露出凭据管理、传输加密、文件读写和资源滥用等攻击面。
- 核心发现：共识别出 8 个潜在威胁，其中高危 3 个，中危 4 个，低危 1 个。
- 主要风险场景：
   - 凭据泄露与重放：密码/DSN token 通过命令行、历史或日志泄露，或被截获后重放。
   - 传输劫持与降级：未强制 TLS 或证书校验，云/远程连接被中间人攻击。
   - 文件导入/导出滥用：路径穿越或重定向覆盖敏感文件；加载恶意 CSV/SQL 注入。
   - 资源与可用性：TAB 补全缓存超限、网络检测被滥用、批量命令/文件执行导致 DoS。
- 结论：需在 CLI 层落实凭据保护、TLS 强制、输入与路径校验、日志脱敏、速率与配额限制、缓存上限与清理、可审计的安全开关，方可通过安全门禁。

### 4. **威胁识别与分析（STRIDE）**

功能描述：命令行工具提供本地/云连接、交互/非交互 SQL 执行、导入导出、TAB 补全、网络检测等能力，支持 DSN token、用户名/密码两类凭据，输出可重定向到文件。

#### 4.1 **关键实体与数据**

| 实体/数据 | 描述 | 敏感性 |
| --- | --- | --- |
| 用户凭据（用户名/密码、DSN token） | 连接 TDengine 的认证信息，可能出现在命令行、配置、历史、日志中。 | 高 |
| 传输数据流 | 本地/云连接的 SQL 请求与结果集，需防窃听与篡改。 | 高 |
| 导入/导出文件 | 本地文件路径与内容（CSV/SQL/输出重定向）。 | 中 |
| 补全缓存 | 表/子表/函数等元数据缓存，可能较大且含敏感命名。 | 中 |
| 日志与历史 | 终端历史、CLI 日志输出。 | 中 |

#### 4.2 **威胁评估**

| 威胁 ID | 威胁描述 / 攻击场景 | STRIDE | 相关组件 / 数据流 | 风险等级 |
| --- | --- | --- | --- | --- |
| T-CLI-01 | 凭据泄露：密码/DSN token 通过命令行参数、shell 历史、日志或错误输出泄露，被重放利用。 | I/S | 参数解析、日志、历史记录 | 高 |
| T-CLI-02 | 传输被劫持/降级：云或远程连接未强制 TLS 或未校验证书，遭中间人篡改/窃听。 | T/I/S | 连接通道（Native/WebSocket/Cloud） | 高 |
| T-CLI-03 | 文件导入/导出路径穿越或覆盖：`FILE` 导入、`>>` 导出或 `--log-output` 指向敏感路径，造成任意文件写/读。 | T/E | 文件导入导出、日志输出 | 高 |
| T-CLI-04 | 恶意输入/注入：命令行参数/文件中的 SQL 被注入；CSV 内容触发异常或恶意 SQL。 | T/S | 命令行执行、文件执行、导入 | 中 |
| T-CLI-05 | 补全缓存 DoS/泄露：子表名过多导致内存膨胀；补全/错误信息泄露内部库表名。 | D/I | TAB 补全 | 中 |
| T-CLI-06 | 网络检测滥用：`--check/-l/-n/-N` 被用于反射/放大或持续压测造成资源占用。 | D | 网络检测 | 中 |
| T-CLI-07 | 输出/日志信息泄露：错误消息或调试日志泄露路径、配置、token 片段。 | I | 日志与错误处理 | 中 |
| T-CLI-08 | 审计不可抵赖：无请求 ID/会话 ID，导致操作难以溯源，出现争议。 | R | 全链路 | 低 |

### 5. **安全需求与设计约束**

| 威胁 ID | 转化后的安全需求 / 设计约束 | 类型 | 优先级 |
| --- | --- | --- | --- |
| T-CLI-01 | 凭据保护：禁止回显/记录密码与完整 DSN token；命令行与历史中掩码；支持从环境变量/交互输入读取密码；token 应短期有效并支持刷新。 | 安全功能需求 | 高 |
| T-CLI-02 | 传输加固：云/远程默认启用 TLS；校验证书与主机名；提供显式关闭开关但默认禁止；记录握手失败原因但不泄露敏感信息。 | 安全设计约束 | 高 |
| T-CLI-03 | 路径/权限校验：导入/导出/日志路径需存在且在允许目录内，拒绝相对路径穿越；防覆盖关键系统文件；输出文件需安全权限（0600）。 | 安全设计约束 | 高 |
| T-CLI-04 | 输入校验与注入防护：对命令行与文件中的 SQL/参数做格式校验；禁用危险选项组合（如空密码+远程）；对 CSV 导入进行大小/列数限制与错误处理。 | 非功能安全需求 | 中 |
| T-CLI-05 | 缓存与信息最小化：补全缓存设定上限（如子表 100k，可配置）；可选关闭补全；补全/错误输出不含敏感元信息。 | 健壮性需求 | 中 |
| T-CLI-06 | 速率与配额限制：网络检测命令限制并发与频率，增加确认提示；长耗时操作可中断；对批量 SQL/文件执行增加最大行数与超时。 | 可用性需求 | 中 |
| T-CLI-07 | 日志脱敏：默认仅输出必要信息；token 仅显示前后若干字符；错误/调试日志不含完整路径与凭据。 | 审计与隐私 | 中 |
| T-CLI-08 | 可审计性：为每次连接/执行生成请求 ID；关键操作写审计日志（不含敏感内容）；与引擎日志可关联。 | 审计需求 | 低 |
