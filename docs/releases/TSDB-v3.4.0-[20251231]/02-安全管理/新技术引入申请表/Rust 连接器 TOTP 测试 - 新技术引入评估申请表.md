## 3. 引入理由

1. 业务/技术价值：
  - 支持基于 TOTP 的自动化测试，提升安全性和测试覆盖率。
  - 满足对动态令牌生成与验证的需求，便于集成安全认证流程。
1. 与现有技术方案对比优势：
  - Rust 生态下无标准库直接支持 TOTP，需组合 base32、hmac、sha1、sha2 实现。
  - 这些库均为社区主流、维护活跃，兼容性好，易于集成。
1. 初步选型调研结论：
  - 经过调研，base32、hmac、sha1、sha2 为 Rust 社区主流选择，文档完善，社区活跃，满足 TOTP 相关需求。
  - 新技术引入前置评估比较充分，需求合理，符合安全规范。
