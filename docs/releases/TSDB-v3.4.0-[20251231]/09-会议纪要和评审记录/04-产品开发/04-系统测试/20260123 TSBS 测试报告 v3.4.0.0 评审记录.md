# 20260123 TSBS 测试报告 v3.4.0.0 评审记录

## 1. 评审信息

1. 评审目的：本次会议针对 TDengine TSDB v3.4.0.0 版本的 TSBS（Time Series Benchmark Suite）竞品性能对比测试报告进行评审，评估该版本在写入和查询性能方面相较 TimescaleDB 和 InfluxDB 的竞争力，确认测试方法、数据及结论的准确性和完整性。

## 2. 评审记录

### 2.1 测试环境与方法评审

- **测试版本**：TDengine TSDB Enterprise 3.4.0.0 vs TimescaleDB ver-2.13（psql 14.12）vs InfluxDB ver-1.8.10，版本选取合理，覆盖了主流竞品的最新稳定版本。
- **测试环境**：服务器与客户端均使用 Intel Xeon E5-2686 v4（32vCPU / 244GiB / 800G SSD 3000 IOPS），硬件配置一致，排除了环境差异对测试结果的影响。
- **编译选项**：TDengine 使用 Release 模式编译，关闭 assert、开启 SIMD，编译配置合理。
- **测试方法**：采用 TSBS 标准数据集，覆盖 cpu-only 和 IoT 两大场景，每个场景包含多种子表规模（100 ~ 10,000,000 devices），能够全面反映不同数据量下的性能表现。

### 2.2 写入性能评审

- **cpu-only 场景**：TDengine 在所有规模下写入速度均大幅领先，对 InfluxDB 优势从 318%（100 devices）增长至 3280%（千万 devices），对 TimescaleDB 优势从 446% 至 913%，大规模场景优势更加显著。
- **IoT 场景**：TDengine 写入同样保持领先，对 InfluxDB 优势 213%~529%，对 TimescaleDB 优势 282%~902%。
- **结论**：评审组认为写入性能测试数据充分验证了 TDengine 在时序数据写入场景下的核心优势，特别是在大规模子表场景中优势更为突出。

### 2.3 查询性能评审

- **对比 InfluxDB**：TDengine 在 cpu-only 和 IoT 两大场景的所有查询项中均优于 InfluxDB，提升幅度 0%~132312%，竞争优势明显。
- **对比 TimescaleDB（cpu-only）**：
  - scale=4000：30 项查询中 TDengine 有 4 项低于 TimescaleDB（single-groupby-1-1-1、single-groupby-1-8-1、single-groupby-5-1-1、high-cpu-1/all 等），落后幅度约 7%~21%。
  - scale=100：30 项查询中 TDengine 有 2 项低于 TimescaleDB（single-groupby-1-1-1、high-cpu-all），落后幅度约 8%~20%。
  - 其余查询项 TDengine 均领先，领先幅度 24%~2599%。
- **对比 TimescaleDB（IoT）**：
  - scale=4000：12 项查询中 TDengine 全部优于 TimescaleDB，领先幅度 8%~2459%。
  - scale=100：12 项查询中 TDengine 有 5 项低于 TimescaleDB（last-loc、low-fuel、high-load、stationary-trucks、breakdown-frequency），落后幅度约 4%~15%。
- **讨论**：评审组建议针对 TimescaleDB 查询领先的场景（主要集中在 Simple Rollups 的单设备单列查询和 Thresholds 查询）进行深入分析，明确是否存在优化空间，并在后续版本中持续跟踪。

### 2.4 报告完整性评审

- 报告结构完整，包含测试总结、变更历史、测试环境、性能统计规则和详细测试数据。
- 性能变化率的计算公式和评判标准明确。
