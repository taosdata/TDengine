# 20251205 TSDB 3.3.8.0 系统测试报告评审记录

## 1. 评审信息

1. 评审目的：本次会议针对 TDengine TSDB 3.3.8.0 版本的系统测试报告进行评审，评估该版本在功能、性能、可靠性、缺陷修复、安全性及兼容性方面是否达到预期的发布标准。
2. 评审文档：[TDengine TSDB v3.3.8.0 系统测试报告](https://taosdata.feishu.cn/wiki/Eaq8wynUiiwVnzkwvNTccrUvn8g)
3. 会议主持：关胜亮、肖波
4. 会议人员：关胜亮、肖波、王旭、贾靖斌（功能测试）、聂敏慧（性能测试）、陈浩然（安全测试）、研发工程师代表潘魏
5. 会议时间：2025-12-5 09:00 - 10:00
6. 会议形式：线下
7. 会议地点：Mnode
8. 会议记录人：肖波

## 2. 评审记录

#### 2.0.1 测试执行情况评审

- **功能符合性**：
  - 冒烟测试执行 151 个用例，通过率 100%。
  - CI 测试共 1715 个用例（含 taosd 1611 个，taosX 104 个），通过率 100%。
  - 验证确认存储、查询、流计算、订阅等核心模块功能完全符合需求规格说明书。
- **性能指标**：
  - 经 24 个场景测试，对比 3.3.7.0 版本，写入吞吐量、查询延迟等关键指标保持稳定，无明显性能下降。
  - 流计算专项性能对比测试结果显示，3.3.8.0 版本与 3.3.7.0 版本性能持平。
- **可靠性与稳定性**：
  - 稳定性测试持续运行超过 48 小时，涵盖查询、写入及多种数据接入场景。
  - 长时间用例测试共 683 个，通过率 100%。
- **安全性与兼容性**：
  - 安全功能（身份鉴别、访问控制、传输加密）已通过验证。
  - 在 Ubuntu、CentOS 及国产化环境（鲲鹏 ARM64 + 麒麟 V10）下的兼容性测试结论为通过。

#### 2.0.2 缺陷与风险评估

- **缺陷修复**：稳定性测试期间捕获的 1 个查询异常已完成修复并回归通过。
- **遗留缺陷**：当前无 P0/P1 级遗留缺陷，满足“P0/P1 缺陷必须关闭”的准出标准。
- **风险说明**：
  - 部分已知问题已记录在 Release Notes 中，不影响核心功能发布。
会议一致认为 TDengine TSDB 3.3.8.0 版本的系统测试活动已按计划完成，测试结果真实有效，各项指标均达到《系统测试计划》定义的通过准则。

## 3. 评审结论

准予通过。
