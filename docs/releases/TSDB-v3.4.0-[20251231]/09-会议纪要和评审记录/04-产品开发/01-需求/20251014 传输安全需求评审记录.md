# 20251014 传输安全需求评审记录

## 1. 评审信息

1. 评审目的：评估 “传输安全” 需求的完整性、合理性、可行性与安全性，确保其满足项目目标且设计得当
2. 评审文档：[传输安全 RS](https://taosdata.feishu.cn/wiki/ACKtwrzpbi4T62kXk79cC3Ixndb)
3. 会议主持：关胜亮
4. 会议人员：关胜亮、霍琳贺、张心治、李珲、程洪泽、徐开礼、邓怡豪、佘彦杰、张博民
5. 会议时间：2025-10-14 16:00 - 17:00
6. 会议形式：线下
7. 会议地点：taosX
8. 会议记录人：关胜亮

## 2. 评审记录

评审认为除以下5点需在FS中明确外，其余需求合理：
1. 私钥文件管理逻辑​：FS 需明确私钥文件的生成、更换和保存完整流程
2. 关键信息传输规范​：SASL 等传输细节应在 FS 中定义，使用开源库需额外评审
3. 连接管理行为澄清​：
   - `connect_idle_time` 指用户连接空闲时间，非 socket 层级
   - `MAX_CALL_PER_VNODE` 需评估对查询写入的影响
4. 安全选项默认行为​：FS 需明确各安全功能的默认启用状态和生效条件
5. 性能测试要求​：增强安全功能后需提供性能衰减测试报告
6. 安全需求评审结果：
   - 对需要认证的消息请求应当遵循权限控制的要求；
   - 对不需要用户认证的消息请求应当进行严格的限流和安全审计；
   - 对影响 MNode 延迟的消息应当及时处理；

## 3. 评审结论

通过
