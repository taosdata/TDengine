## 2. 评审记录

经与会人员充分讨论，就“安全审计”需求形成以下评审意见与决议：
1. 审计功能层级​：明确审计功能覆盖五个层级，分别为系统级、集群级、数据库级、子表级及数据级。
2. 审计数据库权限​：规定审计类型数据库需由具备 `CREATE AUDIT DATABASE`权限的用户创建，且系统内此类数据库仅可存在一个。
3. 审计消息传输​：审计消息将通过 taosKeeper 组件进行传输。传输过程中，由 mnode 节点提供审计数据库名称及审计用户 token 等信息。
4. SYSAUDITOR 与审计日志记录用户​：系统初始化后，将自动创建 SYSAUDITOR 角色。之后，SYSAUDITIOR 会创建一个专用于记录审计日志的用户，该用户仅拥有写入审计信息的权限，并为其分配专属 token。

### 2.1 安全需求评估

1. 审计功能需要对现有 taosKeeper 组件进行重构，以避免潜在的 TOKEN 泄漏风险
