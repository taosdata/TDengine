# 20251224 简版 Lag 函数-设计评审记录

## 2. 评审记录

1. 语法维度：文档明确简版 Lag 函数的语法格式为 lag(expr)，简化了传统 LAG 函数的调用方式，无需参数及 OVER 子句
2. 安全维度：功能设计核心为优化 NULL 值填充逻辑、简化函数调用语法，未涉及数据访问权限、数据加密、数据传输等安全相关逻辑
3. 性能维度：简版 Lag 函数填充相同行数数据的性能与 Interp 函数类似，扫描列的性能相比 DIFF 函数无下降，性能指标描述具体且贴合实际业务场景
