# 20251205 TSDB 3.3.8.0 产品发布报告评审记录

## 1. 评审信息

1. 评审目的：本次会议依据《项目发布过程》要求，针对 TDengine TSDB 3.3.8.0 版本的《产品发布报告》进行综合评审。会议评估了测试覆盖范围、缺陷修复情况、性能基准及已知风险，旨在确认该版本是否满足发布条件。
2. 评审文档：[TSDB 3.3.8.0 产品发布报告](https://taosdata.feishu.cn/wiki/QgnKwGx6jiXzy8kw22EcRRP4nNf)
3. 会议主持：关胜亮、肖波
4. 会议人员：关胜亮、肖波、王旭、贾靖斌（功能测试）、聂敏慧（性能测试）、陈浩然（安全测试）
5. 会议时间：2025-12-5 16:00 - 16:30
6. 会议形式：线下
7. 会议地点：taosX
8. 会议记录人：肖波

## 2. 评审记录

#### 2.0.1 测试结论与准出一致性

- **冒烟测试：** 共运行 151 个用例，通过率 100%。
- **功能与稳定性：** CI 测试（1715个用例）及长时间用例测试（683个用例）通过率均为 100%。
- **稳定性验证：** 持续运行 48 小时以上，捕获并修复了 1 个查询异常，目前系统运行稳定。
- **结论：** 版本质量符合《系统测试计划》中的 P0/P1 缺陷必须关闭且功能覆盖率 100% 的准出标准。

#### 2.0.2 性能基准对比

- **基准测试：** 与 3.3.7.0 版本对比，24 个测试场景中的平均值（avg）和每秒查询数（QPS）仅有小幅波动，未发现性能下降。
- **专项对比：** 第 2 阶段流计算性能测试报告显示 3370 与 3380 性能持平。

#### 2.0.3 发布材料完整性检查

- **安装包：** 已提供 Docker 镜像（tsdb/tsdb-ee/tdgpt）及 NAS 服务器存储路径（/Release/TDengine/3.3/v3.3.8.0）。
- **Release Notes：** 包含新增功能（如 taosAdapter 增强、taosX 优化）、行为变更及修复的 40+ 个问题，已同步至官网及 GitHub。
- **培训材料：** 项目经理已准备好面向市场和交付部门的培训课件及考试题目。

## 3. 遗留问题与风险评估

- **已知限制：** 报告中列出了部分低优先级缺陷，不影响核心业务流程，计划在后续版本解决。
- **应对措施：** 交付团队需在发布后一周内通过产品培训，指导用户规避已知问题。

## 4. 评审结论

**通过**
