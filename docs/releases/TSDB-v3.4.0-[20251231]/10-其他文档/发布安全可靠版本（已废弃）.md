# 发布安全可靠版本（已废弃）

## 1. 背景

为了通过安全可靠认证以及等保四级测评，在 3.4.0.0 及更高的版本，我们增加了一系列安全相关的功能，其中包含但不限于：身份鉴别，访问控制，存储安全，传输安全，安全审计等。这些功能无疑会影响到查询，写入等功能的性能，对于一些不需要安全功能的客户这些性能损耗是没有必要的。因此增加了编译选项 `BUILD_SECURITY` 用于控制版本是否开启安全可靠的相关功能。
之所以要通过编译选项控制，而不是通过配置参数控制。是由于许多安全功能在集群初始化时就已经开始生效，使用配置参数控制会导致行为十分混乱。

## 2. 关于发版流程的修改

要求平台部在 3.4.0.0 后续版本发布时，同时发布两个版本，一个是安全可靠版本，一个是性能版本，由用户自行选择使用哪个版本。
