## 2. 变更申请

### 2.1 BCR-3400-001

| 项目 | 内容 |
| --- | --- |
| 变更申请编号 | BCR-3400-001 |
| 申请日期 | 2025-11-15 |
| 申请人 | 霍琳贺 |
| 所属部门 | 研发部 |
| 影响基线 | BL-3400-001（需求基线） |
| 变更类型 | 需求变更 |

**变更原因：**

v3.4.0 OAuth 2.0 实现过程中，确认需新增定制化 Refresh Token 超时策略（多租户场景下 Token 有效期独立配置）及 Token 撤销接口（Revoke Endpoint），与初版需求规格（CI-3400-FS-001 v1.0）存在偏差。原有功能规格说明未覆盖上述场景，需通过基线变更纳入正式需求范围。对应风险记录：Risk-3400-05。

**变更内容：**

| 序号 | 变更项 | 变更前 | 变更后 |
| --- | --- | --- | --- |
| 1 | OAuth 2.0 Token 超时策略 | 全局统一超时配置 | 支持多租户场景下 Token 有效期独立配置 |
| 2 | Token 管理接口 | 不含 Revoke 接口 | 增加 Token 撤销接口（Revoke Endpoint） |

**影响分析：**

| 影响范围 | 说明 |
| --- | --- |
| 需求文档 | CI-3400-FS-001 更新至 v1.1，CI-3400-RTM-001 同步更新 |
| 设计文档 | CI-3400-DS-001 需补充多租户 Token 配置设计章节 |
| 测试用例 | 需新增多租户 Token 超时及 Revoke 接口相关测试场景（约 8 条用例） |
| 工期影响 | 霍琳贺评估额外工作量约 3 人天，可在原计划内消化（安排加班） |
| 风险 | 进度风险低，已纳入 Risk-3400-05 跟踪 |
