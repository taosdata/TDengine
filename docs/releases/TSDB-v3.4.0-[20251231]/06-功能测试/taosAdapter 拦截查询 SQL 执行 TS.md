## 6. 功能测试

| 3 | 无效正则表达式容错 | 测试配置文件包含无效正则表达式时的容错处理 | 通过 |

### 6.3 Restful SQL拒绝功能

#### 6.3.1 测试要点

本测试主要验证SQL拒绝功能在实际HTTP请求中的正确性，重点测试了多种危险SQL操作（DROP、ALTER等）的拦截效果，同时确保合法的SQL查询能够正常执行，验证了正则表达式匹配规则的准确性和完整性。

#### 6.3.2 用例列表

| # | 测试用例 | 测试描述 | 测试结果 |
| --- | --- | --- | --- |
| 1 | DROP DATABASE 拒绝测试 | 测试DROP DATABASE语句被正则表达式正确拦截并返回403状态码 | 通过 |
| 2 | DROP TABLE 拒绝测试 | 测试大小写混合的DROP TABLE语句被正确拦截并返回403状态码 | 通过 |
| 3 | ALTER TABLE 拒绝测试 | 测试ALTER TABLE语句被正则表达式正确拦截并返回403状态码 | 通过 |
| 4 | SELECT FROM testdb 拒绝测试 | 测试针对testdb数据库的SELECT查询被正确拦截并返回403状态码 | 通过 |
| 5 | 允许的SQL语句测试 | 测试不在拒绝列表中的SELECT语句（information_schema查询）正常执行并返回200状态码 | 通过 |
