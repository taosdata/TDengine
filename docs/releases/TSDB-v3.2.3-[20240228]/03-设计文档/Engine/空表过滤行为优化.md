# 空表过滤行为优化

## 1. 背景

需求：用户执行分组count查询超级表时，期望按tag或子表分组时，能看到所有分组的现状，即那些tag、那些子表下有数据，那些没有数据，且可以进一步筛选出那些没有数据的tag标签、空表。目前由于查询过程中空表被过滤，查询结果只输出了有数据，即count值大于0的分组，看不出那些tag或子表下没有数据。
现状：TDengine服务端已经提供了countAlwaysReturnValue配置开关，默认值=1，即已启用状态。该配置的含义是count查询总是返回结果，即使count值为0也返回结果，明确告知用户是否统计到数据。
目标：扩展countAlwaysReturnValue支持的范围，在启用状态下，select count查询过程中新增对空表的处理，group by/ partition by分组查询结果中，输出count=0的空组, 明确告知用户那些组有数据，那些组没有。

## 3. 行为说明

以超级表meters为例，它有两个tag：location、groupId，仅子表d2001有数据。
```sql
taos> select tbname from meters group by tbname;
             tbname             |
=================================
 d002                           |
 d2001                          |
 d1002                          |
 d2002                          |
Query OK, 4 row(s) in set (0.006065s)

taos> select tbname,* from meters;
             tbname             |           ts            |       current        |   voltage   |        phase         |            location            |   groupid   |
======================================================================================================================================================================
 d2001                          | 2023-12-10 18:44:44.507 |           10.3000002 |         219 |            0.3100000 | California.X                   |           5 |
 d2001                          | 2023-12-11 14:14:57.987 |           10.3999996 |         210 |            0.2100000 | California.X                   |           5 |
 d2001                          | 2023-12-13 16:53:58.398 |           10.3999996 | NULL        |            0.2100000 | California.X                   |           5 |
Query OK, 3 row(s) in set (0.006476s)
```

下面举例说明支持空组输出后，sql查询结果的变化。文中提到的空组指的是结果中，count统计值为0的分组。
**以下sql语句中 group by 可替换为partiton by**。针对tag、tbname的count分组统计结果上，两者表现一致；两者区别在于非聚合场景，不在本文讨论。

### 3.1 Group by tag，支持输出空组

- 如果所有子表对应的tag都非NULL，则不会有tag值为NULL的分组；反之，tag值为NULL的也构成一个分组。本示例子表d002的tag （groupId）值为NULL，groupId=NULL在输出中占一行
- 本功能实现后，**即使某tag值下只有空子表也输出一行空组**。本示例groupId（6，NULL）下只有空子表，会输出空组。用户据此得知那些tag分组下还没有写入数据
- tag、tbname组合分组时，每个子表对应一个分组，子表无数据时会输出为空组
- 可添加针对tag、tbname的过滤条件，符合条件的分组才会输出。例如以groupId=6为过滤条件，此时空组也满足过滤条件的会输出
```sql
taos> select groupId, count(*) from meters group by groupId;
   groupid   |       count(*)        |
======================================
           5 |                     3 |
 NULL        |                     0 |
           6 |                     0 |
Query OK, 3 row(s) in set (0.007703s)

taos> select groupId, tbname, count(*) from meters group by groupId, tbname;
   groupid   |             tbname             |       count(*)        |
=======================================================================
           6 | d2002                          |                     0 |
           6 | d1002                          |                     0 |
 NULL        | d002                           |                     0 |
           5 | d2001                          |                     3 |
Query OK, 4 row(s) in set (0.015850s)

taos> select groupId, tbname, count(*) from meters where groupId=6 group by groupId, tbname;
   groupid   |             tbname             |       count(*)        |
=======================================================================
           6 | d2002                          |                     0 |
           6 | d1002                          |                     0 |
Query OK, 2 row(s) in set (0.015850s)
```

### 3.2 Group by tbname，支持输出空组

此时每个空组对应一个无数据的空子表
可添加针对tag、tbname的过滤条件
```sql
taos> select count (*) from meters group by tbname;
       count (*)       |
========================
                     3 |
                     0 |
                     0 |
                     0 |
Query OK, 4 row(s) in set (0.013853s)

taos> select tbname, count (*) from meters group by tbname;
             tbname             |       count (*)       |
=========================================================
 d1002                          |                     0 |
 d2002                          |                     0 |
 d2001                          |                     3 |
 d002                           |                     0 |
Query OK, 4 row(s) in set (0.013608s)

taos> select tbname, count (*) from meters where groupId=6 group by tbname;
             tbname             |       count (*)       |
=========================================================
 d1002                          |                     0 |
 d2002                          |                     0 |
Query OK, 2 row(s) in set (0.006761s)
```

### 3.3 having count(*)过滤，支持输出或过滤空组

having count(*) = 0 只输出空组；having count(*) > 0 过滤空组
```sql
taos> select tbname from meters group by tbname  having count(*) = 0;
             tbname             |
=================================
 d002                           |
 d1002                          |
 d2002                          |
Query OK, 3 row(s) in set (0.006105s)

taos> select tbname, count (*) from meters group by tbname  having count(*) > 0;
             tbname             |       count (*)       |
=========================================================
 d2001                          |                     3 |
Query OK, 1 row(s) in set (0.007589s)

taos> select groupId, count (*) from meters group by groupId  having count(*) = 0;
   groupid   |       count (*)       |
======================================
 NULL        |                     0 |
           6 |                     0 |
Query OK, 2 row(s) in set (0.004814s)
```

### 3.4 count(*) 、count(1) 、count(colX)都支持，可输出空组

- count查询 + 分组场景，是可输出空组的2个前提
- count 分组查询，和其他聚合算子一起查询时，也支持输出空组
  - Elapsed, irate方法， 涉及 table merge scan，需构建相关用例
- count(*)、count(1)统计的是属于各分组的记录条数
- count(colX) 统计的是属于各分组的，colX列值非空的记录条数，当colX列有空值时，其统计值小于count(*)
```sql
taos> select count(*), sum(1) from meters group by tbname;
       count(*)        |        sum(1)         |
================================================
                     0 |                     1 |
                     0 |                     1 |
                     3 |                     3 |
                     0 |                     1 |
Query OK, 4 row(s) in set (0.018551s)

taos> select groupId, count (*), sum(1) from meters group by groupId;
   groupid   |       count (*)       |        sum(1)         |
==============================================================
           5 |                     3 |                     3 |
 NULL        |                     0 |                     1 |
           6 |                     0 |                     2 |
Query OK, 3 row(s) in set (0.063345s)

taos> select groupId, count (voltage), sum(voltage) from meters group by groupId;
   groupid   |    count (voltage)    |     sum(voltage)      |
==============================================================
           5 |                     2 |                   429 |
 NULL        |                     0 | NULL                  |
           6 |                     0 | NULL                  |
Query OK, 3 row(s) in set (0.005401s)

taos> select count(1), sum(1) from meters group by tbname;
       count(1)        |        sum(1)         |
================================================
                     0 |                     1 |
                     0 |                     1 |
                     3 |                     3 |
                     0 |                     1 |
Query OK, 4 row(s) in set (0.014408s)

taos> select count(ts), elapsed(ts) from meters partition by tbname;
       count(ts)       |        elapsed(ts)        |
====================================================
                     3 |     1.702457638398000e+12 |
                     0 |         0.000000000000000 |
                     0 |         0.000000000000000 |
                     0 |         0.000000000000000 |
Query OK, 4 row(s) in set (59.065883s)
```

### 3.5 对数据做过滤的情形下，支持输出空组

- 分组下有数据记录，但没有满足过滤条件的记录时，会输出空组；
  - 限制条件只加在数据列上时，分组个数不变，输出行数不变，count值在变，严格的条件能使得所有分组都输出为空组
  - 限制条件加在tag、tbname上时，输出的分组个数会变，即结果行数会变，一些分组被过滤掉了，满足条件的空组仍会输出。
- 3.1指出若分组下只有空表会输出空组。注意这两种空组成因有异。一次查询输出，两种成因的空组都可能有。
```sql
taos> select tbname, count (*) from meters where voltage < 215 group by tbname ;
             tbname             |       count (*)       |
=========================================================
 d2001                          |                     1 |
 d002                           |                     0 |
 d1002                          |                     0 |
 d2002                          |                     0 |
Query OK, 4 row(s) in set (0.005867s)

taos> select tbname, count (*) from meters where ts <  '2023-12-11 15:14:57.987' group by tbname ;
             tbname             |       count (*)       |
=========================================================
 d2001                          |                     2 |
 d002                           |                     0 |
 d1002                          |                     0 |
 d2002                          |                     0 |
Query OK, 4 row(s) in set (0.006120s)

taos> select tbname, count (*) from meters where ts <  '2023-10-11 15:14:57.987' partition by tbname;
             tbname             |       count (*)       |
=========================================================
 d1002                          |                     0 |
 d2002                          |                     0 |
 d2001                          |                     0 |
 d002                           |                     0 |
Query OK, 4 row(s) in set (0.005292s)
```

### 3.6 分组子句中含有数据列的，无空组输出

按列值划分分组时，是在已有记录集上划分，不会有空组输出
列值即使为NULL也是存在于行数据中的，故而按列分组时，若有列值为null的记录行，分组结果中就会对应有一行
```sql
taos> select voltage, count (*) from meters group by voltage;
   voltage   |       count (*)       |
======================================
         NULL|                     1 |
         210 |                     1 |
         219 |                     1 |
Query OK, 3 row(s) in set (0.005264s)

taos> select voltage, groupId, tbname, count(*) from meters group by voltage, groupId, tbname;
   voltage   |   groupid   |             tbname             |       count(*)        |
=====================================================================================
         210 |           5 | d2001                          |                     1 |
         219 |           5 | d2001                          |                     1 |
         NULL|           5 | d2001                          |                     1 |
Query OK, 3 row(s) in set (0.003334s)
```

### 3.7 interval 等窗口查询时，无空组输出

时间窗查询不支持输出空组，以避免空组输出影响更为关键的有效数据分布展示。
会话窗口Session、状态窗口state_window、事件窗口event_window ，均不支持空组输出
仅 partition by  可配合使用interval，group by 不可以
```sql
taos> select tbname, count (*) from meters  partition by tbname interval(1d);
             tbname             |       count (*)       |
=========================================================
 d2001                          |                     1 |
 d2001                          |                     1 |
 d2001                          |                     1 |
Query OK, 3 row(s) in set (0.005531s)

taos>  select tbname, count (*),_wstart,_wend from meters  partition by tbname interval(2d);
             tbname             |       count (*)       |         _wstart         |          _wend          |
=============================================================================================================
 d2001                          |                     1 | 2023-12-09 00:00:00.000 | 2023-12-11 00:00:00.000 |
 d2001                          |                     1 | 2023-12-11 00:00:00.000 | 2023-12-13 00:00:00.000 |
 d2001                          |                     1 | 2023-12-13 00:00:00.000 | 2023-12-15 00:00:00.000 |
Query OK, 3 row(s) in set (0.003970s)

taos> select tbname, count (*) from meters  partition by tbname interval(2d) sliding(1d);
             tbname             |       count (*)       |
=========================================================
 d2001                          |                     1 |
 d2001                          |                     2 |
 d2001                          |                     1 |
 d2001                          |                     1 |
 d2001                          |                     1 |
Query OK, 5 row(s) in set (0.002804s)

taos> select tbname, count (*) from meters  group by tbname interval(1d);
DB error: syntax error near "interval(1d);" (0.000058s)
```

### 3.9 支持内嵌select查询时输出空组

内嵌select查询时，内嵌层查询满足空组输出条件的，仍会输出；
最终输出结果取决于外层SQL，可能会透出空组，也可能空组被过滤或被聚合输出。
外层SQL基于内层查询得到的临时表，不涉及本功能空表优化逻辑；union、join查询都是内嵌查询之上的外层行为，不涉及空表优化逻辑
```sql
taos> select * from (select groupId, count(*), sum(voltage) from meters group by groupId);
   groupid   |       count(*)        |     sum(voltage)      |
==============================================================
           5 |                     3 |                   429 |
 NULL        |                     0 | NULL                  |
           6 |                     0 | NULL                  |
Query OK, 3 row(s) in set (0.004684s)

taos> select sum(1) as empty_tag_count from (select count(*) as c from meters partition by groupId) where c=0;
    empty_tag_count    |
========================
                     2 |
Query OK, 1 row(s) in set (0.004189s)

taos> select groupId, c from (select groupId, sum(voltage) as s, count(*) as c from meters partition by groupId) where s is NULL;
   groupid   |           c           |
======================================
 NULL        |                     0 |
           6 |                     0 |
Query OK, 2 row(s) in set (0.005369s)
```

## 4. 性能

本功能点在扫描时对空表，或有数据但没有符合限制条件记录的表，做额外处理，来保障最终输出空组，相比表扫描的代价而言，只有微小耗时，理论上会使查询变慢，但程度轻微

## 5. 兼容性

相比之前分组查询不输出空组而言，本功能使得一些查询输出的rows增多，count=0的分组结果也被输出。
一些ci自动化测试case需要调整输出结果校验逻辑，以适配本次变更
用户一般而言不会利用是否有输出来处理自身逻辑；如果有此类逻辑则需要调整，或将countAlwaysReturnValue配置为0，不使用本功能

无

## 7. 使用场景

1. 查询超级表按指定tag分组时的数据分布，有那些tag标签存在但没有数据。参见3.1
2. 查询指定tag标签值下子表的数据分布，相关各子表有多少条数据。参见3.2
3. 查询超级表下有所有子表的数据分布，那些有数据&数据量多少，那些没有。参见3.2
4. 查询超级表下有/没有数据的子表名。参见3.3
5. 查询特定条件下按tag分组的数据分布，是否有符合条件的记录，那些分组没有符合条件的数据。参见3.5
6. 查询特定条件下各子表的数据分布，是否有符合条件的记录，那些子表没有符合条件的数据。参见3.5

## 8. 约束和限制

需要启用countAlwaysReturnValue开关，在taos.cfg中配置，默认值=1，配置为0时本功能失效。集群内各节点需保持相同配置
只针对分组场景，执行count统计时生效，分组关键字 group by、partition by。
只在分组条件为tag、tbname或它们的组合时，有空组输出。
分组条件中含有数据列的，无空组输出。参见3.6
interval时间窗查询时，无空组输出。参见3.7

## 9. 常见错误和排查

1. 集群部署，已知一些超级表（例如A、B）下子表无数据，超级表A查询返回内容有空组，但超级表B查询返回内容没有空组。
排查：
- 检查集群各节点的countAlwaysReturnValue开关配置是否一致，需要都是打开状态，查询结果才会统一返回空组。
