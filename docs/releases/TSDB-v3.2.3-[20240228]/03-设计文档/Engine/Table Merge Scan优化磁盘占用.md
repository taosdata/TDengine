# Table Merge Scan优化磁盘占用

## 1. 背景

通过查询提示 para_tables_sort(), 选用排序时不占用临时磁盘空间的算法. 此方法使用大量内存, 减少磁盘占用, 解决TS-4463提出的问题.

## 3. 定义

使用 para_tables_sort 提示后, 排序不占用临时磁盘空间.
```json
SELECT [hints] [DISTINCT] [TAGS] select_list

hints: /*+ [hint([hint_param_list])] [hint([hint_param_list])] */

hint:
    PARA_TABLES_SORT | other-hints
```

## 4. 行为说明

提示 para_tables_sort选用的算法实现如下, 
- 对查询的超级表的每个子表, 使用一个 tsdb reader, 按块读取其数据. 读取的数据块存放到内存中
- 使用一颗多路归并树, 对多路数据块进行排序. 路数等同于子表数. 
- 排序后数据直接输出给下级算子
基本内存占用 = 子表数 * (每reader内存占用 + 1024 * 行长) + 1024 * 行长
使用 para_tables_sort 提示后, 排序不占用临时磁盘空间.

## 5. 性能

性能有可能比不使用提示降低. 降低发生在每个子表一个reader读取数据块时. 降低幅度取决于子表数和磁盘数据组织布局.
性能提升非本任务目的

## 6. 兼容性

此算法是3.0版本最初算法.

## 7. 运维

使用前计算内存占用, 使用中关注内存占用

## 8. 使用场景

数据量大, 磁盘空间不足, 机器物理内存大.

## 9. 约束和限制

子表数很多, 数据行很长时, 内存占用过大, 有可能引起OOM
