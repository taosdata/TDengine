# 安装包测试（企业版）

## 一、测试目标

对 3.2.3.0 对外发布的企业版安装包安装过程进行全面测试
nas/Release/TDengine/v3.2.3.0.0227/ 目录下的安装包

## 二、测试结论

使用 27号出的 3.2.3.0 安装包在 LINUX 及 WINDOWS 下做了一个基本安装卸载功能的验证，linux 下主要存在卸载时删除数据的用户体验问题（[TD-28892](https://jira.taosdata.com:18080/browse/TD-28892)），WINDOWNS 下存在卸载菜单没有的问题（[TD-28898](https://jira.taosdata.com:18080/browse/TD-28898)），已提jira。除这两项其他基本功能都没有问题，验证通过！

## 三、测试资源及环境

测试平台：LINUX  WINDOWS 
测试资源：
      192.168.1.51 Ubuntu 20
      192.168.3.131 Window 11

## 四、测试重点及难点

重点测试安装及卸载的流程上的问题

## 五、测试方法

直接手工安装卸载，查看安装过程中的问题
