# 专测测试：数据量极少或空情况下的专项测试 TS-4382

### 1. 测试目标

Task：https://jira.taosdata.com:18080/browse/TD-28146
针对 [TS-4382](https://jira.taosdata.com:18080/browse/TS-4382) crash at tsort.c:905的客户问题，暴露出产品在元数据为空的查询中依然存在问题，本次专项测试的目的是构造出更多的元数据为空的查询场景，保证在元数据为空的查询中，产品代码正确处理，减少产品crash问题，同时将用例补充在CI测试用例test_ts4382.py中。

### 3. 测试范围

本次专项测试主要验证查询执行正常，有无crash的严重问题，对查询结果的正确性不做判断，不涉及正确性验证；同时由于数据量较小，不涉及压力及大压力下的稳定性验证；性能、安全测试不在本次测试范围内。
同时本次测试主要对静态数据中包含元数据为空的查询，数据动态写入的场景不在本次测试范围内。
