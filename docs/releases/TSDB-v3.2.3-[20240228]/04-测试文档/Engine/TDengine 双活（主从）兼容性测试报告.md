# TDengine 双活（主从）兼容性测试报告

## 1. 测试目标

  测试的需求文档：[TDengine 双活 ](https://taosdata.feishu.cn/wiki/E9NmwBfIbiTA5bkq8kScFX0yn8c)，本测试主要对新增的双活功能的兼容性测试，即新增的双活功能的代码在不开启双活功能的情况下不影响原有 TDengine 的功能

## 2. 测试范围

本次测试的范围是双活功能的兼容性，即在不开启双活功能时，原有 TDengine 的功能都能保持正常

## 3. 测试方法

本次兼容性主要在 WAL中，为需求功能需求，在 WAL 中增加了一个标记位，用于记录当前的 WAL 数据是 TAOX 写入的，还是用户写入的。所以测试方法重点在 WAL 的兼容性测试验证，计划按以下步骤验证：
- 使用 3.2.0.0 版本程序安装 TDengine
- 创建 3 节点集群， 1 副本数据库，WAL 保留时长为默认
- 创建 1 个订阅
- 创建 3 个流计算
- 使用 taosBenchmark 写入100w 子表，每个子表 1w 数据
- 不做 flush database ,   让一部分数据保留在 wal 中
- 退出服务，使用合入了双活功能的 3.2.3.0 版本（即3.0 最新代码）编译重新安装 TDengine
- 启动 taosd 服务
- 检查100w 子表，每子表 10w 数据都保留完整
- 检查订阅及功能正常
- 继续写入数据，订阅及流功能应都为正常
以上步骤都符合预期，可验证对 WAL 的改动未影响原来的功能
