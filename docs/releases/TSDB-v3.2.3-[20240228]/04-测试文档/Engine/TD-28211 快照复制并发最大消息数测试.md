# TD-28211 快照复制并发最大消息数测试

TD-28211

参考[[Test Report] -TD-26537 测试优化 TSDB snapshot 传输的效率 特性](https://taosdata.feishu.cn/wiki/TiX5wdrbyidVmPk1FiGcat4MnGm) 
配置参数：syncSnapReplMaxWaitN
取值范围：[16, 256] 默认值：128

## 一. 测试结论

参数可用，由于数据量不大，每次测试波动大。从目前的情况来看，性能跟预期一样，未发生大变化。测试通过。

## 二. 测试用例

1. 测试syncSnapReplMaxWaitN，配置 15、16、256、257、200000 ，只有 16 和 256可用，不配置参数，默认为 128。通过 sql 检查：`select * from information_schema.ins_dnode_variables where name = 'syncSnapReplMaxWaitN'`
2. 测试128、 256和未修改以前的固定值的性能对比 
  ·配置一个6 节点 的集群(可使用test.py来生成)，写入数据以后，配置WAL_RETENTION_PERIOD 为 0。
```shell {wrap}
 alter database test WAL_RETENTION_PERIOD 0
 taosBenchmark -v 1   -t 100000 -n 100000  -y  -c /home/chr/2.6/TDinternal/sim/dnode1/cfg/
 
集群配置：
fqdn yw86
monitor 0
locale en_US.UTF-8
charset UTF-8
firstEp yw86:6030
serverPort 6030
secondEp yw86:6130
dataDir /home/chr/2.6/TDinternal/sim/dnode1/data
logDir /home/chr/2.6/TDinternal/sim/dnode1/log
syncSnapReplMaxWaitN 256

```
