# 空表过滤行为优化

## 一、测试功能简介

  select count查询过程中对空表的返回进行处理，但是对于group by/ partition by分组查询返回结果仍未处理，目前主要增加分组之后的返回结果的处理。
需求文档：[空表过滤行为优化](https://taosdata.feishu.cn/wiki/SAFgwnMGziIf4VkMX4LcUPd1nVf) 

jira:https://jira.taosdata.com:18080/browse/TD-26813?filter=23428 

## 二、测试结论

  该功能测试通过。

## 三、测试资源及环境

   测试平台：Linux x64
   测试资源：192.168.1.44
