# TD-28163 专测：写入包含各类型相同值，各类型空值场景测试测试

### 1. 测试目标

Task：https://jira.taosdata.com:18080/browse/TD-28163
本次专项测试的目的是模拟一种极端的数据场景，表中数据包含各种数据类型，所有有值的列保持相同的值，空列写入空值，基于百万数据执行查询，包括过滤、join、group by ...order by, 窗口等，验证系统在此极端数据场景下无crash、查询正确性问题，同时将用例数据集减小，补充到CI用例集里。
