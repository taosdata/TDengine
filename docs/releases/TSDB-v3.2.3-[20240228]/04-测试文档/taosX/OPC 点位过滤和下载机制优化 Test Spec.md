## 3. Scope

这里用于描述本需求的覆盖范围：
- 测试用例均通过 Explorer 执行。
- 测试包含 OPC DA 和 UA。

## 4. 测试结论

OPC 点位过滤和下载机制优化的功能测试中，主要验证了新的 UI 下 OPC UA/DA 选择数据点位功能是否正确，是否可以直接基于选择数据点位的功能创建写入任务。另外验证的就是使用新的模板 OPC UA/DA 数据写入的功能是否正常工作，除此之外还验证了旧模板是否生效。同时也验证了 OPC UA 在修改了安全模式及安全策略在新的设置方式下是否能正常工作。上述所有验证目前测试用例已经全部覆盖，且已经测试通过。由于验证条件过多，在测试过程中会使用提前组合（比如组合安全模式及安全测试与新的模板自定义超级表名、自定义子表名这样的测试条件会进行组合）的方式以加快效率。
由于条件很多，可能也会存在某些尚未覆盖到的情况。

### 8.2 Usability

测试用例包括但不局限于：
- UI是否美观？
- 交互是否合理？
- 字体、字号是否合适？
- 是否存在错别字？
1. 异步下载的交互是否正确和流畅。
2. 过滤点位的时候 UI 显示是否正确。

### 8.3 Reliability

这里用于描述稳定性测试相关的内容。
1. OPC 相关的修改未涉及到异常处理的内容，稳定性应与之前版本保持一致。

### 8.4 Performance

这里用于描述性能测试相关的内容。
1. taosx 侧的 OPC 此次修改暂不涉及数据处理及数据写入，所以理论上应与之前的性能相同。不过 1.5.0 对 OPC 连接器的采集方式有做修改，所以性能测试需要重新进行。

### 8.6 Compatibility

1. OPC UA/DA 的前一版本的选择所有点位的任务在该版本需要能够正常运行。
2. OPC UA/DA 的前一版本使用旧有模板文件的任务在该版本需要能够正常运行。
