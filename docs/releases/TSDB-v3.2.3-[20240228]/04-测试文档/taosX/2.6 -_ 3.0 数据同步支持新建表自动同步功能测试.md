# 2.6 -> 3.0 数据同步支持新建表自动同步功能测试

## 1. Objectives

本次测试的主要目标：
- 在 TDengine 2.6-3.0 数据同步和数据迁移过程中，TDengine 2.6 中新建超级表、子表、写入实时数据，taosX 能够支持自动同步在数据源一侧的新增元数据和数据。

## 2. 测试结论

1. 在数据库级的数据同步过程中，源库中新增超级表、子表、普通表、写入实时数据，目标库可同步更新表信息和实时数据；
2. 在超级表级的数据同步过程中，源超级表中新增子表、写入实时数据，目标超级表可同步新增子表信息和实时数据；
3. 在数据库级的数据迁移过程中，源库中新增超级表、子表、普通表、写入任务指定时间范围内的时序数据，目标库可同步更新表信息和时序数据；
4. 在超级表级的数据迁移过程中，源超级表中新增子表、写入任务指定时间范围内的时序数据，目标库可同步更新子表信息和时序数据；
综合测试结果，本次测试通过，满足功能需求。
