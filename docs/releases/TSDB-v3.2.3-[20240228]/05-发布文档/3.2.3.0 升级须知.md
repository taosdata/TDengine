# 3.2.3.0 升级须知

1. 授权：License 机制重构，能够兼容旧的 License
2. 运维：redistribute vgroup, split vgroup 对写入的阻塞时间变短，但命令执行时间变长
3. TDinsight 进行了升级，请使用 tdengine-datasource-3.5.0 版本
4. taosKeeper 新增了日志配置，请在 taoskeeper.toml 中增加下面配置
  ```java {wrap}
  [log]
  rotationCount = 5
  rotationTime = "24h"
  rotationSize = 100000000
  
  ```

1. taosd 监控：taosd 监控数据重构，如果使用了旧版本 taosd 并且启用了监控，建议在升级前先删除 log 库，或者修改 taosKeeper 配置将新的监控数据写入一个不同的库，具体操作步骤如下：
   - 停止 taosKeeper （避免新数据写入）
   - 删除 log 库， 或修改 taosKeeper 配置
   - 停止集群（含taosd, taosAdapter)
   - 升级 （含 taosd, taosAdapter, taosKeeper）
   - 启动集群，taosKeeper 需在 taosd 启动后再启动， 一分钟后待监控数据上报后，执行sql
  ```sql
  delete from log.taos_sql_req;
  ```

  然后再重启一次 taosKeeper。 （此问题会在下版本修复）
   - 升级 TDengine Grafana 插件版本，重新 import 监控面板
   - 查看监控
1. taosX 监控：
   - 需要安装 TDinsight for taosX 监控面板
   - taosX 配置项：新增 monitor 部分，当配置了 monitor.fqdn 时就会开启 taosX 的监控功能。具体如下
    ```toml
    [monitor]
    # FQDN of taosKeeper service, no default value
    # fqdn = "localhost"
    # port of taosKeeper service, default 6043
    # port = 6043
    # how often to send metrics to taosKeeper, default every 10 seconds. Only value from 1 to 10 is valid.
    # interval = 10
    ```
