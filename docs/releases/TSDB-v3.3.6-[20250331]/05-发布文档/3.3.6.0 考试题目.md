# 3.3.6.0 考试题目

#### 1. 第一部分，笔试题目，所有人回答

1. TDgpt 的功能特点
2. TDgpt 的主要亮点
3. TDgpt 支持那些时序模型
4. 虚拟表能解决哪些问题
5. 虚拟表的功能特点
6. 虚拟表的主要亮点
7. 虚拟表和视图的区别
8. Excel 如何连接 TDengine
9. 客户端兼容性可解决哪些问题
10. 3.3.6.0 版本 taosX 优化了哪些功能

#### 2. 第二部分，笔试题目，售前交付回答

1. 以智能电表数据模型为例，编写 SQL 语句，使用 TDtsfm 模型进行预测
2. 以智能电表数据模型为例，编写 SQL 语句，使用 Time-MOE 模型进行预测
3. 以智能电表数据模型为例，讲解 COLS 函数的作用，编写一个使用 COLS 函数的 SQL 语句
4. 讲解流计算事件通知机制的作用
5. 讲解流计算计算最小持续时长的作用
6. 讲解 DECIMAL 的使用场景、参数说明与限制
7. Interp 函数的插值策略有哪些
8. 请给出如下命令：taos shell 使用 WebSocket 连接 192.168.0.201 的 taosAdapter（6041 端口）
9. 请给出如下命令：taosBenchmark 使用 WebSocket 连接 192.168.0.201 6041 端口创建智能电表数据， 1000 子表，每表 1000 行数据

#### 3. 第三部分，实操题目，售前交付回答

1. 使用 taosBenchmark WebSocket 连接构建单列数据模型，要求：10 个电表，每个电表采集电流、电压、相位 3 个参数，合计 30 个子表，每个子表 1 万条数据，采样频率分别为 1Hz、5Hz、10Hz
2. 创建电表的虚拟超级表，包含电流、电压、相位三个数据列，包含地区、型号两个标签列
3. 为每个电表创建虚拟子表
4. 设计投影查询、窗口查询、断面查询等至少三个虚拟表应用场景，用文字说明并编写、执行 SQL 语句
5. 安装 TDgpt，使用 自研模型、Time-MOE 预测某个子表的未来 60 秒的电压
6. 使用 Explorer 进行数据库备份
