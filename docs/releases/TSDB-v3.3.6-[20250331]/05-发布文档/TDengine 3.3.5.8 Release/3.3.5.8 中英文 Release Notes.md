   - TD-33306 优化：MQTT/Kafka/CSV 新增写并发参数
   - TD-33423 优化：开源版本 TDengine 支持与 TDgpt 对接
   - TD-33534 优化：Flink 连接器支持 BinaryRowData 数据传输类型
   - TD-33551 优化：参数绑定 SQL 语句中，LIMIT 子句支持使用 ? 作为参数占位符
   - TD-33593 优化：taosX 备份开启 WebSocket 压缩
   - TD-33598 优化：ODBC SQLSetStmtAttr 支持 SQL_ROWSET_SIZE 属性

   - TS-5933  优化：Explorer float 显示精度与 taos shell 一致

   - TD-33550 修复：taosX 平滑升级

   - TD-33592 修复：received/processed_messages 当前运行指标重启未清零

   - TD-33640 修复：创建数据库时，keep_time_offset 选项支持使用后缀 h和 d 来指定时间值
   - TD-33704 修复：删除流计算时可能的死锁

   - TS-5896  修复：taosX 任务写入中断后未重新启动

   - TS-5971  修复：同时使用 DISTINCT 和 ORDER BY 关键字时出现的语法错误问题

   - TS-5981  修复：websocket 接口 timing 字段有时为负值

### 5. English

```plaintext

### 6. Features

   - TD-33663 feat: suppport tmq subscription with ONLY META in JDBC
   - TS-5965  feat: support multiple-line SQL editor in Grafana
   - TD-33564 feat: add support for VARBINARY/GEOMETRY in ODBC
   - TD-33778 feat: support TDengine with ODBC dirver in Excel
   - TS-5722  feat: taosX agent use specific port range in local connection

### 7. Enhancements

   - TD-33441 enh: websocket handle consumer error when tmq polled nothing
   - TS-5888  enh: JDBC add support for unsigned integers
   - TD-33306 enh: expose global.written_concurrent configuration for kafka/mqtt/csv in Explorer
   - TD-33423 enh: support integration with TDgpt in community version
   - TD-33534 enh: support BinaryRowData type in flink
   - TD-33551 enh: in stmt2 SQL statements, the LIMIT clause supports the use of ? as a parameter placeholder
   - TD-33593 enh: enable compression via websocket in taosX backup
   - TD-33598 enh: ODBC support SQL_ROWSET_SIZE in SQLSetStmtAttr
   - TD-33601 enh: expose num.of.consumers/writters configurations in Explorer
   - TD-33735 enh: Add connector files to the macOS installation package.
   - TD-33768 enh: handle errors when poll result is null in rust connector
   - TS-4924  enh: tsbs support csv output format
   - TS-5573  enh: add Classified Connections Counts table in TDinsight
   - TS-5933  enh: use consist float precision in explorer and tao shell
   - TS-5951  enh: flink table support update/delete
   - TS-5938  enh: taosX agent will resume connection when taosX server disconnected for long time

### 8. Fixes

   - TS-6030  fix: explorer support signup email with dot `.`
   - TD-33739 fix: flock syscall error on aws cloud storage in taosAdapter
   - TD-33755 fix: modify boolean tag values in sub-tables results in erroneous metadata from data subscriptions.
   - TS-5977  fix: allow spaces in columns of csv in explorer datain
   - TD-32588 fix: resolved the issue of high CPU usage by the stmtbind thread when the system is in an idle state
   - TD-33427 fix: health state tick to idle when no data consumed
   - TD-33503 fix: fix security issues in JDBC sample code
   - TD-33550 fix: fix upgrade compaibility issue of taosX
   - TD-33553 fix: ODBC core when set SQL_ATTR_TXN_ISOLATION with SQLSetConnectAttr
   - TD-33592 fix: received/processed_messages should be reset when task rerun
   - TD-33606 fix: when restoring data using taosX, it may crash if the database is not specified
   - TD-33640 fix: when creating a database, the keep_time_offset options supports suffixes h (hours) and d (days) for time values
   - TD-33704 fix: potential deadlocks while drop stream
   - TS-5923  fix: failed to write data in a dual-replica database when a single dnode is disconnected from the network
   - TS-5968  fix: when querying the information_schema.ins_tables table, a "Sync leader is unreachable" error may be triggered if the Leader of the mnode changes.
   - TS-5984  fix: the time-filtering query results involving composite primary keys were incorrect after data compact
   - TS-5985  fix: when the join condition of the primary key column is not a simple equality condition, it may lead to incorrect JOIN results
   - TS-5989  fix: error caused by cursor.fetchmany with custom length in python taosws
   - TS-6017  fix: the issue where the "show grants" command returned an incorrect number of columns
   - TD-33633 fix: unexpected backup points before schedule executing
   - TS-5896  fix: taosX task does not restart after interrupted
   - TS-5895  fix: jdbc select server_version() caused mem high-usage
   - TS-5932  fix: when using the WHERE tbname IN () statement, executing LAST query may cause taosd crash if the subtables filtered out do not belong to the same super table
   - TS-5937  fix: after taosd exits abnormally and is restarted, if the WAL that has not been written to the data file is too large, it may cause an OOM error during startup
   - TS-5941  fix: when using interp interpolation, if the select list contains string constants or string tags, the returned string content may be incomplete.
   - TS-5946  fix: when performing a JOIN query on a super table, using a subquery as the right table may lead to missing results
   - TS-5971  fix: syntax error while use DISTINCT and ORDER BY together.
   - TS-5972  fix: when using the CAST function to convert a floating-point number to a binary and then performing a comparison, the result may be inaccurate due to loss of precision
   - TS-5974  fix: after upgrading from version 3.3.4 to 3.3.5, the taosd service fails to start properly if the configured charset does not exist in the system
   - TS-5981  fix: websocket api timing field should not be negtive
   - TS-5983  fix: duplicates backup points in taosX
   - TS-6021  fix: configuration item s3BucketName was incorrectly set as a global variable, leading to failures while file uploads to S3.
```
