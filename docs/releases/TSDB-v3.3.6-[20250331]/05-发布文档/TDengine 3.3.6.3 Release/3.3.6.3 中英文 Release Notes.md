# 3.3.6.3 中英文 Release Notes

### 1. 中文

```markdown

### 2. 特性

   - TD-33588 特性：taosBenchmark 支持 Decimal 类型
   - TS-5969  特性：添加 DNode 主机信息和组件信息
   - TD-29134 特性：连接器 websocket 订阅支持 auto commit
   - TS-5725  特性：写入和查询大流量下的参数建议

### 3. 优化

   - TS-6260  优化：taosBenchmark ctrl-c 快速退出
   - TD-33709 优化：优化 taosX 数据库大小
   - TD-34225 优化：允许无 sysinfo 权限的用户执行 show anodes 命令
   - TS-6195  优化：流计算支持 cols 函数
   - TS-6220  改进：Python REST 连接器支持密码特殊字符 ‘/'
   - TS-6318  优化：复合主键的关键字从 primary key 修改为 composite key
   - TS-5988  改进：taosdump 支持多列或少列时仍然恢复

### 4. 修复

   - TS-6030  修复：Explorer 注册邮箱支持包含 "."
   - TD-34359 修复：OSS Explorer 注册页面缺失
   - TS-6266  修复：通过 stm2 方式写入乱序数据时可能失败的问题
   - TD-34094 修复：执行 interval fill(prev) 并使用 _wstart 排序时，如果遇到空值，结果可能不正确
   - TD-34203 修复：重启后，follower vnode 有时会长期处于 restore=false 状态
   - TD-34230 修复：taosBenchmark 配置 firstEp 不生效
   - TD-34234 修复：STMT2 高效写入模式下，Geometry 字段值为 NULL 时，写入失败
   - TD-34250 修复：创建用户时 createdb 选项不生效
   - TD-34252 修复：taosX 支持 sysinfo=0 的用户进行数据迁移
   - TD-34256 修复：taosd 退出过程中 regex 释放失败导致的死锁问题
   - TD-34340 修复：频繁创建删除 TOPIC 导致 TDB 占用磁盘空间持续增长
   - TD-34344 修复：修复 Windows 编译错误
   - TD-34377 修复：调用 stmt_set_tbname_tags 后再次调用 stmt_set_tags 会导致内存泄漏
   - TD-34451 修复：taosX 允许删除已创建状态的任务
   - TS-6217  修复：Sparse 模式同步时 taosAdapter 中断数据丢失
   - TS-6226  修复：高吞吐时双副本数据库选主失败
   - TS-6241  修复：更新数据库参数 s3_compact 时的误报问题
   - TS-6245  修复：删除数据库时，若存在离线的 Vnode，SQL 语句将无法返回
   - TS-6269  修复：Explorer 数据库名区分大小写
   - TS-6272  修复：从单副本变更到三副本的操作失败并需要回滚时，回滚过程中的数据清理错误可能导致变更失败
   - TS-6276  修复：当系统表 information_schema.ins_user_privileges 中的 condition 字段长度超过 32 个字符时，显示内容不完整。
   - TS-6301  修复：允许普通用户执行 show disk_info 命令
   - TS-6306  修复：taosBenchmark 多线程 CSV 文件建表异常
   - TS-6311  修复：Explorer 密码长度最长 255 位
   - TS-6312  修复：Excel ODBC WebSocket 加载数据报错
   - TS-6159  修复：流计算结果表在某些情况未创建完整的问题
   - TS-6166  修复：当创建数据库的事务失败时，循环发送消息会导致 CPU 占用过高
   - TS-6173  修复：show compacts 命令显示的文件组数量与实际数量不一致的问题
   - TS-6176  修复：滚动升级后流任务无法启动
   - TS-6177  修复：流任务中 checkpointBackupDir 过大的问题
   - TS-6149  修复：使用 Websocket 参数绑定批量写入数据时，子表名含中文会产生乱码
   - TS-6223  修复：TDgpt 运行在 ARM64 平台上时可能会出现异常结果
   - TS-6232  修复：STMT 语句绑定失败后再次绑定会导致崩溃


```

### 5. English

```markdown

### 6. Features

   - TD-33588 feat: taosBenchmark should suppport decimal datatype
   - TS-5969  feat: add dnode information and components status
   - TD-29134 feat: support auto commit in websocket subscription
   - TS-5725  feat: add suggestions in case of large-throughput queries

### 7. Enhancements

   - TS-6260  enh: taosBenchmark ctrl-c fast exit
   - TD-33709 enh: reduce taosX db size
   - TD-34225 enh: allow users without sysinfo privileges to execute the show anodes command.
   - TS-6195  enh: stream computing supports the cols function.
   - TS-6220  enh: support '/' in python taosrest connector
   - TS-6318  enh: changed the keyword for composite primary keys from "primary key" to "composite key" 
   - TS-5988  enh: taosdump restore backups in case of cols del/add

### 8. Fixes

   - TS-6030  fix: explorer support signup email with dot `.`
   - TD-34359 fix: user registration page not exist in oss explorer3
   - TS-6266  fix: writing out-of-order data via stm2 may fail
   - TD-34094 fix: when performing interval fill(prev) and sorting by _wstart, if there are null values encountered, the results may be incorrect.
   - TD-34203 fix: the follower vnode sometimes remains in the restore=false state for a long time after restart
   - TD-34230 fix: firstEp setting in taos.cfg not work in taosBenchmark
   - TD-34234 fix: in STMT2 high-efficiency write mode, the write operation will fail when the value of the geometry field is NULL.
   - TD-34250 fix: the createdb option does not work when creating user
   - TD-34252 fix: support migration with sysinfo=0 in taosX
   - TD-34256 fix: the deadlock issue caused by the failure of regex release during the taosd exit process
   - TD-34340 fix: frequent creation and deletion of TOPIC causes TDB's disk space usage to keep growing.
   - TD-34344 fix: windows compile error
   - TD-34377 fix: call stmt_set_tags again after stmt_set_tbname_tags may cause memory leak.
   - TD-34451 fix: taosX allow deleting tasks in "created" status
   - TS-6217  fix: fix data lost in case of taosAdapter interrupted under sparse mode
   - TS-6226  fix: leader election failure in a two-replica database under high throughput.
   - TS-6241  fix: false alarm when update the database parameter s3_compact
   - TS-6245  fix: SQL statements do not return when deleting a database with offline vnodes
   - TS-6269  fix: explorer database name now case-sensitive
   - TS-6272  fix: when rolling back a failed change from a single replica to three replicas, data cleanup errors during the rollback process can lead to the failure of the change.
   - TS-6276  fix: when the length of the condition field in the system table information_schema.ins_user_privileges exceeds 32 characters, the displayed content is incomplete.
   - TS-6301  fix: allow regular users to execute the show disk_info command
   - TS-6306  fix: tables error in case of taosBenchmark input with csv
   - TS-6311  fix: explorer max password length should be 255
   - TS-6312  fix: excel odbc loading data error via websocket
   - TS-6159  fix: stream computing result table not being fully created in certain situations
   - TS-6166  fix: when the transaction to create a database fails, repeatedly sending messages can cause high CPU usage.
   - TS-6173  fix: the number of file groups displayed by the “show compacts” command does not match the actual number.
   - TS-6176  fix: stream task fails to start after the rolling upgrade.
   - TS-6177  fix: the checkpointBackupDir being too large in the stream task.
   - TS-6149  fix: when using Websocket parameter binding to batch write data, Chinese characters in subtable names will cause garbled text
   - TS-6223  fix: TDgpt may yield abnormal results when running on the ARM64 platform.
   - TS-6232  fix: ftmt binding failure followed by re-binding causes a crash.


```
