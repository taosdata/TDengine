## 3. 需求目标

1. 增加配置参数，控制是否启用强密码校验
2. 将允许密码长度扩展到 255 位

## 4. 功能需求

如下需求，大部分已经在 3.3.5.0 中实现，汇总在此，避免破坏之前的约定。
1. 密码长度必须为 8 到 255 位
2. 密码字符的取值范围
   - 大写字母
   - 小写字母
   - 数字
   - 特殊字符： `! @ # $ % ^ & * ( ) - _ + = [ ] { } : ; > < ? | ~ , .`
3. 增加配置参数 EnableStrongPassword
   - EnableStrongPassword 开启时：密码至少包含大写字母、小写字母、数字、特殊字符中的三类
   - EnableStrongPassword 关闭时：关于“大写字母、小写字母、数字、特殊字符”的种类限制不再需要
   - EnableStrongPassword 是集群范围的参数，默认开启，支持通过  SQL 修改，且可通过 show variables 系列命令查看具体取值
4. 创建用户时已存在 is_import 选项，当设置了 is_import 选项时，行为和 EnableStrongPassword 开启时相同
5. 有关密码的限制，仅影响创建用户、修改用户密码时的行为，对于已存在的用户（特指已经存储的用户密码）不受影响
