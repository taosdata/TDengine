## 3. 需求目标

`interp` 函数支持指定固定时间点、指定时间区间内多个时间点（ every ），向前（`prev`）、向后（`next`）、最近（`near`）等方式来查找数据并进行填充。然而，在实际应用中，可能会出现以下情况：某些数据表在一个月前有数据记录，但用户在进行插值操作时，仅希望向前查找最多一个小时的数据。如下是具体示例，
1. 原始数据
```sql {wrap}
taos> select ts, col from tb;

          ts            |  col       | 
======================================
2024-11-15 06:13:10.000 | 14.0601978 |  
2024-11-15 06:13:10.000 | 14.0601978 |  
2024-11-15 06:13:10.000 | 14.0601978 |  
2024-11-15 06:13:10.000 | 14.0601978 |  
2024-11-15 06:13:10.000 | 14.0601978 |  
```

1. 当前插值结果
```sql {wrap}
taos> select _irowts, _irowts_origin，INTERP(col) from tb range('2025-02-05 00:00:00') FILL(prev)

          _irowts       |        _irowts_origin   |   col      | 
================================================================
2025-02-05 00:00:00.000 | 2024-11-15 06:13:10.000 | 14.0601978 |  
```

1. 期待插值结果
```sql {wrap}
taos> select INTERP(col) from tb range('2025-02-05 00:00:00') FILL(prev) 新选项   

没有查询结果       
```

## 4. 功能需求

为 `Fill` 语句新增选项，当采用值填充方式时，可指定插值操作的查找时间范围。例如
```sql {wrap}
select _irowts, INTERP(col) from tb range(...) every(...) FILL(prev, threshold)
```

其中：
1. `threshold`：插值操作的查找时间范围
2. 支持的插值操作：`prev`、`next`、`near`
*说明：以上语法为示例，在编写 *`*FS*`* 时参考即可*
