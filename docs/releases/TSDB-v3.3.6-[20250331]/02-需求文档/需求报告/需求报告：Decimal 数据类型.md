# 需求报告：Decimal 数据类型

### 1. 背景

目前多个客户场景(金融、车联网GPS)指定长度和小数位数写入、查询，对这些数值进行统计、计算。
在这类场景中，总长度和小数位数需保证，不允许出现 1.00 显示为 0.99999999或1.000000001。

### 2. 客户功能需求

1. Decimal数据类型表达形式为 decimal(x,y)，其中：
x表示全部十进制数字的最大个数，最大38
y表示十进制小数位数，不含小数点。小数位数必须是从 0 到 x之间的值，默认小数位数是 0
1. 适用范围。所有数值类型适用的函数，均需支持Decimal数据类型
2. Decimal数值进行比较、排序时，按照用户定义的精度进行比较。例：对于decimal(5,2)，9.80 == 9.80为真

2. 支持聚合类、选择类、时序特有函数，需正确返回对所有符合条件的记录的计算果
3. 支持 distinct unique函数，需返回不重复的数值，去除重复值
4. 支持TDengine子句、UDF，包括未来将实现的LEFT JOIN、ASOF JOIN、Window JOIN等 （注：理论上透明，需要测试验证）
