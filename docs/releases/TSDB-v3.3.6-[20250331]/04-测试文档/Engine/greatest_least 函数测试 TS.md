### 8.4 性能

#### 8.4.1 测试方法

greatest/least 为新函数，没有历史性能数据供对比。但根据原理，可以设计有参考意义的测试方法。
原理：greatest / least 对于一行数据的多个不同列比较，最后选出“最大/最小”的一个数据作为结果，因此充分且必要的操作是 n-1 次大小比较，n 是列数。因此，在 n 列数据上进行 greatest/least 操作，耗时理应和 n-1 个比较操作耗时相当。
方法：对目标数据表的 n 列，查询 gretest / least 进行时间统计，另外对目标数据表的 n 列进行 n -1 次比较操作，统计时间。注意：n -1 次比较的左边是 n 列数据，右边是具体的一列，该列的数据类型应该为：gretest / least 函数作用在 n 列上比较时，最终选择转为那个统一的数据类型。
数据准备：python 脚本，对 1000 的数据表，写入1000 条数据。（已写入 ci 脚本， test_function.py）

    def test_greatest_large_table(self):
        tdLog.info("test greatest large table.")
           
        ts = 1741341251000
        create_table_sql = "CREATE TABLE `large_table` (`ts` TIMESTAMP"

            if i % 5 == 1:
                create_table_sql += f", `col{i}` INT"
            elif i % 5 == 2:
                create_table_sql += f", `col{i}` FLOAT"
            elif i % 5 == 3:
                create_table_sql += f", `col{i}` DOUBLE"
            elif i % 5 == 4:
                create_table_sql += f", `col{i}` VARCHAR(64)"
            else:
                create_table_sql += f", `col{i}` NCHAR(50)"
        create_table_sql += ");"
        tdSql.execute(create_table_sql)
 
        for j in range(1000):
            insert_sql = f"INSERT INTO `large_table` VALUES ({ts +j}"
            for i in range(1, 1001):
                if i % 5 == 1:
                    insert_sql += f", {j + i}"
                elif i % 5 == 2:
                    insert_sql += f", {j + i}.1"
                elif i % 5 == 3:
                    insert_sql += f", {j + i}.2"
                elif i % 5 == 4:
                    insert_sql += f", '{j + i}'"
                else:
                    insert_sql += f", '{j + i}'"
            insert_sql += ");"
            tdSql.execute(insert_sql)

        greatest_query = "SELECT GREATEST("
        for i in range(1, 1001):
            greatest_query += f"`col{i}`"
            if i < 1000:
                greatest_query += ", "
        greatest_query += ") FROM `large_table` LIMIT 1;"
        tdLog.info(f"greatest_query: {greatest_query}")
        tdSql.execute(greatest_query)
        
        greatest_query = "SELECT "
