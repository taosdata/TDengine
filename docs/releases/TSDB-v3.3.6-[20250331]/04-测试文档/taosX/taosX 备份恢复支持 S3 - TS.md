## 5. 已知问题和限制

### 5.1 从 S3 恢复时，本地存储空间不足

- 问题描述：
恢复任务运行前，如果本地存储空间不够，任务会直接中断。
- 解决方法：
1. 创建恢复任务时，指定备份点的 From 和 To，将一个大的恢复任务，分割成多个小的恢复任务。
2. 备份文件设置高的压缩等级，可以减小备份文件，但降低恢复任务的性能。
- 改进措施（不属于本次发布）：
1. 从 S3 恢复时，分段从 S3 下载，恢复完成后，删除本地的备份文件副本。
