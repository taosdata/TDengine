# taos-explorer 与 taosx 重构后兼容性测试 - Test Spec

## 1. 测试目标

本次测试的核心目标是验证重构后的 taos-explorer 及 taosx 接口是否保持了良好的兼容性，确保系统功能完整且一切正常，确保旧版本升级到新版本后一切正常。

1. taos-explorer 页面操作：
   - 数据写入任务：
      - 任务列表、任务运行指标、任务活动状态
      - 创建任务
      - 编辑任务
      - 复制任务
      - 删除任务
   - 代理
      - 代理列表、代理活动状态
      - 创建代理
      - 编辑代理
      - 删除代理
   - 备份
   - 数据同步
   - 数据浏览器
   - 其他
- 版本升级：
  - 仅升级 taosx
  - 同时升级 taos-explorer 与 taosx
