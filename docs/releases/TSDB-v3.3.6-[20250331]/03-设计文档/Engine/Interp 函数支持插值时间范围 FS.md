# Interp 函数支持插值时间范围 FS

## 1. 背景

目前 Interp 函数支持单点插值指定时间范围，本功能在现有功能基础上补充多点插值时指定时间范围。

## 2. 变更历史

| --- | --- | --- | --- |

## 3. 定义

文档中所使用的一些并非众所周知的术语的定义。

## 4. 行为说明

- `interp` 函数目前已经支持指定固定时间点、指定时间区间内多个时间点（ every ），向前（`prev`）、向后（`next`）、最近（`near`）等方式来查找数据并进行填充。对于插值额外指定时间范围的需求，目前只在固定时间点场景下支持，指定时间区间的场景下则不支持，本次通过扩展 `interp` 语法来支持该需求。
- `interp` 在指定时间区间场景下且额外指定插值时间范围时，只支持 `prev`、`next`、`near`三种插值方式，必须指定插值默认值。
- 支持伪列 _irowts_origin 为插值原始数据行的时间戳。

### 4.1 语法变更

```sql {wrap}
interp_clause:
      RANGE(ts_val [, ts_val] [, surrounding_time_val]) EVERY(every_val) FILL(fill_mod_and_val)
```

说明： surrounding_time_val 及 fill_mod_and_val 值域和要求同当前保持不变。

## 5. 性能

## 6. 兼容性

新增功能，原来不支持的语法改为支持。

## 8. 使用场景

| 场景分类 | 场景描述 | SQL 示例 |
| --- | --- | --- |
| 正常 | 在一段时间范围内每2小时向前插值，插值限制在1小时以内，默认值0 | RANGE（ts1, ts2, 1h) every(2h) FILL(prev, 0) |
| 正常 | 在一段时间范围内每2小时向后插值，插值限制在1小时以内，默认值0 | RANGE（ts1, ts2, 1h) every(2h) FILL(next, 0) |
| 正常 | 在一段时间范围内每2小时最近插值，插值限制在1小时以内，默认值0 | RANGE（ts1, ts2, 1h) every(2h) FILL(near, 0) |
| 异常 | 在一段时间范围内每2小时线性插值，插值限制在1小时以内，默认值0 | RANGE（ts1, ts2, 1h) every(2h) FILL(linear, 0) |
| 异常 | 在一段时间范围内每2小时向后插值，插值限制在1小时以内，无默认值 | RANGE（ts1, ts2, 1h) every(2h) FILL(next) |

## 9. 约束和限制

- `interp` 在指定时间区间场景下且额外指定插值时间范围时，只支持 `prev`、`next`、`near`三种插值方式，必须指定插值默认值。
- 流计算暂不支持额外指定插值时间范围功能（当前功能）。
