# 修复损坏数据文件的工具使用手册

## 1. 背景

中船客户环境比较特殊，无法远程，环境都在船上，硬盘客户经常掉。所以会经常出现数据文件损坏的情况：
期望开发人员能够提供一个处理数据文件损坏的工具，能够针对出现问题的数据文件进行处理、删除掉。能避免用户查询遇到 data file corrupted 的报错。

## 3. 实现机制

1. 在 taosd 中增加 日志打印，确保 data file corrupted 时，输出 fid 。
2. 使用 python3 脚本处理 tsdb 文件夹下的 current.json 。
   - 判断输入的 fid 是否存在于 current.json ，不存在则报错。
   - 备份当前的 currenet.json 
   - 删除 current.json 中出现问题的 fid。

## 4. 使用方法

--help
```python
python3 repair_tsdb_data.py --help
usage: repair_tsdb_data.py [-h] fid [file_path]

Repair TSDB data by removing specified fid.

positional arguments:
  fid         The fid to be removed
  file_path   The path to the JSON file (default: current.json)

options:
  -h, --help  show this help message and exit
```

### 4.1 详细步骤：

1. 发现错误 Data file corrupted 之后在日志中 grep 改报错，确定出问题的 fid 。
2. 停止 taosd 的服务 
3. 使用 python3 repair_tsdb_data.py fid [file_path] 修复 current.json 
4. 重启 taosd 服务。
