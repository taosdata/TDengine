# explorer 集群监控

## 1. 背景

为玉溪卷烟厂部署的 grafana 监控系统不能通过集团安全扫描，玉溪卷烟厂期望将监控功能内置在 explorer 中，同时对监控的页面和操作也有一些具体的要求。详见：。
TX-192

第一个版本已经做了一个页面集成方案并且实现将 grafana dashboard 页面通过 iframe 嵌入在 explorer 页面内。详见：。但是和用户交流后，并未达到用户的预期。用户还是期望监控首页能有一个总览页面，可以查看所有服务器的主机监控信息，及其部署的 TDengine 组件的健康状态。
TS-5583

基于此需求，目前研发侧提出一个方案，在集群页面 mnodes 列表中展示这些信息，详见。
TS-5969

## 4. 行为说明

### 4.1 主机监控

目前没有所有主机的信息，不知道我们部署的集群里有多少物理主机。
取 dnode 作为主机列表；

| 主机名称 | 主机ip | 内存使用率 | 内存总大小 | cpu | 磁盘 IO | 网络 | 组件&状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | trd01:6030 | 82% | 65.8G |  |  |  | taosd: 红 taosX: 绿 |
|  |  |  |  |  |  |  |  |

1. 内存显示内存使用率（%）： (mem_total - mem_free) / mem_total  这里把 Buffer/Cached 内存也计算到使用中，会非常高。
2. 内存总大小（mem_total）
3. Cpu 核数   : cpu_cores
4. Cpu: 使用率大于95% 则 alert 状态；80%~90%， warning 状态
5. 磁盘I/O  io_read_disk/io_write_disk
6. 网络I/O  io_read/io_write
7. 组件状态：根据log 库监控指标，如果 3 分钟内没有数据，则认为是 error 状态，如果1分钟内没有数据，则认为是 warning 状态。

如果监控主机在近一天内没有log 数据，则认为是 offline, 不在集群范围内。
