# TS-3598 集群多副本环境支持某个磁盘损坏

## 一、测试背景及目的

     在企业生产环境中部署 TDengine 多级存储，在长时间的对磁盘的反复读写中，有时候会发生某些磁盘故障或损坏的情况，TDengine 通过多副本备份的功能，增加了故障磁盘无感自动停用的技术，保障生产服务的不间断运行。

## 二、功能描述及使用

    此自动化停用故障磁盘功能需要存储配置为多磁盘并开启集群多副本功能方可支持故障磁盘无感自动停用，故障盘停用后，集群的写入及查询服务都可以正常对外提供服务，使用 show dnodes; 查询服务节点状态时，故障磁盘所在的节点显示为 offline，管理员应在适合的时机更换新磁盘进来。 

## 三、测试步骤

    1)   机房中选择 192.168.1.36 机器，此机器有多个磁盘插槽
    2） 建立一个五节点三副本集群，三个管理节点
    3)   存储节点挂载五块磁盘
    4)   把最后一个节点的 dataDir logDir 都修改到第五块磁盘上，重启此节点
    5）使用 taosBenchmark -f ../case/insertMix.json 持续写入（此配置中即有写入也有查询）
    6）到机房拔出第五块磁盘
    7）观察集群，第三节点会自动退出，集群对外服务在短暂几秒不可用后又恢复到了正常状态，可以正常对外提供读写及查询服务
