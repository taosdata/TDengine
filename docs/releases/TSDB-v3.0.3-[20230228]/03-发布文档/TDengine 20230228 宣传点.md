# TDengine 20230228 宣传点

1. 数据压缩 （Data Compact） (Enterprise Only)
   - 功能：将存储的数据文件重新整理，删除文件空洞和无效数据，提高数据的组织度，从而提高存储和查询的效率
   - 效果：大幅提升有乱序数据和数据更新时的查询性能
2. 事件窗口 （Event Window）
   - 功能：按照用户指定的条件来决定开启和结束的边界
   - 效果：丰富窗口类型，提供更灵活的窗口支持，满足由事件驱动的业务需求
3. 标签索引 （Tag Index）
   - 功能：可以按需在标签列上创建和删除索引，原先仅对第一个标签内置了索引。
   - 效果：用户可以按需创建标签索引，提升基于标签过滤的查询的性能
4. taosX (Enterprise only) 
   - 从 2.x 到  3.0 以及 3.0 到 3.0 的数据复制，包括存量和增量数据
   - 备份数据到本地文件，从本地文件恢复数据
5. taosExplorer (Enterprise only): 基于 Web UI 查看、操作、和管理 TDengine 集群
   - Data Explorer:
      - 使用图形界面查看和浏览集群中的数据库、超级表、子表、普通表
      - 使用图形界面创建和删除库、超级表、子表、普通表
      - 输入和执行 SQL 语句，查看执行结果
      - 收藏常用的 SQL 语句以快速执行
      - 浏览 SQL 语句的执行记录
   - 数据导入（Data In）：从另一 TDengine 集群导入数据
   - 创建和删除 Topic 
   - 创建和删除流
   - 管理用户和权限
   - 备份数据到本地文件和从本地文件恢复
   - 从另一集群复制数据到当前集群，从当前集群复制数据到另一集群
   - 集群管理和运维：添加/删除 dnode/mnode/qnode 
   - 集群监控：基于 Grafana
6. 流式计算优化 （可以去除）
   - 将计算结果写入已经存在的超级表，使用户保存流计算结果的方式更灵活
   - 指定存储流计算结果的超级表可以自定义标签，使用户能够更好地控制存储流计算结果的超级表和对它的查询
7. Java 连接器：基于 WebSocket 订阅消息队列
8. Python 连接器：基于 WebSocket 订阅消息队列
9. Grafana Plugin
   - Dashboard 可以监控 HTTP status code
   - Multi-dimensional alert
10. taosBenchmark （可以去除）
   - 分段写入指定子表
   - 命令行参数指定 vgroup 数建 db
