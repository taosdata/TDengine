# TD-21966 流计算-写入已存在的超级表功能测试

## 一、测试概述

建流时指定已存在的超级表，然后进行写入和查询，写入需要触发流，确保系统的稳定性和结果的正确性。
测试用例基于过去已覆盖的场景进行编写，交叉覆盖 fill_history、partition by tbname/column/tag、subtable、三种 trigger_mode（at_once/window_close/max_delay）、三种窗口（interval/state_window/session_window）等功能。
