# TD-22464 流计算需要重启以后手动启动，不自动拉起计算

## 一、测试概述

taosd 服务重启以后，流需要手动拉起，不再自动启动；避免在流计算重放过程中再次 crash，导致 taosd 服务进入循环 crash 的状态。

### 3.3 测试用例

该功能应是一个全覆盖的功能，不再根据具体模块细分测试；
测试步骤：
1. 准备数据，建库建表建流写入数据并触发流计算；
2. 破坏某个流相关的数据文件，目的是为了 stop taosd 后无法 restart（文件路径示例/var/lib/taos/vnode/vnode3/tq/stream/2054472787）；
3. Stop taosd并重启，确保无法启动；
4. 设置 taos.cfg 中的 disableStream 为 1；
5. 启动 taosd，确保可以启动；
6. 进行写入和查询，确保均正常；
7. 删掉流及对应超级表，stop taosd；
8. 同时删掉所有的 stream 数据文件（/var/lib/taos/vnode/vnode*/tq/stream）；
9. 设置 disableStream 为 0 并重启 taosd，确保可以启动；
10. 重新建流，并再次进行写入查询，确保均正常

## 五、测试结论

1. 测试完成，所有问题已修复；
2. 测试用例的第 8 条中，建议删流时自动删除所有的 stream 配置文件，既然是开放给用户的功能，那么由用户操作很有可能删错文件，造成不可预知的影响；
