### 3.2 测试方案

   只需要测试目前最新的版本。副本搭建三节点三 mnode 的集群即可测试。
   后续加到定时测试中：docker 启动三个节点，配置三个 mnode，taosBenchmark 新建三副本的库，插入 1000 个子表，每个子表 1000 条数据。（后续增加4096 列的数据表，增加订阅，增加流计算）。查询数据数量，订阅和流计算结果都准确，停止 mnode 的 leader 节点，升级，重启，然后依次重启其余俩节点。再次查询数据数量，订阅和流计算结果都准确。
目前流计算不支持多副本的库，后续再添加。

####     1、**需要验证版本：**

        选取已经支持的版本 3.0.2.0 以后的，选中 3.0.2.4作为基准版本。
        抽取版本：

（ 原计划使用 3.0.2.2 版本作为基准版本，测试过程发现 3.0.2.2建立集群报错：failed to connect to server, reason: Sync is restoring，开发说之前的版本有 bug，推荐使用 3.0.2.4 版本，）

#### **     2、 验证步骤**

1. 手工搭建3 数据节点 3 副本mnode的集群，
2. 使用 taosBenchmark生成数据库 db ，3 副本，超级表 meters , 表数 10000个， 每表 1000 行。
3. 创建订阅的新库，三副本，新表，创建 topic（按着官网的示例数据）。
4. 查询订阅结果和写入数据的结果，均正确
5. 创建stream，创建单副本库，插入数据，查看流结果，均正确（按着官网的示例数据）
6. 该单个节点升级，然后查询订阅结果和写入数据的结果，均正确
7. 该单个节点退回，然后查询订阅结果和写入数据的结果，均正确（不确认是否支持回退，先测试下)
8. 再次逐个单个节点升级，完全升级完成，查询订阅结果和写入数据的结果，均正确。
