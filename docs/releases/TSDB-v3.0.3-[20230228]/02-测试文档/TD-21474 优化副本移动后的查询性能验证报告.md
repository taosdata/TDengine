# TD-21474 优化副本移动后的查询性能验证报告

## 1. 测试结论：

**移动后比移动前性能更好了。**

## 2. 测试环境：

192.168.1.35

## 3. 测试步骤

1.启动一个四节点集群
2.使用 taosBenchMark 写入 1 亿条数据，单副本，1 个 vgroup
3.执行 select count(*) from db.stb 查看 1 亿条数据的查询时间
4.删除 dnode 4，数据会从 dnode4 -> dnode3
5.再次执行 select count(*)  from db.stb 查看 1 亿条数据的查询时间
