## 二、测试结论

通过大流量数据进行了验证，测试过程中校验了数据同步前后的count和sum的一致性，未发现问题。
认为该功能已完成测试。

## 三、测试方案及测试用例

##### （1）测试环境：

| 软件项 | IP |
| --- | --- |
| TDengine（3.0.2.5） | 192.168.1.41 |
| TDengine（3.0分支，含taosx） | 192.168.1.42 |

##### （2）测试用例

行转列格式主要是针对3.0.2.x和最新3.0之间的存储格式变化，所以采用以下策略：
1.源库集群采用3.0.2.x版本，并写入数据
2.源库在写入数据后，重新用3.0分支源码编译生成taosd，重新启动集群
