# TD-21973 流计算-自定义 tag 功能测试

## 一、测试概述

流计算支持写入已存在的超级表功能后，可以自定义tag，然后进行写入和查询，写入需要触发流，确保系统的稳定性和结果的正确性。
测试用例结合TD-21966，基于过去已覆盖的场景进行编写，交叉覆盖 fill_history、partition by tbname/column/tag、subtable、三种 trigger_mode（at_once/window_close/max_delay）、三种窗口（interval/state_window/session_window）等功能。
相关链接：
[TD-21966](https://jira.taosdata.com:18080/browse/TD-21966) [完成 流式计算新功能—自定义tag 功能的测试](https://jira.taosdata.com:18080/browse/TD-21973)
[TD-21455流式计算新功能——自定义tag](https://taosdata.feishu.cn/docx/NKgodwzzzoKOT9xDDACcecrrnOg)
