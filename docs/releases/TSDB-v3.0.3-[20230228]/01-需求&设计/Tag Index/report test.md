#### 1.0.4 性能测试

建立index 的速度 

| Vgroups 个数 | 字表数量 | 字段类型 | 耗时 | Meta 数据占用（只计算磁盘），加索引之前和加索引之后 |
| --- | --- | --- | --- | --- |
| 2 | 10000 | INT | 0.773307s | 200k左右（原始1.4M, 加索引之后1.6M ） |
| 2 | 10000 | Varchar(16) | 0.850120s | 200k 左右 |
| 2 | 100000 | INT | 8.430806s | 2M 左右 (原始的16M, 加索引之后18M ) |
| 2 | 100000 | Varchar(16) | 8.880723s | 2M 左右 |
| 2 | 1000000 | INT | 78.64842s | 20M左右（原始200M，加索引之后215~220M） |
| 2 | 1000000 | Varchar(16) | 79.793756s | 20M左右 |

1. 索引的建立主要耗时时间在于vnode上遍历meta 模块，而这些遍历在各个 vnode是并发进行的，单个vnode上有50万子表的时候，大体耗时在70s
2. 相比没有加索引之前，单列索引会导致meta空间增减10%～15%，
