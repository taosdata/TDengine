## 3. 需求目标

Influxdb 在遇到大量数据需要同步时，每个任务需要进行单独的性能优化调参，页面增加性能调参参数，方便交付人员根据客户场景进行任务适配。

## 4. 功能需求

### 4.1 控制任务的 JVM 内存和 CPU 消耗

任务实际执行过程中，JVM 默认最高会消耗使用物理机器内存的 1/4，CPU 消耗为了保证最大吞吐量，会尽可能多的使用物理CPU，直至达到吞吐平衡。
在资源有限的场景，页面增加 JVM 参数，缓存队列，数据源读取函数，并发读取类型 等页面参数，可以针对每个任务进行资源控制。
