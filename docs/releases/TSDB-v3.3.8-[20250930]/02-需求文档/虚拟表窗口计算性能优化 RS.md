## 3. 需求目标

优化虚拟表在窗口场景下的执行性能，拆分窗口判断条件和查询计算逻辑，解决稀疏数据和密集数据混合计算时的效率。

无

## 5. 性能需求

优化范围
1. 流计算
2. 批查询
关键逻辑
1. 从窗口定义时给的数据列中，提取窗口边界
2. 当窗口触发后，再激活后续数据对齐与计算逻辑
不同窗口类型的数据列选择方式不完全相同
1. **状态窗口和时间窗口**，在窗口定义时已指定数据列，可立刻进行此优化
   - STATE_WINDOW (col_name)
   - EVENT_WINDOW START WITH start_trigger_condition END WITH end_trigger_condition
2. **计数窗口**，如果在窗口定义时指定了 `col_name` 选项，可进行此优化
   - COUNT_WINDOW(count_val[, sliding_val][, col_name ...])
3. **会话窗口和时间窗口**，需要增加 `col_name` 选项，才可进行此优化
   - SESSION(ts_col, tol_val)
   - INTERVAL(interval_val [, interval_offset])
按以上分析，**会话窗口和时间窗口 **需要增加语法，考虑下期再实现。
