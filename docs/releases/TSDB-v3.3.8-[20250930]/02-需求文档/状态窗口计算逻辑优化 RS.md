## 3. 需求目标

扩展 `STATE_WINDOW` 的窗口选项，灵活处理不同状态之间的时间空隙：
1. Extend：窗口的开始和结束时间，支持 0-2 三种选项

| Extend 取值 | 窗口开始 | 窗口结束 | 其他 |
| --- | --- | --- | --- |
| 0 | 本状态首个时间点 | 本状态最后时间点 | 默认值 |
| 1 | 本状态首个时间点 | 下一个状态的首个时间点 1. 如状态未结束，取查询范围的结束时间 1. 如未指定结束时间，取本状态最后时间 |  |
| 2 | 上一状态的最后时间点 1. 如无上一状态，取查询范围的开始时间 1. 如未指定开始时间，取本状态首个时间点 | 本状态最后时间点 |  |

1. Boundary: 窗口的开闭区间，支持 0-3 四种选项

| Boundary 取值 | 开闭区间定义 | 其他说明 |
| --- | --- | --- |
| 0 | 左闭右开 | Extend = 0 和 1 时的默认值 |
| 1 | 左开右闭 | Extend = 2 时的默认值 |
| 2 | 左开右开 | 暂不实现 |
| 3 | 左闭右闭 | 暂不实现 |

## 4. 功能需求

### 4.1 语法定义

在现有语法基础上，增加 window_option 关键字，第一个参数为 Extend，第二个选项为 Boundary。状态窗口需求实现后，其他窗口的类似需求也可复用该语法。
```sql
select count(*) from t count_window(2) window_option(extend, boundary);
```

### 4.2 使用举例

以如下数据为例，说明 Extend 参数的调整方式
```sql
taos> create table t (ts timestamp, val int);
Create OK, 0 row(s) affected (0.002504s)

taos> insert into t values
         ('2024-06-13 00:00:00.000 ', 0)
         ('2024-06-13 00:00:01.000 ', 1)
         ('2024-06-13 00:00:02.000 ', 1)
         ('2024-06-13 00:00:04.000 ', 0)
         ('2024-06-13 00:00:05.000 ', 1);
Insert OK, 5 row(s) affected (0.001509s)

taos> select * from t;
           ts            |     val     |
========================================
 2024-06-13 00:00:00.000 |           0 |
 2024-06-13 00:00:01.000 |           1 |
 2024-06-13 00:00:02.000 |           1 |
 2024-06-13 00:00:04.000 |           0 |
 2024-06-13 00:00:05.000 |           1 |
Query OK, 5 row(s) in set (0.003668s)
```

当前逻辑：划分 4 个窗口，窗口持续时间分别为 0、1000、0、0
```sql
taos> select _wstart, _wduration, _wend, count(*) from t 
      where ts <= '2024-06-14 00:00:08.000'
      state_window(val);

============================================================================
 2024-06-13 00:00:00.000 |          0 | 2024-06-13 00:00:00.000 |        1 |
 2024-06-13 00:00:01.000 |       1000 | 2024-06-13 00:00:02.000 |        2 |

 2024-06-13 00:00:05.000 |          0 | 2024-06-13 00:00:05.000 |        1 |
```

```sql
         _wstart         | _wduration |          _wend          | count(*) |
============================================================================

 2024-06-13 00:00:04.000 |       1000 | 2024-06-13 00:00:05.000 |        1 |
 2024-06-13 00:00:05.000 |       3000 | 2024-06-13 00:00:08.000 |        1 |

```

Extend = 2：窗口持续时间为 1000、3000、1000、3000，输出结果如下
