# 3.3.7.5 中英文 Release Notes

### 1. 中文

```markdown

### 2. 特性

   - TS-6952  特性：taosX 支持导入 ORC 文件
   - TD-36878 特性：C 连接器支持 WebSocket 连接上设置时区
   - TD-37437 修复：含虚拟表查询时建流会指向错误的数据库
   - TS-6614  特性：ODBC 支持 ADO 接口
   - TS-6796  特性：taosAdapter 支持记录 SQL 到 CSV

### 3. 优化

   - TD-37254 优化：Explorer 可使用环境变量 EXPLORER_SKIP_REGISTER 跳过注册
   - TD-37274 优化：减小 taosX 二进制文件体积  ~60M(直接编译大小，压缩后降低 15M)
   - TD-37353 优化：Explorer 登录用户名中的空格可以被忽略
   - TD-37474 改进：C WebSocket 连接支持自动重连参数
   - TD-37510 优化：Windows 下支持使用 DDD 格式化时间
   - TD-37538 优化：Explorer 开源版面板页面不弹出taosX相关错误
   - TS-5791  优化：新增 verifyPeer 参数，支持用户在上传 S3 数据时跳过证书验证
   - TS-6242  优化：改造 S3 数据迁移的状态控制机制，提升精确性与效率
   - TS-6755  优化：Explorer 配置 OPCUA 枚举变量超时
   - TS-6756  优化：Show Create Table 不输出压缩信息
   - TS-6869  优化：共享存储支持 NAS
   - TS-6888  优化：taosBenchmark 支持 WebSocket 下重试
   - TS-7028  优化：优化 Kafka 数据接入性能
   - TS-7072  改进：未启动 taosX 时联通性检查报告实际错误

### 4. 修复

   - TS-7008  修复：taosX influxdb 1.x 查询慢和OOM 问题
   - TS-6996  修复：Explorer 使用非默认密码创建数据同步报密码错误
   - TS-7035  修复：长查询的内存回收过程中因竞争条件导致的崩溃
   - TS-7060  修复：文件恢复过程中文件不存在导致 Failed to open file 持续报错
   - TD-37190 修复：批量创建流任务时偶发的 stream task lost 错误
   - TD-37511 修复：Explorer 删除流计算报错 Database not specified
   - TD-37608 修复：Explorer Transform varbinary 类型自动对应
   - TS-6980  修复：Oracle 数据导入 Decimal 类型错误
   - TS-6981  触发表 tag 为null 导致写入表名无法计算
   - TS-7000  修复：MQTT 特殊情况下获取数据超时
   - TS-7053  修复：taosdump 微秒纳秒数据库时间范围导出报错
   - TS-7064  修复：流计算使用 CALC_NOTIFY_ONLY 选项时的 crash 问题
   - TS-7101  修复：ipv6 下 taoskeeper 记录审计日志报错 value too long for column/tag: client_address
   - TS-7103  修复：Explorer CSV 导入带有 value 列时报错
   - TS-7120  修复：Explorer 超级表多个 tag 值相同时多级标签显示子表错误
   - TS-7128  修复：Kafka 导入同一字段类型不同导致出现 NULL 值
   - TS-7139  修复：Explorer 在 Nginx 服务重启后连接报错


```

### 5. English

```markdown

### 6. Features

   - TS-6952  feat: taosX support importing ORC format
   - TD-36878 feat: C WebSocket connection-level timezone
   - TD-37437 feat: [TD-37437]: incorrect database targeting when creating streams containing virtual table queries
   - TS-6614  feat: support ADO interface in ODBC
   - TS-6796  feat: taosAdapter support recording sql to csv

### 7. Enhancements

   - TD-37254 enh: set EXPLORER_SKIP_REGISTER=true to skip register in Explorer
   - TD-37274 enh: reduce taosX binary size for nearly ~60M(plain, 15M compressed)
   - TD-37353 enh: explorer will trim spaces in user name
   - TD-37474 enh: C WebSocket support configuration options for auto reconnect
   - TD-37510 en: support for formatting time using DDD on Windows.
   - TD-37538 enh: disable alert in dashboard on explorer oss
   - TS-5791  enh: add verifyPeer parameter to allow users to skip certificate verification during S3 data upload.
   - TS-6242  enh: enhance the state control mechanism for S3 data migration to improve precision and efficiency
   - TS-6755  enh: explorer can config requret timeout in opcua
   - TS-6756  enh: Show Create Table does not output compression information.
   - TS-6869  enh: shared storage supports NAS
   - TS-6888  enh: support retries in taosBenchmark via ws
   - TS-7028  enh: improve kafka datain performance
   - TS-7072  enh: taosX not started cause ui undefined error

### 8. Fixes

   - TS-7008  fix: speedup influxdb 1.x querying and fix oom in taosX influxdb datasource
   - TS-6996  fix: create data replication error in explorer with non-default password
   - TS-7035  fix: crash caused by race conditions during memory reclamation in long-running queries
   - TS-7060  fix: non-exist file cause unstopped failed to open file error in restore
   - TD-37190 fix: intermittent “stream task lost” error when creating stream tasks in batches.
   - TD-37511 fix: delete stream cause 'Database not specified' in explorer
   - TD-37608 fix: varbinary database mapping in explorer transform
   - TS-6980  fix: panic in case of decimal converting from oracle
   - TS-6981  fix: trigger table tags being null causes crash
   - TS-7000  fix: mqtt get sample data timeout if frequency too low
   - TS-7053  fix: taosdump export by time range error in case of us/ns precision
   - TS-7064  fix: crash issue when using CALC_NOTIFY_ONLY option in stream computing
   - TS-7101  fix: taoskeeper audit log error with `value too long for column/tag: client_address` in taoskeeper
   - TS-7103  fix: import csv with value field in explorer cause error
   - TS-7120  fix: explorer cascading tag table list error in case of same values in multi tag fields
   - TS-7128  fix: taosX got unexpected null values in case of different types in single field
   - TS-7139  fix: nginx service restart cause explorer error


```
