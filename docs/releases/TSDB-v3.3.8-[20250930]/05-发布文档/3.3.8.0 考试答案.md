2. Block-Wise-SMA 的特点和适用场景是什么？
   - 核心特点：数据块级别的预计算，与数据写入紧密耦合
   - 适用场景：通用聚合查询加速
3. Rollup-SMA 的特点和适用场景是什么？
   - 核心特点：多层级自动降采样，保留聚合趋势
   - 适用场景：历史趋势分析
4. Timerange-Wise-SMA 的特点和适用场景是什么？
   - 核心特点：时间范围导向的流式降采样
   - 适用场景：高频 Interval 查询
5. TDgpt 的 Imputation 算法的作用是什么
   - 缺失数据补值
   - 基于时序基础模型开发， 根据时间戳自动检测缺失的时序数据点位
6. TDgpt 的 Prophet 算法作用是什么？
   - 时间序列预测
   - 适用于具有明显季节性、节假日效应以及趋势变化的时间序列数据
7. taosX 逻辑备份和恢复支持那些使用场景？
   - 备份数据库
   - 备份超级表
   - 备份查询
   - 备份元数据
8. JDBC 如何使用多个 taosAdapter 进行负载均衡和 failover？
   - 在 JDBC URL 中配置多个 taosAdapter 地址，使用逗号分隔，并开启自动重连。如：`jdbc:TAOS-WS://192.168.1.100:6041,192.168.1.101:6041/test?enableAutoReconnect=true`

#### 2. 第二部分，笔试题目，售前交付回答

1. 如何为子表的字符串类型标签指定多个值？
   - 在字符串类型标签中，通过逗号分隔多个标签
   - 通过 FIND_IN_SET LIKE_IN_SET、REGEXP_IN_SET 三个函数确定是否匹配
2. RSMA 的原理是什么？
   - 配置三个不同的数据保存层级，并为每层指定聚合周期和保存时长
   - **Level 1** 存储原始数据，**Level 2 **和 **Level 3** 存储按指定周期聚合后的数据
   - 低层级存储向高层级迁移时自动触发降采样计算，计算完成后删除原有数据文件
3. TSMA 的原理是什么？
   - 用与普通流计算相同的逻辑，对 interval 类型的查询结果按照 interval 窗口进行预聚合
   - TSMA 内部存储匿名的结果表，用于保存降采样后的计算结果
   - 查询时，对可加速的聚合函数查询重写执行计划，查询对应的计算结果表
4. 给出数据补值函数示例语句，先进行窗口聚合，然后再进行缺失聚合窗口的数据补值
  
  ```sql {wrap}
  SELECT imputation(col_val) FROM (SELECT _wstart, min(val) col_val FROM foo INTERVAL(1s));
  
  SELECT imputation(col_val)
  FROM (SELECT timetruncate(val) from foo);
  ```

1. 状态窗口的关键参数是什么？
   - EXTEND 指定窗口在开始结束时的扩展策略，可选值为 0（默认值）、1、2，分别代表无扩展、向后扩展、向前扩展
   - TRUE_FOR 指定窗口最小持续时长，时间范围为正值，精度可选 1n、1u、1a、1s、1m、1h、1d、1w，如 TRUE_FOR(1a)
2. 解释一下 BSS（Byte-Stream-Split）字节流分割编码
   - 字节流分割编码，将一个浮点数的二进制表示按字节拆分成多个部分，再进行后续的压缩
   - 测试结果显示，相比于 delta-D 编码，BSS 编码压缩比能提升 4%-7%，写入速度和查询速度无明显变化
