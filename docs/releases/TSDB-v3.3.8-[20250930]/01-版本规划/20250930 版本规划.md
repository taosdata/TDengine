# 20250930 版本规划

表格中若未特别标注完成时间，默认将在 0930 版本发布时完成。

## 1. Highlights

### 1.1 引擎

1. 流计算性能提升
2. Rollup SMA 发布
3. Timewise SMA 发布
4. 支持 TLS 证书认证传输
5. 支持 MySql 的聚合、条件函数
6. TDgpt：数据补全
7. 提升 Last 查询的 QPS

### 1.2 工具

1. ~~Explorer UI 自动化测试 (按需添加)~~
2. 性能测试自动化报告（部分完成已发布：连接器：Java/Go，taosX：tmq2td/td2td/csv2td/tmq2local）
3. ODBC ADO 接口（已完成）
4. taosX 逻辑备份和恢复（基于时间范围）
5. ORC 数据源写入（已完成）
6. API 权限控制（新增，启动开发，不承诺发布）
7. OAuth 2.0 （启动开发，与安可工作统一安排）
8. taosX 高可用第一个版本（架构变动较大，预计 1130 发布）
9. 云服务升级 taosX，支持到 3.3.7.0 的所有数据源（新增 SparkPlugB、MQTT 主题解析等）（已更新云服务 taosX，MQTT 变更已上线，后续逐步上线其他数据源变更）
10. 生态支持：ThingsBoard （开发人员支持流计算，无进展）

### 1.3 应用

1. Cloud  完成 UI 支持 vue3 和集成 taos-ui 的 data-in。
2. Cloud TDgpt 公共服务完成部署。
3. Cloud 完成 Azure 欧洲区部署。
4. IDMP 多实例支持。
5. IDMP 面板支持 map 和 散点图。
6. IDMP 支持表达式和 StringBuilder。
7. IDMP 分析模板支持子元素模板。
8. IDMP 支持导入和导出。
9. IDMP 支持 CSV 文件上传创建数据模型导入。
10. IDMP 样例支持上传和下载 JSON。

### 1.4 平台

1. 依据 [Roadmap](https://taosdata.feishu.cn/wiki/MPcQw0hOdilrmKkn1Ync6hNrnih) 增加客户场景模拟的组件支持
2. 测试框架 Windows 平台的支持
3. TDengine 云服务的运维
4. 依据产品线调整生成各产品的安装包
5. 测试用例的迁移
