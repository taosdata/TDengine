# 状态窗口起止点配置功能 - FS

## 1. 背景

现在的实现里，状态窗口的开始时间与结束时间是一个状态的值保持不变的时间段。这导致两个问题：
1. 两个状态之间的时长没有被统计，
2. 如果设备仅仅当状态变化时才报告新的状态，那么每个状态只有一条记录，无法形成状态窗口。
因此要给状态窗口增加一个新的配置参数extend，对窗口的起止位置进行额外设置。

## 3. 定义

时间点的前一时刻：时间戳减1，单位为当前时间精度
时间点的后一时刻：时间戳加1，单位为当前时间精度
E.g.
在一个时间分辨率为“毫秒”的数据库中，时间点"2025-01-01 00:00:00.000UTC+0800"的时间戳为1735660800000，其前一时刻为1735660799999，即"2024-12-31 23:59:59.999UTC+0800"；其后一时刻为
1735660800001，即"2025-01-01 00:00:00.001UTC+0800"。

## 4. 行为说明

```sql
window_clause: {
    SESSION(ts_col, tol_val)
  | STATE_WINDOW(col[, extend]) [TRUE_FOR(true_for_duration)] [WINDOW_OPTION(extend)]
  | INTERVAL(interval_val [, interval_offset]) [SLIDING (sliding_val)] [FILL(fill_mod_and_val)]
  | EVENT_WINDOW START WITH start_trigger_condition END WITH end_trigger_condition [TRUE_FOR(true_for_duration)]
  | COUNT_WINDOW(count_val[, sliding_val][, col_name ...])
}
```

状态窗口新增参数extend，用于指定窗口起止位置，对窗口触发没有影响。
其中，extend取值与对应行为如下：

| Extend | 窗口开始时间 | 窗口结束时间 | 其他 |
| --- | --- | --- | --- |
| 0 | 1. 本状态首个时间点 1. 如无上一状态，取首条数据的时间点 | 1. 本状态最后时间点 1. 如状态未结束，取最后一条数据的时间点 | 默认值 |
| 1 | 1. 本状态首个时间点 1. 如无上一状态，取首条数据的时间点 | 1. 下一个状态的首个时间点的前一时刻 1. 如状态未结束，~~取查询范围的结束时~~~~间~~~~；~~~~如未指定结束时间，取~~~~本状态最后时间点~~取最后一条数据的时间点 | 流计算中只有下一个状态出现才触发窗口关闭 |
| 2 | 1. 上一状态的最后时间点的后一时刻 1. 如无上一状态，~~取查询范围的开始时间~~~~；~~~~如未指定开始时间，取本状态首个时间点~~取首条数据的时间点 | 1. 本状态最后时间点 1. 如状态未结束，取最后一条数据的时间点 |  |

## 8. 使用场景

在批查询与流计算中，启用状态窗口时，均可使用该参数。
尤其是在“设备仅在状态改变时才上报”，“不同状态窗口之间的空白间隔会导致计算错误”等情况下，可以通过该参数，使相邻状态窗口成为在时间上连续、时间间隔足够小的窗口。
