## 4. 行为说明

1. 慢日志行为说明
   - 慢日志文件一天一个，如果当天没有慢日志，没有当天的文件。
   - 文件名为 taosSlowLog.yyyy-mm-dd（taosSlowLog.2024-08-02），日志存储路径通过 logDir 配置。
   - 多个客户端的日志存储在相应日志路径下的同一个 taosSlowLog.yyyy.mm.dd 文件里。
   - 慢日志文件不自动删除。
   - 慢日志文件不压缩。
2. 配置参数
   - 使用和普通日志文件相同的三个参数 logDir,  minimalLogDirGB,  asyncLog。另外两个参数 numOfLogLines，logKeepDays 不适用于慢日志
   - 具体参数含义参见 https://docs.taosdata.com/reference/config/#logdir

## 15. 附录

1. 普通日志行为说明
  普通日志 client 端日志文件名如何确定规则为：
   - 确定日志序号，使用 10 个序号作为日志命名方式，/var/log/taos/taoslog0.x  -  /var/log/taos/taoslog9.x，依次检测每个序号是否使用，找到第一个没使用的序号作为该client 进程的日志文件使用的序号。
   - 确定日志后缀，0或者1。比如确定序号为3，备选的日志文件名就为 /var/log/taos/taoslog3.0 /var/log/taos/taoslog3.1。如果两个文件都不存在用后缀0，一个存在一个不存在，用存在的后缀。两个都存在，用修改日志最近的那个后缀。
   - 如果 10 个序号都被进程使用，不使用序号，即 /var/log/taos/taoslog.x，进程都往相同的文件里写。
   - 如果日志文件超过配置的条数 numOfLogLines，会切换后缀名，继续写日志，比如/var/log/taos/taoslog3.0 写够了，切换到 /var/log/taos/taoslog3.1 继续写日志。/var/log/taos/taoslog3.0  会添加时间戳后缀重命名并压缩归档存储（异步线程操作）。
   - 通过配置 logKeepDays 控制日志文件保存几天，几天之外的日志会被删除。比如 配置为1，则一天之前的日志会在新日志压缩存储时检测删除。不是自然天。
   - 日志文件路径磁盘大于 minimalLogDirGB 配置，才可以写日志文件，否则不写日志（目前实现为大于 0 即可写，为了磁盘满 taosd 可以重启起来才改成的0，不合理。taosd 磁盘满可起来通过大于0来判断，是否可写日志通过判断大于 minimalLogDirGB 来实现）。
