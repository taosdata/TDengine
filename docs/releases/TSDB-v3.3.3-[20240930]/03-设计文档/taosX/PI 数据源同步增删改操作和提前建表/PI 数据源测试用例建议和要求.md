# PI 数据源测试用例建议和要求

## 1. 背景

为保证 PI 数据源功能的稳定性，我从开发角度给出一份测试用例的建议。

## 2. 整体说明

- 本文所有用例**只需在有 agent 条件下验证**，因绝大多数客户都会选择使用 agent。
- 用例设计，**应涵盖 PI 数据源的所有核心功能**，并且用尽量较少的用例覆盖尽量多的功能，
- 理论上，每个用例都既可以用于 CI 用例，又可以用于稳定性测试。用例的数据源切换到 CI 数据源时，即可加入 CI，切换到稳定性测试数据源时，即可做稳定性测试。
- 所有测试用例，连接器日志级别设置为 debug，以便出问题的时候排查。

## 3. **数据源配置**

数据源分两类，一类用于 CI 用例，快速验证功能。一类用于长稳测试，尽量模拟真实用户场景。
数据源的结构一定要包含以下几类特殊情况（Cargill 数据源已经满足要求）：
1. 存在没有任何时序数据的模板
2. 存在多层子元素
3. 存在不同类型的 Data Reference。PI 支持的每种类型都要有。

### 3.1 CI 数据源配置

使用 Cargill 的数据模型测试，复制 Cargill 一个 Plant 的 element 配置即可
使用 CI 数据源的用例，执行时间 1 分钟以上即可停止。

### 3.2 稳定性测试数据配置

完全模拟 Cargill 生产环境的数据频率，使用 cargill 库全部元素。**Cargill 有很多 1 天一个点的模板，可以考验系统保持空连接不断开的能力**。@贾晨阳统一进行配置 统一进行配置
- 模板  LI*，5 分钟
- 模板 Equipment tag， 5 分钟
- 模板 OP*，1 天
- 模板 MTPM*， 1天
稳定性测试用例需要执行 1 天以上。

## 4. 用例设计

要测试的整体范围包括 3 种数据模型和 2 种运行模式。所以整体至少 6 个基本功能测试用例:
1. Achive 单列 backfill
2. AF 单列 backfill
3. AF 多列 backfill
4. Achive 单列实时 + backfill
5. AF 单列实时  + backfill
   - 动态属性需要指定不同的 UOM，因为现在是按照 UOM 加类型分超级表
6. AF 多列实时 + backfill
另外还需要一个断点续传功能的测试用例。
1. 断点续传

**对 transfrom 功能的测试分散在这用例之间。因为 transform 是在超级表级别配置的，所以对 transform 的不同功能的测试，可以分布在不同用例不同超级表之间，可以自由组合**。tansfrom 配置文件可以提前准备好, @贾晨阳进行用例的补充 进行用例的补充
transfrom 测试功能点：
1. 子表名映射表达式
2. 过滤表达式
3. 增加自定义列
4. 删除列
5. map 表达式变换普通列值
   - 重点测试数学函数
6. map 表达式变换 TAG 列值
   - 重点测试字符串变换，比如字符串替换：$element_paths.replace('\', '.')

### 4.1 断点续传用例设计

Backfill 一个模板的数据，任务结束前停止问题，再启动任务，此时：
1. 检查 agent 端是否存在断点文件
2. 进一步，检查断点文件的内容是否正确(可选)
3. 进一步，检查是否用上了断点文件。一个简单的方法是依赖连接器的输出日志：
```rust
if (breakpoints != null && breakpoints.ContainsKey(elementID))
{
    var breakPoint = breakpoints[elementID];
    if (breakPoint >= currentStart)
    {
        currentStart = breakPoint.AddMilliseconds(1);
        log.Info($"Backfill element {superTableName}:{element.ID} from breakpoint {currentStart}.");
    }
}
```

## 5. 正确性验证

所有测试用例都需要验证**目标库数据量和子表数是否符合预期**。

## 6. 需要人工参与测试的功能

需要人工参与测试的功能如下，
1. 同步新增、删除元素
2. 同步修改、删除历史数据
3. 同步编辑元素属性
4. 生产模型配置文件各种搜索条件
   - 按点搜索
   - 按元素搜索
   - 按模板搜索
