## 6. 已知问题和限制

- 慢 SQL 明细页面执行耗时min>max前后端未校验
- 无log数据库时，接口有返回错误，页面无错误，只是不加载数据

## 7. 测试环境

- OS: Windows, Linux
- Browser: Chrome
