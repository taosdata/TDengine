# OPC 点位支持动态添加和查看 Test Spec

## 1. 测试目标

1. 确保新的功能的引入不会破坏已有正常的功能
2. 验证新增的批量对于任务的启动、停止、删除功能可以正常工作
3. 验证 UI 的改动符合 FS 中的描述
4. 验证 OPC UA / OPC DA 通过 CSV 配置文件创建的任务可以在运行中添加点位并实时生效

## 3. 测试范围

1. 前端 UI 的修改，包括新增的按钮及页面 tab 改动
2. OPC UA / OPC DA 通过 CSV 创建的任务

## 4. 测试结论

1. 数据源列表也存在多个任务时，能够勾选多个任务，对勾选的任务进行“启动”，“停止”和“删除”操作，验证通过。
2. OPC UA 及 OPC DA 使用 CSV 配置文件的任务在运行中可以实时添加数据点位，并且在等待一分钟后新增的点位在不需要重启任务的情况下可以进行数据采集，验证通过。
