## 3. 测试范围

- IP 地址和端口号的配置拆分，只涉及 Kafka 数据源
- 对端口的校验会涉及所有数据源，但采用的是统一的实现，不同的数据源没有特殊逻辑，所以测试时通过 Kafka 数据源覆盖

## 4. 测试结论

1. 所有数据源的服务器和端口地址的输入格式已经统一，并且会对不合规的输入进行检测和提示
2. 新增、查看、编辑数据源任务使用新的统一格式都能正常工作
3. 在老的TDengine创建的数据源任务，在升级TDengine以后，仍然可以正常运行
