## 3. 测试结论

1. 在较大规模的正则匹配中，单pattern，双pattern和5个pattern的情况下查询速度在2/3的情况下有提升，主要提升在5个pattern的情况下。具体数据见下表。
2. 在较小规模的正则匹配中，单pattern和双pattern的情况下基本不分伯仲，差异很小，在5个pattern的大数据表情况下有明显性能提升。具体数据见下表

| match类型 | pattern类型 | 数据量大小 （表数*表行数） | 相比过往版本提升 |

| 10*1000 | 14.46% |
