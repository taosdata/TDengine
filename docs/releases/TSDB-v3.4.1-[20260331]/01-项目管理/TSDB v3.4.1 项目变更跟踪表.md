## 3. 20260225 工作范围变更

### 3.1 变更描述

1. 变更原因
   - IDMP 产品开发新增的部分任务
   - 交付部门根据客户需求，新增的部分任务
2. 变更类型：工作范围变更

### 3.2 变更内容

#### 3.2.1 新增工作项

1. [交付][河北电力] 海量子表且存在订阅的场景下，频繁修改子表标签影响数据写入
2. [售前] 同时支持 Ipv4 & Ipv6 协议栈
3. [售前][信通院IDMP测试] 时序模型管理和时序数据预处理 测试项临时工作
4. 流计算支持 ANY/SOME/ALL/EXISTS/NOT EXISTS 运算符
5. [上海电气]idmp 元素的属性页面刷新很慢
6. [规划] 优化虚拟表列多时的查询性能
7. [安全可靠测评] 支持更新密钥过期时间和过期策略
8. [规划] 提升虚拟表查询含 tbname 列时的性能
9. [规划] 优化虚拟超级表状态窗口的查询性能
10. [规划] 流计算支持 IN 子查询

#### 3.2.2 移除工作项

无

### 3.3 变更影响分析

新增工作项已经高优先级完成，但影响到已经规划的工作。后续和业务部门沟通，移除优先级低的工作项

## 4. 20260318 工作范围变更

### 4.1 变更描述

1. 变更原因
   - 有客户需要 Windows 版本，需要补充 Windows 缺失功能
   - 已经按照 [Windows 适配工作计划](TSDB%20Windows%20适配计划.md) 实施
2. 变更类型：工作范围变更

### 4.2 变更内容

1. TDgpt 支持 Windows
2. 流计算支持 Windows
3. taosX 支持 Windows
4. 修复 Windows 测试过程中发现的问题
5. 制定并实施 Windows 下 Coredump 文件生成策略

### 4.3 变更影响分析

1. 新增工作由已经完成规划任务的同事负责，对工期无明显影响

## 5. 20260414 工作范围变更

### 5.1 变更描述

1. 变更原因
   - v3.4.1 已于 2026 年 3 月底发版，4 月份进入验证和收尾阶段
   - 根据飞书项目最新导出数据，同步更新各任务的最终状态
   - 补充此前未纳入跟踪表的工作项
2. 变更类型：工作范围变更

### 5.2 变更内容

#### 5.2.1 新增工作项

**业务（新增 33 项）**

主要来自交付和售前部门在项目周期内陆续追加的客户需求，包括：版本滚动升级检查保障机制、多变量异常检测、海量子表标签修改影响写入、TSDB 内部点位不计入授权测点数、力控 pSpace 实时同步/历史迁移、taosX 导入 Parquet 格式、Explorer 数据库压缩率和磁盘用量展示、go 支持多端点 failover 等。

**IDMP（新增 8 项）**

主要来自信通院测试项临时工作、上海电气 IDMP 元素属性页面性能优化等。

**规划（新增 49 项）**

主要涵盖安全加固（权限控制独立参数、v3.4 授权语法兼容 v3.3、密码策略可配置、SQL Fuzzing Test、各连接器安全检查和 SBOM 生成）、Windows 适配（TDgpt、流计算、xnoded、Coredump 策略）、连接器 token 认证支持（JDBC/Python/Rust/Node.js/C#/Go/taosadapter 订阅）、工具优化（taosdump blob/stmt2 支持、日志默认保存时长变更、MQTT Topic 支持任意字符、taosX 超级表模板表达式计算）、AI 能力（taosgen config skill、IDMP MCP server）等。

#### 5.2.2 移除工作项

1. [售前][上海电气中央研究院] 扩展 taosX 解析功能（移至 v3.4.2）

### 5.3 变更影响分析

1. 新增工作项在项目周期内已全部完成或取消，对交付进度无影响
2. 所有任务已标记为最终状态（Done/Canceled），项目进入收尾阶段
