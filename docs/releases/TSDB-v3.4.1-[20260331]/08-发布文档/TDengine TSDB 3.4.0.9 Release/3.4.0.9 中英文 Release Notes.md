### 5. English

```markdown

### 6. Features

   - 6734823388 feat: taosAdapter add token support for subscription
   - 6689665829 feat: taosdump support import/export virtual tables

### 7. Enhancements

   - 6771172404 enh: massive ui enhancement for explorer
   - 6765905149 enh: optimize the impact of frequent child table tag modifications on data writing when child tables of super table have subscriptions
   - 6757417051 enh: table name template support expression
   - 6747163479 enh: improve performance of virtual table queries with the tbname column
   - 6837004097 enh: reduce log files to 3
   - 6670224710 enh: adjust the maximum value of configuration parameter supportVnodes from 4096 to 1024
   - 6833801941 fix: CREATE XNODE TASK error message refinement

### 8. Fixes

   - 6663139356 fix: Kafka connection check log refinement
   - 6776701499 fix: the GRANT ALL permission does not take effect when granted to a specific stream
   - 6775872381 fix: the START/STOP STREAM permission does not take effect after being granted
   - 6775867757 fix: failed to drop stream when having the DROP STREAM permission
   - 6772905851 fix: taosd crashes when querying a view without permission
   - 6772894791 fix: the ALTER VIEW permission does not take effect after being granted
   - 6771304625 fix: auditor fails to view the complete user information
   - 6771200393 fix: stream crashes when reading the timestamp of a table with a varchar-type composite primary key
   - 6769590726 fix: failed to drop role using the IF EXISTS syntax
   - 6769435767 fix: the error message is unclear when permissions are missing
   - 6769316072 fix: port occupancy keeps increasing on macOS when calling the taos_query method of the native connection
   - 6769305510 fix: in stream subquery, JOIN statements falsely report the error of missing timestamp primary key when using time placeholders such as _twstart as the first column of query results
   - 6764293258 fix: timestamp columns in query results are incorrectly set when stream subquery contain interval windows
   - 6755488313 fix: audit database creation operations fails to return when the data encryption key is not set
   - 6747415944 fix: ordinary users lack write permission without explicit authorization after creating ordinary tables
   - 6739688865 fix: modify the names of newly added encryption functions to keywords to resolve the issue of keywords being incorrectly written as actual content into the database during data writing
   - 6739571506 fix: timetruncate function occasionally returns no results
   - 6735485359 fix: unexpected error log when create xnode
   - 6723638357 fix: expand parser length to 48k in taosX
   - 6653149496 fix: no response in explorer tmq connection check
   - 6796052026 fix: str len calculation error cause create clause error with invalid raw data len
   - 6793548966 fix: create task via agent error
   - 6793518088 fix: Explorer alert syntax error when switching tag to share topics
   - 6793469478 fix: xnode task stuck at created status
   - 6782639009 fix: Grid auto scalable in Explorer
   - 6770241526 fix: reading tinyint(1)/boolean type for mysql
   - 6734892865 fix: memory leak caused by unreleased auto table creation requests during STMT data writing
   - 6719807401 fix: explorer backup task create error
   - 6802466041 fix: opcplc special point id cause data points list error
   - 6802127560 fix: data in tasks api respond as empty after created successfully
   - 6800867086 fix: Explorer batch operation api error
   - 6807646581 fix: build task update sql error in explorer
   - 6827767497 fix: fast-xml-parser CVE-2026-25896
   - 6812792935 fix: xnoded role time check error cause exit unexpectedly
   - 6777974944 fix: the merge logic processes data incorrectly when stream handles out-of-order data of trigger tables with primary keys
   - 6741687463 fix: client crashes when querying decimal data type using stmt
   - 6644387794 fix: the scan interval is judged incorrectly when sliding < interval during stream sliding trigger
   - 6635280371 fix: during the stream trigger phase, when pending calculation requests are accumulated, max_delay triggering resets the waiting time, resulting in the calculation not being triggered for a long time
   - 6840310702 fix: taosX compatible with 3.4.x information_schema query result changes
   - 6834851377 fix: invalid user login cause adapter memory increase
```
