#### 3. 第三部分,实操题目,售前交付回答

**任务说明:**

使用 TDengine 3.4.1 版本完成以下实操任务,综合运用外部窗口、子查询、流计算、批量标签修改、数据订阅等功能。

**任务一:数据准备**

1. 创建两个超级表:
   - `alarm_events` (告警事件表):包含 ts, event_id, alarm_level, device_id 等字段
   - `device_metrics` (设备监控表):包含 ts, temperature, pressure, power 等字段
   - 标签:device_id, region, device_type

2. 使用 taosBenchmark 或自定义脚本写入数据:
   - 10 个设备子表
   - 每个设备每分钟产生一条监控数据
   - 随机产生告警事件(告警级别 1-3)
   - 数据时间跨度:最近 7 天

**任务二:查询操作**

1. **外部窗口查询**:基于 alarm_events 中告警级别 ≥2 的事件,查询告警后 5 分钟内 device_metrics 的平均温度和最大压力,列出未在 5 分钟内收到监控数据的告警事件

2. **子查询功能**:查询最近 24 小时内温度超过全局平均温度 1.2 倍的设备及其监控数据

3. **INTERVAL 窗口 SURROUND 查询**:按小时统计设备平均功率,使用 FILL(PREV),但只探索最近 2 小时的数据,超过 2 小时填充为 0

4. **性能诊断**:对任务二的查询 2 执行 EXPLAIN ANALYZE VERBOSE,分析 exec_elapsed 和 file_load_elapsed 指标,定位性能瓶颈

**任务三:流计算**

1. 创建流计算任务,监控设备温度:
   - 使用 TRUE_FOR(AND 1m COUNT 5) 触发条件:持续 1 分钟且至少 5 条记录温度超过 80℃
   - 窗口结束条件:温度低于 60℃
   - 统计窗口内的平均温度、最大压力、窗口持续时间
   - 结果写入 temp_warning 表

2. 创建定时流计算任务,生成每周一上午 9 点的设备周报:
   - 使用 PERIOD(1w, 9h) 定时触发
   - 统计每个设备上周的平均温度、总功率消耗、告警次数
   - 结果写入 weekly_report 表

3. 创建分组空闲检测流:
   - 使用 STREAM_OPTIONS(IDLE_TIMEOUT(10m)) 检测设备 10 分钟无数据
   - 监听 IDLE 事件,将离线设备信息写入 device_offline 表

**任务四:批量标签修改**

1. 批量修改 3 个设备的 region 标签:
   - device_001: region = '华北'
   - device_002: region = '华东'
   - device_003: region = '华南'
   - 要求:使用一条 SQL 完成

**任务五:数据订阅 (可选)**

1. 创建 TOPIC 订阅 device_metrics 超级表的数据
2. 编写消费者程序,使用 Token 认证连接
3. 验证是否能正常消费到数据
