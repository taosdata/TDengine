### 3. 数据准备

1. 原始表数据准备
  ```bash
  taosBenchmark -n 100000000 -t 1
  ```

1. 虚拟表创建语句
  ```sql
  create vtable v_d0(tss timestamp, cur float from d0.current, vol int from d0.voltage, pha float from d0.phase);
  ```

1. 需要测试的查询语句
  ```sql
  select cols(last(cur), cur, _c0), cols(last(vol), vol, _c0), cols(last(pha), pha,_c0) from v_d0;
  ```
