## 6. 功能测试

主要测试覆盖内容包括：
1. 准备数据：
   - 创建虚拟超级表，虚拟子表、虚拟普通表。并且 ref 引用到子表或者普通表。
   - 所有列都有 ref，只有部分列有ref。
2. 测试超级表 topic，数据库 topic两种情况。
3. 测试 snapshot = true 和 snapshot = false 两种情况
4. 测试创建虚拟超级表，虚拟子表，虚拟普通表，tmq_get_json 接口返回数据正确
5. 测试修改虚拟子表 ref（包括 set null)，虚拟普通表的 ref（包括 set null)，tmq_get_json 接口返回数据正确
6. 测试为虚拟普通表增加 column with ref，tmq_get_json 接口返回数据正确
7. 测试没有 with meta 选择，返回数据为空，正常
8. 测试配置参数 tmqWriteRefDB 和 tmqWriteCheckRef，可以正确设置，并且生效。
9. 测试通过 tmq_get_raw/tmq_write_raw 迁移建立的超级表 topic 和 数据库 topic，数据迁移校验正确，迁移成功。
