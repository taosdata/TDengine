## 2. **引言**

### 2.1 **术语与缩写名词**

1. **Machine Code**: 机器码，用于 TDengine license 激活的唯一标识符
2. **Cluster ID**: 集群 ID，TDengine 集群的唯一标识
3. **Explorer**: taosX 的 Web 管理界面
4. **License**: 许可证，用于激活 TDengine 企业版功能

### 2.2 **相关文档资料**

- TDengine License 激活流程文档
- Explorer 管理界面现有实现: `explorer/src/views/8_administrator/views/license.vue`
- TDengine SQL 命令: `show cluster machines`

### 2.3 **优先级要求**

1. **优先级**: 高
2. **期望交付时间**: 2026-01-20
3. **重要程度**: 简化用户激活流程，提升用户体验

### 2.4 **版本要求**

- 仅在企业版 Explorer 中支持
- 计划在 taosX 3.3.6+ 版本发布
- 需要 TDengine 3.x 版本支持 `show cluster machines` 命令

## 3. **需求目标**

目前用户在 Explorer 的 License 管理页面可以查看 Cluster ID，但无法直接查看机器码（Machine Code）。用户需要激活 license 时，必须先通过命令行执行 `show cluster machines` SQL 命令来获取机器码，这增加了用户的操作复杂度。
本需求的目标是：
1. 在 Explorer License 管理页面直接显示机器码
2. 简化用户获取激活信息的流程
3. 提供与 Cluster ID 一致的展示体验
4. 支持页面刷新时重新获取机器码

## 4. **功能需求**

| 序号 | 功能类别 | 功能名称 | 功能描述 |
| --- | --- | --- | --- |
| 1 | 数据获取 | 机器码查询 | 通过 `show cluster machines` SQL 命令获取机器码 |
| 2 | UI 展示 | 机器码显示 | 在 License 页面的基本信息区域显示机器码 |
| 3 | 国际化 | 多语言支持 | 支持中英文界面显示 |
| 4 | 错误处理 | 兼容性处理 | 兼容不支持该命令的旧版本 TDengine |
| 5 | 数据刷新 | 刷新功能 | 点击刷新按钮时重新获取机器码 |

## 5. **性能需求**

1. **查询性能** 
  - `show cluster machines` 命令执行时间应在 200ms 以内
  - 不影响页面其他数据的加载速度
1. **页面加载**
  - 机器码获取失败不应阻塞其他 license 信息的显示
  - 使用异步查询，避免页面卡顿

## 6. **安全需求**

1. **数据访问权限**
  - 机器码是敏感信息，仅在用户已登录且有权限访问 License 页面时显示
  - 遵循现有的 Explorer 权限控制机制
1. **数据传输**
  - 通过已有的安全连接传输数据
  - 不在日志中输出完整的机器码信息

## 7. **其他需求**

### 7.1 **兼容性需求**

- 对于不支持的版本，显示 "N/A" 而不是报错
- 不影响现有 License 页面的其他功能

### 7.2 **接口需求**

- 使用现有的 `sendSQLReq` API 执行 SQL 命令
- 数据格式与现有 license 信息保持一致
- 返回数据包含: id, dnode_num, machine, version 字段

### 7.3 **运维需求**

- 查询失败时记录日志，便于问题排查
- 不在前端控制台输出敏感的机器码信息
- 错误处理应优雅降级，不影响用户体验

### 7.4 **易用性需求**

- 机器码与 Cluster ID 并列显示，方便用户同时查看激活所需的所有信息
- 显示位置醒目，易于查找
- 支持文本选中和复制

### 7.5 **测试需求（不含测试例）**

- 功能测试：验证机器码显示是否正确
- 兼容性测试：验证在不同 TDengine 版本下的表现
- 刷新测试：验证刷新功能是否正常工作
- 国际化测试：验证中英文界面显示
- 错误处理测试：验证命令不支持时的降级处理
