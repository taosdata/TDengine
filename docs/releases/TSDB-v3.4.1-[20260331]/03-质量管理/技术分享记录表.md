## 1. Dependabot 与飞书项目集成的设计与实现

1. 分享人：王旭
2. 分享日期：2026-01-10
3. 分享简介：介绍了为解决人工处理 GitHub Dependabot 安全漏洞通知流程繁琐、易遗漏的问题，设计并实现了 Dependabot 与飞书项目的自动化集成方案 。该方案通过配置 GitHub Webhook 接收 Dependabot Alert 的三类主要消息（created、fixed、dismissed），并利用飞书项目开放平台插件调用 API 自动创建、关闭或取消飞书项目缺陷 。在实现过程中，采用了 FastAPI 框架、策略模式、工厂模式及依赖注入等设计思想，并结合 uv 工具链、@dataclass、YAML anchor 及 dotenv 等技术，确保了代码的可扩展性、低耦合性和安全性 。
4. 分享材料：[Dependabot 与飞书项目集成的设计与实现](https://taosdata.feishu.cn/wiki/AUOkwC7mUiXu8AksiT7cHRAEnw5)
