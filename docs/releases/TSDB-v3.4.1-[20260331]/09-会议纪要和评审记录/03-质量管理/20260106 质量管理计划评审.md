## 2. 会议决定事项

1. **审阅通过** 《TSDB v3.4.1 质量管理计划》（v1.0），确认文档内容已覆盖 v3.4.0 质量保证报告中提出的三项过程改进建议：
   - 提升缺陷报告规范率：本版本目标 ≥ 95%（较 v3.4.0 提升 5 个百分点），由肖波负责在功能测试阶段建立缺陷报告质量门禁。
   - 需求追踪矩阵（RTM）维护频率：确认从"按阶段更新"改为"每周更新"，责任人为需求负责人，王旭每月审计执行情况。
   - NCR 整改时效：延续 v3.4.0 的严重 3 天 / 一般 7 天处理时限，并在每月度量中增加时效达标率指标。
2. **安全审计重点确认**：本版本安全漏洞修复（含 SQL 注入风险 Risk-341-01）需在需求与设计阶段审计中专项覆盖，霍琳贺提供相关修复方案的技术说明，作为审计依据。
3. **AI 工具使用规范**：会议识别到研发成员使用 AI 编程辅助工具（如 GitHub Copilot）的规范尚未明确，存在潜在知识产权及代码安全风险。决定在本版本内由平台组牵头（关胜亮负责落实责任人）起草《AI 工具使用内部规范》，纳入 v3.4.1 质量管理计划跟踪事项。
4. **供应链安全采购**：确认 v3.4.0 识别的供应链安全工具（堡垒机、防火墙、主机安全、上网行为分析）采购申请已在本版本内推进，杨亮负责跟进采购流程，王旭跟踪采购进度作为质量风险监控项。
5. **质量度量周期**：延续每月第三个周四进行度量指标采集，本版本新增对"需求追踪矩阵更新及时率"的跟踪。
