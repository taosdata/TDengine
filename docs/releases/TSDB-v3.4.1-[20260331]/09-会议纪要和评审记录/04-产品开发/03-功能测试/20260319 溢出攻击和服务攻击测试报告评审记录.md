## 2. 评审记录

**测试目标与设计文档契合度** ：测试报告明确将“验证 TDengine 引擎在溢出攻击和遭受网络攻击时的稳定性和安全性”作为核心目标，与 TS 文档的背景与设计目标高度一致。报告直接响应了 TS 中关于验证 DoS/DDoS 攻击、协议层攻击、认证攻击、连接攻击、数据完整性及溢出攻击的核心诉求，测试方向精准。
**功能测试覆盖度与深度** ：报告的功能测试部分分为多个主要项目，覆盖了多种攻击场景下的系统稳定性与安全性验证：
- **DoS/DDoS 攻击测试** ：通过 SYN Flood、UDP Flood、HTTP Slowlori 等方式模拟流量攻击，验证了引擎在流量攻击下的抗压能力，测试过程中服务端可以正常连接并做查询，CPU 比之前高 10% 左右，大规模攻击下建立正常连接比没有攻击下慢了 10% 左右。
- **协议层攻击测试** ：通过发送超长包、空包、随机字节包等畸形数据包，验证了引擎对畸形数据包的处理能力，服务端有报错，但不影响正常的访问。
- **认证攻击测试** ：通过连续尝试错误密码和尝试 SQL 注入等方式，验证了引擎对暴力破解和 SQL 注入的防护能力，符合预期，直接返回报错或解析失败。
- **连接攻击测试** ：通过大量并发连接请求，验证了引擎对大量并发连接的处理能力，达到连接上限之前，客户端和服务端都稳定进行，达到连接上限之后，新的 taos-shell 无法建立连接，旧的 taos-shell 可以正常访问。
- **数据完整性验证** ：通过 SELECT COUNT(*) 验证攻击后数据无丢失或损坏，攻击过程中可以正常返回数据，CPU 有一定的变高，性能比没有攻击的情况下慢 10% 到 30%，攻击之后，可以正常返回数据，性能恢复正常。
- **溢出攻击测试** ：通过脚本检测不安全函数，验证接口的异常值输入和静态检测不安全函数的使用，测试结果为通过。
**其他测试模块的评审** ：
- **易用性测试** ：报告包含了测试脚本执行、报告生成、日志记录等方面的测试，认为脚本使用简单，参数配置灵活，能够自动生成 HTML 测试报告，详细记录攻击过程和系统状态。
- **长期稳定性测试** ：报告包含了持续攻击、多次攻击、资源监控等方面的测试，认为攻击过程中服务依然稳定，没有出 crash，性能受到一定的影响，攻击完毕后，服务端稳定，性能恢复到未攻击之前。
- **性能测试** ：报告包含了 SYN Flood、UDP Flood、连接攻击等方面的性能测试，认为攻击未对 TDengine 性能造成显著影响，服务响应时间 < 1s，资源占用 CPU < 30%。
- **安全测试** ：报告包含了 SQL 注入防护、暴力破解防护、畸形包处理、权限控制等方面的测试，认为所有注入尝试被正确拒绝，无数据泄露，多次错误密码后服务仍正常，未锁定，异常数据包未导致服务崩溃或挂起，测试用户无法执行未授权操作。
- **兼容性测试** ：报告包含了 IPv4 兼容、IPv6 兼容、双栈支持等方面的测试，认为支持 IPv4 地址连接和通信，支持 IPv6 地址连接和通信，同时支持 IPv4/IPv6 双协议栈。
**测试文档规范性与可追溯性** ：报告结构完整，包含了测试目标、参考文档、测试项目、测试结果、测试现象、测试环境等内容，符合标准测试文档的规范。报告明确列出了参考的文档链接，确保了测试活动与需求的可追溯性。
**测试结论的客观性与决策价值** ：报告基于现有测试用例结果，给出了“TDengine 网络安全测试通过溢出攻击通过”的结论。该结论与已执行的功能测试结果相符，认为服务在各种网络攻击场景下表现稳定，攻击时可以正常对外提供服务，数据完整性和一致性得到保障，安全防护机制工作正常。

测试报告合格，完全覆盖设计要求，同意归档。
