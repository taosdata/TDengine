### 2. 安全评审记录

评审团队对设计文档进行了审查，评估其安全机制、架构和实现细节是否足以抵御威胁。具体评审意见如下：

#### 2.1 身份认证与访问控制

- **评审意见与发现：** FS 第 6 节明确说明"该页面已有权限控制，仅管理员可访问"，机器码查询通过现有的 `sendSQLReq` API 执行，复用 Explorer 已有的认证和授权机制。机器码仅在 License 管理页面展示，不引入新的 API 端点或权限模型。权限校验依赖 Explorer 已有的管理员权限体系，设计合理。
- **状态：** 通过
- **说明/依据：** 本功能未引入新的认证或授权逻辑，完全复用现有管理员权限校验机制，无额外权限风险。

#### 2.2 数据安全

- **评审意见与发现：** 机器码（Machine Code）是用于 license 激活的集群标识信息，非用户隐私数据或密钥。FS 中说明数据通过"现有的连接传输方式"传输，使用已有的 `sendSQLReq` API。机器码在前端为只读展示，不涉及存储、缓存或持久化操作。该数据本质上是集群硬件指纹信息，敏感性较低。
- **状态：** 通过
- **说明/依据：** 机器码属于集群标识类信息，非高敏感数据，且仅做只读展示，无加密存储或特殊保护需求。

#### 2.3 输入/输出验证与编码

- **评审意见与发现：** 本功能执行的 SQL 命令是硬编码的 `show cluster machines;`，不接受任何用户输入参数，从根本上排除了 SQL 注入风险。前端使用 Vue.js 模板渲染（`{{ machineCode || 'N/A' }}`），Vue 的模板引擎默认对输出进行 HTML 转义，可防止 XSS 攻击。FS 第 6 节提到"查询错误时不在前端控制台输出完整机器码"，错误处理使用 `.catch()` 静默处理，不会泄露敏感信息。
- **状态：** 通过
- **说明/依据：** SQL 命令硬编码无注入风险，Vue 模板默认转义防止 XSS，错误处理设计合理。

#### 2.4 会话与通信安全

- **评审意见与发现：** 本功能未引入新的通信通道或会话机制，完全复用 Explorer 现有的 HTTP/HTTPS 通信和会话管理。
- **状态：** 不适用
- **说明/依据：** 无新增通信通道或会话管理逻辑，由 Explorer 整体安全架构保障。

#### 2.5 安全日志与监控

- **评审意见与发现：** FS 第 6.3 节提到"查询错误时不在前端控制台输出完整机器码"，体现了日志脱敏意识。`show cluster machines` 的执行会通过 Explorer 的 `sendSQLReq` API 走正常的请求链路，服务端已有的 SQL 审计日志可以记录该查询操作。
- **状态：** 通过
- **说明/依据：** 复用现有日志框架，错误处理避免前端泄露信息，满足基本审计要求。

#### 2.6 威胁缓解机制

- **评审意见与发现：** 本功能攻击面极小（只读展示、硬编码 SQL、仅管理员可访问）。威胁建模报告（参见 TM-TSDB-EXPLMC-001）识别出的威胁均为低危级别，现有 Explorer 安全机制已提供充分缓解：管理员权限控制防止未授权访问（T-EXPLMC-01），HTTPS 传输防止网络层信息泄露（T-EXPLMC-02），硬编码 SQL 防止注入（T-EXPLMC-03），现有请求机制防止滥用（T-EXPLMC-04）。
- **状态：** 通过
- **说明/依据：** 功能攻击面小，已有安全机制可有效缓解识别到的威胁。

#### 2.7 默认安全配置

- **评审意见与发现：** FS 第 8 节明确"无需修改配置文件"，本功能不引入任何新的配置项或端口。
- **状态：** 不适用
- **说明/依据：** 无新增配置项，不影响系统默认安全配置。

#### 2.8 依赖组件安全

- **评审意见与发现：** 本功能使用的 Element Plus `el-descriptions-item` 组件是 Explorer 已有的 UI 框架组件，未引入新的第三方依赖。
- **状态：** 不适用
- **说明/依据：** 无新增第三方依赖，复用现有 UI 组件库。

#### 2.9 隐私设计

- **评审意见与发现：** 机器码是集群硬件指纹，不属于个人身份信息（PII）或用户隐私数据，无隐私合规要求。
- **状态：** 不适用
- **说明/依据：** 机器码为集群级别技术标识，不涉及个人隐私。

#### 2.10 其他（可扩展性、运维安全等）

- **评审意见与发现：** 本功能无新增密钥、证书或运维管理接口。FS 第 8 节确认"无需重启服务"、"部署方式与现有 Explorer 一致"。功能设计简洁，可维护性好。
- **状态：** 不适用
- **说明/依据：** 功能简单，无运维安全新增需求。
