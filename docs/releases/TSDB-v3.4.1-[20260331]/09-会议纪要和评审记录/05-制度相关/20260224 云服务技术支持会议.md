## 2. 会议决定事项

会议讨论了当前云服务（含TSDB、IDMP），包括海外云服务过程中，旧有的管理规范要求需要进行调整。
会议议定事项如下：
1. 由服务中心承接所有云服务的运维工作，为云服务运维第一责任人；
2. 由解决方案中心承接所有云服务的售前工作，为云服务售前第一责任人；
3. 由平台部承接云服务平台基础架构管理工作；
4. 由研发部承接云服务产品所有二线支持工作；
5. 由服务中心@张心治 修订《云服务客户支持规则》，经与会人员确认后发布。
