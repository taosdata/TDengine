### 3.2 测试重点

依据《安全管理计划》，本次渗透测试重点覆盖：

1. 身份认证机制（TOTP、TOKEN）

5. 审计日志完整性
6. 三员权限 + 强制访问控制

## 4. 测试方法

### 4.1 使用工具

| 工具 | 用途 |
| --- | --- |
| Nmap | 端口扫描、服务识别 |
| Burp Suite | Web 应用测试 |
| sqlmap | SQL 注入测试 |
| Metasploit | 漏洞利用验证 |
| 自定义脚本 | 协议 Fuzzing |

### 4.2 测试步骤

1. **信息收集**：端口扫描、服务识别、版本探测
2. **漏洞分析**：自动化扫描 + 手动验证
3. **漏洞利用**：对确认漏洞进行受控利用
4. **后渗透测试**：评估横向移动和权限提升可能性
5. **报告编制**：整理发现、提供修复建议
