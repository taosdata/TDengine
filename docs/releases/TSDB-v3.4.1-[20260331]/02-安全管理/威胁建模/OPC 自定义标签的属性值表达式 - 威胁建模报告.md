### 3. 分析报告

本报告针对 OPC 自定义标签的属性值表达式功能进行了威胁建模分析。该功能旨在通过 `{Attr#XY}` 语法，允许用户在自定义标签 pattern 表达式中对 OPC 节点属性值（BrowseName、DisplayName、Description、Path）进行单字符替换和首尾修剪，以便将属性值规范化后写入 TDengine 子表标签。

- **核心发现：** 共识别出 `3` 个潜在威胁，其中 `高危` `0` 个，`中危` `2` 个，`低危` `1` 个。
- **主要风险场景：**
   - 设备拓扑信息随标签写入后经 TDengine 查询接口泄露。
   - taosx 配置（DSN/CSV）被篡改，导致标签字段写入异常内容。
- **结论：** 本功能为受严格约束的轻量字符串处理扩展，不引入 I/O 或网络调用，攻击面极小。识别出的风险均依赖于外部系统（taosx 访问控制、TDengine 权限管理）提供缓解，本功能设计本身安全合理，可进入编码实现阶段。

### 4. 威胁识别与分析（STRIDE）

本功能的处理流程为：用户在 DSN 参数或 CSV 配置文件中定义包含 `{Attr#XY}` 占位符的 pattern 表达式，taosx 在数据采集时读取 OPC 节点属性值，在内存中执行字符替换和首尾修剪，将结果写入 TDengine 子表标签字段。

#### 4.1 关键实体与数据

| 实体/数据 | 描述 | 敏感性 |
| --- | --- | --- |
| DSN 参数 / CSV 配置文件 | 包含 pattern 表达式的 taosx 连接器配置 | 中（配置可控写入内容） |
| OPC 节点属性值 | BrowseName、DisplayName、Description、Path 等节点元数据 | 中（可能含设备拓扑信息） |
| pattern 替换结果 | 经 {Attr#XY} 处理后的字符串 | 低（元数据衍生值） |
| TDengine 子表标签字段 | 最终写入的标签值，随 SELECT 查询暴露 | 中（工业设备拓扑） |

#### 4.2 威胁评估

| 威胁ID | **威胁描述/攻击场景** | **STRIDE** | **相关组件/数据流** | **风险等级** |
| --- | --- | --- | --- | --- |
| T-OPCTAGEXPR-01 | 设备拓扑信息泄露：攻击者通过查询 TDengine 标签数据（如 `SELECT tag FROM stable`），获取由 Path 或 DisplayName 属性经 `{Attr#XY}` 转换而来的标签值，从而推断 OPC 服务器的设备层级拓扑结构（如 `Objects_ControlSystem_Pump01`），为针对工业控制系统的后续攻击提供情报。 | I（信息泄露） | OPC 节点属性 → {Attr#XY} 替换 → TDengine 子表标签 | 中 |
| T-OPCTAGEXPR-02 | 配置篡改导致标签污染：攻击者若已获取 taosx 配置修改权限（如读写 CSV 文件或 DSN 参数的操作系统权限），可将 pattern 表达式替换为精心构造的字符串（如特殊符号组合），导致特定标签字段写入意外内容，污染 TDengine 历史标签数据，影响数据分析和运维判断。 | T（篡改） | CSV 配置文件 / DSN 参数 → pattern 解析 → TDengine 子表标签 | 中 |
| T-OPCTAGEXPR-03 | 异常属性值长度导致写入失败：若 OPC 服务器返回异常超长属性值（如因服务器配置错误或恶意 OPC 服务器），经 `{Attr#XY}` 替换后的标签值可能超出 TDengine 对应 VARCHAR 字段长度限制，导致该点位标签写入失败。在高频率数据采集场景下，写入失败可能引发 taosx 批量重试风暴，消耗服务器端资源。 | D（拒绝服务） | OPC 节点属性值 → {Attr#XY} 替换结果 → TDengine 写入 | 低 |

### 5. 安全需求与设计约束

| 威胁ID | **转化后的安全需求/设计约束** | **类型** | **优先级** |
| --- | --- | --- | --- |
| T-OPCTAGEXPR-01 | SEC-OPCTAGEXPR-001（访问控制）：含设备拓扑信息的 TDengine 标签查询接口应受到适当的角色权限控制，避免非授权用户读取设备结构信息。此需求由 TDengine 权限管理机制负责落实，本功能层面不做额外处理。 | 非功能安全需求 | 中 |
| T-OPCTAGEXPR-02 | SEC-OPCTAGEXPR-002（配置文件保护）：taosx 的 DSN 参数和 CSV 配置文件应受到操作系统级文件权限保护，仅允许授权用户读写。此需求由 taosx 安装和运维规范负责落实。 | 安全设计约束 | 中 |
| T-OPCTAGEXPR-03 | SEC-OPCTAGEXPR-003（长度防护）：taosx 在将 pattern 替换结果写入 TDengine 之前，应校验结果长度是否超出目标 VARCHAR 字段定义的最大长度，超出时截断或记录警告日志，避免写入失败引发重试风暴。 | 健壮性需求 | 低 |
