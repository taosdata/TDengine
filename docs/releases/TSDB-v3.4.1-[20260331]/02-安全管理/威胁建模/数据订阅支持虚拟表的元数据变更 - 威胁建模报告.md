### 3. 分析报告

本报告针对「数据订阅支持虚拟表的元数据变更」功能进行了威胁建模分析。该功能旨在扩展 TDengine TMQ（消息队列）数据订阅能力，使其支持对虚拟超级表（Virtual STable）及虚拟子表的元数据变更（meta）进行订阅和消费，并通过新增配置参数 `tmqWriteRefDB` / `tmqWriteCheckRef` 支持跨集群 meta 数据迁移场景。

- **核心发现：** 共识别出 `4` 个潜在威胁，其中 `高危` `0` 个，`中危` `1` 个，`低危` `3` 个。
- **主要风险场景：**
  - 跨集群元数据伪造写入：攻击者获取目标集群写入权限后，可通过 `tmq_write_raw` 写入伪造的虚拟表 DDL 消息，干扰数据迁移结果。
  - 虚拟表 Schema 信息未授权读取：若订阅权限配置不当，表结构信息可能被低权限用户获取。
- **结论：** 该功能为现有 TMQ 订阅框架的低影响扩展，攻击面新增有限。现有 TDengine 认证与权限体系能够有效覆盖主要威胁，无需额外安全机制，可正常进入开发阶段。

### 4. 威胁识别与分析（STRIDE）

本功能在现有 TMQ 订阅框架基础上扩展，引入虚拟表 meta 数据流（SVCreateStbReq / SVAlterTbReq 编码消息）及跨集群写入（`tmq_write_raw`）两个关键交互路径。

#### 4.1 关键实体与数据

| 实体/数据 | 描述 | 敏感性 |
| --- | --- | --- |
| 虚拟表 Meta 消息 | SVCreateStbReq / SVAlterTbReq 等结构的二进制编码，描述虚拟超级表和子表的结构定义 | 中（含表名、列名、类型、ref DB 信息） |
| TMQ Consumer 连接 | 客户端与 TDengine Server 之间的订阅连接 | 中 |
| tmqWriteRefDB 参数 | 替换 meta 中 ref DB 名称的配置字符串 | 低 |
| 目标集群写入接口 | `tmq_write_raw` 调用的目标集群写入 API | 中 |

#### 4.2 威胁评估

| 威胁ID | **威胁描述/攻击场景** | **STRIDE** | **相关组件/数据流** | **风险等级** |
| --- | --- | --- | --- | --- |
| T-VTMETA-01 | **Schema 信息未授权读取：** 若目标库的 TMQ 订阅权限配置不当（如误授予低权限用户 subscribe 权限），攻击者可通过订阅虚拟超级表获取数据库 schema 结构（表名、列名、类型）及 ref DB 关系，泄露内部数据架构设计信息。 | I（信息泄露） | TMQ Consumer → TDengine Server | 低 |
| T-VTMETA-02 | **跨集群 Meta 伪造写入：** 攻击者获取目标集群的写入凭证后，通过 `tmq_write_raw` 接口直接写入伪造的 SVCreateStbReq / SVAlterTbReq 消息，在目标集群上创建或篡改虚拟表定义，干扰数据迁移结果或业务使用。 | T（篡改）、S（仿冒） | tmq_write_raw → 目标集群 | 中 |
| T-VTMETA-03 | **Meta 订阅资源耗尽：** 恶意 Consumer 对某一数据库发起持续、大量的 meta 订阅轮询，迫使服务器频繁序列化虚拟表 meta 消息，消耗 CPU 和 I/O 资源，影响其他正常业务。 | D（拒绝服务） | TMQ Consumer → TDengine Server | 低 |
| T-VTMETA-04 | **tmqWriteRefDB 参数配置误用：** 若 `tmqWriteRefDB` 参数配置了无效或错误的数据库名，在迁移写入时会将 ref DB 替换为该值，导致虚拟表的 ref 引用指向无效数据库，后续查询 ref 列均返回 NULL。此为配置误用风险，不引发安全事件。 | T（篡改，配置误用） | tmqWriteRefDB → tmq_write_raw | 低 |

### 5. 安全需求与设计约束

| 威胁ID | **转化后的安全需求/设计约束** | **类型** | **优先级** |
| --- | --- | --- | --- |
| T-VTMETA-01 | SEC-VTMETA-001（权限最小化）：订阅虚拟超级表 meta 的权限应严格遵循现有 TDengine subscribe 权限模型，确保未授权用户无法通过 TMQ 接口绕过数据库访问控制获取 schema 信息。 | 安全设计约束 | 低 |
| T-VTMETA-02 | SEC-VTMETA-002（目标集群写入鉴权）：`tmq_write_raw` 写入目标集群时，需使用具有对应数据库写权限的凭证；目标集群侧应对该操作执行正常的 DDL 权限校验，防止低权限凭证创建或篡改虚拟表定义。 | 安全设计约束 | 中 |
| T-VTMETA-03 | SEC-VTMETA-003（TMQ 消费速率限制）：可依赖现有 TDengine TMQ 连接管理和流控机制限制单 Consumer 的轮询频率，无需针对本功能新增专项限流。 | 非功能安全需求 | 低 |
