# TS-4724 多级存储数据迁移阻塞读写 测试报告

## 1. 测试目标

验证关于多级存储数据迁移引起的高磁盘IO导致读写阻塞问题的修复

## 2. 变更历史

| 2024/06/21 | 0.2 | Astro | 使用 TDinternal 源码编译重新测试 |

## 3. 测试结论

从测试结果来看，trim database 会对磁盘IO和写入性能造成影响：
1. 没有执行 trim database 时，taosBenchmark 写入性能 353793 rows/s
2. 当执行trim database，且retentionSpeedLimitMB=0 即没有限制时，磁盘写入速率最大可达 600MB/s，大部分时间在 100-300M/s左右波动，taosBenchmark 写入性能平均为240050 rows/s，写入性能下降32%
3. 当执行trim database，且 retentionSpeedLimitMB=50时，磁盘写入速率最高80M/s，大部分时间在40-60M/s左右波动，taosBenchmark 写入性能平均为293956rows/s，写入性能下降 16%
由此可见，retentionSpeedLimitMB 参数确实生效并限制了 trim database 对磁盘写入的速度，测试通过

## 6. 测试范围及方法

### 6.1 测试范围：

TDengine 企业版，多级存储，数据插入和查询

### 6.2 测试方法：

1. database 的三级保留参数KEEP为 30天，60天，90天，DURATION 设置为 10天。
2. 先只配置一块 0 级盘，写入大量30天前和60天前的数据。写完后停服。
3. 多配置一块1级盘和一块2级盘，配置完成后启动服务。
4. 运行 trim database 命令，触发数据文件的迁移，并观察写入性能及磁盘IO
分别配置 retentionSpeedLimitMB 为 0 和 50 M，观察文件迁移速度及对写入和查询性能变化的影响。
