## 6. 测试范围及方法

测试方法：
通过多线程方式模拟10个客户端数据写入，5个为指定列写入、5个非指定列写入，用单独的线程修改超级表（普通表）schema，协同管理数据写入与修改schema状态来判断每个测试用例成功或失败。
测试范围：
主要是多客户端数据写入，同步修改数据库表的元数据，重点验证如下场景：
- 指定列/非指定列写入无影响
   - 超级表增加、删除标签
   - 子表修改标签值
   - 超级表（普通表）修改列、标签宽度
- 指定列写入无影响，非指定列写入报错
   - 超级表（普通表）增加列
- 指定列写入报错，非指定列写入无影响
   - 超级表（普通表）修改列名
- 指定列/非指定列写入报错
   - 超级表（普通表）删除写入列
- ~~多客户端数据写入超级表（普通表），增加、修改超级表列、标签，指定列写入不受影响；修改列名、标签名，指定列写入报错~~
- ~~多客户端数据写入超级表（普通表），增加、修改超级表列、标签，~~~~非指定列写入报错~~
- ~~多客户端数据写入超级表（普通表），删除超级表列、标签，指定列/非指定列写入报错~~
