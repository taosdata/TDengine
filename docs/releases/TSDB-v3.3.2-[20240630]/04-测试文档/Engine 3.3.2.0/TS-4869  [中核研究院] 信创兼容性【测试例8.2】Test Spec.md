## 8. 测试备忘 

环境配置：
1. 配置git环境并下载TDinternal 3.0分之最新代码
Git https配置方法可参考：https://jira.taosdata.com:18090/pages/viewpage.action?pageId=224625463
1. 安装依赖库
  ```plaintext
  yum install -y zlib-devel zlib-static xz-devel snappy-devel jansson jansson-devel pkgconfig libatomic libatomic-static libstdc++-static openssl-devel go cargo
  yum install perl-IPC-Cmd rust go
  ```

d. 本地命令编译：在TDinternal的debug目录下执行“cmake .. -DBUILD_HTTP=false -DBUILD_TOOLS=true -DBUILD_TEST=true -DWEBSOCKET=false -DTOOLS_BUILD_TYPE=Debug -DBUILD_TAOSX=false -DJEMALLOC_ENABLED=0 -DBUILD_CONTRIB=1 && make -j 20”，保证本地编译正常
e. 安装python3.9以及依赖库
```sql
yum install python39
pip3.9 install fabric2 toml distro psutil pandas faker pexpect bs4 numpy taos taospy taos-ws-py
```
