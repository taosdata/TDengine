## 5. 测试数据

**schema：**

|  | **name** | **type** | **count** | **values** |
| --- | --- | --- | --- | --- |
| **tag** | location | BINARY | 1 | [str1, str2, ......, str10] |
| current | FLOAT | 1 | "max": 12, "min": 8 |
| voltage | int | 1 | "max": 225, "min": 215 |
| phase | FLOAT | 1 | "max": 1, "min": 0 |

**建流 SQL：**
create stream if not exists test_stream trigger at_once ignore update 0 ignore expired 0 fill_history 1 into test2.stream_tb tags(loc binary(16)) as select _wstart, last(current) as last_current,last(voltage) as last_voltage,last(phase) as last_phase from test1.meters partition by location as loc interval(60s)

### 7.3 运行示例

python3 data_migration.py -h localhost -p 6030 -t 10000 -n 100000 -v 10 -r 10000 -T 40 -s 60000
说明：
taosBenchmark 连接 localhost:6030，写入 10000 * 100000 条数据，batch 为 10000，线程为 40，每条数据时间间隔 1分钟，那么如果建流语句要求以 60s 降采样 partition by 10 个 tag，那么最终流的结果应有 100W 个窗口。
