# OPC 查看和动态调整点位列表 Test Spec

## 1. 测试目标

- 确保 OPC 动态调整点位功能的引入不会影响之前的功能
- 验证 taosx 对于创建的 OPC 任务能够查看上传的点位列表
- 验证 taosx 支持创建动态调整点位的 OPC 任务

## 3. 测试范围

这里用于描述本需求的覆盖范围：
- OPC UA/DA 使用文件上传创建采集任务之后可以查看这些文件中的点位
- 可以创建支持动态新增点位的 OPC 任务

## 4. 测试结论

测试过程中涉及到 OPC UA 及  OPC DA 的功能：
- OPC 任务上传 CSV 文件之后支持查看 CSV 文件中的点位信息，页面上依据 ID、name、enable 进行筛选。验证通过。
- 创建的 OPC UA 选择数据点位的任务，支持设置点位更新方式为 Append 或 Update，筛选条件支持根结点、命名空间、点位名称正则。在服务端新增或删除点位之后，经过至多一个点位更新周期，新增或删除的点位会更新到 OPC 连接器使用的配置文件中，数据会开始或停止采集。验证通过。
- 创建的 OPC DA 选择数据点位的任务，支持设置点位更新方式为 Append 或 Update，筛选条件支持根结点、点位名称正则。在服务端新增或删除点位之后，经过至多一个点位更新周期，新增或删除的点位会更新到 OPC 连接器使用的配置文件中，数据会开始或停止采集。验证通过。
- 单个 OPC UA 任务支持一万点位每秒的数据写入速率。验证通过。
