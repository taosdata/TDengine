# 产品会议 20240530

## 1. 发版机制简介

1. 周期：两个月（发布时间：双月月底）
2. 内容：引擎（taosd），客户端（taosc），工具 （taosBenchmark, taosdump），REST/WS 服务（taosAdapter），taosX（含附带连接器），taos-Explorer， taosKeeper, TDinsight
3. 范围：按照版本规划确定的功能列表
4. 平台：
   - 企业版：Linux/x64, Linux/ARM64，Windows/x64
   - 社区版：
      - Server：Linux/x64，Linux/ARM64，macOS(x64, ARM64); 
      - Client：Linux/x64, Linux/ARM64, Windows/X64, macOS(x64, ARM64)

## 2. 版本发布序列

在 3.2.2.0 以前 TDengine 版本和 taosX 版本没有对应关系，taosX 独立发版，其版本号从 1.0.0 到 1.3.0，但其可以与 3.x 的各版本引擎共同工作。 
在 3.2.2.0 (含） 及以后，taosX 不再独立发版，改为与引擎在同一安装包中发布，其版本对应关系和 TDengine 发版时间如下表：

| TDengine 版本 | taosX 内部版本 | 发布时间 |
| --- | --- | --- |
| 3.2.2.0 | 1.4.0 | 2023/12/31 |
| 3.2.3.0 | 1.5.0 | 2024/2/29 |
| **3.3.0.0** | 1.6.0 | 2024/4/30 |
| 3.3.1.0 （暂定） | 1.7.0 | 2024/6/30 |
| 3.3.2.0 （暂定） | 1.8.0 | 2024/8/31 |
