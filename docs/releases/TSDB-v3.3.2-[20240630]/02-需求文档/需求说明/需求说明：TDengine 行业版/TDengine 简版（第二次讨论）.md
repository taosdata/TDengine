# TDengine 简版（第二次讨论）

#### 1. **为什么要做行业版**

1. 以较低的价格
2. 大量出货
3. 快速占据市场

#### 2. **占据什么样的市场**

1. 低价市场
   - 电力行业：数据中心可以承受高价，电厂、风厂的集控软件可承受价格较低
   - 储能行业：数据中心可以承受高价，储能箱的 EMS 软件可承受价格较低
   - 金融行业：券商、运营商可以承受高价，但散户可承受价格较低
2. 有普适需求的市场
   - 替换实时库：与亚控、麦杰竞争
   - 替换 SCADA 的历史库：与达梦、MySQL 的历史库功能竞争

#### 3. 如何能低价

1. 不与已经售卖的，功能、点数要求较少的高价客户产生冲突，典型的是烟草行业
2. 对低价市场进行调研，仅保留必须的功能，其他功能大量裁剪（即便已经在社区版）
3. 不追求为特定行业开发特定功能，这是为了提价而不是降价
