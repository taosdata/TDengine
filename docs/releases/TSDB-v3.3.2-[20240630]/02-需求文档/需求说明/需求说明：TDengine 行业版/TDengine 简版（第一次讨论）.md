# TDengine 简版（第一次讨论）

## 1. 需求目标

为了覆盖低成本客户群，考虑裁剪一个最简单的时序数据库，只保留基础功能，去除流计算、数据订阅、UDF 等普通用户不需要的功能，让安装包变的只有一半大小。主要目的是简化一切过程，降低成本，反向选择出一批客户，这样的客户群有如下特征。

| 序号 | 特征 | 说明 |
| --- | --- | --- |
| 1 | 预算较少 | 通常在 5 万以内 |
| 2 | 私有化部署需求 |  |
| 3 | 单节点 | 不确定，有可能需要支持主备、双副本、三副本 |
| 4 | 测点较少 | 通常在 5000 点以内 |
| 5 | 数据量较少 | 通常在 1 亿条记录以内 |
| 6 | 客户有一定的 IT 能力 | 可以自己安装、运维 |
| 7 | 一次性出售软件授权 | 一次性收款 |

这类客户不应显著增加销售成本，可采取不同的销售策略
- 依靠市场部和分销商售卖，销售部不卖这个版本
- 固定合同范本
- 只提供远程支持，上门支持按小时收费
