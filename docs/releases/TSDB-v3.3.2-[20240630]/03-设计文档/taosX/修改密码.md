# 修改密码

## 1. 背景

通常，对安全有要求的用户（含企业版和社区版用户），都需要修改 TDengine 的 root 密码。当用户修改 root 密码后，对 taosx 可能造成以下问题：
1. “数据写入/数据源”标签，“运行中”的 DataIn 任务，报错，Authentication failure。
2. “数据写入/数据源”标签，“已停止”的 DataIn 任务，无法启动，报错：Authentication failure。
3. “系统管理/备份”任务无法启动，报错：Authentication failure。
4. “系统管理/数据同步”任务，报错：Authentication failure。
这个 FS 的目标是：
1. 提供一个通过 taosX + explorer 修改 TDengine 密码的流程；
2. 提供文档，用户可以按照流程修改密码；
3. 按照流程，解决修改密码过程遇到的 taosX 的问题，包括上面提到的所有问题，保证 taosX 在修改密码后可以正常运行。

TD-29214

## 4. 行为说明

目前，修改密码有 3 种方式：
1. 用户登录 taos Shell，执行`alter user USERNAME pass NEW_PASS`修改密码；
2. 用户登录 explorer，右上角的修改密码中修改当前用户的密码，包括 root 用户；
3. root 登录 explorer，在“系统管理/用户”标签中，只能修改普通用户的密码。

### 4.1 修改密码的流程

#### 4.1.1 修改当前用户密码

通过“修改密码”，修改当前用户的密码，流程如下：
1. 在 explorer 登录；选择右上角的“**修改密码” **； 填写合法的旧密码、新密码、确认密码；
2. 修改密码成功后，如果当前用户是 root，应该提示检查 taosadapter 等其他组件的密码需要修改，且要重新登录 explorer；如果当前用户非 root，提示重新登录；
3. （可选）如果修改了 root 密码且启用了 taosadapter，必须修改 taosadapter 的配置文件（/etc/taos/taosadapter.toml），修改所有 password 部分，重启 taosadapter；
4. （可选）如果修改了 root 密码且启用了 taoskeeper，必须修改 taoskeeper 的配置文件（/etc/taos/taoskeeper.tom），修改所有 password 部分，重启 taoskeeper；

#### 4.1.2 root 修改普通用户密码

root 用户可以通过“系统管理/用户”可以修改普通用户的密码，流程如下：
1. 在 explorer 使用 root 登录，选择“**系统管理”**的“用户”标签；
2. 选择用户，点击修改，输入合法的新密码，保存；

### 4.2 修改密码对 Data In 任务的影响

无论采用何种方式修改密码，如果 Data In 任务使用用户名/密码进行认证，则都需要用户停止任务、手动修改配置、并重启任务。

### 4.3 采用 Token 进行认证 （TODO)

如果 Explorer 登录界面或 Data In 任务使用用户名/密码进行身份认证，则修改密码必然会带来明显影响。为彻底解决修改密码带来的用户体验问题，需要将 Explorer/Data In 的认证方式与密码解耦。方案如下表中的方案 1 ，其详细行为待定。

| **编号** | **方案** | **描述** | **优点** | **缺点** |
| --- | --- | --- | --- | --- |
| 1 | taosd 支持 token 鉴权 | taosd 支持使用 token 方式鉴权。 1. 用户在登录时使用 username 和 password 登录，发起鉴权请求；taosd 根据 username 和 password 生成 token； 1. taosX 和 explorer 的 API 均使用 token，不在 DataIn 任务中存储 user 和 password。 1. 用户通过任何方式修改了 password，token 不会失效。 |
| 2 | taosX 做用户和权限管理 | taosX 在内部基于 TDengine 的认证和授权，实现 RBAC （基于角色的访问控制）。这种方式和云服务的方式类似： 1. 用户系统初始化时，创建虚拟 root 用户，之后创建的任何用户名和密码都由 taosX 维护。 1. 用户创建 DataIn 任务时，用的是虚拟 root 的用户名和密码，用户不能修改虚拟 root 的密码； |
| 3 | taosX 批量修改密码 | taosX 提供一个接口，explorer 在修改密码时，调用这个接口，将用户和密码相关的 DataIn 任务都更新为新密码。 | 1. 开发量最小 | 1. 不能覆盖使用 alter user 修改密码的使用场景； 1. “运行中”的 DataIn 任务需要重启； 1. 如果使用了方案1/2，则方案3还需要返工。 |

## 10. 使用场景

### 10.1 修改 root 密码

按照 4.1.1 节中的流程，修改 root 密码，taosX 的功能正常运行。

### 10.2 修改普通用户密码

按照 4.1.1 节中的流程，修改普通用户密码，taosX 的功能正常运行。

### 10.3 root 修改普通用户密码

按照 4.1.2 节中的流程，root 修改普通用户密码，taosX 的功能正常运行。

### 10.4 通过 taos Shell 修改 root 密码

当通过 taos Shell 修改了 root 密码后，taosX 中的 DataIn 任务还在使用旧密码，taosX 的功能正常运行。

### 10.5 通过“数据浏览器”修改密码

和 taos Shell 同理，通过 explorer 的“数据浏览器”也可以执行 alter user 语句修改密码。

## 11. 约束和限制

1. 当通过 explorer 修改 root 密码时，要求包含大小写字母、数字、特殊字符，且 8～16 位；修改后，不能通过 explorer 改回默认密码 taosdata。保留这个限制，即：**强密码不能改为弱密码**。

## 16. 附录 1 ：用户名和密码的规则

TDengine 用户名的规则如下：
1. 最大长度为 23 个字节；
2. 符合 TDengine 命名规范的字符串，即：英文字符、数字和下划线，不允许以数字开头，不区分大小写；
3. 如果使用```转义用户名，除了`.`不能使用，其他任何字符都可以使用。
<callout emoji="exclamation" background-color="light-orange" border-color="light-orange">
如果使用转义，中文用户名，最大长度是 7 个字符，例如：
create user `一二三四五六七` pass 'taosdata'
</callout>

TDengine 密码的规则如下：
1. 最大长度为 31 个字节；
2. 合法的字符包括：`a-zA-Z0-9!?$%^&*()_–+={[}]:;@~#|<,>.?/`；
3. 如果使用```转义密码，除了`.`不能使用，其他任何字符都可以使用。
<callout emoji="exclamation" background-color="light-orange" border-color="light-orange">
如果使用转义，中英文密码，最大长度是 29 个字节，例如：
create user `一二三四五六七` pass 'taosdata'
</callout>
