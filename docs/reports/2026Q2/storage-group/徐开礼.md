该类事务大致特点如下：
- 2.
- 1）txnId 最高位标记为
- 1，与目标集群的事务进行区分；
- 2.
- 2）txnId 从源集群带过来，不需要新建；
- 2.
- 3）如果 mnode 没有对应的事务，需要先构建，如果 vnode 没有对应的事务索引，需要先构建；
- 2.
- 4）由于 tmq 只订阅 vnode 端的 wal + snapshot，没有 mnode 端的 wal，因此，需要将 vnode 端的 commit/rollback 消息转换为发向 mnode 的 commit/rollback 消息，重复消息支持幂等；
- 2.
- 5）目标集群，同步过来的事务，DDL 操作出错不影响事务 commit;
- 2.
- 6) 目标集群，同步过来的事务不需要超时回滚机制；
commit/rollback 完全依赖源集群。
基于上述逻辑，由 Claude 进行实现并添加测试用例。
