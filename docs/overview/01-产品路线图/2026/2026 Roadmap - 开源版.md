# 2026 Roadmap - 开源版

| 季度 | 功能 |
| --- | --- |
| 2026Q1 | - 存储：批量标签修改、动态调整数据缓存的 LRU <br> - 查询：子查询、外部窗口、ANY/SOME/ALL/EXISTS 运算符、窗口及插值增强、Explain 和 ShowQueries 优化 <br> - 虚拟表：虚拟表支持引用虚拟表、虚拟表查询性能优化、订阅虚拟表的元数据变更 <br> - 流计算：按自然周/月/季/年触发、事件触发条件优化、分组计算性能优化、虚拟超级表触发支持子表增删改 |
| 2026Q2 | - 存储：多副本切主和节点恢复优化、数据缓存优化（如强制刷新、多列写入优化、指定列缓存） <br> - 查询：关联查询，放宽窗口查询限制、时间窗口支持周/月/季/年、Interp 性能提升 <br> - 函数：窗口函数及 OVER 字句 <br> - 虚拟表：支持虚拟表继承、虚拟超级表列名修改 <br> - 流计算：多个客户场景性能优化、多测点场景性能优化、历史计算性能优化、虚拟表触发性能优化 <br> - 其他：TDgpt 预测性维护、分钟级时区 |
| 2026Q3 | - 存储：提升数据拆分和移动的性能、数据重整不影响写入、磁盘限速 <br> - 查询：复杂查询性能优化、标量相关子查询、累计窗口、关联查询进一步增强、SQL 测试工具 <br> - 函数：15 个客户需要的函数 <br> - 虚拟表：通过连续查询订阅虚拟表数据 <br> - 流计算：可维护性提升 <br> - 其他：TDgpt 支持 PCA、PLS、聚类分析 |
| 2026Q4 | - 存储：TEXT 数据类型、不定长字符串数据类型、库名修改、列名修改 <br> - 查询：查询并行化、增加可观测指标 <br> - 函数：支持 MySQL 运算符及函数、UDF 函数框架重构 <br> - 其他：引擎的 CPU 和内存管控 |
