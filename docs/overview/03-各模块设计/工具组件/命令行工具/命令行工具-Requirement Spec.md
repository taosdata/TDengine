## 2. 引言

由于以下原因，TDengine 需要一款能够连接、执行 SQL 命令和管理 TDengine 的客户端命令行工具。
1. TDengine 常部署在无图形界面的服务器 / 容器环境中，命令行工具是无依赖的原生访问入口，适配各类部署场景；
2. 方便通过命令行实现脚本化，契合 TDengine 高效运维的需求；
3. 命令行直连内核，能执行图形化工具未封装的底层配置、故障排查，是生产环境应急运维的可靠手段。

### 2.1 术语与缩写名词

**TDengine TSDB CLI****：**TDengine 客户端命令行接口程序
**命令行参数** ：指通过命令行输入的长参及短参
**TDengine Cloud **：全托管的物联网、工业大数据云服务平台
**TAB  补全 **:  指通过在指定位置按下 TAB 键，自动匹配输入可能出现的命令行、关键词等自动化填写技术

### 2.2 相关文档资料

本工具基于 TDengine 数据库开发，涉及  TDengine 相关资料请参考：https://docs.taosdata.com/

### 2.3 优先级要求

本工具需随 TDengine 3.0 产品一起发布，节奏要与 TDengine 3.0 开发一致

### 2.4 版本要求

与 TDengine 3.0 版本一致

## 3. 需求目标

为用户提供一款通过命令行连接 TDengine 服务的客户端工具，能够实现：
1. 提供连接 TDengine 服务器，包括原生和 WebSocket 连接方式。能连接云服务。
2. 提供执行 SQL 命令
3. 提供显示查询数据集
4. 提供数据导入导出功能，包括：
   - 导出查询结果到某个 CSV 文件中
   - 将 CSV 文件中数据导入到某个表中
5. 提供灵活显示选项
6. 提供辅助输入，包括 tab 键补全，历史命令查看等。

## 6. 安全需求

为确保数据的机密性、完整性与可用性，需落实以下需求（参照 TM-TSDB-CLI-001）：
- 凭据保护（T-CLI-01）：密码/DSN token 不得以明文出现在命令行回显、历史和日志；支持交互/环境变量获取；展示时掩码；翻看命令历史记录功能中不提供带密码的命令回翻。
- 传输加固（T-CLI-02）：支持启用 TLS，建议生产系统强制使用 TLS 传输加密并记录配置。
- 路径与权限校验（T-CLI-03）：导入/导出、日志路径需在允许目录内，拒绝路径穿越和覆盖敏感文件。
- 输入校验与注入防护（T-CLI-04）：命令行/文件 SQL 做格式校验；拒绝空密码远程连接；导入/文件执行配置行数与大小上限。
- 补全缓存控制（T-CLI-05）：TAB 补全缓存设上限，输出不泄露敏感元数据。
- 速率与配额（T-CLI-06）：网络检测与批量执行需限频/限并发，长耗时可中断；必要时二次确认。
- 日志脱敏（T-CLI-07）：默认最小化日志；token 仅显示部分；错误/调试日志不含完整路径与凭据。
- 审计可追溯（T-CLI-08）：连接/执行生成请求 ID，关键操作可选审计日志并与引擎日志关联。

## 7. 其他需求

描述功能、性能之外的需求。
- 兼容性需求
接口兼容：支持原命令行
- 接口需求
全部为命令行接口实现
- 运维需求
长时间运行不能有内存泄露
- 易用性需求
命令行参数命名要简洁、表意
- 测试需求（不含测试例）
   对主要功能都需要有测试用例覆盖
   能够提供调试模式方便查找问题
