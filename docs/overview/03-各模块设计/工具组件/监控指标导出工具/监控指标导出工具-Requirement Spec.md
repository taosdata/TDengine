## 2. 引言

taosKeeper 是 TDengine 3.0 版本中新增的监控指标导出工具，旨在方便用户对 TDengine 的运行状态和性能指标进行实时监控。通过简单的配置，TDengine 能够将其运行状态、指标等信息上报给 taosKeeper。当接收到监控数据后，taosKeeper 会利用 taosAdapter 提供的 RESTful 接口，将这些数据存储到 TDengine 中。
taosKeeper 的一个重要价值在于，它能够将多个甚至一批 TDengine 集群的监控数据集中存储在一个统一的平台上。这使得监控软件能够轻松获取这些数据，从而实现对 TDengine 集群的全面监控和实时分析。通过 taosKeeper，用户可以更加便捷地掌握 TDengine 的运行状况，及时发现并解决潜在问题，确保系统的稳定性和高效性。

### 2.1 术语与缩写名词

1. **TDengine**：一个高性能、分布式的时序数据库。
2. **taosd**：TDengine 数据库引擎的核心服务。
3. **taosAdapter**：一个 TDengine 的配套工具，是 TDengine 集群和应用程序之间的桥梁和适配器。
4. **taosX**：TDengine Enterprise 的数据管道功能组件，旨在为用户提供一种无需编写代码即可轻松对接第三方数据源的方法，实现数据的便捷导入。

## 3. 需求目标

设计并开发一款轻量级监控指标导出工具 taosKeeper，目标包括：
1. 实时监控 taosd、taosAdapter、taosX 和 taosExplorer 的运行状态和性能指标。
2. 收集系统性能指标。
3. 记录慢查询。
4. 提供监控数据存储和查询接口。

## 4. 功能需求

| 序号 | **功能类别** | **功能名称** | 功能描述 |
| --- | --- | --- | --- |
| 1 | 监控 | 状态监控 | 实时监控 taosd、taosAdapter、taosX 和 taosExplorer 的运行状态和性能指标。 |
| 2 | 监控 | 系统指标采集 | 收集 CPU、内存等系统指标。 |
| 3 | 监控 | 慢查询记录 | 记录执行时间超过阈值的 SQL 语句。 |
| 4 | 存储 | 数据持久化 | 将监控数据存入 TDengine 数据库。 |
| 5 | 接口 | REST API | 提供 HTTP 接口存储和查询监控数据。 |

无。

## 6. 其他需求

- 兼容性需求
   - 版本兼容：支持 TDengine 3.3.0.0 及以上版本。
   - 操作系统支持：
      - 支持常见 Linux 发行版（如 CentOS、Ubuntu）。
      - 支持 Windows 平台（Windows 10 或 Server 2016 及以上版本）。
      - 支持 MacOS 平台（macOS 10.15 Catalina 及以上版本）。
- 接口需求
  提供标准化的 RESTful 接口，确保易于集成与扩展。
- 运维需求
   - 日志记录：提供详细的日志记录，支持不同日志级别的配置，以便于问题排查和监控。
   - 多实例支持：支持多实例部署，满足不同规模的运维需求。
- 易用性需求
  接口返回应包含详细的错误信息，便于用户快速定位并解决问题。
- 测试需求
  对所有主要功能进行单元测试，确保系统的稳定性和可靠性。
