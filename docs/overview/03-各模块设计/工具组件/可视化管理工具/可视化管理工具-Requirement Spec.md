## 2. **引言**

### 2.1 **术语与缩写名词**

1. **taos****Explorer**：TDengine 数据库的 Web 管理工具，提供可视化的数据库管理、数据浏览、任务管理等功能
2. **taosX**：TDengine 数据接入和同步工具套件
3. **TSDB**：Time Series Database（时序数据库），此处特指 TDengine
4. **SSO**：Single Sign-On（单点登录）
5. **OAuth 2.0/OIDC**：开放授权协议及 OpenID Connect 身份层
6. **IdP**：Identity Provider（身份提供商）
7. **OPC UA/DA**：工业自动化通信协议
8. **MQTT**：消息队列遥测传输协议
9. **PI**：OSIsoft PI 工业数据平台

### 2.2 **相关文档资料**

- TDengine 官方文档
- taosX 产品文档

### 2.3 **优先级要求**

- 核心功能（数据浏览、用户管理、任务管理）：P0 - 必须实现
- 数据接入功能：P0 - 必须实现

- OAuth/SSO 功能：P1 - 重要
- 流计算和数据订阅：P1 - 重要

### 2.4 **版本要求**

- 社区版：提供基础的数据浏览、编程接口示例、基本管理功能
- 企业版：提供完整的集群管理、数据接入、备份恢复、OAuth/SSO、审计日志等功能
- 云服务版：集成云平台特性，提供多租户支持

## 3. **需求目标**

### 3.1 **背景**

TDengine Explorer 是 TDengine 数据库的 Web 管理工具，作为 taosX 产品套件的重要组成部分。随着 TDengine 在物联网、工业互联网、车联网等领域的广泛应用，用户需要一个直观、易用的 Web 界面来管理数据库、浏览数据、配置数据接入任务、监控系统状态。
当前挑战：
- 需要支持多种工业协议和数据源的接入配置
- 需要提供企业级的用户管理和权限控制
- 需要支持大规模集群的管理和监控
- 需要与企业现有的身份认证系统集成（SSO）

### 3.2 **目标**

1. **易用性**：提供直观的 Web 界面，降低 TDengine 使用门槛
2. **数据接入**：支持多种工业协议（OPC UA/DA、MQTT、PI、Kafka 等）的可视化配置
3. **数据管理**：提供强大的数据浏览和查询功能
4. **企业级特性**：支持 OAuth/SSO、审计日志、角色权限管理
5. **监控运维**：提供集群监控、慢查询分析、备份恢复等功能
6. **开发友好**：提供编程示例、API 文档、SDK 下载

## 5. **性能需求**

### 5.1 **响应时间**

- 页面加载时间：首次加载 < 5 秒，后续切换 < 1秒
- SQL 查询响应：小规模查询（< 1万条记录）< 1秒
- 数据浏览器操作：表/数据库创建/删除 < 2秒
- API 响应：95% 请求 < 500ms

### 5.2 **并发支持**

- 支持同时 100+ 用户在线
- 支持同时运行 50+ 个数据接入任务
- 支持单任务处理 10,000+ 数据点/秒

### 5.3 **资源使用**

- 内存使用：基础运行 < 512MB，正常负载 < 2GB
- CPU 使用：空闲时 < 5%，正常负载 < 50%
- 网络带宽：支持每秒数千次 API 请求

### 5.4 **数据规模**

- 支持管理 100+ 个数据库
- 支持每个数据库 10,000+ 张表
- 支持查询结果集 100,000+ 条记录（分页加载）

## 6. **安全需求**

### 6.1 **认证与授权**

- 支持本地用户名/密码认证
- 支持 OAuth 2.0/OIDC 单点登录
- 支持基于角色的访问控制（RBAC）
- 支持会话管理和超时退出
- 密码必须加密存储（AES-256-GCM）

### 6.2 **数据安全**

- HTTPS 强制加密传输（生产环境）
- 敏感配置加密存储（数据库密码、OAuth token 等）
- SQL 注入防护
- XSS 攻击防护（CSP、输入过滤）
- CSRF 攻击防护（Token 验证）

### 6.3 **审计日志**

- 记录用户登录/登出操作
- 记录敏感操作（创建/删除用户、修改权限、删除数据库等）
- 审计日志不可由普通用户删除或修改

### 6.4 **安全配置**

- 支持配置密码复杂度策略
- 支持登录失败锁定机制
- 支持 IP 白名单/黑名单
- 支持会话超时配置
