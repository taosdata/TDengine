## 2. **测试目标**

1. 功能测试：验证 Node.js 连接器所有功能接口的正确性，包括连接管理、SQL 执行、无模式写入、参数绑定、数据订阅等核心功能。
2. 性能测试：评估连接器在高并发、大数据量场景下的性能表现，包括响应时间、吞吐量、资源消耗等。
3. 安全性测试：确保连接器满足安全需求，包括凭证脱敏、传输加密、资源管理、认证授权等。
4. 稳定性测试：验证连接器在长时间运行、异常情况下的稳定性和可靠性，包括连接池管理、错误恢复、内存管理等。
5. 兼容性测试：验证连接器在不同 Node.js 版本、TDengine 版本、浏览器环境下的兼容性。

## 3. **测试范围**

1. 功能测试：
  - 连接功能：建立连接、连接池管理、SSL 连接、云服务 token 连接
  - 执行 SQL：建库建表、插入数据、查询数据、执行带有 reqId 的 SQL
  - 无模式写入：三种行协议（InfluxDB 行协议、OpenTSDB telnet 行协议、OpenTSDB JSON 格式协议）
  - 结果获取：获取结果集数据和元数据
  - 参数绑定：参数绑定写入、自动建表、批量提交
  - 数据订阅：创建消费者、订阅主题、轮询消息、提交 Offset、取消订阅、关闭消费
1. 性能测试：
  - 连接建立和销毁性能
  - SQL 查询和写入性能
  - 批量数据插入性能
  - 数据订阅吞吐量
1. 安全性测试：
  - 凭证脱敏验证
  - TLS/SSL 连接测试
  - 会话超时测试
  - 认证失败处理测试
  - SQL 注入防护测试
1. 稳定性测试：
  - 长时间运行测试
  - 连接池压力测试
  - 网络异常恢复测试
  - 内存泄漏检测
1. 兼容性测试：
  - Node.js 14.x.x 及以上版本兼容性
  - TDengine 3.3.2.0 及以上版本兼容性
  - 浏览器 ES2020 兼容性

## 5. **已知问题和限制**

1. 假设 taosAdapter 和 TDengine 实例已正确配置并能够稳定运行。
2. Node.js 应用系统运行在高可靠性的网络环境中。
3. 支持 TDengine 3.3.2.0 及以上版本。
4. 支持 Node.js 14.x.x 及以上版本。
5. 浏览器支持 ES2020。
6. 由于查询结果大时在内存缓存，可能占用较多内存。
7. 客户端创建连接过多时，频繁创建和释放可能影响性能。

## 9. **风险评估**

1. 测试环境依赖 TDengine 和 taosAdapter，环境不稳定可能影响测试进度。
2. 性能测试需要模拟高负载场景，可能对生产环境造成影响，需在隔离环境进行。
3. 浏览器兼容性测试需要多浏览器环境，可能增加测试复杂度。
4. 安全性测试涉及加密和认证，需要专业安全测试知识。
