## 2. 引言

在当今物联网和工业互联网快速发展的背景下，大量设备产生的时序数据需要高效的存储和实时分析解决方案。TDengine 作为一款专为物联网、车联网等场景设计的时序数据库，已广泛应用于各行各业。然而，随着 Rust 编程语言在系统编程和高性能应用开发中的流行，Rust 社区对与 TDengine 数据库交互的需求也日益增长。
Rust 以其内存安全、高性能和零运行时开销的特点受到开发者的青睐，特别适用于对性能和可靠性要求极高的场景。为了满足 Rust 开发者与 TDengine 交互的需求，设计并实现一个功能强大的 Rust 连接器显得尤为重要。

### 2.1 术语与缩写名词

1. **TDengine**：一个高性能、分布式的时序数据库。
2. **参数绑定**：通过使用占位符替代具体的值，可防止 SQL 注入并提升查询性能。
3. **数据订阅**：用于实时订阅数据库中的数据变化，客户端可以通过 TMQ 接收增量数据，适用于需要实时监控和数据流处理的场景。
4. **无模式写入**：无模式写入是一种写入机制，在写入数据时无需事先定义表结构，系统会根据数据自动生成或调整表结构。

1. 重要程度：高。

## 3. 需求目标

Rust 连接器旨在为开发者提供高效、简洁且易用的 API 接口，支持 Rust 语言的现代编程风格和生态系统。通过封装 TDengine 的核心功能，Rust 连接器将支持 SQL 执行、参数绑定、无模式写入和数据订阅等关键特性。

## 4. 功能需求

| 序号 | **功能类别** | **功能名称** | 功能描述 |
| --- | --- | --- | --- |
| 1 | 连接功能 | 原生连接 | 通过 TDengine 客户端（libtaos.so 或 taos.dll）与 TDengine 进行交互。 |
| 2 | 连接功能 | WebSocket 连接 | 通过 WebSocket 协议与 taosAdapter 进行交互。 |
| 3 | 数据操作 | 数据写入 | 支持通过 SQL 语句插入数据。 |
| 4 | 数据操作 | 数据查询 | 支持通过 SQL 语句查询数据，提供结果集遍历和列值获取功能。 |
| 5 | 数据操作 | 参数绑定 | 支持单行和多行数据的参数化绑定操作。 |
| 6 | 高级功能 | 无模式写入 | 支持通过 InfluxDB 行协议、OpenTSDB Telnet 协议以及 OpenTSDB JSON 协议进行数据写入。 |
| 7 | 高级功能 | 数据订阅 | 支持通过 TMQ（TDengine 消息队列）订阅数据，实时获取最新写入的数据。 |

## 5. 安全需求

| 序号 | **功能类别** | **功能名称** | 功能描述 |
| --- | --- | --- | --- |
| 凭证脱敏 | 所有连接器必须在日志、错误消息、调试输出中脱敏密码、Token 等敏感凭证信息 |
| 安全存储指导 | 文档必须提供环境变量、密钥管理服务（Vault/Secrets Manager）等安全存储方案，禁止硬编码 |
| 2 | 传输加密 | 支持 TLS/SSL 连接 | 支持 TLS 加密连接 |
| 3 | 资源管理 | 会话超时 | 支持会话超时、连接超时 |
| 4 | 认证授权 | 认证失败处理 | 记录认证失败事件，支持速率限制防止暴力破解 |

## 6. 性能需求

无。

## 7. 其他需求

- 兼容性需求
   - TDengine 版本支持：兼容 TDengine 3.3.0.0 及以上版本。
   - Rust 版本支持：支持 Rust 1.65 及以上版本。
- 接口需求
   - 简洁易用的 API：设计直观、易于理解和使用的 API，降低开发者的学习和使用成本。
   - 多连接方式支持：支持原生连接和 WebSocket 连接两种模式，满足不同部署环境和使用场景的需求。
- 运维需求
  提供详细的日志记录，支持不同日志级别的配置，以便于问题排查和监控。
- 易用性需求
   - 文档和示例：提供详细的文档和示例代码，方便开发者快速上手。
   - 错误信息友好：接口返回应包含详细的错误信息，便于用户快速定位并解决问题。
- 测试需求
  对所有主要功能进行单元测试，确保系统的稳定性和可靠性。
