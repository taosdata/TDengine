## 2. 引言

TDengine 是一款高性能、分布式的时序数据库，专为物联网 (IoT)、工业互联网和 IT 监控等应用场景设计。它提供了高效的数据存储和查询能力，能够处理海量时序数据，同时具备低存储成本和高吞吐能力。
Go 语言因其高效、并发友好的特性，在云计算、微服务和数据处理领域得到了广泛应用。为了更好地支持 Go 开发者访问 TDengine 数据库，提供一个高效、易用的 Go 连接器至关重要。

### 2.1 术语与缩写名词

- **TDengine： **一款高性能、可扩展的时序数据库。
- **Go： **一种开源的编程语言，广泛用于后端开发。
- **RESTful： **一种基于 HTTP 协议的网络应用程序设计风格。
- **WebSocket： **一种在单个 TCP 连接上进行全双工通讯的协议。
- **tmq： **TDengine 消息队列，支持订阅写入的数据。

## 3. 需求目标

随着大数据和物联网技术的不断发展，时序数据库在数据存储和分析方面的优势日益凸显。TDengine 作为一款高性能、可扩展的时序数据库，已经在众多领域得到了广泛应用。然而，对于 Go 语言开发者来说，直接操作 TDengine 数据库存在一定的门槛，需要熟悉 TDengine 的接口和通信协议。
为了满足 Go 语言开发者对 TDengine 数据库的需求，taosdata/driver-go 项目应运而生。该项目通过封装 TDengine 数据库的底层操作，提供了简洁易用的 API 接口，使得 Go 语言开发者能够轻松实现数据库的连接、查询、插入等操作。同时，该项目还支持多种连接方式，包括原生、HTTP 和 WebSocket，可以根据具体的应用场景选择合适的连接方式。

## 4. 功能需求

| 序号 | **功能类别** | **功能名称** | 功能描述 |
| --- | --- | --- | --- |
| 1 | 数据库连接 | 原生连接 | 通过 TDengine 客户端（libtaos.so、taos.dll）与 TDengine 进行交互。 |
| 2 | 数据库连接 | WebSocket 连接 | 通过 WebSocket 协议与 taosAdapter 进行交互。 |
| 3 | 数据库连接 | RESTful 连接 | 通过 HTTP 协议与 taosAdapter 进行交互，支持 SQL 的插入和查询操作。 |
| 4 | 数据操作 | 数据写入 | 支持通过 SQL 语句插入数据。支持原生、WebSocket、RESTful 连接 |
| 5 | 数据操作 | 数据查询 | 支持通过 SQL 语句查询数据，支持结果集的遍历和列值获取。支持原生、WebSocket、RESTful 连接 |
| 6 | 数据操作 | 单行数据绑定 | 支持单行参数绑定写入和查询。支持原生、WebSocket连接 |
| 7 | 数据操作 | 多行数据绑定 | 支持单行参数绑定写入。支持原生、WebSocket连接 |
| 8 | 数据操作 | STMT2 数据绑定 | 支持 STMT2 参数绑定写入和查询。优先实现原生连接 |
| 9 | 高级功能 | schemaless 写入 | 支持通过 InfluxDB 行协议、OpenTSDB telnet 协议和 OpenTSDB JSON 协议写入数据。支持原生、WebSocket连接 |
| 10 | 高级功能 | 订阅功能 | 支持通过 tmq 订阅 TDengine 消息队列，实时获取写入的数据。支持原生、WebSocket连接 |

## 6. 安全需求

### 6.1 认证与授权

| 序号 | 安全类别 | 需求名称 | 需求描述 |
| --- | --- | --- | --- |
| 1 | 身份认证 | 用户名密码认证 | 支持基于用户名和密码的基本身份认证机制，用于原生连接、WebSocket 和 RESTful 连接。 |
| 2 | 身份认证 | Token 认证 | 支持基于 Token 的身份认证机制，用于云服务连接（WebSocket 和 RESTful）。 |
| 3 | 身份认证 | Bearer Token 认证 | 支持 Bearer Token 认证机制，用于 TSDB 企业版鉴权（WebSocket 和 RESTful）。 |
| 4 | 身份认证 | TOTP 双因子认证 | 支持基于时间的一次性密码（TOTP）双因子认证机制，增强 WebSocket 连接的安全性。 |
| 5 | 凭证管理 | 密码安全传输 | 用户密码在 DSN 解析时通过 URL 编码处理，避免特殊字符导致的解析错误。 |

### 6.2 传输安全

| 序号 | 安全类别 | 需求名称 | 需求描述 |
| --- | --- | --- | --- |
| 6 | 传输加密 | WSS 协议支持 | WebSocket 连接支持 WSS（WebSocket Secure）协议，提供传输层加密。 |
| 7 | 传输加密 | HTTPS 协议支持 | RESTful 连接支持 HTTPS 协议，提供传输层加密。 |
| 8 | 证书验证 | TLS 证书验证 | RESTful 连接默认启用 TLS 证书验证，可通过 `skipVerify` 参数控制是否跳过证书验证。 |
| 9 | 数据压缩 | 传输压缩 | WebSocket 和 RESTful 连接支持数据压缩功能，减少传输数据量，同时提升传输效率。 |

### 6.3 连接安全

| 序号 | 安全类别 | 需求名称 | 需求描述 |
| --- | --- | --- | --- |
| 10 | 超时控制 | 读写超时 | WebSocket 连接支持配置读超时（默认 5 分钟）和写超时（默认 10 秒），防止连接挂起。 |
| 11 | 连接管理 | 连接关闭 | 支持安全关闭连接，释放相关资源，防止资源泄露。 |
| 12 | 请求追踪 | 请求 ID | 支持请求 ID（req_id）机制，用于链路追踪和审计日志记录。 |

### 6.4 数据安全

| 序号 | 安全类别 | 需求名称 | 需求描述 |
| --- | --- | --- | --- |
| 13 | SQL 注入防护 | 参数绑定 | 支持参数化查询（PreparedStatement），防止 SQL 注入攻击。 |
| 14 | SQL 注入防护 | 客户端占位符替换 | 支持客户端占位符插值（interpolateParams），在客户端进行参数替换。 |
| 15 | 数据验证 | 输入验证 | 对 DSN 参数进行严格验证，防止非法配置导致的安全问题。 |

## 7. 其他需求

- 兼容性需求
  - 支持 Go 版本 1.14 及以上。
  - 兼容 TDengine 3.3.6.0 及以上版本
- 接口需求
  - 提供简洁易用的 API 接口，支持多种连接方式（原生、HTTP、WebSocket）。
  - 支持通过 DSN 配置连接参数。
- 运维需求
  - 无特殊运维需求。
- 易用性需求
  - 提供详细的文档和示例代码，方便开发者快速上手。
  - 支持通过 Go 的 `database/sql` 标准接口进行操作，降低学习成本。
- 测试需求
  - 提供单元测试和集成测试，确保功能的正确性。
