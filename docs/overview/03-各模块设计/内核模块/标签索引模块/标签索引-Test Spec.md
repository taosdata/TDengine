### 2. **测试概况**

#### 2.1 **测试目标**

本测试旨在验证 TDengine 标签索引功能的正确性、性能、稳定性及安全性。标签索引是针对超级表的标签字段创建的索引，用于加速基于标签的查询操作。测试将验证索引的创建、删除、更新、查询优化等核心功能。

#### 2.2 **测试范围与依据**

测试范围覆盖标签索引的全部功能，对齐以下规格文档：
- 《标签索引 - Function Spec》
- 《标签索引 - Requirement Spec》

#### 2.3 **测试周期**

1. 计划开始时间：2024-12-25
2. 计划结束时间：2024-12-30
3. 总周期：5个工作日

### 12. **测试通过准则**

1. **功能覆盖**：Function Spec和Requirement Spec描述的所有功能点均有对应测试用例，且执行通过率≥95%
2. **性能达标**：
- 索引创建时间符合性能指标要求
- 索引查询响应时间<10ms（1000并发场景）
- 写入性能影响<5%（自动建表场景）
1. **兼容性**：在社区版和企业版、x86和ARM平台、主流Linux发行版上均通过测试
2. **安全性**：索引文件完整性可验证，操作可审计，数据可安全删除
3. **稳定性**：无P0级别缺陷，P1级别缺陷修复率≥90%

| **安全测试依赖存储引擎** | 低 | 索引安全测试主要依托存储引擎的安全机制，重点验证索引特有的安全需求 |
