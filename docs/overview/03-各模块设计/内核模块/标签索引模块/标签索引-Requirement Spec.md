## 2. 引言

### 2.1 术语与缩写名词

1. **TDengine**：一种高性能、支持分布式架构的时间序列数据库。
2. **超级表（Super Table）**：在TDengine中"一个设备一张表" 的建模设计思路情况下，针对同一类型的每种设备的表，用来标识该类型的全部表集合称为“超级表”。超级表用来代表一组相同类型的数据采集点在数据库中表的集合。由于同一类型的设备拥有完全相同的数据模式，可以像操作普通表一样针对超级表进行写入、查询等操作。
3. **标签（Tag）**：用于描述每个设备的相对稳定的属性信息，每个子表一条标签信息。标签信息也具有模式（schema）的定义，归属于同一个超级表的表的标签具有相同的模式。
4. **结构化查询语言（Structured Query Language，SQL）：**是一种用于管理和操作关系型数据库的标准编程语言。 它允许用户存储、更新、删除、搜索和检索数据库中的数据。 SQL 被广泛应用于各种数据中心应用程序中，是 ISO 和 ANSI 等标准化机构认可的国际标准。
5. **索引（Index）: **针对数据库中数据进行位置定位和组织的一种数据结构，可以快速定位搜索的数据的位置从而提升查询性能。

## 3. 需求目标

### 3.1 背景

在时间序列数据库中，超级表的 标签 是描述数据采集点属性的关键字段。在实际业务场景中，用户经常需要根据 标签进行查询和过滤。然而，随着数据量的增加，标签 查询的性能可能成为瓶颈，尤其是在高频查询场景下。
通过为超级表的 标签 字段创建索引，可以显著提升查询性能，降低系统负载，改善用户体验

### 3.2 目标

1. 实现超级表 标签 字段的索引功能，用于加速基于 标签 的查询。
2. 确保索引数据的准确性和一致性，满足用户对实时性和性能的双重需求。
3. 支持用户自定义索引策略，以满足不同业务场景需求。

描述功能性要求，在可能的情况下，使用图表、流程图等可视化工具来辅助描述。如果是大的或复杂的功能，将功能性需求先粗分再细分。下表中的 Feature A, Function A.1 等符号应当被替换成有含义的名称。

| 1 | 索引创建 | 支持为超级表的指定 标签字段创建索引 |

| 4 | 索引更新 | 当超级表的 标签 字段数据发生变化时，自动更新索引。当新建子表时，自动添加索引值 |

## 5. 性能需求

描述本需求对写入、查询、启动等方面的性能要求。
1. **启动性能**
   - 索引的实现不应影响 TDengine 启动性能
2. **写入性能**：
  索引实现不显著影响数据写入性能。主要分为两种情况:
  - 通过自动建表写入，只有建立表的时候有很小影响，影响在5%以内
  - 通过子表写入： 无影响。 
1. **查询性能**：
  - 在索引命中时，查询性能应有显著提升。
  - 在索引未命中时，查询性能应与未启用索引时基本一致。
1. **资源消耗**：
   - 索引值占据较小的内存空间和磁盘空间

## 6. 安全需求

文件完整性需求：依托于存储模块提供的加密存储和完整性校验机制，确保保存的索引文件完整性和防篡改的能力。
操作审计跟踪：记录调用索引的时间和调用缘由、发起调用的用户、调用索引的查询对象，特别是高频率的索引扫描。后续审计员可以利用这些日志监控数据库中的各种行为，追踪非法存取数据的人员和时间，实现追溯和责任认定。
标签索引安全管理：当原始时序数据删除时，确保相关的索引块数据被不可恢复地安全删除，防止标签索引数据导致的信息泄露。

## 7. 第三方依赖需求

无，不依赖任何第三方的库或源代码。

## 8. 其他需求

### 8.1 **兼容性需求**

 需与现有查询功能完全兼容。

### 8.2 **接口需求**

1. 对外提供 SQL 接口支持：
   - 针对超级表的标签 创建/删除索引
   - 通过系统表可以查看是否已经创建的索引列信息

### 8.3 **运维需求**

1. 日志记录：系统异常需记录到日志中，供运维人员排查问题。
2. 使用统计：通过系统命令可以查看索引使用情况，包括索引大小、命中率等。

### 8.4 **易用性需求**

1. 提供详细的文档说明，指导用户如何配置和使用缓存功能。
2. 提供默认配置，降低用户的使用门槛。

### 8.5 **测试需求**

1. **功能测试**：验证索引创建、删除、更新等功能是否正常工作。
2. **性能测试**：验证索引功能对查询性能的提升效果
3. **兼容性测试**：验证索引功能是否与其他功能兼容。 
4. **压力测试**：在高并发场景下测试索引的稳定性
