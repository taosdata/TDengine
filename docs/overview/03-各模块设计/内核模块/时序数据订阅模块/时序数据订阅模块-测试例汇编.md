## 2. Tmq: drop lost consumers - 剔除失联消费者

场景数量：3 个
具体场景：
1. 验证 session_timeout_ms 的边界值和有效值是否生效
2. 验证 max_poll_interval_ms 的边界值和有效值是否生效
3. 验证当 session_timeout_ms 和 max_poll_interval_ms 过期后，消费者是否会被关闭
对应脚本：test_drop_lost_comsumers.py

## 3. Tmq: force drop topic - 强制删除主题

场景数量：5 个
具体场景：
1. 创建数据库
2. 创建超级表和子表
3. 向子表中插入数据
4. 创建主题并从子表中消费数据
5. 强制删除主题，检查另一个主题中的消费者状态是否仍处于活跃
对应脚本：test_force_drop_topic.py

## 4. Tmq: topic mgmt - 主题管理

对应脚本：test_topic.py
