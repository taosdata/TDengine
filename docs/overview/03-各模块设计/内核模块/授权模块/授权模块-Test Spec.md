### 2. **测试概况**

#### 2.1 **测试目标**

本测试旨在验证 TDengine 授权模块的正确性、安全性和稳定性。授权模块通过授权码控制企业版功能的使用，支持多种产品定价策略，包括基础功能和可选功能的灵活授权。授权模块涵盖以下核心功能：
- **授权状态管理**：未授权、已授权、授权过期、授权回收四种状态
- **授权码生成与激活**：通过 taosGrant 工具生成授权码，支持普通授权码和特殊授权码
- **授权项控制**：基础功能（时间戳、测点数、服务器数、CPU核数）和可选功能（流计算、数据订阅、视图、多级存储等）
- **硬件变更检测**：自动识别集群复制或硬件扩容导致的机器码变更
- **授权查询与监控**：通过 SHOW GRANTS 查看授权信息

#### 2.2 **测试范围与依据**

本次测试的范围完全覆盖授权模块功能规格，包括：
- 授权状态转换测试（未授权→已授权→授权过期→授权回收）
- 测点数量统计与限制测试
- SHOW GRANTS 命令测试（包括 SHOW GRANTS FULL）
- 集群机器码检测与授权码生成测试
- 授权项限制测试（dnode 数量、CPU 核数、流、订阅、视图等）
- 授权码叠加与更新测试
- 双副本集群授权测试
- information_schema.ins_grants 系统表测试

#### 17.2 **术语表**

| **术语** | **说明** |
| --- | --- |
| **授权码 (activeCode)** | 对可授权的部分或所有功能项加密生成的字符串 |
| **机器码 (machineCode)** | 根据服务器硬件信息生成的固定字符串，长度为 24 |
| **clusterId** | 集群唯一标识符 |
| **测点数 (timeseries)** | 集群中所有非虚拟表的列数总和（不含时间戳列） |
| **未授权状态 (ungranted)** | 集群未激活授权码的初始状态 |
| **已授权状态 (granted)** | 集群激活授权码后的正常运行状态 |
| **授权过期状态 (expired)** | 基础功能授权时间到期的状态 |
| **授权回收状态 (revoked)** | 检测到硬件变更或授权被回收的状态 |
| **普通授权码** | 包含 clusterId 但不包含机器码的授权码 |
| **特殊授权码** | 同时包含 clusterId 和机器码列表的授权码 |
