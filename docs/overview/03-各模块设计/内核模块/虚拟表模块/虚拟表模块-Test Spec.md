### 2. 测试概况

#### 2.1 测试目标

本文档旨在验证 TDengine 虚拟表（Virtual Table）功能的正确性、性能表现、安全可靠性及兼容性。测试设计严格对齐《虚拟表 Function Spec》，确保满足以下关键目标：
1. **功能完整性**：验证虚拟超级表、虚拟子表及虚拟普通表的创建、查看、修改及删除功能。
2. **核心查询逻辑**：验证基于时间戳对齐的数据合并规则，以及插值函数的准确性。
3. **权限与安全**：确保 root 用户权限及普通用户对虚拟表的 READ/WRITE 权限控制符合预期。
4. **系统稳定性**：验证在大量原始表、复杂查询场景下的系统稳定性。

#### 2.2 测试范围与依据

本次测试范围完全覆盖虚拟表模块的功能规格，测试执行将引用测试例汇编相关脚本。

#### 15.2 术语表

| 术语 | 说明 |
| --- | --- |
| 虚拟表（Virtual Table） | 从多个原始表动态组合数据的逻辑表，基于时间戳对齐 |
| 原始表（Base Table） | 虚拟表数据的来源表，通常为普通表或子表 |
| 时间戳对齐 | 将多表数据按时间戳对齐到同一时间轴，缺失值填充NULL |
| 空值插值（Padding） | 对虚拟表查询结果中的空值进行填充（如前值、后值、线性插值等） |
| 虚拟超级表（Virtual STable） | 用于创建虚拟子表的模板，定义列结构与标签 |
| 虚拟子表（Virtual Child Table） | 基于虚拟超级表创建，指定具体数据源与标签值 |
| 数据源（Data Source） | 虚拟表中某列对应的原始表列（table_name.col_name） |
