# TDengine Privilege Control How-To

This directory provides skills and guidance for using TDengine privilege control features, including RBAC (Role-Based Access Control) introduced in v3.4.0.0 and compatibility with legacy v3.3 syntax.

## Contents

- skill.md: Step-by-step instructions and best practices for privilege management in TDengine v3.4.0.0 and legacy modes.

## Key Features

- User and role management
- Fine-grained privilege assignment (database, table, column, topic)
- Legacy syntax compatibility and migration tips
- Privilege query, troubleshooting, and verification

## Usage

1. Refer to skill.md for detailed workflows and command examples.
2. Use RBAC features for modern privilege control.
3. Enable legacy syntax if compatibility with v3.3 is required.
4. Test and verify privilege assignments using provided examples.

## Reference

- See test_priv_rbac.py for comprehensive test cases covering both RBAC and legacy privilege scenarios.
