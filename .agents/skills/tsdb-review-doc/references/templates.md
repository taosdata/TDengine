# TSDB 文档模板规范

本文件定义 TSDB 各类文档的**必需章节**。文档可增加额外章节，但**不得删减或省略**模板中已有的任何章节（标记为"可选"的章节仍需作为标题存在，内容可标注"无"或"N/A"，但不得整节缺失）。

模板来源：`https://git.tdengine.net/rd-public/tsdb/-/tree/main/docs/templates`

---

## 文档类型识别

根据文件名后缀判断文档类型：

| 文件名模式 | 文档类型 |
|---|---|
| `*-rs.md` / `*RS.md` / `*需求规格*` | 需求规格说明书（RS） |
| `*-fs.md` / `*FS.md` / `*功能规格*` / `*概要设计*` | 概要设计说明书（FS） |
| `*-ds.md` / `*DS.md` / `*设计说明*` / `*详细设计*` | 详细设计说明书（DS） |
| `*-ts.md` / `*TS.md` / `*测试报告*` / `*功能测试*` | 功能测试报告（TS） |
| 无法识别 | 尝试通过文档 H1 标题或 MR title 判断；仍无法确定则跳过模板合规检查，在 finding 中说明 |

## RS — 需求规格说明书 必需章节

```
## 1. 修订记录          （表格：编写日期/发布日期/版本/修订人/主要修改内容）
## 2. 引言
### 2.1 术语与缩写名词
### 2.2 相关文档资料
### 2.3 优先级要求
### 2.4 版本要求
## 3. 需求目标
## 4. 功能需求           （包含功能需求表格）
## 5. 性能需求
## 6. 安全需求
## 7. 其他需求
```

## TS — 功能测试报告（Test Spec）必需章节

```
## 1. 修订记录          （表格：编写日期/发布日期/版本/修订人/主要修改内容）
## 2. 测试目标
## 3. 参考文档
## 4. 测试结论
## 5. 测试环境
## 6. 功能测试          （按功能点列子章节，含用例表格）
## 7. 易用性测试        （可选，可标"无"，但标题必须存在）
## 8. 长期稳定性测试    （可选，可标"无"，但标题必须存在）
## 9. 性能测试
## 10. 安全测试
## 11. 兼容性测试
## 12. 已知问题和限制   （可选，可标"无"，但标题必须存在）
```

## 修订记录表格要求

所有文档类型的 `§1 修订记录` 必须包含以下列的 Markdown 表格：

| 编写日期 | 发布日期 | 版本 | 修订人 | 主要修改内容 |

表格中至少有一行实际数据（非全占位符 `XXX` / `YYYY-MM-DD`），若 MR 是文档初稿提交则允许发布日期为空。

---

## 检查规则

1. **章节完整性**：逐一对照必需章节列表，检查文档是否包含所有必需标题（大小写、数字编号应与模板一致，允许在正确编号的章节后添加额外的子章节）。
2. **修订记录有效性**：修订记录表格是否存在、是否有有效数据行。
3. **内容非空**：必需章节（非标注"可选"的）不得只有标题而没有任何正文内容；但允许内容为"无"或"N/A"这类明确说明无相关内容的文字。
4. **禁止删减**：任何必需章节（含标注"可选"的章节标题）均不得缺失。
