# 安装包 examples 目录的显式拷贝清单
#
# 格式（空白分隔）：<group> <包内目录> <docs/examples 下的相对路径>
#
# group 取值：
#   all     社区 tarball、社区 deb/rpm、企业 deb/rpm 都拷贝
#   debrpm  仅社区 deb/rpm 拷贝（rust 示例只有它带）
#
# 清单由来：按旧安装包每个语言目录覆盖的「示例用途」挑选对应文件，只保留原生连接
# 变体（旧包的语言示例全部是原生连接），使包内 examples 体积不超过改动前的安装包。
# 包内目录名沿用安装包历史命名（C#、nodejs），与仓库中的目录名（csharp、node）不同。
#
# 新增示例请注意体积上限：48 个 all 文件 + 5 个 debrpm 文件，合计需分别小于改动前
# 安装包的 205413 B（不含 rust）与 222354 B（含 rust）；当前 all 组合计 149191 B。

# 用户也能在包内直接 `cmake -S examples/c -B build`。
