## Documentation Organization

1. `overview/`: Stores global materials such as roadmaps and high-level design documents.
2. `releases/`: Stores iteration-related process information, including planning, security, quality, requirements, design, testing, and release documentation.
3. `unplanned/`: Stores technical documents that are not yet included in a planned iteration.
4. `reports/`: Stores daily reports. Each employee maintains reports under their own name, with one document per quarter, appended over time. Daily report updates must be reviewed and merged by the team leader.
