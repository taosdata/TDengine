# 安装库文件

* libmseed库
  * cd TDinternal/enterprise/tests/cenc/deps/libmseed
  * make && make install 
* 安装curl库
  * centos: yum install libcurl-devel
  * Ubuntu: apt install libcurl4-openssl-dev
* 安装open-ssl
  * Centos: yum install openssl-devel
  * Ubuntu: apt install libssl-dev

# 编译程序

> 目录:TDinternal/enterprise/tests/cenc
> 编译方法:make
> 分支：feature/cenc（均在此分支下，后文不再赘述）

* consumeImport

  * miniseed解析入库程序
  * 参数：`-help`查看，`./consumeImport [-h=src_host -u=src_user -p=src_password -H=dst_host -U=dst_user -P=dst_password -S=src_port -D=dst_port -t=topic -d=result_db_name -s=result_stb_name -r=retry -async -restart -nokeep -help]`

* httpImport

  * 台网http数据流接入
  * 参数：`-i url[ -l login -L logout -h host -u user -P port -t topic -r <on|off> -c count]`

* subscribe

  *  filterpicker实时计算程序,编译目录：filterPicker/FilterPicker/
  * 参数：`-help`查看，`./subscribe [-h=src_host -u=src_user -p=src_password -H=dst_host -U=dst_user -P=dst_password -S=src_port -D=dst_port -t=topic -f=result_db_name -s=result_stb_name -c=channel -r=retry -nolimit -async -restart -nokeep -help]`

* packetDelay

  * 数据包延迟计算程序
  * 参数：`-help`查看，`./packetDelay [-h=src_host -u=src_user -p=src_password -H=dst_host -U=dst_user -P=dst_passwd -S=src_port -D=dst_port -t=topic -d=result_db_name -s=result_stb_name -r=retry -async -restart -nokeep -help]`

* fileConvert

  * miniseed导入和导出

    * databaseToFile:导出数据到文件

      `./databaseToFile -o filename -t tb_name[ -b begin_time(YYYY-MM-DD hh:mm:ss.sss) -e end_time(YYYY-MM-DD hh:mm:ss.sss) -s tsdb_server -u user -p password -P port -d db_name]`

    * fileToDatabase:导入文件

      `./fileToDatabase -i filename[ -s tsdb_server -u user -p password -P port -d db_name -S stable_name]`

    * fileToDatabaseRaw:导入文件成原始miniseed包

      `./fileToDatabaseRaw -i filename[ -s tsdb_server -u user -p password -P port -t topic]`
