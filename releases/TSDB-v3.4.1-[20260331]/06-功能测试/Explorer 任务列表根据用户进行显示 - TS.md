## 4. 测试结论

1. 非 root 用户登录，创建任务后，在任务页面可以看到自己创建的任务，但看不到其他用户创建的任务
2. root 用户登录，创建任务后，在任务页面可以看到自己创建的任务和其他所有任务创建的任务

## 5. 测试环境

- OS: macOS
- Browser: Chrome

### 6.1 任务列表展示

#### 6.1.1 用例列表

| 测试用例 | 测试描述 | 测试结果 |
| --- | --- | --- |
| 普通用户查看自己的任务 | 1. 创建普通用户 1. 使用新创建的用户名登录，创建任务 1. 返回任务列表，任务需要正常显示 | 通过 |
| root 用户查看所有任务 | 1. 使用 root 用户登录，创建任务 1. 返回任务列表，可以看到两个任务，分别是自己创建的，和普通用户创建的 | 通过 |
| 普通用户查看 root 用户的任务 | 1. 使用普通用户登录 1. 任务列表应该看不到 root 用户创建的任务，只看到自己的任务 | 通过 |
| 普通用户查看其他用户的任务 | 1. 再次创建一个普通用户 1. 任务列表应该看不到任何任务 | 通过 |
