## 3. 行为说明

1. 数据订阅：
   - 支持虚拟超级表的订阅，仅能订阅出虚拟超级表的 meta 信息，所以虚拟超级表订阅需要带上 with meta 参数，否则订阅不到内容。
   - 库订阅的时候，有 with meta 的情况下可订阅出虚拟表的信息，并且仅能订阅出虚拟表的 meta 信息。
   - 虚拟表的订阅，结果都是 meta 数据。具体的内容为相应消息的二进制编码（比如创建虚拟超级表为 SVCreateStbReq 结构的 encode msg，修改虚拟子表为 SVAlterTbReq 结构的 encode msg)。
   - 订阅到的 meta 二进制消息，可以通过 tmq_get_json_meta 接口获取对于内容的 json 描述。或者直接使用 tmq_get_raw/tmq_write_raw 同步恢复到另一个集群。
2. 数据迁移写入
   - tmq_get_json_meta 接口返回的 json 结构增加虚拟表相关内容，具体参见：https://jira.taosdata.com:18090/pages/viewpage.action?pageId=158206215
   - 增加配置参数 tmqWriteRefDB 和 tmqWriteCheckRef。
      - tmqWriteRefDB 配置参数标识写入集群的时候，虚拟表 ref 信息里的 db 替换为该参数，默认为空标识不替换。
      - tmqWriteCheckRef 标识 tmq_write_raw 接口写入另一个集群时，是否校验虚拟表 ref 信息的有效性。默认为 false，在数据迁移时，一般不校验。因为源库 ref 的数据可能已经不存在了，并且即使不存在，虚拟表依然有效，只是查询时候 ref 的列返回 NULL 而已。
