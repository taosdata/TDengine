## 4. 系统集成测试

系统集成测试将采用**自底向上**的分层集成策略，首先验证基础核心模块的协同工作，然后逐步集成和验证 TDengine 的特色高级功能，确保作为一个完整的、高性能的时序数据库系统，正确、可靠、安全地运行。

### 4.1 基础内核与集群集成测试

1. 此阶段验证 TDengine 作为分布式时序数据库的最基础功能集合，确保数据能稳定、一致地存储和查询。
2. **存储与查询集成验证** :
   - **超级表/子表模型完整流程**：测试百万级子表创建后，数据写入（存储模块）和基于标签过滤的查询（查询模块）的准确性和性能。
   - **列式存储与查询优化**：验证存储模块的列式存储压缩效率对查询模块（如时间窗口查询、跨表聚合查询）性能提升的有效性。
3. **多副本与集群集成验证**：
   - **数据一致性与故障切换**：测试 RAFT/双副本一致性机制在集群节点动态加入/退出或单节点故障时，数据读写的一致性和服务自动切换的准确性。
   - **数据分片与均衡调度**：验证集群模块的数据分片均衡调度机制在水平切分（弹性扩容缩容）场景下的负载均衡效果。

### 4.2 高级功能集成测试

1. 此阶段将高级功能（订阅、流计算）叠加到基础模块上进行验证。
2. **数据订阅与查询集成**：
   - **实时数据流一致性**：测试数据写入存储模块后，订阅模块能否通过 Kafka-like 接口实时、可靠地投递消息，并验证订阅到的数据与直接查询结果的一致性。
   - **过滤功能协同**：测试按表/按标签过滤功能与底层标签索引模块 协同工作时的性能和准确性。
3. **流计算与存储/查询集成**：
   - **流计算结果准确性**：测试流计算引擎对乱序数据处理能力，并验证内置流计算的结果能否准确地写入目标存储（新的超级表/子表）。
   - **实时计算与查询性能**：验证毫秒级计算延迟下，流计算吞吐量基准 与常规查询性能的相互影响。
4. **预聚集与查询集成**：
   - **加速效果验证**：测试预聚集模块计算的统计信息能否被查询优化器有效利用，并对比查询响应时间的提升效果。

### 4.3 安全与工具链集成测试 (端到端)

1. 此阶段将安全模块和工具链（客户端/运维）集成到完整的数据流中，以进行端到端的业务验证。
2. **安全全链路集成**：
   - **身份与访问控制到数据操作**：测试用户通过 C/C++ 连接器登录（身份鉴别），执行数据操作（查询/写入）时，细粒度权限控制是否准确生效，并验证传输加密（SASL+TLS） 在全链路中的稳定性。
   - **安全审计与数据流转**：验证在数据写入、查询、集群操作等全过程中，安全审计模块是否完整记录了所有数据级、系统级、集群级审计信息。
3. **工具链与核心功能集成**：
   - **数据接入与数据管道集成**：测试 taosAdapter或 taosX零代码对接第三方数据源后，数据的导入效率和处理能力（如离线文件处理）是否满足性能要求。
   - **命令行/备份与集群运维**：验证 taosShell对 SQL 语句的执行准确性；使用 taosdump进行大数据量备份恢复时，验证数据一致性。

## 5. 功能测试

### 5.1 内核模块测试

#### 5.1.1 时序数据存储模块测试

时序数据存储模块测试，测试验证超级表/子表模型，包括：高基数场景测试、百万级子表创建和管理、列式存储压缩效率测试、存储空间占用优化验证功能，以及写入性能测试，包括：单设备单表写入吞吐量、多设备并发写入性能、大数据量持续写入稳定性。

#### 5.1.2 时序数据查询模块测试

时序数据查询模块测试，测试验证SQL 兼容性，包括：标准 SQL 语法支持完整性、时序扩展语法功能验证、复杂查询语句执行正确性，以及查询优化验证，包括：时间窗口查询性能测试、跨表聚合查询效率、查询计划优化器准确性。

#### 5.1.3 时序数据订阅模块测试

时序数据订阅模块测试，测试发布/订阅功能，包括：Kafka-like 接口兼容性测试、多消费组负载均衡验证、消息可靠投递机制测试，以及过滤功能测试，包括：按表过滤准确性、按标签过滤性能、内容过滤功能完整性。

#### 5.1.4 时序数据缓存模块测试

时序数据缓存模块测试，测试 LRU 缓存策略，包括：缓存命中率性能测试、内存使用效率监控、缓存失效机制验证，以及查询加速效果，包括：缓存命中与未命中响应时间对比、高频查询场景性能提升验证。

#### 5.1.5 时序数据流计算模块测试

时序数据流计算模块测试，测试流计算引擎功能，包括：内置流计算准确性验证、多种触发方式测试、乱序数据处理能力，以及实时计算性能，包括：毫秒级计算延迟测试、流计算吞吐量基准、资源消耗监控。

#### 5.1.6 虚拟表模块测试

虚拟表模块测试，测试动态逻辑表功能，包括：多测点数据组合测试（含时间戳自动对齐验证和动态更新机制测试），以及性能对比测试，包括：虚拟表 vs 传统 JOIN 性能对比、多测点关联分析易用性验证。

#### 5.1.7 预聚集模块测试

预聚集模块测试，测试预计算准确性，包括：统计信息计算正确性验证、时间窗口预聚集测试、数据一致性检查，以及性能提升验证，包括：预聚集查询响应时间对比、计算资源消耗优化效果。

#### 5.1.8 标签索引模块测试

标签索引模块测试，测试索引性能，包括：百万级设备标签查询性能、索引构建和维护效率、内存使用优化验证，以及过滤查询测试，包括：基于标签的快速过滤、复杂标签条件查询性能。

#### 5.1.9 自定义函数模块测试

自定义函数模块测试，测试扩展功能，包括：C/C++ UDF (User-Defined Function) 开发接口验证、Python UDF 集成测试、自定义聚合函数功能测试，以及性能和安全，包括：UDF 执行性能基准测试、安全沙箱机制验证。

#### 5.1.10 多副本模块测试

多副本模块测试，测试RAFT 一致性和双副本一致性。针对 RAFT 一致性 和 双副本一致性，测试内容均包括：数据一致性验证、数据零丢失验证、副本同步性能测试、故障切换自动化测试、节点故障恢复时间测试以及脑裂防护机制测试。

#### 5.1.11 集群模块测试

集群模块测试，测试集群管理，包括：节点动态加入/退出测试、数据分片均衡调度验证、全局元数据一致性、虚拟节点机制，以及水平切分功能测试，包括：负载均衡效果验证、弹性扩容缩容测试。

#### 5.1.12 授权模块测试

授权模块测试，测试 License 绑定机制，包括：硬件机器码生成准确性、License 强绑定安全性测试、防拷贝机制验证，以及授权策略，包括：功能限制有效性测试、有效期控制验证。

#### 5.1.13 通信模块测试

通信协议模块测试，测试二进制协议兼容性，包括：二进制协议兼容性测试、数据传输效率验证、协议安全性测试，以及网络性能，包括：节点间通信延迟测试、客户端-服务器通信性能、网络异常处理能力。

#### 5.1.14 基础库模块测试

基础库模块测试，测试核心功能，包括：数据结构正确性验证、内存管理机制测试、消息编解码准确性，以及稳定性测试，包括：内存泄漏检测、资源管理稳定性、异常处理健壮性。

#### 5.1.15 跨平台模块测试

跨平台模块测试，测试操作系统兼容性，包括：Windows 功能完整性测试、Linux 各发行版兼容性、Mac 系统支持验证，以及架构兼容性，包括：x86_64 架构性能测试、ARM32/64 架构兼容性验证、不同架构功能一致性。

### 5.2 安全模块测试

#### 5.2.1 身份鉴别模块测试

身份鉴别模块测试，测试强认证机制，包括：强口令策略有效性测试、登录保护机制（失败锁定、密码有效期）、TOTP 动态验证码集成测试、TOKEN 认证安全性验证；以及访问控制，包括：IP 地址和时间限制功能、会话数和连接时长限制、资源滥用防护机制；以及密码安全，包括：加盐哈希存储安全性验证、密码传输加密测试、密码策略合规性检查。

#### 5.2.2 访问控制模块测试

访问控制模块测试，测试三权分立机制，包括：SYSDBA、SYSSEC、SYSAUDIT 角色权限分离、权限授予/回收操作准确性、角色创建和管理功能测试，以及细粒度访问控制，包括：表列范围权限控制测试、时间戳行范围访问控制、root 用户权限限制验证，以及合规性要求，包括：权限定期审查机制、安全策略执行有效性、等保三级合规性验证。

#### 5.2.3 传输安全模块测试

传输安全模块测试，测试全链路加密，包括：SASL+TLS 加密认证测试、登录信息加密传输、SQL 语句和查询结果加密；以及会话管理，包括：精细化 SESSION 管控、会话安全策略执行、防窃听和防篡改验证。

#### 5.2.4 存储安全模块测试

存储安全模块测试，测试全加密保护，包括：配置文件加密存储测试、元数据文件加密验证、数据文件透明加密，以及密钥管理，包括：分级密钥管理体系、密钥生命周期管理、密钥安全存储机制。

#### 5.2.5 安全函数模块测试

安全函数模块测试，测试四类函数验证，包括：加密函数功能完整性、哈希函数准确性测试、脱敏函数效果验证、编码函数兼容性测试，以及合规需求满足，包括：数据加密存储合规性、敏感信息脱敏效果、安全函数性能基准。

#### 5.2.6 安全审计模块测试

安全审计模块测试，测试分级审计能力，包括：数据级审计（SELECT/INSERT/DELETE）、系统级审计（节点创建/删除/恢复）、集群级审计（权限操作、VGROUP 平衡），以及审计完整性，包括：操作时间记录准确性、用户和资源信息完整性、SQL 详情记录完整性。

#### 5.2.7 加密算法模块测试

## 7. 性能测试

### 7.1 核心性能测试

核心性能测试，测试数据写入性能，包括：单节点写入性能、集群写入性能、叠加高低基数（10k/1M）、单列/多列、全数值列/部分文本列、单/双/三副本不同组合；以及查询性能，包括：简单查询性能、复杂嵌套查询、多表关联查询；以及订阅性能，包括：简单订阅性能、条件筛选订阅性能、多副本订阅性能；以及流计算性能，包括：定时流计算性能、复杂窗口流计算性能、每条实时流计算性能；以及数据接入性能，包括：Kafka DataIn 性能、MQTT DataIn 性能、CSV DataIn 性能。

安全性能测试，测试加密性能影响，包括：传输加密对吞吐量的影响、存储加密对 IO 性能的影响、安全审计对系统负载的影响，以及访问控制性能，包括：细粒度权限检查性能、角色权限验证效率、大规模用户并发访问性能。

### 7.3 工具组件性能测试

工具组件性能测试，测试数据接入性能，包括：taosAdapter 并发处理能力、协议转换性能开销、数据预处理效率，以及备份恢复性能，包括：大数据量备份时间测试、恢复过程性能指标、增量备份效率验证。
