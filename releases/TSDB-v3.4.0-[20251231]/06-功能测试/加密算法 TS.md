## 2. 测试目标

1. 可以正常查看内置算法
2. 配置自定义算法扩展，添加、删除自定义算法
3. 创建db时可以指定内置的加密算法，也可以指定自定义算法
4. 加密后的数据库读写性能符合要求

### 6.2 自定义算法

#### 6.2.1 测试要点

添加删除自定义算法

#### 6.2.2 用例列表

| # | 测试用例 | 测试描述 | 测试结果 |
| --- | --- | --- | --- |
| 1 | 配置encryptExtDir | encryptExtDir指向自定义算法扩展的目录，在该目录中放置自定义算法的so文件。 so文件可直接编译开源项目https://github.com/provider-corner/vigenere ，可以根据openssl的接口编写并且编译一个 | 通过 |
| 2 | create encrypt_algr 'vigenere' name 'vigenere' desc 'my custom algr' type 'Symmetric_Ciphers_CBC_mode' ossl_algr_name 'vigenere'; | 执行show encrypt_algorithms，检查是否存在名为vigenere的算法。 | 通过 |
| 3 | drop encrypt_algr 'vigenere'; | 执行show encrypt_algorithms，检查名为vigenere的算法已经不存在。 | 通过 |
| 4 | 不能删除正在使用的算法 | 使用vigenere算法创建一个db。 执行drop encrypt_algr 'vigenere'， 错错信息为算法在被使用，无法删除 | 通过 |
