# taosX 写入异常处理 V2 Test Spec

## 1. 测试目标

验证写入异常处理的功能项满足 FS 的设计（V2）。

## 3. 测试范围

V2 包含以下内容：
1. 异常场景处理：
   - 目标库连接超时
   - 目标库不存在
   - 表不存在
   - 主键时间戳溢出
   - 主键时间戳空
   - 列数据长度溢出
   - 列数据类型不匹配
   - 标签数据长度溢出
   - 标签数据类型不匹配
   - 其他数据写入异常
2. 支持归档：
   - 临时存储
   - 归档文件保留时长、归档文件大小限制、归档异常处理策略
3. 支持配置：
   - 连接超时时长
   - 列/标签长度是否自动扩展

## 4. 测试结论

使用 taos-explorer 测试 csv 数据源任务，基础用例均已测试通过，“其他数据写入异常”其实在开发测试过程中也已经测到，但代码优化后，各种异常基本都有专项处理，所以暂时没有合适的用例补充到文档中。

## 5. 已知问题和限制

1. 归档文件写入错误的场景较多，如果处理策略选择“删除旧文件”，可能会误删清空掉所有文件；
2. 根据数据库错误码进行相应的错误处理，但很难准确列出所有真实的异常情况，所以会有一定的遗漏；
3. 如果任务没有运行或没有触发“归档”，则不自动清理旧文件。
