# 必示科技时序模型

## 1. 模型介绍

必示科技时序模型的介绍内容见 [必示科技产品-基线SDK.pdf](https://taosdata.feishu.cn/docx/XMmhbia26o0CSrxjyBQcQhYdnBc)
时序数据模型类型：预测

## 2. 部署信息

### 2.1 部署服务器

公司内网服务器
硬件配置为 2 核 4G

### 2.2 登录信息

192.168.2.97 
root@taos123456 
机器名： anode

### 2.3 备注

该服务器上部署有TDengine，写入了演示验证数据，taosanode服务，以及必示科技的时序数据预测模型。
forecast 查询可以直接调用时序预测模型，也可以通过 grafana 直接查看结果。Grafana 也部署在该节点上。

## 3. 使用方式

使用如下 SQL 语句也可以直接调用该模型。
```sql
taos> use dataset;
Database changed.

taos> select _flow, _fhigh, _frowts, FORECAST(vl, "algo=baselina,rows=100,threshold=60") from nab_2  where ts>"2024-10-02 00:00:00" and ts<="2024-10-24 00:00:00";
```
