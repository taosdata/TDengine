# 双活授权测试

## 1. 测试目标

- 验证双活授权能够正确工作。包括：
1. 在master和slave的双活授权都有效的情况下，双活任务能够正确工作
2. 在master和slave之一或两者的双活授权过期的情况下，双活任务无法运行，并且会在输出信息中指明是哪台机器的双活授权过期

## 3. 测试范围

这里用于描述本需求的覆盖范围：
- master和slave机器的双活有效和过期，启动双活任务
- “订阅”有效和过期的情况，启动双活任务

## 4. 测试结论

1. 两台执行双活的机器双活授权有效的情况下，双活任务可以成功执行
2. 两台执行双活的机器之一双活授权过期的情况下，双活任务无法执行，并能在输出中指出是哪台机器的双活授权失效
