# 数据库加密测试

## 1. 测试内容：

离线设置
taosd -y {encryptKey}

在线设置
create encrypt_key 'abcdEFGHH';

创建加密数据库
create database test4 ENCRYPT_ALGORITHM  'sm4';

修改加密算法
alter database test4 ENCRYPT_ALGORITHM  'none';

查看数据库加密配置
select name, `encrypt_algorithm` from information_schema.ins_databases;

查看节点密钥状态
show encryptions;
select * from information_schema.ins_encryptions;

更新密钥配置,需要先停止 taosd,密钥在数据库创建后不能修改。
taosd -y  {encryptKey}
