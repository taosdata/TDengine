# TD-21971 WAL 格式变化后的兼容性测试

## 一、测试概述

    本次发布的版本 wal 中存储数据的格式发生了变化，所以是不兼容原来的WAL 数据格式的，所以需要验证对原来老版本格式的支持

### 3.2 测试方案

    本功能只需测试单机版功能正常即可，集群同理，无需测试

####     1、**需要验证版本：**

        选取自 3.0 发布以来的各版本的大版本即可，无需每一个版本都测试
        抽取版本：               
              3.0.1.0    9-15   发布
              3.0.2.0   12-10  发布
              3.0.2.5   2-10    发布        

#### **     2、 验证步骤**

       1）安装各版本，
       2）使用 taosBenchmark 统一生成 wal 文件
             生成数据库 db ，vgroup=1  默认参数
              超级表 meters , 默认参数生成
              表数 1个， d0
              行数，每表 1000 行
              开始时间从 “2022-01-01 10：00：00” 开始，每秒一个
        3）生成数据完成后把 VNODE1 下面的 WAL 文件复制出来备用
        4） 启动待验证程序，使用 taosbenchmark 相同参数生成相同数据库，不写入数据
        5） 创建一个流 create stream  stream_a into sta as select count(*) from meters interval(10s)
        6）  停止 taosd 服务，复制前面各版本 wal 覆盖到当前数据环境中同名文件
        7）  启动 taosd 验证以下结果：
1. 程序不崩溃不报错
2. 行数正确   select count(*) from meters 返回为 1000行
3. 查首行 Select first(ts) from meters 返回为预期值
            - 查尾行 select last(ts) from meters 返回为预期值
            - 统计 stream 中数据行数正确 100行
       
#### **3、 放入CI** 

   前半段收集各版本   wal 文件人工操作
         后半段验证程序来完成
         放到CI中做为 WAL 兼容性验证的 CASE 
         在 0-other/compatibility.py 中有兼容性验证框架，增加流对象即可

## 五、测试结论

    wal 格式本次修改，如果有流对象的情况下， 3.0.1.6及之后的版本都可以实现兼容。
    没有流对象的情况下，测试计划中列的三个大版本 3.0.1.0 3.0.2.0 3.0.2.5 都能支持到。
    测试功能符合预期。
