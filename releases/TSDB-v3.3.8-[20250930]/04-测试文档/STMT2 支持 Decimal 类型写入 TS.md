# STMT2 支持 Decimal 类型写入 TS

## 1. 测试目标

本次测试的主要目标：测试将decimal64和decimal128类型的数据通过参数绑定的方式写入数据库

## 3. 测试范围

功能及正确性测试：测试参数绑定写入decimal，各种行为是否符合预期。

## 4. 测试结论

功能符合预期，测试通过。
