# 消息订阅消费延迟测试报告

## 测试结论：

**在消费客户端速度 大于等于 写入客户端速度 时，消费的平均延迟大概在 300 ms 以内。****但存在抖动，最大延迟可能达到 3s 以上。**
**如果消费客户端速度 小于 写入客户端速度，那消费延迟只会越来越大。**
**在本次测试环境下，5个并发写入线程 与 6个并发消费线程（在同一个groupid 内消费1个topic） 的速度大概相当。**

## 一、测试概述

验证问题：

TS-3222

验证在写入的同时进行消费时，消费到的消息的延迟。
