# 测试报告

## 1. 功能测试

| 条件 | 结果 |
| --- | --- |
| 无配置 | 缓存无上限控制 |
| metaCacheMaxSize配置为-1 | 缓存无上限控制 |
| metaCacheMaxSize配置为-2 | 启动报错 |
| metaCacheMaxSize配置为10 | 到达临界值时开始删除子表内存 |
| 子表数量不多，其他元数据较多场景 | 先清理表数据后继续清理其他元数据 |

### 2.2 结果

| metaCacheMaxSize大小 | 写入速度（rows/s） |
| --- | --- |
| -1（无限制） | 600562.86 |
| 10（10MB） | 555264.57 |
| 5（5MB） | 562777.62 |
| 1（1MB） | 554222.83 |
| 0（不缓存） | 558048.19 |

### 2.3 结论

- 启用内存控制后，写入性能影响在10%以内；
- 查询本次未测试，根据之前性能优化时的经验，缓存不命中额外耗时在毫秒级别，因此对查询性能的影响取决于额外耗时占查询总耗时的比例；
