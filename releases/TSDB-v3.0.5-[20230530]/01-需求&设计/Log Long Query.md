# Log Long Query

TD-19567


TS-1621


慢查询（长查询）在2.x版本会记录到log库中，3.0该功能暂时缺失，目前第一步先通过日志的方式记录慢查询。

## 1. 功能

- 每个客户端在一个语句执行完成后，记录慢查询到日志目录下单独的日志文件taosSlowLog中；
- 记录的内容包括客户端PID、链接ID、查询ID、SQL语句、执行时间、起始时间；
- 慢查询是指任何语句的执行时间（从开始执行到资源释放为止）大于等于N秒，不限于查询语句，N值由配置项slowLogThreshold 指定，默认值是3秒；
- 慢查询记录功能默认启动，可以通过配置项 slowLogScope 来启动/关闭某项或所有慢查询记录；

## 2. 范围

适用于查询、写入（SQL、Schemaless、STMT）、其他语句，不适用于 TMQ。
限制：
- STMT每次写入SQL语句保持不变；
- Schemaless方式写入，SQL为第一行数据或整个原始语句或SML操作类型，对于超出1MB部分可能被截断；

## 3. 配置项

| 名称 | 值类型 | 作用域 | 作用 | 默认值 | 值域 | 其他说明 |
| --- | --- | --- | --- | --- | --- | --- |
| slowLogThreshold | INT | 客户端 | 指定慢查询门限值，大于等于门限值认为是慢查询，单位：秒 | 3 | [0-INT32_MAX] | 0 表示记录所有SQL查询 |
| slowLogScope | STRING | 客户端 | 指定启动哪种类型的慢查询记录 | ALL | ALL: 启动所有类型记录 QUERY: 只记录查询 INSERT:只记录写入 OTHERS:除写入、查询外其他语句 NONE:不记录 | 配置值错误报错且启动失败，值大小写不敏感 |
