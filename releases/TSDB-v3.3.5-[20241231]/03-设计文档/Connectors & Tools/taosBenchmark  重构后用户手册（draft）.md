# taosBenchmark  重构后用户手册（draft）

## 1. 产品概述

### 1.1 产品简介 

taosBenchmark 产品是涛思公司面向用户推出的一款用于测试 TDengine 产品基准性能的测试工具，使用者可以利用此工具快速搭建及模拟出各种 TDengine 写入场景并验证此场景下的性能表现。

### 1.2 产品特点

1. 快速构建压测场景
2. 性能指标专业详细
3. 多样化数据生成能力
4. csv 交换数据能力

### 1.3 目标用户

本产品目标用户为想要了解或在自己环境中实测 TDengine 写入性能的用户群

### 1.4 系统要求

1. 支持操作系统
支持主流 linux window 及 mac 三种操作系统
1. 硬件要求
最小内存    256 M
最小 CPU:  1 核
最小硬盘： 1 G
作为性能压测工具，硬件要求主要取决于使用的压测参数，过大的参数在小内存下可能会产生 OOM 

### 1.5 安装指南

本产品随 TDengine 安装包一同发布，可到官网参考 TDengine 安装包下载安装使用指南
