英文
```plaintext
[Change behavior  and compatibility]
1. snode must be used in stream computing in a multi-replica database.
2. add a compatiability guarantee mechanism for stream, to avoid new compatiblity issued caused by subsequent functions, but the previously created stream must be deleted and recreated. see: https://docs.taosdata.com/advanced/stream/#%E6%B5%81%E8%AE%A1%E7%AE%97%E5%8D%87%E7%BA%A7%E6%95%85%E9%9A%9C%E6%81%A2%E5%A4%8D
3. adjust the result type of the case when statement. 

[New Features/Improvements]
TD-30836 feat: the twa function in stream computing support time-driven result push mode. 
TD-30837 feat: the interp function in stream computing support time-driver result push mode. 
TD-31185 feat: optimized the error msg when compact + split vgroup operation is performed in sequence 
TS-5215 feat: support Azure Blob 

[Optimizations]
TD-29948 enh: improve the efficiency of pulling data between dnodes when performing large concurrent query. 
TD-30667 enh: support use AVX2 and AVX512 to perform decoding optimization for double, timestamp and bigint types. 
TD-30681 enh: adjust the result type of the case when statement. 
TD-31566 enh: improve the data scanning speed of the query "select... from... where ts in (...)". 
TD-32184 enh: add a compatiability guarantee mechanism for stream, to avoid new compatiblity issued caused by subsequent functions, but the previously created stream must be deleted and recreated. 
TD-32354 enh: improve the data synchronization performance of taosX in interlace scenarios. 
TD-32540 enh: support turn off encoding for integer and float data types. 
TD-32567 enh: in a multi-replica database, snode must be used in stream computing. 
TD-32732 enh: generate unique ID to identify each query task to avoid memory corruption. 
TS-4785 enh: speed up the creation time of the database. 
TS-5248 enh: modify the default value of s3MigrateEnabled to 0. 
TS-5484 enh: support recording delete operations in the audit database. 
TS-5575 enh: support create database in the specified dnode list [enterprise]. 

[Fixed issues] 
TD-32338 fix: query performance of last_row has significantly decreased in version 3.3.3.0. 
TD-32800 fix: taosd cannot start when the WAL entry is incomplete. 
TS-5567 fix: incorrect query results when partitioning by a constant. 
TD-29667 fix: when the scalar function include _wstart and the fill method is prev, the calculation result is wrong. 
TD-31003 fix: the time zone setting problem on Windows. 
TD-31334 fix: the translation can't finish if compacting on empty database [enterprise] 
TD-31348 fix: logic error with transaction conflicts 
TD-32316 fix: some errors of the mnode can cause transactions to be unable to stop. 
TD-32359 fix: some errors of the mnode can cause transactions to be unable to stop. 
TD-32485 fix: the problem of taosc driver retrying errors after clearing the dnode data. 
TD-32508 fix: after Data Compact is abnormally terminated, intermediate files are not cleaned up. 
TD-32526 fix: after adding a new column, the earliest mode of the Kafka connector cannot consume the data of the new column. 
TD-32559 fix: the behavior of the interp function is incorrect when use fill(prev). 
TD-32579 fix: the problem that TSMA abnormally stops during high-frequency metadata operations. 
TD-32589 fix: the execution result of the "show create stable" statement is incorrect. 
TD-32592 fix: the percentile function will crash when querying a large amount of data. 
TD-32664 fix: syntax error when using partition by and having together. 
TD-32727 fix: tbname is empty when interp function is used with partition by tbname, c1. 
TD-32733 fix: taosd may crash while writing illegal boolean values through stmt. 
TS-4837 fix: library symbol 'version' confict with other lib which use the same symbol. 
TS-5194 fix: the number of JAVA process handles in JDBC driver keeps increasing on Windows environment. 
TS-5571 fix: the occasional startup failure when upgrading from version 3.3.3.1 to 3.3.4.0. 
TD-32474 fix: memory leak caused by repeated addition and deletion of tables on the Windows platform. 
TD-32818 fix(stream): check the right return code for concurrent checkpoint trans. 
TS-5554 fix: adjust the error message when deleting data columns of the super table. 
TS-5383 fix: the "too many session" problem while perform large concurrent queries. 
TS-5459 fix: the problem of taos shell crashing in slow query scenarios on the Windows platform. 
TS-5507 fix: the encrypted database cannot be recovered when opening the dnode log. 
TS-5513 fix: the problem that taosd cannot be started due to mnode synchronization timeout. 
TS-5519 fix: the slow sorting of file group data during snapshot synchronization leads to the inability of Vnode to recover. 
TS-5528 fix: when writing data with escape characters to a varchar field throug line protocol, taosd will crash. 
TS-5529 fix: metadata file damage caused by incorrect logic processing of error code 
TS-5531 fix: when a query statement contains multiple nested "not" conditional statements, not setting the scalar mode will lead to query errors. 
TS-5532 fix: the problem of dnode going offline due to timeout of vnode stat report. 
TS-5537 fix: taosd failed to start on servers that not support AVX instructions. 
TS-5588 fix(taosX): handle 0x09xx error codes in migration
```
