## 3. 测试范围

- Explorer 前端页面的数据写入任务列表的页面行为

## 4. 测试结论

1. Explorer 前端任务列表和代理列表已经做拆分，验证通过；
2. Explorer 前端任务列表任务类型和任务状态两列支持过滤，验证通过；
3. Explorer 前端任务列表任务名称、任务类型及任务状态散列支持排序，且组合排序的时候以最后一列的排序规则生效，验证通过。
