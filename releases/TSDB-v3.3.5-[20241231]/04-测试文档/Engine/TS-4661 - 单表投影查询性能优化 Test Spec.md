# TS-4661 - 单表投影查询性能优化 Test Spec

## 1. 测试目标

验证关闭数据类型编码对单表投影查询的性能提升。

## 2. 变更历史

| Date | Version | Owner | Memo |
| --- | --- | --- | --- |
| 2024.11.12 | 1.0 | 邝金清 | 初始版本 |
|  |  |  |  |

## 3. 测试范围

表的数据类型包括：
- Int
- Bigint
- Float
- Double
测试语句包括：
- SELECT 单列
- SELECT 多列

## 4. 测试结论

1. 对于多列查询，v3.3.4.3 关闭编码后比 v3.3.2.4 均有性能提升，double 类型提升最明显，有 46%，其他类型提升为 10%-20%
2. 对于单列查询，无论开/关编码，v3.3.4.3. 性能均比 v3.3.2.4 差，约 20%-30%

## 5. 已知问题和限制

无

## 8. 测试用例

### 8.1 用例 1. INT 类型单列查询

**用例描述：**
对每个数据集执行 3 次以下查询，取最短时间并进行对比：
`select i01 from test.st;`
**期望结果：**
开启编码时，两个版本性能无明显差异。关闭编码后，性能略有提升。
**测试结果：**

| 场景 | 100w行 | 1000w行 | 5000w行 | 1亿行 |
| --- | --- | --- | --- | --- |
| v3.3.2.4 开启编码 | 86.201 ms | 434.734 ms | 1898.135 ms | 3659.141 ms |
| v3.3.4.3 开启编码 | 44.781 ms | 451.054 ms | 2511.941 ms | 4989.192 ms |
| v3.3.4.3 关闭编码 | 41.989 ms | 460.552 ms | 2181.761 ms | 4187.164 ms |

**测试结论：**
开启编码后，新版本比旧版本性能下降 27%。关闭编码后，新版本比旧版本性能下降 13%。
