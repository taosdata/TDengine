## 1. 测试目标

<quote-container>

</quote-container>

## 3. 测试范围

1. 基本功能是否正常，能否正确修改多个TAG值
2. 边界情况下是否能正常报错
3. 动态增删TAG后，能否正常工作。
4. 是否兼容之前语法和数据。 
5. 当前的订阅/数据迁移是否受影响。
6. 是否存在内存泄露等问题。 
7. 是否在多线程下有race condition问题
