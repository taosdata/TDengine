# TD-30667 - AVX2/AVX512 对 double 支持和 timestamp/bigint 解码优化 Test Spec

## 1. 测试目标

1. 验证taosd对float、double类型投影查询的性能提升
2. 验证函数MIN/MAX对float、double类型查询的性能提升

## 3. 测试结论

子表包含1亿行数据，打开 或关闭AVX2优化，投影查询及MIN/MAX函数查询效率提升明显，约20%-30%；
随子表中行数增加，5亿行数据时，打开或关闭AVX2优化，投影查询及MIN/MAX函数查询效率衰减明显，主要原因是随着行数增大，主要时间开销在读取每个块的时间，约1%-2%

## 5. 已知问题和限制

1. AVX512 对 double 解码支持：不支持
2. AVX2 对 timestamp/version 解码优化（现在是128指令集一次两个值，使用 256指令集 一次解码 4 个值）：实测性能没有提升，已关闭
3. AVX512 对 timestamp/version 解码优化，现在只使用了装载值优化 shuffle 优化，需要改造支持批量化一次解码 8 个值：不支持
avx512 指令目前大多数服务器不支持，且部分架构下性能甚至不如 avx2
