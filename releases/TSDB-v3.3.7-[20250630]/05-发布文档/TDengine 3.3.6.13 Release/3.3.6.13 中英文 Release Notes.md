### 8. Fixes

   - TS-6739  fix: schemaless write mode cannot modify string length in dual-active mode
   - TS-6718  fix: when maxRetryWaitTime is set too high, the client will perform unlimited retries when connecting to the server.
   - TD-35454 fix: the error message is not clear when the super table and sub table have the same name during auto-creation of tables.
   - TD-35697 fix: replicaiton support convertion from double/float to decimal in taosX
   - TS-6244  fix: when there are offline dnodes, "show dnode * variables" does not return any output.
   - TS-6316  fix: the REPLICA parameter supports plural forms when used to create and alter a database 
   - TS-6625  fix: fix unknown error 65534 when connecting to cloud
   - TS-6629  fix: taosc does not retry when encountering the "Out of memory in queue" error during write failure
   - TS-6686  fix: tables with composite primary keys cannot use the forcast function.
   - TS-6693  fix: fix read file error when replicatting by a net guard
   - TS-6717  fix: influxdb datain cause "Unknown named curve" under Kylin V10
   - TS-6733  fix: nchar tag index is not taking effect
   - TS-6710  fix: allow non-select query result set export as csv
   - TS-6319  fix: inner join queries failing to retrieve data in a nanosecond-precision database.
