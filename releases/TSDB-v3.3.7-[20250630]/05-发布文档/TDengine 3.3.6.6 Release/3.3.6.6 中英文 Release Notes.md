### 5. English

```markdown

### 6. Features

   - TS-6203  feat: taosAdapter add process/connection-pools metrics etc.
   - TS-6488  feat: support initialization scripts in docker image
   - TS-6222  feat: subscribe database/stable in jdbc
   - TS-6382  feat: TDgpt support covariate forecasting
   - TS-6385  feat: add mqtt received bytes metric

### 7. Enhancements

   - TD-33248 enh: connectors support special chars in password
   - TD-34472 enh: increasing backup support interval < 60s
   - TD-34531 enh: use consist error style in c websocket connection
   - TS-6191  enh: adjust the authorization strategy for dual-node, dual-replica scenarios
   - TS-6292  enh: upgrade JDBC connection in DBeaver
   - TS-6326  enh: refine the timeout parameter in taosX backup
   - TS-6335  enh: improve taosX backup performance
   - TS-6363  enh: config parameter minReservedMemorySize supports hot updates.
   - TS-6387  enh: taosX rename 2.x to TDengine Query, 3.x to Data Subscription
   - TS-6408  enh: adjust the alter logic of the KEEP property for the super table
   - TS-6423  enh: improve initialization performance in taosBenchmark

### 8. Fixes

   - TS-6323  fix: when data contains a mix of null, none, and value entries, synchronizing data via TMQ may cause taosAdapter to crash
   - TS-6375  fix: creating streams on virtual sub-tables with a NOTIFY statement produces no data in the super table
   - TS-6424  fix: deadlock when websocket writes data using stmt2.
   - TS-6430  fix: when using STMT write mode, failed SQL parsing can lead to memory leaks.
   - TS-6432  fix: memory leaks when writing with STMT2 in multi-threaded mode
   - TD-34419 fix: support chinese chars in taos shell with ws connection
   - TD-34481 fix: timezone in taos.cfg not work in taosc websocket connection
   - TD-34504 fix: multiple prepare operations on the same STMT statement can cause the program to crash.
   - TD-34561 fix: multiple prepare operations on an STMT statement may report error.
   - TD-34594 fix: allow spaces between \G and ; 
   - TD-34597 fix: taosBenchmark -s parameer parse error in 
   - TD-34611 fix: ensure uid/pwd are passed during ws_connect in ODBC
   - TD-34629 fix: taosBenchmark create table with tag values cause core dump
   - TD-34631 fix: when the time unit of timetruncate is set to y, it causes taosd to crash.
   - TD-34636 fix: the reference to the zlib repository had the CVE-2023-45853 vulnerability
   - TD-34637 fix: fix CVE-2024-56337 in JDBC example code
   - TD-34638 fix: when querying a virtual table, an error "Table Schema is old" occurs if the query column order doesn't match the physical table's column order.
   - TD-34725 fix: fix possible panic in exec of rust connector
   - TS-6148  fix: support double-quote in opcua node id
   - TS-6213  fix: stuck on stopping status when stop after connection failed
   - TS-6217  fix: fix data lost in case of taosAdapter interrupted under sparse mode
   - TS-6320  fix: when synchronizing data snapshots between multiple replicas, network failures that cause duplicate data transmission can lead to query errors
   - TS-6343  fix: when user privlilege are updated, restarting taosd may cause client subscriptions to occasionally fail.
   - TS-6345  fix: taosBenchmark json cfgdir not work
   - TS-6370  fix: fix authentication failure in case of speciall chars in Explorer
   - TS-6376  fix: when a DB contain a virtual table, setting snapshot=true in the subscription parameters causes taosd to coredump during subscription.
   - TS-6377  fix: show create table and desc table statements return composite key instead of primary key
   - TS-6399  fix: incorrect measurement point calculation when using virtual tables
   - TS-6419  fix: stream compute on virtual tables was not triggered correctly.
   - TS-6422  fix: taosX mem leak with native connection
   - TS-6434  fix: fix copy-and-paste error in case of sql containing spaces in explorer
   - TS-6442  fix: schema is old when origin table's column has same prefix during virtual supertable query
   - TS-6445  fix: virtual tables can not detecting table schema changes
   - TS-6463  fix: dedup timestamp in transformer now generator
   - TS-6159  fix: stream computing result table not being fully created in certain situations
   - TS-6346  fix: taosd fails to start after upgrading from 3.3.6.2 to 3.3.6.3.
   - TS-6360  fix: taosd fails to start after modifying the timezone configuration parameter.
   - TS-6392  fix: When subscribing, if the consumer's held WAL version has been deleted due to WAL file rolling, the subscription will fail.
   - TS-6262  fix: Driver was not loaded error when using native connection on Mac platform
   - TS-6289  fix: the number of windows in an Interval query is incorrect in the nanosecond database.
   - TS-6333  fix: tables with decimal types may crash when filtering with tag conditions.
   - TS-6364  fix: when the forecast function is provided with exactly the same data, some algorithms will report an error.
   - TS-6383  fix: error when executing "DROP VTABLE IF EXISTS" on a non-existent virtual table.
   - TS-6398  fix: error alert in explorer
   - TS-6449  fix: migration cause error when rename table and schema mismatch


```

### 10. 行为变更

   - TD-34687: 数据结构的变更会导致 tdb 格式的变化，老版本可以自动升级到新版本，但新版本无法退回老版本。
