# 20250630 版本规划

表格中若未特别标注完成时间，默认将在 0630 版本发布时完成。

## 1. Highlights

1. 引擎部门
   - BLOB 类型
   - 数据订阅支持 MQTT
   - 流计算触发、计算、通知的机制改造
   - 多副本的第二、三级存储支持共享存储
   - 天脉系统适配（数据挂载）
   - TDgpt 支持协变量分析
   - 支持 IPv6
2. 工具部门
   - 数据源接入 MQTT Sparkplug B 协议
   - 支持 OpenMetrics 格式写入（新增）
   - JDBC 提升 WebSocket 连接下小结果集的并发性能
   - taosX 高可用第一阶段（支持多节点 FailOver，高优先级）：本周期不发版
   - taosX 自动化性能测试报告（性能测试不同版本对比在 0930 发布）
   - 连接器性能测试工具和报告（性能测试不同版本对比在 0930 发布）
   - 连接器、工具等支持 IPv6 （新增）
   - 支持 Node-RED 接入（新增）
3. 平台部门 
   - 测试框架的整合优化
   - 客户场景模拟
      - 新增河北电力场景
      - 支持工具的离线安装
      - 丰富部署方式 Ansible, 完成 X%
   - TDasset 支持
      - CI/CD Workflow 迁移至 Github Action
      - 基本流程的 UI 自动化
      - 部署、一键安装
   - 企业版安装包开放下载
