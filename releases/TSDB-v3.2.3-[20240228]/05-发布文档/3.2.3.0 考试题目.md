# 3.2.3.0 考试题目

考试方式为飞书问卷，开卷考试，问答题能考查被考核人的表达能力
1. TDengine 有哪些必选授权项？哪些可选授权项？
2. TDengine 有哪些授权状态？为什么要识别硬件信息变更，硬件信息变更后会进入那种状态？
3. 在哪些情况下，用户会关注网络带宽，TDengine 做了哪些工作？
4. 在哪些情况下，需要向用户推荐 TDengine 的流计算功能？
5. TDengine 流计算支持那些窗口？讲述每个窗口的可能应用场景
6. TDengine 流计算相比 Flink 等框架有什么优势？
7. DataIn: Wonderware Historian 的应用场景有哪些？有哪些技术亮点？
8. 武汉水务为什么要用 TDengine ？
9. 什么是多表低频场景，TDengine 能否用于该场景？
10. TDengine 能缓存每个子表的最新数据，缓存函数是哪两个？各自含义是什么？
11. TDengine 在 4 月底发布的版本中有哪些你关注的重要功能？
