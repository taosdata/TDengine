## 7. 测试重点

本次测试的重点如下：
1. 普通用户默认无建库权限
2. 普通用户被授予建库权限后，默认拥有数据库所有读写权限，与之前逻辑保持一致
3. 普通用户没有建库权限，可以被授予其他数据库、超级表、子表的读写权限，与之前逻辑保持一致
4. 只有超级用户可取消普通用户建库权限
5. 升级后，普通用户需要显式授予建库权限；降级后，普通用户均拥有建库权限。
