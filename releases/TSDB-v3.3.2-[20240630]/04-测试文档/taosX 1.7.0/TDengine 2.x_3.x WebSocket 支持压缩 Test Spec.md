# TDengine 2.x/3.x WebSocket 支持压缩 Test Spec

## 1. 测试目标

这里用于描述本需求主要的测试目标
- 确保新的参数的引入不会影响已有的功能
- 验证创建的使用 WebSocket TDengine 2.x/3.x 任务可以配置 compression 参数
- 验证创建的使用 WebSocket 任务配置写入源启用压缩之后在发送数据时有实际的压缩效果
- 确保新的参数不会影响数据的准确性

## 3. 测试范围

这里用于描述本需求的覆盖范围：
- 通过 Explorer 创建 Data In 以 TDengine 2.x 和 TDengine 3.x 为源的任务启用压缩
- 通过 Explorer 创建数据同步的任务配置 DSN 设置压缩

## 4. 测试结论

1. 通过 TDengine 2.x 创建的 2.x 迁移到 3.x 的任务，由于 taosadapter 不支持 websocket 压缩，所以压缩不会生效，但开启压缩的任务也不会出错。验证通过。
2. 通过 TDengine 3.x 创建的 3.x 迁移的任务，在开启压缩的时候任务可以正常同步。验证通过。
3. 开启了压缩之后，压缩率在 60% - 70% 之间。
4. 实际测试中发现开启压缩和不开启压缩对于任务处理的整体耗时并没有特别的影响，即开启压缩不会导致任务用时有显著的增长。

## 6. 已知问题和限制

- TDengine 2.x 的 taosadapter 不支持开启压缩，设置了开启压缩也不会生效。
- TDengine 3.x 的 taosadapter 应该是在 3.1.1.15 版本之后才开始支持 websocket 压缩的，之前的版本设置之后也不会生效。
