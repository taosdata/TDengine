## 4. 行为说明

### 4.1 导出用户信息

启动taos shell，连接被导出的集群，在taos shell中执行如下SQL
```plaintext
export users to ~/user.json


```

export 命令导出这个集群中的所有用户，包括启用和未启用的用户。
导出的信息包括：
- 用户名
- 加密后的密码
- 是否是 superUser
- sysInfo
- 用户是否被启用
- IpWhiteList
导出的文件格式为 json 格式。

### 4.2 导入用户信息

启动taos shell，连接被导入的集群，在taos shell中执行如下SQL
```plaintext
import users from ~/user.json
```

当被导入的集群存在同名的用户时，import 命令跳过这个用户。
