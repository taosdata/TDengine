# 表过期TTL增强测试计划

## 一、测试概述

[表过期TTL增强](https://taosdata.feishu.cn/wiki/wikcnuCilouVKIDYaEoFq0JT6Me) 

## 二、测试环境

- 软件环境： TDengine 3.0 分支
- 硬件环境： 192.168.1.96

## 三、测试场景

1. 基础场景（ **ttlChangeOnWrite **= false** **单节点，3副本）：
   - 建超级表
   - 建子表（自动建表，正常建表，alter TTL）
   - 建普通表
   - 修改表结构（超级表，子表，普通表）
   - Show create table
   - 表结构查询 information_schema.ins_table
2. **ttlChangeOnWrite **= true 场景 （单节点，3副本）
   - 添加，删除记录以及修改表结构会同步修改到期时间
3. 其他场景：
   - TTL 时间之外确认表是否被删除 （查询，修改表结构是否报错）
   - TTL 时间之内，keep 时间之外，确认表没有被删除，但是数据会被删除
4. 特殊场景：
   - TTL 时间是否支持其他值 （负数，字符等）
   - 修改 TTL 过期时间到当前时间之前，表是否会被删除（是否TTL可以往小修改，以及修改过期时间已经过去了）
5. 性能测试：
   - 增加 TTL 功能后是否影响数据库性能
6. 兼容性测试 （升级后无法降级）
