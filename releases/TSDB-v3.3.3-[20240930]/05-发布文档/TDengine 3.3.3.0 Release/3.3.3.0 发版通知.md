# 3.3.3.0 发版通知

TDengine 3.3.3.0 产品经质量部、研发部对已知问题进行风险评估后判定，决定予以【放行】。
自预发布以来的已知问题见下表，部分问题已修复，尚有部分问题待继续定位、修复。
- Bug 类问题：将在修复验证后，及时发布 hotfix 版本
- 功能及改进类问题：在完成开发、测试验证后，原则上并入下一版本发布 (12/31)
