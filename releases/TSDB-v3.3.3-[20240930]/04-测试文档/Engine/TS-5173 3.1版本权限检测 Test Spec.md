# TS-5173 3.1版本权限检测 Test Spec

## 1. 测试目标

这里用于描述本需求主要的测试目标：

TS-5173

- 验证低版本授权码，在高版本中仍然生效
- 验证高版本授权码，在低版本中仍然生效
- 验证 3.1.2.x TDengine 中 TD2-TD3 和 TD3-TD3 授权功能的正确性
- 验证 3.1.2.x TDengine 中 关系型数据库 datain 功能授权的正确性

## 3. 测试范围

本次测试按照以下优先级验证：
1. 对于 3.1.1.x 版本的 TDengine，其授权码在升级到 3.1.2.x 版本后仍然生效
2. 数据源和目标源均为 3.1.2.x ，taosx为main分支最新版本下，TD2-TD3 和 TD3-TD3 功能
3. 数据源为 3.1.1.x，目标源为 3.1.2.x，taosx为main分支最新版本，TD2-TD3 和 TD3-TD3 功能
4. 在 3.1.2.x 版本下，验证关系型数据库 datain 授权功能
5. 对于新版本的授权程序，其授权码在 3.1.1.x 版本上也能授权成功

## 4. 测试结论

本次测试验证了第3章节中的测试场景：
- 在 3.1.2.x 版本下，TD2-TD3 和 TD3-TD3 功能均可正常使用；
- 关系型数据库datain授权功能正常验证均通过。

## 6. 已知问题和限制

和交付沟通后确认，taosd 与 taosx 不同步升级并不是客户使用场景，而是交付更新时的操作导致，实际用户使用并不会有该情况出现。本次测试中先不对 taosd 与 taosx 分别升级的场景进行验证，taosx 均使用最新 main 分支编译。
