# [Test Report] - TS-3976 [树根互联]count(*) 查询效率低

### 1. 概述：

[TS-3976](https://jira.taosdata.com:18080/browse/TS-3976) 的问题是在乱序及数据更新的场景下，读取stt文件数据行性能较低导致的查询性能问题，本次测试主要针对不同stt_trigger参数下的count查询性能对比，验证此次的查询优化效果。

### 2. 测试环境：

192.168.1.35（3副本）：
CPU: Intel(R) Xeon(R) CPU E5-2630 v2 @ 2.60GHz （2）24核
Mem: DDR3  32 GB * 2
Disk: 2792GB

### 3. 测试用例：

测试数据包括10亿数据，1个超级表，100w子表，同时包含部分乱序及数据更新操作。
