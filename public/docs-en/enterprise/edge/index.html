Edge-Cloud Orchestration

Introduction​

Side-cloud collaboration can be easily realized using taosX, a zero-code data migration platform, and the data subscription feature of TDengine server. Deploying taosX in the cloud (or on the centralized storage side using the TDengine server) and creating topics on the edge side using the TDengine server allows for selective real-time synchronization of critical data from the edge side to the cloud as needed. Edge-Cloud Collaboration only supports TDengine 3.0 for both edge and cloud. This section describes how to use the command line of taosX for side cloud collaboration, you can also use the visual interface of taos-explorer for side cloud collaboration, please refer to Visualization Management. For service installation and deployment, please refer to Installation and Deployment.

Command Line Parameters​

For command line arguments see taosX.

Detailed command-line parameter​

The following table describes the parameters for SideCloud Collaboration

NameDescriptionDefault value
group.iddata subscription group IDgenerated by hash if empty
client.iddata subscription client IDtaosx
timeoutdata subscription timeout period; set to never to never timeout500ms
offsetdata subscription offset in format <vgroup_id>:. use commas to separate multiple vroups.starts at 0 if empty
tokentarget source parameter Used for authenticationNone

DSN​

The object of the data source (DSN for the -f parameter) must be configured as a subscribable topic that already exists in the database.

taosx run \
  -f 'tmq://root:taosdata@localhost:6030/tp1 ?group.id=taosx1&client.id=taosx&timeout=never&offset=2:10' \
  -t 'taos://root:taosdata@another.com:6030/db2'

In the above example, tp1 is a topic that has been created in the database, the topic can be created according to the needs of the edge cloud collaboration, you can specify the necessary filtering conditions in the topic according to the needs, so that only the data that meets the conditions will be synchronized to the cloud in real time.
