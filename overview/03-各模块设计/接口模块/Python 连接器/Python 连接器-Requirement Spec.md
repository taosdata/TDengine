## 2. 引言

随着技术的不断发展，越来越多的前端开发者开始涉足后端和全栈开发领域。在这一趋势之中，Python 作为一种功能强大且应用广泛的编程语言，正变得愈发重要。通过使用 Python 开发 TDengine 连接器，能够使 Python 开发者轻松地与 TDengine 进行交互，这样不仅可以降低开发的门槛，而且还能显著提高开发的效率。

### 2.1 **术语与缩写名词**

1. **无模式写入：**是指在写入数据时无需预先定义表结构，系统会根据数据自动创建或调整表结构的特性。
2. **数据订阅：**允许客户端实时接收数据库中的数据变化，适用于实时监控场景。
3. **参数绑定：**是在 SQL 语句中使用占位符替代具体值的技术，可以防止 SQL 注入并提高性能。
4. **WebSocket：** 是一种在单个 TCP 连接上提供全双工通信的协议。它允许客户端和服务器之间的双向实时通信，避免了 HTTP 请求-响应模型的限制。WebSocket 协议的定义和规范是由 IETF（Internet Engineering Task Force）标准化的，其主要文档是 [RFC 6455](https://datatracker.ietf.org/doc/html/rfc6455)。
5. **FQDN：**全限定域名是互联网域名系统（DNS）中的一种完整的、唯一的域名表示形式，用于明确标识互联网上的特定主机或服务器。
6. **RFC3339：**RFC 3339 是一种时间和日期格式的标准，旨在规范化地表示时间和日期，以便在计算机系统之间传递和处理。

### 2.2 相关文档资料

本连接器采用 python 语言基于 TDengine 数据库开发， 涉及  TDengine 相关资料请参考：TDengine 官方文档（[https://docs.taosdata.com/](https://docs.taosdata.com/)）。

无

### 2.4 版本要求

支持 Python 3.0 及以上版本以及 TDengine 3.3.2.0 及以上版本。

## 3. 需求目标

- 提供 Python 语言接口:
  - 实现连接器相关的接口，支持常见的数据库操作，如连接、查询、插入、参数绑定，数据订阅等。
- 支持核心特性:
  - 支持 TDengine 的关键功能，例如高效的 SQL 执行、参数绑定、批量插入等，确保用户能够充分利用数据库的性能优势。
- 易于使用:
  - 方便用户构建一个易于集成和使用的 Python 应用程序，附带详尽的技术文档和代码示例，帮助开发者快速上手。
- 稳定性和可靠性:
  - 经过严格的测试流程，保证连接器的稳定性和可靠性，确保其能够在实际生产环境中成功部署和运行。

## 4. 功能需求

| 序号 | 功能类别 | 功能名称 | 功能描述 |
| --- | --- | --- | --- |
| 1 | 数据库连接 | 原生连接 | 通过 TDengine 客户端（libtaos.so、taos.dll）与 TDengine 进行交互。 |
| 2 | 数据库连接 | WebSocket 连接 | 通过 WebSocket 协议与 taosAdapter 进行交互。 |
| 3 | 数据操作 | 数据写入 | 支持通过 SQL 语句插入数据。支持原生、WebSocket 连接。 |
| 4 | 数据操作 | 数据查询 | 支持通过 SQL 语句查询数据，支持结果集的遍历和列值获取。支持原生、WebSocket 连接。 |
| 5 | 数据操作 | 多行数据绑定 | 支持单行参数绑定写入。支持原生、WebSocket连接 |
| 6 | 高级功能 | schemaless 写入 | 支持通过 InfluxDB 行协议、OpenTSDB telnet 协议和 OpenTSDB JSON 协议写入数据。支持原生、WebSocket连接 |
| 7 | 高级功能 | 订阅功能 | 支持通过 tmq 订阅 TDengine 消息队列，实时获取写入的数据。支持原生、WebSocket连接 |

## 6. 安全需求

基于[威胁建模分析](https://taosdata.feishu.cn/wiki/BsJUw1ZlKieir8knu0kcMUYLnzf)，Python 连接器需要满足以下安全要求，以确保数据的机密性、完整性和可用性。

### 6.1 **认证与授权**

1. **凭证安全存储**（高优先级）
  - 禁止在代码中硬编码用户名、密码或 Token
  - 支持从环境变量、密钥管理服务或加密配置文件读取凭证
  - 提供安全的凭证管理最佳实践文档和示例
1. **Token 认证**
  - 支持 TDengine 云服务的 Token 认证
  - Token 应安全传输和存储，避免明文暴露

### 6.2 **数据保护**

1. **传输加密**（高优先级）
  - WebSocket 连接必须支持 WSS（WebSocket Secure）协议
  - 文档应明确原生连接的加密支持情况和网络安全建议
1. **SSL/TLS 证书验证**
  - 默认启用 SSL/TLS 证书验证
  - 提供配置选项但需明确警告禁用验证的风险
1. **数据完整性**
  - 通过加密通道保证数据传输完整性
  - 支持参数绑定防止数据篡改

### 6.3 **SQL 注入防护**

1. **参数绑定**（高优先级）
  - 提供参数绑定（Prepared Statement）接口
  - 原生连接和 WebSocket 连接支持 STMT/STMT2 参数绑定
  - 文档必须强调参数绑定是防止 SQL 注入的最佳实践
  - 提供清晰的参数绑定使用示例
1. **输入验证**
  - 对于不支持参数绑定的场景，提供输入验证和转义指南
  - 在文档中说明 SQL 注入的风险和防护措施

### 6.4 **日志与审计**

1. **日志脱敏**（高优先级）
  - 日志输出必须对密码、Token、个人身份信息进行脱敏
  - SQL 语句日志应可配置开关
  - 避免在日志中记录完整的连接字符串
1. **审计日志**
  - 支持记录关键操作（连接、查询、数据修改）
  - 审计日志应包含时间戳、用户标识、操作类型

### 6.5 **错误处理**

1. **错误信息安全**
  - 生产环境错误信息应简化，避免暴露内部实现细节
  - 详细错误仅记录到安全的日志系统
  - 提供调试模式开关用于开发环境

### 6.6 **资源保护**

1. **连接管理**
  - 实现或文档说明连接池最佳实践
  - 支持配置最大连接数、连接超时、空闲连接回收
1. **查询超时**
  - 提供查询超时配置，防止慢查询长时间占用资源
1. **写入限流**
  - 文档建议在应用层实现写入速率限制
  - 参数绑定和无模式写入接口应有合理的数据量限制

### 6.7 **供应链安全**

1. **库文件完整性**
  - 提供客户端库文件的哈希值或数字签名
  - 使用官方 PyPI 仓库分发
1. **依赖管理**
  - 定期扫描和更新第三方依赖库
  - 在 CI/CD 流程中集成依赖安全检查

### 6.8 **合规要求**

1. **数据隐私**
  - 遵循 GDPR、CCPA 等数据保护法规
  - 提供数据最小化和匿名化指导
1. **行业标准**
  - 遵循 OWASP 安全编码标准
  - 参考 PCI DSS（如适用于金融场景）

## 7. **其他需求**

1. 兼容性需求
  - 兼容 TDengine 3.3.2.0 及更高版本。
1. 接口需求
  - 提供 SQL，无模式写入，参数绑定，数据订阅功能的相关接口。
1. 运维需求
  - 无特殊运维需求。
1. 易用性需求
  - 接口设计合理，调用简单。
1. 测试需求（不含测试例）
  - 对主要功能以及异常情况都需要有测试用例覆盖。
